# 괴이와 손님 설계 후보 모음

> 2026-11-01 · 사용자 검증용 발상안. 수치·상태·예외는 채택된 규칙이나 검증된 밸런스가 아니다.

**괴이는 강한 상황과 약한 조건을 나누고, 손님은 그 조합의 서로 다른 연결을 건드린다.** 공급자를 지켜 수확을 이어가기, 지원 행동을 마무리 공격으로 바꾸기, 손상을 감수해 출력 얻기, 적의 방해를 끊기, 전투 규칙 자체를 바꾸기까지 폭넓게 설계했다.

## 설계의 출발점

- [Darkest Dungeon 조사](../competing_products/darkest_dungeon.md): 주 역할에 보조 기능을 붙이고, 각자 특별히 강한 상황과 동료가 해결해 줄 제약을 남긴다. 보호가 후속 공급·공격으로 이어지는 연결을 만든다.
- [Slay the Spire 조사](../competing_products/slay_the_spire.md): 통과·도착·직접 사용·지속을 구별하고 수치·대상·비용·시점·수명을 적는다. 공통 판정은 키워드 설명으로, 이번 효과의 고유 조건은 카드 본문으로 읽힌다.
- [Balatro](../competing_products/balatro.md)와 [Luck be a Landlord](../competing_products/luck_be_a_landlord.md): 순서·재발동·증폭·축적·소비를 서로 다른 설계 축으로 쓴다.
- [Deck of Haunts](../competing_products/deck_of_haunts.md), [Clash Royale](../competing_products/clash_royal.md), [Boardlike](../competing_products/boardlike.md): 공간의 가치, 즉시 개입과 장기 자산, 역할별 대응, 이동의 선택을 함께 본다.

실제 출발값은 [사용자 설정 3](../mvps/mvp-config-user-3.md)과 [현재 핵심 규칙](../rules.md)이다. 불안 상한9, 호텔6~10층, 영혼 경제, 통과·도착 배타 판정, 한 공포 효과당 심장 최대1개, 타격별 파훼를 기본으로 한다. 과거 레퍼런스 문서의 블러드 웹·공포 재화·발자국 증가량 제한을 되살리지 않는다.

이번 요청에 따라 **발상과 카드 문구 작성에 집중했다.** 시뮬레이션·승률 평가·플레이 테스트·밸런스 선별은 하지 않았다. 목록의 숫자는 그대로 시험하거나 바꾸기 위한 시작값이며, 한꺼번에 모두 도입하는 구성은 아니다.

## 후보의 구분

| 표시 | 뜻 |
|---|---|
| **기본 자원** | 현재의 불안·공포·공략도·토큰·보호·횟수·층 관계를 활용한 새 능력. 새 발동 조건은 구현이 필요할 수 있다. |
| **확장** | 새 축적 상태, 예약·복제·해제·방해, 횟수 이동, 전투 중 배치 같은 새 판정이 필요하다. |
| **급진** | 여러 도착·잔상 손님·호텔 구조·선택 확정 권한 등 전투 골격의 예외를 연다. 해당 후보를 선택할 때만 그 예외를 적용한다. |

종류의 수를 늘리기 위해 수치만 바꾼 재색칠을 하기보다, **무엇을 만들고·쓰고·참조하고·보존하고·방해하는지**를 바꿨다. 공격자 전원에게 수리와 보호를 주거나, 모든 손님이 모든 빌드를 동시에 막게 하지는 않았다.

## 카드 표기와 공통 판정

- 괴이의 기본 내구는 **공략 한계12·파훼 토큰2**다. 별도로 적은 값만 다르다. 가격·희귀도는 배정하지 않았다.
- 기재하지 않은 통과·도착·직접 사용 효과는 **효과 없음**이다. 기본 직접 사용 창은 **주사위 확정 뒤·첫 이동 전**이며 같은 턴 반복도 매번 비용을 낸다. 다른 입력 창은 카드에 적는다.
- **전투당**은 일반 손님 여러 명을 포함할 수 있는 전투 노드 전체다. **손님당**은 손님 한 명이다. 전투당 횟수는 다음 전투 준비 최초 진입 시 복구하고, 준비 재열기·배치 변경으로 다시 채우지 않는다.
- `공포3을 3회`는 세 개의 실제 공포 효과다. `공포9를 1회`와 구분한다. 각각 심장 판정을 하고 마지막 심장을 제거하면 즉시 중단한다.
- 별도 언급 없는 임시 상태·예약은 현재 손님 종료 시 제거한다. `전투 유지`는 다음 손님으로 이월하고 다음 전투 준비에서 초기화, `판 유지`는 이번 모험 동안 보존한다. 매 카드의 다른 수명 표기가 우선한다.
- `다음 턴 시작`은 같은 손님의 다음 주사위를 굴리기 직전이다. `다음 이동 완료까지`, `다음 손님 행동 종료까지`처럼 만료 시점을 따로 적은 상태는 해당 경계에 제거한다.
- 새 공략도 비용·이전·추가는 **직접 추가**이며 보호가 막지 않는다. 직접 공격 타격과 구별한다. 대상·자원·횟수가 부족하면 비용을 내지 않고 사용하지 않는다.
- `괴이 하나`는 살아 있는 배치 괴이 중 플레이어가 선택한다. `다른 괴이`가 아니면 자기 자신도 가능하다. 적의 동률 표적은 별도 설명이 없으면 가장 낮은 층 번호를 쓴다. 인접은 꼭대기와1층도 이웃이다.
- 지속 오라는 시전 괴이가 살아 있을 때만 작동한다. 이미 부여한 보호·상태는 명시한 수명까지 남는다. `살아 있으면 발동`이라고 적힌 예약은 발동 시 생존을 다시 검사한다.
- 대행·복제는 추가 방문이 아니다. **효과 항목 대행**은 원본의 비용·조건을 다시 검사한다. **기록한 공포량만 복제**하는 O10은 자기 카드에 적힌 비용만 내고 원본 비용을 다시 내지 않는다. 대행 안에서 다른 대행·복제를 재귀 실행하지 않으며 후보별 더 좁은 조건이 우선한다.
- 공포량을 기록할 때는 적 저항 적용 후·심장 판정으로 초과분을 버리기 전 실제 부여량을 쓴다. 양수 공포 기록에는0을 새 원본으로 넣지 않는다. 거리 이력은 이동 직전 최종 설정한 칸수이며 강제 정차·처치로 짧아진 실제 방문 수와 구분한다.
- 파괴된 괴이는 기본적으로 영구 손실·즉시 빈층이다. **파괴 직전 예방**은 명시한 능력만 전멸 판정 전에 개입한다. 파괴 후 반응을 핑계로 이미 확정된 전멸을 되돌리지 않는다.

## 공통 키워드의 짧은 설명

| 키워드 | 카드 옆에서 확인할 뜻 |
|---|---|
| **보호N** | 대상이 받는 공략 타격을 총N만큼 흡수. 순서대로 소모하고 이번 손님 행동 뒤 남은 양 제거. |
| **차단N회** | 다음 직접 공략 타격 N개를 통째로 무효. 작은 선행 타격에도 한 회 소모. |
| **엄호** | 지정된 동료에게 올 직접 타격의 수신자를 시전자에게 변경. 상태만 부여하는 행동은 옮기지 않음. |
| **반격N** | 조건을 만족한 타격 뒤 손님에게 공포N. 생존·발동 횟수 조건은 본문에 표시. |
| **앙갚음N** | 대상 괴이가 다음에 주는 한 공포 효과에 N 추가. 한계 도달 뒤 추가 공포 효과를 새로 만들지는 않음. |
| **정화** | 현재 유지되는 해로운 상태 아이콘 제거. 이미 받은 공략도·잃은 토큰·지출한 자원은 되돌리지 않음. |
| **해제** | 손님의 이로운 지속 상태 제거. 남은 심장과 기본 공격 자체를 지우는 효과가 아님. |
| **침묵** | 지정 괴이의 직접 사용을 명시한 경계까지 금지. 통과·도착은 가능. |
| **봉인** | 적힌 효과 항목만 명시한 횟수·기간 동안 정지. 통과 봉인과 도착 봉인을 구분. |
| **예약** | 공개된 미래 시점에 효과를 처리. 귀속·취소 조건·남은 시간은 상태에 표시. |
| **대행** | 다른 괴이의 명시한 효과 한 항목을 대신 실행. 원본 괴이를 이동시키거나 방문하지 않음. |
| **보호 관통** | 해당 타격은 일반 보호를 소모하지 않고 공략도에 적용. 차단·엄호·위력 감소와의 관계는 해당 손님 문구를 따름. |

새 상태 이름만 보여주지 않고 **양·상한·대상·수명·불발 조건**을 각 카드에 함께 적는다. 적의 상시 능력은 전투 시작부터, 다음 행동은 주사위 선택 전에 공개한다. 적이 행동 후 부여한 방해를 이미 끝난 이번 이동에 소급 적용하지 않는다.
