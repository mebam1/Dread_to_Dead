# 호텔·영업 준비 UI 설계

> 2026-11-01 현행 구현 반영 · 사용자 설정 3 v1.2 · 실행 규칙 `user-3-v1.2`. [mvp_user_3](../mvp_user_3/README.md)의 준비·상점·회복·호텔 확인 화면에 적용한 기준이다. 같은 막의 토큰 이월, 새 막의 최대 토큰 복구, 내구 시각화와 10층 기준의 호텔 최대 높이를 반영한다. 실제 브라우저 시각 검증 완료를 뜻하지 않는다.

## 1. 목표와 적용 기준

다음 경로를 고르는 모험과 호텔을 재구성하는 준비를 연결한다. 매 전투 뒤 같은 구매 화면을 반복해서 여는 대신, 지도에서 선택한 노드가 제공하는 결정에 집중한다. 정중한 손님 초대장과 지하 직원 전용 구역의 괴이 제조 설비로 호텔의 이중적인 성격을 드러낸다.

- 진행·보상·경제·노드 구성의 기준은 [사용자 설정 3](../mvps/mvp-config-user-3.md)이다. 기존 설정 2의 고정 영업 순서·블러드 웹·리셋권·보스 주사위 보상은 이 화면에 적용하지 않는다.
- 전투의 공통 판정과 선택 없는 전환 원칙은 현행 [핵심 규칙](../rules.md#turn)과 설정 3을 함께 따른다. 과거 버전의 구매망·공포 재화·전투마다 토큰 복구를 이 화면에 적용하지 않는다.
- 지도·7종 노드·전투 보상의 화면과 전환은 [모험 UI 설계](adventure.md), 전투 화면은 [전투 UI 설계](battle.md)를 따른다. 이 문서는 호텔 조작·영업 준비·노드별 호텔 패널을 다룬다.
- 재화는 **영혼**, 손님에게 쌓는 처치 진행값은 **공포**로 부른다. 영혼 잔액과 공포 수치를 같은 이름·아이콘으로 표현하지 않는다.
- 괴이는 획득 전·보관 중에는 카드, 배치 뒤에는 호텔 복도 속 존재로 표현한다. 정보는 전체 이름으로 제공하며 약자로 축약하지 않는다.
- **호텔은 최대 10층과 지하가 스크롤 없이 한 화면에 들어오며, 10층 기준으로 호텔 프레임의 세로 공간을 최대한 채운다.** 전투 준비·상점·회복과 호텔 확인 창에 공통으로 적용한다. 너비 조정이 필요해도 층 이름·상태와 조작 영역을 읽을 수 있게 유지한다.

## 2. 호텔 화면의 기본 배치

호텔을 조작하는 화면의 주 작업 영역은 **왼쪽 약 55% / 오른쪽 약 45%**로 나눈다. 오른쪽 영역의 높이는 **현재 노드·준비 정보 약 70% / 보관함 약 30%**로 배분한다. 상점 패널은 상점 노드에서만 나타난다.

**상단 정보·손님 썸네일·조작 영역을 제외한 실제 호텔 프레임 높이를 기준으로, 10층과 지하가 세로 공간을 채우도록 각 층의 높이를 계산한다.** 층 높이를 고정 픽셀로 제한해 프레임을 비워 두지 않는다. 기본 검토 크기는 1280×720이며 글자·공략도 바·파훼 심장·클릭 영역까지 일괄 확대/축소하지 않는다.

```text
┌──────────────────────────────────────────────────────────────┐
│ 현재 막 n/3 · 방문 완료 k/8 · 현재 노드 · 영혼 · 지도 · 옵션 │
├──────────────────────────────────┬───────────────────────────┤
│ 전투 준비: 다음 손님 썸네일      │ 현재 노드의 결정          │
│ 호버하면 호텔 초대장 표시        │                           │
│ 10층 ─ 복도 · 괴이 · 상태       │ 상점: 괴이 8개·영혼 가격  │
│  9층 ─ 복도 · 괴이 · 상태       │ 상점 증설: 비용·전후 비교 │
│  8층 ─ 복도 · 괴이 · 상태       │ 발견: 랜덤 주사위 1개     │
│  7층 ─ 복도 · 괴이 · 상태       │ 회복: 토큰 배분 또는 강화 │
│  6층 ─ 복도 · 괴이 · 상태       │ 이벤트: 설명·선택지       │
│  5층 ─ 복도 · 괴이 · 상태       │ 전투 준비: 손님·장비 정보 │
│  4층 ─ 복도 · 괴이 · 상태       │                           │
│  3층 ─ 복도 · 괴이 · 상태       ├───────────────────────────┤
│  2층 ─ 복도 · 괴이 · 상태       │ 보관함                    │
│  1층 ─ 복도 · 괴이 · 상태       │                           │
│ ───────── 지하 ────────────────   │                           │
│ 직원 전용 구역 · 괴이 제조 기계  │ 보유 괴이 카드 리스트     │
│                                  │                           │
├──────────────────────────────────┴───────────────────────────┤
│ 장착 주사위 정보                    노드별 확정·퇴장 조작     │
└──────────────────────────────────────────────────────────────┘
```

도식은 최대 10층까지 증설한 화면의 영역 관계를 보여준다. 6층일 때도 10층 기준으로 계산한 같은 층 높이를 사용해 실제 6층과 지하를 아래 정렬하고, 증설하면 꼭대기에 층을 추가한다. 빈 상단 공간을 구입한 층처럼 그리거나 6층을 프레임 전체에 늘리지 않는다. 55:45와 70:30은 공통 정보·조작 영역을 제외한 주 작업 영역의 기본 비율이다. 지도와 전투 보상에서는 경로와 후보 비교를 우선하도록 주 영역을 전환한다.

- 왼쪽~중앙은 호텔의 지상층과 지하가 이어지는 하나의 공간으로 구성한다. 지하 설비는 호텔 아래의 작은 영역에 배치해 10층 전체 표시 공간을 확보한다.
- 호텔·오른쪽 노드 패널·보관함·주요 조작을 한 화면 안에 배치한다. 호텔의 층 탐색을 위한 세로 스크롤은 제공하지 않는다. 상품·보관함 목록과 긴 상세 설명은 각 패널 안에서만 스크롤할 수 있다.
- 폭 1080px 미만에서는 호텔 화면의 최소 너비를 유지하고 가로로 탐색한다. 글자나 정보 버튼을 계속 줄이거나 숨기는 방식으로 맞추지 않는다. 배치 선택 안내의 자리는 미선택 상태에도 확보해 조작 중 층 위치가 움직이지 않는다.
- 전투 준비일 때 다음 손님 썸네일 리스트를 호텔 영역 상단에 고정한다. 비전투 노드에서 아직 선택하지 않은 전투를 ‘다음 손님’으로 확정해 보여주지 않는다.
- 전투 준비의 오른쪽 위는 초대장·장착 주사위·배치 요약을 제공한다. 장착 주사위·확정·퇴장 등의 보조 조작은 주 작업 영역을 과도하게 가리지 않게 배치한다.
- 모든 전투 전 준비에서 무료 배치·보관·교환을 제공한다. 상점의 괴이 재고·층 구매는 준비 화면에 상시 붙이지 않는다. 봉인된 객실의 제시 괴이를 영혼 3으로 구매하는 거래는 해당 이벤트에서만 제공한다. 플레이어가 선택하는 토큰 회복·강화는 회복 노드의 기능이며, 새 막 시작의 자동 토큰 복구는 별도 진행 경계다.
- 지도와 비전투 노드에서도 호텔 확인과 무료 재배치를 제공한다. 괴이 보상·주사위 교체·이벤트/회복/강화 대상의 확정 창에서는 호텔을 읽기 전용으로 확인해 선택 조작과 충돌하지 않게 한다.

## 3. 지도에서 준비로 이어지는 진행

- 3막·각 막 8개 방문·7번째 공통 회복·8번째 보스의 지도와 모든 노드별 전환은 [모험 UI](adventure.md)를 따른다. 막당 전체 20개 노드와 호텔 층 번호·방문 수를 구별한다.
- 연결된 전투 노드의 방문을 확정하면 해당 전투 준비로 간다. 이때부터 지도는 읽기 전용이며 다른 노드로 취소 이동하지 못한다.
- 상점·회복 등 비전투 노드를 방문하면 같은 호텔 공간 옆에 해당 기능 패널만 연다. 전투 준비에 상점을 자동으로 붙이지 않는다.
- 영업 시작은 실제 준비 종료 결정으로 기다린다. 같은 영업의 다음 손님·정산·선택 완료 후 화면 전환에는 별도 진행 승인 버튼을 요구하지 않는다.
- 일반·엘리트 전투의 승리 보상을 마치면 지도, 1·2막 보스는 괴이 선택 후 생존 배치·보관 개체의 토큰을 최대 복구하고 다음 막 지도, 3막 보스는 토큰 복구 없이 괴이 선택 후 승리 결과로 간다.
- 일반·엘리트 탈출은 이미 처치한 영혼만 유지하고 지도에 돌아간다. 괴이·주사위 보상은 없으며 어느 막의 보스든 탈출하면 패배한다.

## 4. 전투 준비 진입 시 상태

전투 노드에 진입해 준비를 시작할 때 **그 전투에 실제로 사용할 상태**를 보여준다.

| 항목 | 전투 준비 첫 진입 시 표시 |
|---|---|
| 생존 괴이의 공략도 | 0으로 초기화 완료. 한 칸이 1인 12칸 이산 바와 현재/12 숫자 |
| 생존 괴이의 파훼 토큰 | 준비 진입은 현재 수량 유지. 채운/빈 심장과 현재/최대 표시. 새 막 첫 준비라면 막 시작 때 이미 복구된 값 |
| 개체 강화 | 이름의 `+`와 해당 개체의 강화 효과 유지 |
| 영업별 직접 사용 잔량 | 해당 개체의 초기 횟수로 복구. 호출벨 2회·호출벨+ 3회·방화문은 기본/강화 모두 2회 |
| 파괴된 괴이 | 영구 손실을 적용한 빈층. 보관함에도 복귀하지 않음 |
| 영혼 | 이전 노드까지의 보상·구매·이벤트가 반영된 잔액 |
| 지난 전투의 손상·소모 | 기록에서 확인 |

- 공략도·직접 사용 잔량은 준비 첫 진입에 복구된 실제 값으로 표시한다. 파훼 토큰이 남은 최대값보다 적어도 `복구 예정`으로 표시하거나 시작 시 채우지 않는다.
- 공략도·직접 사용 복구는 해당 전투 준비 첫 진입에서 한 번 처리한다. 준비 화면 재열기, 보관·재배치, 지도 열기, 영업 시작에서 복구를 반복하지 않는다.
- 지도·상점·발견·이벤트·회복을 여는 것만으로 새 전투 준비 복구를 발동하지 않는다. 회복 노드는 토큰 배분을 명시적으로 확정할 때만 토큰을 회복하고, 강화 선택은 토큰을 바꾸지 않는다.
- 같은 영업에서 손님이 바뀌면 생존 괴이의 공략도를 0으로 초기화하고 이전 손님에게 사용한 보호를 제거한다. 파훼 토큰·직접 사용 잔량은 유지한다. 이전 손님의 불안·공포는 다음 손님에게 이월하지 않는다.
- 1막→2막, 2막→3막에서는 보스의 필수 괴이 보상 선택 후 생존 보유 개체 전부의 토큰을 각 최대치로 한 번 복구한다. 배치·보관 위치와 강화는 유지하고 공략도·현재 사용 잔량을 이 경계에서 별도로 복구하지 않는다. 파괴/계약 제거 개체는 부활하지 않는다.
- 첫 1막은 초기 토큰으로 시작한다. 판이 끝나면 다음 전투용 복구를 실행하지 않으며 3막 최종 승리도 토큰 복구를 실행하지 않는다.

## 5. 손님 썸네일과 호텔 초대장

### 5.1. 썸네일 리스트

- 선택한 전투 노드에 등장할 손님을 방문 순서대로 보여준다. 일반 전투는 손님 3명, 엘리트·보스 전투는 각 1명이다.
- 일반·엘리트·보스 분류와 현재 막을 표시하고, 여러 손님을 상대하는 영업이면 전체 순서와 남은 인원을 보여준다.
- 같은 종류의 손님이 여러 번 방문해도 각 방문을 별도 썸네일과 순번으로 구별한다.
- 썸네일은 손님을 빠르게 식별하는 역할을 맡고 자세한 수치는 초대장에서 제공한다.

### 5.2. 초대장 형태의 정보

손님 썸네일을 호버하면 정중한 호텔 초대장 느낌의 정보 카드가 펼쳐진다. 크림색 종이, 호텔 문장, 얇은 금박 테두리를 사용하되 문구와 숫자는 선명하게 유지한다.

| 초대장 정보 | 내용 |
|---|---|
| 수신인 | 손님 전체 이름과 일반·엘리트·보스 분류 |
| 인사말 | 호텔에서 정중하게 초대하는 짧은 문구 |
| 내구 정보 | 공포 한계·남은 심장 수 |
| 위협 정보 | 공격 범위·타격 순서·개별 위력·중요 조건 |
| 처치 보상 | 해당 손님 처치로 획득할 영혼 |
| 노드 승리 보상 | 괴이 3개 중 1개. 엘리트는 별도 주사위 보상도 안내 |

예시:

> **성급한 투숙객 귀하**  
> 귀하의 방문을 기다리고 있겠습니다.
>
> 공포 한계 **12** · 심장 **1개**  
> 공격: 도착층에 **공략도 6씩 두 번**  
> 처치 보상: **영혼 2**  
> 이 전투 노드 승리 시: **괴이 3개 중 1개 선택**

정중한 인사말과 실제 전투 정보는 구분한다. 효과·공격 규칙을 비유적인 문장만으로 설명하지 않는다. 키보드 초점과 터치로도 같은 초대장을 확인한다. 여러 손님 각각에게 괴이 보상이 나온다고 오해하지 않게 처치 보상과 노드 승리 보상을 구분한다.

## 6. 호텔과 지하 직원 전용 구역

### 6.1. 배치할 호텔 공간

- 각 층은 여러 객실 문과 이어지는 바닥·벽·조명을 가진 짧은 복도 단면으로 표현한다.
- 빈층도 정상적인 호텔 복도로 보이게 한다. 괴이를 배치하면 해당 층에 이상 현상이 나타난다.
- 현재 층 수, 층 번호, 배치된 괴이와 빈층을 구별한다.
- 배치된 괴이를 호버하거나 정보 조작을 하면 효과·비용·현재 상태가 담긴 카드를 보여준다.
- **실제 호텔 프레임에서 지하 높이와 10층 사이의 9개 여백을 뺀 높이를 10으로 나누어 층 높이를 정한다.** 최대 10층이 세로 공간을 채우며 실제 보유 층만 아래에서부터 표시한다. 화면 크기 변경 때 다시 계산하되 조작 중에는 동일 프레임과 층 영역을 유지한다. 구형 브라우저의 고정 높이 대체값은 현행 크기 설계의 기준이 아니다.
- 층 선택·배치·교환·보관 중에도 호텔의 위치·배율과 층의 대상 영역을 고정한다. 화면 밖 층을 찾기 위한 스크롤이나 대상 층으로의 자동 확대·카메라 이동은 하지 않는다.
- 괴이의 공략도는 한 칸이 1인 12칸 바와 현재/12로, 파훼 토큰은 남은 수만큼 채운 심장과 잃은 수만큼 빈 심장으로 표시한다. 현재/최대 수량을 함께 제공하고 색만으로 상태를 구별하지 않는다. 자세한 효과·타격 내역은 정보 카드에서 확인한다.

### 6.2. 지하의 괴이 제조 설비

지하는 직원 전용 공간이며, 검은 비닐이 씌워진 손님을 투입하는 기계와 괴이 카드 출력구를 배치한다. 지상층과 같은 호텔 건물의 아래쪽 공간으로 연결해 보여준다.

상점의 괴이 구매를 다음의 짧은 연출로 표현한다.

```text
상점에서 괴이 구매 확정
→ 검은 비닐이 씌워진 손님이 기계에 들어감
→ 기계 작동
→ 구매한 괴이의 그림과 이름이 카드로 인쇄됨
→ 카드가 오른쪽 아래 보관함으로 들어감
→ 보관함에서 호텔로 배치 가능
```

- 구매 비용은 영혼이다. 연출 때문에 별도의 손님 포획·제조 재료·제조 대기 단계를 추가하지 않는다.
- 구매 한 번으로 투입·작동·출력을 자동 진행한다. 연출 단계마다 버튼을 요구하지 않는다.
- 비용 차감, 해당 상품의 구매 완료, 괴이 획득은 한 번만 처리한다. 연출이 판정을 반복 실행하지 않는다.
- 구매 결과와 함께 해당 상품을 품절로 바꾼다. 구매로 다른 상품을 개방하거나 지도 연결선을 바꾸지 않는다.
- 제조 연출 중에도 호텔의 최대 10층 전체와 구매한 카드의 보관함 유입을 확인할 수 있게 한다. 연출을 위해 호텔을 확대하거나 카메라를 옮기지 않는다. 빠른 연출에서도 획득한 괴이의 정체와 보관 위치는 읽혀야 한다.
- 전투 보상으로 얻는 괴이는 무료 획득이다. 카드 출력 연출을 공유하더라도 영혼 지불이나 상점 방문으로 표현하지 않는다.

## 7. 오른쪽 위: 방문 목적에 맞춘 패널

자세한 화면 구성·후보 비교·버튼·전환은 [모험 UI](adventure.md)를 따른다. 호텔 화면에서는 오른쪽 위 약 70% 영역을 다음처럼 바꾼다.

| 현재 화면 | 오른쪽 위 패널 | 주 조작 |
|---|---|---|
| 전투 준비 | 손님 초대장·장착 주사위·배치 요약 | 영업 시작 |
| 상점 | 괴이 8개·영혼 가격·품절·별도 증설 비용/경로 비교 | 상품 구매·층 구매·상점 떠나기 |
| 회복 | 배치/보관 생존 개체·현재/최대 토큰·강화 전후·예산 잔량 | 토큰 총 2개 배분 또는 1개 강화 확정·노드 스킵 |
| 주사위 발견 | 랜덤 1개와 현재 장착 3개의 모든 면·효과 | 교체할 자리 선택·교체·건너뛰기 |
| 이벤트 | 사건·공개된 선택·영혼 전후·필요한 대상 | 선택 확정·떠나기 |

- 상점의 괴이 8개는 동종 중복을 허용하는 상품 슬롯이다. 선행 구매·개방 연결·리셋권·재고 갱신은 없다. 상품 검토만으로 구매하지 않는다.
- 층 구매는 상점에서 괴이 8슬롯과 별도로 제공한다. 한 방문에 여러 층을 살 수 있고 매번 가격과 잔액을 갱신한다. 비교를 닫아도 상점에 남으며 `상점 떠나기`로만 방문을 마친다. 같은 가상 시작 위치·눈·불안·공포로 증설 전후 경로를 비교하며 다음 실제 눈의 예고로 표현하지 않는다.
- 회복 패널은 생존 보관 개체도 대상으로 제시한다. 회복 총 2개 예산과 최대 토큰을 검사하며 남은 양 포기·스킵을 허용한다. 강화는 미강화 개체 1개만 가능하고 토큰 회복·최대 토큰 증가를 표시하지 않는다. 회복과 강화 중 하나를 확정하면 방문을 완료한다.
- 주사위 발견은 무료 랜덤 1개 제시이며 영혼 증감이 없다. 엘리트·이벤트의 주사위도 새 후보와 장착 세 자리를 비교한다. 교체 대상 검토·취소로 재추첨하거나 기존 장비를 먼저 버리지 않는다.
- 이벤트의 영구 제거 대상에는 이름·배치 위치·남은 생존 보유 수를 확인한다. 주사위 비교 취소는 이벤트 선택으로 돌아오며, 이벤트 떠나기와 발견 주사위 건너뛰기를 구분한다.
- 전투 보상의 괴이 3중 1은 상점 상품 패널과 구별한다. 서로 다른 세 종류를 비교해 반드시 하나를 무료 획득하며, 선택 중 호텔·보관함·장착 주사위는 읽기 전용으로 확인한다.
- 구매·증설·보상·이벤트·회복·강화 확정의 효과와 비용·완료를 한 번만 처리한다. 호버·상세 정보 열기·미확정 선택은 실제 소유·배치·영혼·토큰·강화를 바꾸지 않는다.

## 8. 오른쪽 아래: 괴이 카드 보관함

보관함은 오른쪽 영역 높이의 약 30%를 사용한다. 카드가 가로로 나열되는 스크롤 영역으로 구성한다.

- 상점·전투 보상·이벤트로 얻은 괴이와 배치에서 회수한 괴이를 카드로 보여준다.
- 같은 종류의 여러 괴이를 개별 카드로 구별한다.
- 카드의 전체 이름·대표 그림과 핵심 효과를 읽을 수 있게 한다. 강화 개체는 이름에 `+`를 표시하고 해당 개체의 강화 효과·현재/최대 토큰을 정보 카드에서 확인한다. 보관함에 넣어도 강화·손실 토큰은 유지한다.
- 새로 획득한 카드는 유입 연출로 보관함에 들어왔음을 알린다. 모든 카드에 구매 연출을 강요하지 않는다.
- 배치가 가능한 화면에서 카드에서 호텔의 원하는 층으로 바로 드래그해 배치한다.
- 배치된 괴이를 보관함으로 끌어오면 층에서 회수되어 카드 상태로 돌아온다.

## 9. 드래그 앤 드롭 배치

전투 전 준비, 지도와 비전투 노드에서 배치·이동·교환·보관은 무료이며 자유롭게 반복한다. 구매·보상 선택과 배치를 별개 행동으로 유지한다.

| 드래그하는 대상 | 놓는 곳 | 적용 결과 |
|---|---|---|
| 보관함 카드 | 빈층 | 해당 층에 괴이 배치 |
| 보관함 카드 | 괴이가 있는 층 | 새 괴이를 배치하고 기존 괴이는 보관함으로 이동 |
| 호텔의 괴이 | 빈층 | 해당 층으로 이동 |
| 호텔의 괴이 | 다른 괴이가 있는 층 | 두 괴이의 층 교환 |
| 호텔의 괴이 | 보관함 | 배치를 해제하고 카드로 보관 |

- 드래그하는 동안 원래 위치를 표시한다.
- 유효한 대상 층과 보관함을 강조하고 놓았을 때의 배치·교환·보관 결과를 미리 보여준다.
- 기존 괴이가 보관함으로 돌아가는지, 두 층의 괴이가 교환되는지를 확정 전에 구별한다.
- 유효한 위치에 놓았을 때 실제 배치를 적용한다. 드래그 도중에는 실제 소유·배치를 바꾸지 않는다.
- 최대 10층의 모든 배치 대상이 한 화면에 보이므로 어느 층으로든 직접 드래그해 놓을 수 있다. 드래그 중 호텔의 위치·배율·대상 영역을 바꾸거나 가장자리에서 자동 스크롤하지 않는다.
- 바깥이나 유효하지 않은 곳에 놓거나 Esc로 취소하면 원래 위치로 돌아가고 대상 강조·가상 배치 예고를 해제한다.
- 이동·교환·보관은 해당 개체의 상태를 보존한다. 배치 조작으로 복구나 추가 비용이 발생하지 않는다.
- 같은 동작을 **카드·괴이 선택 → 대상 층 또는 보관함 선택**으로도 제공한다. 키보드·터치에서도 드래그만 강요하지 않는다.
- 전투 중과 괴이 보상·주사위 교체·이벤트/회복/강화 대상의 확정 창에서는 준비 배치 조작을 제공하지 않는다.

## 10. 함께 확인할 정보와 보조 조작

### 10.1. 자원·진행·괴이 정보

- 현재 막 n/3, 방문 완료 k/8, 현재 노드 종류와 보유 영혼을 표시한다.
- 괴이의 전체 이름과 강화 여부, 실제 통과·도착·직접 사용 효과, 대상과 비용, 공략도·공략 한계, 현재/최대 파훼 토큰, 현재/전투당 직접 사용 횟수를 확인한다.
- 기본 카드는 효과가 있는 항목 중심으로 읽히게 하고 상세 보기와 용어 설명으로 공통 규칙을 확인한다.
- 같은 이름의 여러 괴이는 층 번호 또는 개체 구분으로 식별한다.

### 10.2. 장착 주사위와 설계 비교

장착한 세 주사위의 이름, 전체 눈 구성, 선택 효과를 나란히 확인한다. 받은 특수 주사위를 보며 배치를 판단하고 상점에서는 층 구매 전후의 연결도 비교한다. 강화된 개체의 효과를 실제 개체별로 비교에 적용한다. 장비 정보 열람으로 주사위를 임의 재장착하지 않는다.

### 10.3. 안내·기록

첫 등장 설명, 도움말, 용어 설명, 옵션과 지난 전투·노드 기록을 필요할 때 열어본다. 기록에는 방문 경로, 전투 처치 영혼, 보상 후보와 선택, 상점 괴이/층 구매, 회복 배분·소멸량, 강화 대상·효과, 새 막의 개체별 토큰 복구 전후·복구량, 주사위 교체·스킵, 이벤트 결과를 남긴다. 기록 열람을 위한 별도 정산 승인 단계를 만들지 않는다.

## 11. 영업 시작

‘영업 시작’은 선택한 전투의 손님·장비·배치 준비를 끝내겠다는 플레이어의 결정이다. 전투 준비 화면의 눈에 잘 띄는 위치에 둔다.

- 배치된 괴이 수와 빈층 수를 확인한다.
- 배치된 생존 괴이가 없으면 시작할 수 없으며 이유를 보여준다.
- 준비 화면에 보이는 배치·강화·이월 토큰과 공략도/직접 사용 복구 상태로 해당 전투를 시작한다.
- 시작 버튼을 복구 실행이나 추가 정산 승인을 위한 버튼으로 사용하지 않는다.
- 시작 후에는 정해진 전투 흐름으로 전환한다. 상점·회복·발견·이벤트를 끝내는 버튼에 ‘영업 시작’을 쓰지 않는다.

## 12. 구현 시 확인할 기준

- 각 막에서 8개를 방문하며 보스가 마지막이고 분기 지도 전체 노드 수와 방문 수를 혼동하지 않는가.
- 7종 노드와 다음에 갈 수 있는 연결을 읽고 경로를 직접 선택할 수 있는가.
- 호텔 55%와 오른쪽 45%, 오른쪽 결정 패널 70%와 보관함 30%의 기본 배분에서 각 기능을 읽고 조작할 수 있는가.
- 최대 10층 전체가 상단 정보·손님 썸네일·지하 설비·하단 조작과 함께 한 화면에 들어오며 층 탐색용 스크롤이 없는가.
- 실제 호텔 프레임 높이를 10층과 지하가 채우며, 6층에서도 같은 층 높이로 아래 정렬하고 미구입 층은 그리지 않는가.
- 작은 호텔에서도 모든 층 번호·괴이 상태·토큰·글자와 클릭/드롭 대상 영역을 구별할 수 있는가.
- 공략도 12칸의 한 칸이 1이고 파훼 심장의 채움/비움과 현재/최대 수량이 일치하는가.
- 호텔의 지상층과 지하 직원 전용 구역이 하나의 공간으로 이어지는가.
- 다음 손님 순서를 썸네일로 파악하고 초대장에서 정확한 전투 수치·영혼·노드 보상을 구별하는가.
- 상점에는 괴이 8개가 있으며 영혼 구매·품절·자원 부족을 확인하고 구매 선행 조건·웹 갱신이 없는가.
- 구매 한 번으로 제조·출력·보관함 유입을 보여주며 불필요한 확인 버튼이나 새 재료 요구가 없는가.
- 모든 승리 전투에서 서로 다른 괴이 후보 3종을 비교해 하나만 얻고 손님마다 중복 지급하지 않는가.
- 상점에서 괴이 8개와 별도로 층을 구매하며 구매 전후 비교·영혼 차감·상점 퇴장을 구별하는가.
- 회복은 보관 포함 생존 개체에 총 2토큰만 배분하고 최대값·미사용분 소멸·강화와의 배타 선택을 전달하는가.
- 강화 개체의 이름 `+`·실제 효과와 토큰 이월을 호텔/보관함에서 일관되게 보여주는가.
- 주사위 발견은 랜덤 1개·무료·스킵 가능이며 엘리트·이벤트 외에 주사위를 지급하는 경로가 생기지 않는가.
- 주사위 후보를 검토·취소·재열기해도 재추첨·중복 획득·묵시적 스킵이 없는가.
- 보관함 카드와 호텔 속 괴이가 같은 개체라는 것을 인식하고 드롭 결과를 미리 구별하는가.
- 호텔 위치·배율을 고정한 채 1~10층 어느 층으로든 직접 배치할 수 있고, 잘못 놓거나 취소하면 원래 상태가 보존되는가.
- 전투 준비 진입 때 공략도/직접 사용은 복구하고 토큰/강화는 유지하며, 지도·배치·재열기·영업 시작으로 중복 복구하지 않는가.
- 1·2막 보스 보상 뒤 새 막 시작에 생존 배치·보관 개체의 토큰만 최대 복구하며, 최종 승리에는 복구하지 않고 파괴/제거 개체도 부활하지 않는가.
- 보상·이벤트·상점 퇴장 등 실제 결정은 기다리고 선택 없는 정산·지도 복귀는 자동 진행하는가.
