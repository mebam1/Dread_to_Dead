# Dread-to-Dead — 사용자 프로토타입 2

[사용자 설정 2 v1.1](../mvps/mvp-config-user-2.md)를 구현한 브라우저용 2D 도형 게임입니다. 구매·배치에서 시작해 일반 영업 6회와 보스전 2회, 최종 승리·패배·재시작까지 플레이할 수 있습니다. user-1과 독립된 디렉터리이며 외부 패키지는 사용하지 않습니다.

## 실행

Node.js 20 이상이 설치된 Windows에서 [play.cmd](play.cmd)를 더블 클릭합니다. 로컬 서버와 브라우저가 열리며, 서버 창을 닫으면 종료됩니다.

터미널에서는 이 디렉터리에서 실행합니다.

```powershell
npm start
```

[게임 주소](http://127.0.0.1:4173)는 `http://127.0.0.1:4173`입니다. HTML 파일을 직접 여는 대신 이 주소를 사용하세요. 터미널에서 `Ctrl+C`로 서버를 종료합니다. user-1의 서버가 열려 있다면 먼저 종료하세요. 같은 브라우저·주소를 사용하면 user-1의 옵션과 기존 설명 확인 이력을 이어받습니다. 별도 포트가 필요하면 `$env:PORT = 4184`를 지정한 뒤 실행할 수 있지만, 브라우저 저장 설정은 주소별로 분리됩니다.

## 새 기능과 조작

- **꼭대기 증설:** 경영 단계에 6층부터 최대 10층까지 늘릴 수 있습니다. 비용은 순서대로 4·6·8·10입니다. 기준 위치·주사위 면·불안·공포를 정해 증설 전후 경로를 비교하고 확정합니다.
- **특수 주사위:** 중간 보스를 처치하면 장거리·짝수·불안 주사위 중 하나로 장착 주사위를 교체하거나 보상을 건너뜁니다. 항상 세 개를 굴리고 하나만 고릅니다.
- **주사위 선택:** 숫자뿐 아니라 이름과 효과를 보고 검토한 뒤 확정합니다. 불안 주사위의 3은 확정 시 불안 1을 한 번 지급하며, 바로 수리 비용으로 사용할 수도 있습니다.
- **괴이 정보:** 구매·보관 상태는 카드, 배치 뒤에는 층 박스로 보입니다. 호버하거나 정보 버튼을 눌러 카드를 확인합니다. 밑줄 용어로 공통 규칙을, 상세 보기로 모든 효과 항목을 확인합니다.
- **직접 사용:** 눈을 확정한 뒤 층의 사용 버튼을 누릅니다. 보호·수리는 대상 층을 고른 뒤 비용을 소비합니다. 취소 버튼이나 `Esc`로 미완료 대상 선택을 취소합니다.
- **결과 예고:** 도착·공포 부여량·심장 제거·반격·손실을 먼저 표시합니다. 상세에서는 선택 효과부터 통과·도착·개별 공격 순서를 확인합니다. 무작위 비활동 패널티는 확정 결과와 분리합니다.
- **큰 호텔:** 층 목록 스크롤과 층 바로가기를 사용합니다. 주사위 검토만으로 호텔 스크롤 위치를 바꾸지 않습니다.
- **안내 옵션:** 첫 등장 설명 팝업을 켜고 끌 수 있습니다. 옵션과 확인 이력은 같은 브라우저에 저장됩니다. 진행 중인 판은 메모리에 있으므로 페이지를 새로고침하면 초기화됩니다.
- **전체 기록:** 호텔의 기록에서 전체 과정을 다시 읽거나 JSON 파일로 내려받을 수 있습니다. 난수 번호, 층 수, 장착 주사위, 구매·증설·효과·공격 기록이 포함됩니다.

빈 프런트의 호출벨은 도착·직접 사용 모두 공포 3, 따라오는 발자국은 통과 시 현재 불안만큼 추가합니다. 불안 전체 상한은 9입니다. 파괴된 괴이는 영구적으로 사라지며, 마지막 보스를 탈출시키거나 배치 괴이가 전멸하면 패배합니다.

## 검증

```powershell
npm test
npm run verify:campaign
```

판정 테스트는 강제 눈·진단 상태를 사용하는 경계 검사입니다. 화면 테스트는 브라우저 없는 DOM 대역에서 렌더링과 조작을 확인합니다. 캠페인 검사는 실제 공개된 눈과 구매·배치·직접 사용 API만 사용하는 자동 플레이이며, 진단 상태를 주입하는 테스트와 구분합니다. 시작 난수 번호는 21001이며 추가 시험 번호는 21002·21003입니다.

2026-11-01 검증에서 판정 검사 54개와 화면·조작 검사 19개, 총 **73개가 통과**했습니다. HTML·스크립트·스타일의 로컬 HTTP 응답도 확인했습니다.

고정된 자동 플레이 정책으로 세 번호 모두 끝까지 실행한 결과입니다. 중간 보상은 불안 주사위로 선택했고, 번호를 바꿔 성공한 판만 고르지 않았습니다.

| 난수 번호 | 결과 | 턴 수 | 처치 | 최종 층 | 재화 소비 | 영구 파괴 |
|---|---|---:|---:|---:|---:|---:|
| 21001 | 최종 보스 처치 | 90 | 20 | 6 | 11 | 0 |
| 21002 | 최종 보스 처치 | 113 | 20 | 7 | 40 | 3 |
| 21003 | 최종 보스 처치 | 93 | 20 | 6 | 15 | 0 |

원하는 번호 하나만 확인하려면 `node verify-campaign.mjs 21001 1`을 실행합니다. 이 스크립트는 게임의 필수 진행 절차가 아니며, 게임 안에서 자동 플레이를 실행하지 않습니다.

실제 브라우저 자동 확인은 개발 환경의 로컬 주소 접근 승인 거부로 차단되었습니다. 따라서 브라우저 레이아웃·호버 위치의 실측 검증은 완료하지 못했습니다. 자동 테스트와 자동 플레이 결과는 인간 플레이의 이해도·재미·난이도 검증을 대신하지 않습니다.
