# P3. 덱 소진의 위험과 대응 기회

[전체 계획](prototypes-main.md) · **v0.2 / 2026-10-29 / 검증 전**  
기준: rules.md v0.4 §4.3~4.5, §5.3~5.4. 예상 20~30분/덱 상태 한 종류.

## 1. 질문과 재미 하락 위험

**심장 부담 증가와 드로우 중단이 겹치면, 감수할 제약보다 무력한 대기로 느껴지는가?** 위험이 커지는 순간 회복 카드까지 사라지는 문제를 두 요소로 나누어 비교한다. 손패 0장이나 큰 덱 선호 자체를 실패로 보지 않는다.

소진 직전부터 한 턴만 진행한다. 참가자가 덱을 직접 고르지 않으므로 작은 덱의 장기 가치나 최적 덱 크기를 결론내리지 않는다.

## 2. 장면과 비교 조건

모든 수치·카드 효과는 실험용이다. 입구 0, 슬롯 1~9, 출구 10. **위치 2·불안 1·공포 0·심장 부담 6/12·손패 0**에서 드로우 직전으로 시작한다. 전체 직원 7장, 요청 드로우 5장, 이후 공개할 눈/마나는 2다.

| 위치 | 타일 | 효과 |
| --- | --- | --- |
| 3, 7 | 속삭임 W1/W2 | 통과: 불안 +1 |
| 4, 8 | 부담 거울 M1/M2 | 도착: 불안 2 이상이면 2 소비, 공포 +8, 심장 부담 +2 |
| 5 | 진정실 | 통과: 심장 부담 -1, 최저 0 |
| 나머지 | 빈 복도 | 없음 |

이번 이동은 위치 4 도착까지다. 이후의 타일은 맥락으로만 보여준다. 심장 부담이 12에 도달하면 즉시 종료한다. 배치·모집·융합·경제·보스·추가 드로우는 제외한다.

| 직원 | 장수 / 마나 | 실험용 효과 |
| --- | --- | --- |
| G1/G2 강화 | 2장 / 각 2 | 이번 도착 타일의 수확 성공 시 공포 +4 |
| R1/R2 회복 | 2장 / 각 1 | 손님의 심장 부담 -3, 최저 0 |
| S1/S2 공급 | 2장 / 각 1 | 손님에게 불안 +1 |
| B1 완충 | 1장 / 1 | 이번 도착 타일의 수확 부담을 1 줄임. 소진 부담에는 영향 없음 |

강화·완충은 이번 턴에만 적용한다. 사용 카드와 턴 종료의 남은 손패는 버리고 마나는 이월하지 않는다. 현재 손패는 버린 더미의 셔플에 포함하지 않는다.

| 시작 상태 | 뽑을 덱 | 버린 더미 | 진행자용 셔플 순서 |
| --- | --- | --- | --- |
| Z 빈 덱 | 없음 | 전체 7장 | G1→R1→B1→S1→G2→R2→S2 |
| P 부분 드로우 | 위부터 G1→R1 | 나머지 5장 | B1→R2→S1→G2→S2 |

미래 카드 순서는 참가자에게 공개하지 않는다. Z와 P에 참가자를 나누어 배정하고, 각자 아래 네 조건을 모두 경험하게 한다. 두 상태를 모두 체험시킬 경우 세션을 나누고 순서를 바꾸며 학습된 두 번째 결과로 표시한다.

| 조건 | 빈 덱에서 뽑으려 할 때의 부담 | 버린 더미 셔플 뒤 이번 드로우 |
| --- | --- | --- |
| E11 현재 규칙 | +3 | 즉시 중단 |
| E10 부담만 유지 | +3 | 부족분을 보충해 총 5장 |
| E01 중단만 유지 | +0 | 즉시 중단 |
| E00 둘 다 제거 | +0 | 부족분을 보충해 총 5장 |

변형 세 조건은 원인을 분리하기 위한 비교용이다. 같은 시작 상태 안에서는 지도·카드·눈·셔플 순서·표시 속도를 유지한다. 참가자에게 이번 조건의 소진 규칙은 미리 알려준다.

## 3. 진행 방법

1. ‘빈 덱에서 추가로 뽑으려 할 때’ 소진한다는 규칙과 이번 조건을 설명한다. 예상 손패 수와 부담 변화를 말하게 한다.
2. 드로우 5장을 요청해 소진 과정을 본다. 그 뒤 눈 2를 공개하고 카드 사용 또는 바로 이동을 선택하게 한다.
3. 위치 4의 수확까지 진행한다. 원했던 대응과 실제 선택을 짧게 설명한 뒤 Q1~Q7을 평가한다.
4. 같은 시작 상태로 다음 조건을 진행한다. 네 조건 순서는 참가자마다 교차 배정한다. 이전 턴의 카드·부담은 이어받지 않는다.
5. 네 평가가 끝나면 2×2 비교 화면을 보여준다. 위험 증가와 손패 감소 중 무엇이 경험을 바꾸었는지, 감수할 만한 조건은 무엇인지 이유를 받는다.

처음 선택과 힌트·재생 뒤 선택을 구분한다. 한 조건이 빠졌다면 그 이유를 남기고 두 요소의 결합에 대한 결론은 유보한다.

## 4. 검증 UI 구성

| 화면 | 표시와 조작 | 연결 문항 |
| --- | --- | --- |
| 이번 규칙 | 드로우 5장, 부담 +3/+0, 중단/보충, 현재 더미 수. 예상 결과 한 줄 입력 | Q1 |
| 소진과 손패 | 덱·손패·버린 더미를 구분하고, 실제 부담 변화와 최종 손패를 보여줌. 처리 과정 복기 | Q1, Q4, Q6 |
| 현재 행동 | 눈·마나·경로·부담/12와 카드 효과. 카드 사용 또는 바로 이동, 행동 이유 입력 | Q2, Q3 |
| 경험 평가 | Q1~Q7의 미선택 1~5점·N/A·이유/장면. 못 한 대응과 중단 사유를 추가로 받음 | 전체 |
| 진행자 2×2 비교 | 행은 부담 유무, 열은 중단/보충. 각 셀에 질문별 점수·중앙값·1~2점 수·발언·행동을 연결. Z/P는 분리 | 핵심 Q4·Q6·Q7 |

참가자의 이전 점수와 조건 간 비교는 네 평가가 끝난 뒤 공개한다. 미래 셔플 순서·권장 카드는 보여주지 않는다. 공통 설문 방식은 [전체 계획](prototypes-main.md)을 따른다.

## 5. 경험 validation: 질문–점수

각 조건 직후 **1~5점의 `점수/5 + 이유 + 장면`**으로 답한다. 1은 전혀 그렇지 않다, 5는 매우 그렇다. 미경험 항목은 N/A다.

| ID | 평가 요소 | 참가자 질문 | 응답 |
| --- | --- | --- | --- |
| Q1 | 예측 가능성 | 드로우 전에 소진으로 일어날 일을 예상할 수 있었다. | __/5 |
| Q2 | 대응 수단 | 소진 뒤에도 원했던 대응을 실행할 수 있었다. | __/5 |
| Q3 | 선택의 재미 | 소진 뒤에 무엇을 할지 판단하는 과정이 흥미로웠다. | __/5 |
| Q4 | 위험의 수용 | 이번 소진으로 생긴 위험은 감수할 만했다. | __/5 |
| Q5 | 영향력 | 소진 뒤에도 내 선택으로 결과를 바꿀 수 있다고 느꼈다. | __/5 |
| Q6 | 중단의 수용 | 이번 턴에 직접 할 수 있는 행동의 양은 받아들일 만했다. | __/5 |
| Q7 | 운영 지속 의향 | 이 소진 규칙으로 영업을 한 번 더 해보고 싶다. | __/5 |

핵심은 **Q4·Q6·Q7**이다. 문항별 중앙값 4/5 이상과 구체적인 이유·행동의 부합을 임시 진행 기준으로 삼는다. 위험이 없는 E01/E00의 Q4는 ‘위험 없음’으로 N/A 처리할 수 있으며 위험 수용의 증거로 쓰지 않는다. 1~2점 응답을 따로 보고, 네 조건을 전체 평균으로 순위 매기지 않는다.

## 6. 결과를 읽고 다음 실험 정하기

| 점수·행동 패턴 | 원인 후보 | 다음 조치 |
| --- | --- | --- |
| E10/E00에서 Q2·Q5·Q6가 개선되고 하고 싶던 대응이 생김 | 드로우 중단이 개입을 막음 | 소진 턴의 최소 대응 기회 또는 빈도를 한 요소씩 바꿔 비교 |
| E11/E10에서 Q4·Q7이 낮고 회복만 강요된다고 설명 | 부담 증가가 선택을 좁힘 | 손패 조건을 유지하며 소진 부담량을 조정 |
| 단독 페널티 조건은 수용하지만 E11의 Q6·Q7만 낮음 | 위험 증가와 대응 부재가 겹침 | 위험량과 대응 기회를 각각 조정해 결합 문제 재시험 |
| Q1이 낮고 실제 소진을 예상하지 못함 | 규칙 이해 문제 | 설명·소진 표시를 다듬고 미노출 참가자에게 반복 |

소진 순간의 경험이 수용되면 직접 고른 작은/큰 덱을 짧은·긴 영업에 사용하는 후속 실험으로 간다. 위험을 감수할 이유는 [P6](prototype-6.md), 빈 턴의 반복 부담은 [P11](prototype-11.md)로 연결한다. 융합에 따른 직원 소모 문제는 융합 방식 확정 뒤 별도 분석한다.
