# P6 — 심장 부담이 흥미로운 위험 선택을 만드는가

[전체 계획](prototypes-main.md) · v0.2 / 2026-10-29 · 검증 전 실험 계획 · 예상 20~25분  
근거: `rules.md` §4.4~4.5, §5.3~5.4. 아래 수치·사망 정산·후속 이동은 실험용 조건이다.

## 1. 질문과 재미 하락 가설

**위험을 알고 수익을 택하는가, 아니면 회복만 반복하거나 납득하기 어려운 처벌을 받는가?** 낮은 부담·위험을 감수할 만한 부담·즉시 생존 조치가 필요한 부담을 나누어 판단과 감정을 비교한다. 안전을 선호하거나 사망을 아쉬워한다는 사실만으로 재미 실패로 보지 않는다.

모집·융합·배치·덱 순환·경영·보스는 제외한다. 드로우와 현재 주사위 확인이 끝난 한 턴에서 시작하며, 이후는 선택의 결과를 확인하는 구간이다. 장기 경찰 시스템과 실제 사망 페널티의 적절성은 이번 범위 밖이다.

## 2. 시작 상태와 비교 조건

현재 위치 2, 불안 2, 공포 0, 주사위 2와 마나 2에서 시작한다. 목표는 **생존 정산 공포를 많이 얻기**다. 심장 부담은 10에 도달하면 즉시 사망하며, 회복 후 최솟값은 0이다.

| 위치 | 타일 | 실험용 효과 |
| --- | --- | --- |
| 3·5 | 빈 복도 | 효과 없음 |
| 4 | 거울 괴이 | 도착 시 불안을 전부 소비하여 1개당 공포 3, 이어 심장 부담 +2 |
| 6 | 맥박의 방 | 도착 시 심장 부담 +2. 통과만 하면 효과 없음 |
| 7 | 출구 | 처음 도달·통과하면 즉시 퇴장 |

| 현재 손패 | 비용 | 효과 |
| --- | ---: | --- |
| 자극 담당 | 2 | 이번 이동의 거울 수확 공포 +8, 그 사건의 심장 부담 추가 +3 |
| 진정 담당 | 2 | 즉시 심장 부담 -4와 불안 1개 소비. 불안이 부족하면 사용 불가 |
| 사용 안 함 | 0 | 현재 상태로 이동 |

카드 두 장을 함께 쓸 수는 없다. 현재 이동 후 살아 있다면 다음 눈은 1 또는 2, 각각 50%이며, 마지막 눈은 2다. 분포와 마지막 눈은 처음부터 알려주고, 실제 다음 눈은 선택 확정 후 공개한다. 후속 구간에는 추가 직원 사용이 없다.

생존 퇴장하면 이번 장면의 공포를 인정하고 사망하면 이번 장면 점수만 0으로 한다. 이전 장면의 수익은 보존한다. 경찰 의심도 +1은 표시만 하며 추가 불이익은 없다.

| 장면 | 초기 심장 부담 | 경험상 역할 |
| --- | ---: | --- |
| 낮음 | 2 | 안전한 수익 기회를 읽는지 확인 |
| 중간 | 6 | 확실한 작은 수익과 실패 가능성이 있는 큰 수익 사이의 선호 확인 |
| 높음 | 8 | 당장의 생존 행동을 알아보고 결과를 납득하는지 확인 |
| 새 장면 | 4 | 앞선 선택을 암기하지 않고 다른 위험 수준에서 다시 판단하는지 확인 |

첫 세 장면의 순서는 참가자 간 교차하고 부담 4는 마지막에 제시한다. 지도·손패·정산·주사위 분포는 같다. 실제 후속 눈도 함께 기록하여 운에 따른 점수 차이를 위험 선택의 재미와 혼동하지 않는다.

## 3. 실험 진행

1. 정산과 후속 주사위 분포를 설명한다. 참가자가 생존·사망 시 무엇을 얻거나 잃는지 짧게 말하게 한다.
2. 각 장면에서 카드를 고른 뒤, 확정 전에 예상 수익과 사망 가능성을 묻는다. 진행자는 위험한 선택에도 대안을 권하지 않는다.
3. 카드 사용 → 현재 이동 → 거울 수확·부담 증가 → 생존 시 후속 이동 → 정산 순으로 진행한다. 사망·퇴장·중단이면 해당 장면을 끝낸다.
4. 장면마다 아래 질문을 평가하고, 각 점수의 이유와 기억나는 장면을 한 줄씩 받는다. 이전 장면 점수나 다른 선택의 결과는 아직 보여주지 않는다.
5. 부담 4까지 끝난 뒤 상황별 선택을 비교한다. 원하는 장면 하나를 다시 해보게 하고, 바꾸려는 행동과 이유를 받는다. 재시도·힌트 후 응답은 최초 응답과 분리한다.

## 5. 경험 validation — 질문과 5점 만점 응답

공통 척도는 1=전혀 그렇지 않다, 5=매우 그렇다. 실제 응답은 아직 없으며, 미경험 항목은 N/A로 남긴다. 자세한 운영은 [전체 계획](prototypes-main.md)을 따른다.

| ID | 평가 요소 | 참가자 질문 | 응답 |
| --- | --- | --- | --- |
| Q1 | 위험 정보 이해 | 심장 부담이 언제 증가하는지 이해할 수 있었다. | __/5 |
| Q2 | 결과 예상 | 선택 전에 어떤 경우에 손님이 사망할지 예상할 수 있었다. | __/5 |
| Q3 | 선택의 매력 | 지금 상황에서 고려해볼 만한 선택지가 둘 이상 있었다. | __/5 |
| Q4 | 위험의 주도권 | 실패 가능성을 감수할지 내가 정한다고 느꼈다. | __/5 |
| Q5 | 결과 납득 | 실제 결과는 내가 받은 정보에 비추어 납득할 만했다. | __/5 |
| Q6 | 긴장의 기여 | 심장 부담 때문에 이번 선택이 더 흥미로웠다. | __/5 |
| Q7 | 판단 부담 | 위험을 판단하는 데 드는 노력은 감당할 만했다. | __/5 |
| Q8 | 지속 의향 | 다른 위험 수준의 손님을 더 상대해보고 싶다. | __/5 |

**핵심은 중간 부담과 부담 4에서의 Q3·Q4·Q8이다.** 각 문항의 중앙값 4/5 이상과 구체적인 이유·행동의 부합을 다음 실험으로 진행할 임시 기준으로 삼는다. 즉시 생존 조치가 필요한 부담 8의 낮은 Q3를 전체 실패로 판정하지 않는다. 이 장면은 주로 Q1·Q2·Q5로 본다.

## 6. 점수 해석과 후속 실험

| 응답·행동 패턴 | 원인 후보 | 다음 조치 |
| --- | --- | --- |
| Q1·Q2가 낮고 사망 원인을 설명하지 못함 | 위험 발생 시점이나 정산의 이해 어려움 | 정보 표시를 보완한 새 장면으로 재평가 |
| 이해는 높지만 중간 부담의 Q3·Q4가 낮음 | 안전·위험 선택의 가치 차이가 빈약함 | 회복의 비용 또는 위험 선택의 수익 중 하나를 조정 |
| Q5만 낮고 특정 사망 결과에 집중됨 | 예상과 다른 처벌 체감 또는 운의 영향 | 실제 눈과 사전 예상·발언을 함께 보고 동등 장면 추가 |
| 이해·납득은 높지만 Q6·Q8이 낮음 | 위험 관리 자체가 반복 업무로 느껴짐 | 위험 시점이나 직원 대응 방식을 바꾸어 비교 |

문항을 하나의 총점으로 합치지 않으며, 1~2점 응답과 이유는 따로 본다. 충분히 경험하지 못했거나 진행자의 해법을 먼저 들은 항목은 판정을 유보한다. 위험 선택이 작동하면 [P3 덱 소진](prototype-3.md)과 짧게 결합하여 같은 부담이 다른 원인으로 발생할 때의 반응을 확인한다.
