# P2. 직원 카드로 결과에 개입하는 재미

[전체 계획](prototypes-main.md) · **v0.2 / 2026-10-29 / 검증 전**  
기준: rules.md v0.4 §3.3, §4.3~4.4, §5.1~5.4. 예상 30~40분.

## 1. 질문과 재미 하락 위험

**주사위를 본 뒤 카드로 결과를 바꾸는 판단이 생기는가?** 필요한 손패·마나·대상이 없어 개입하지 못하는 문제와, 매번 같은 강화만 누르는 문제를 구분한다. 카드 사용량보다 선택 이유와 결과에 대한 영향력을 본다.

독립적인 한 턴 장면을 사용한다. 장기 덱 전략과 다음 턴의 가치까지 판단하지 않는다. 아무 카드도 쓰지 않는 것이 적절한 장면도 포함한다.

## 2. 장면과 비교 조건

모든 수치·카드 효과는 실험용이다. 입구 0, 슬롯 1~8, 출구 9. 손패 4장을 받은 뒤 눈 공개 전부터 시작한다. 직원 사용 뒤 이동하며, 눈과 마나는 같다. 배치·융합·경제·소진·보스는 제외한다.

| 위치 | 타일 | 효과 |
| --- | --- | --- |
| 1, 4 | 속삭임 | 통과: 불안 +1 |
| 2, 8 | 빈 복도 | 없음 |
| 3, 7 | 거울 | 도착: 불안 2 이상이면 2 소비, 공포 +8 |
| 5 | 큰 거울 | 도착: 불안 3 이상이면 3 소비, 공포 +14, 심장 부담 +3 |
| 6 | 진정실 | 통과: 심장 부담 -2, 최저 0 |

수확 조건이 부족하면 소비·공포·부담 모두 발생하지 않는다. 심장 부담 한계는 12이며 도달 시 즉시 종료한다. 출구 첫 도달에도 종료한다. 사망 시 수익 정산은 이번 실험에서 다루지 않는다.

| 카드 | 마나 | 실험용 효과 |
| --- | ---: | --- |
| G 조명기사 | 2 | 이번 경로의 수확 타일 하나를 강화. 이번 턴 실제 수확 시 공포 +4 |
| S 속삭임 담당 | 1 | 손님에게 즉시 불안 +1 |
| R 진정 담당 | 2 | 손님의 심장 부담 -3, 최저 0 |
| P 준비 담당 | 2 | 남은 경로의 속삭임 타일 하나를 지정. 다음 통과 때 불안 +1 추가, 1회 |

각 카드는 한 번 사용한다. G는 턴 종료, P는 발동 또는 퇴장·사망에 만료한다. 유효 대상이 없으면 G/P는 사용할 수 없다. 사용 가능하더라도 현재 목표에 기여하지 않는 카드가 있을 수 있다.

**목표:** 손님을 살려 두면서 이번 장면에서 공포를 얻는다. 아래 장면은 매번 공포 0·기본 손패 G/S/R/P로 새로 시작한다.

| 장면 | 위치 | 불안 | 부담 | 공개할 눈/마나 | 확인할 경험 |
| --- | ---: | ---: | ---: | ---: | --- |
| A 수확 준비 | 0 | 0 | 2 | 3 | 공급과 강화 중 무엇을 왜 고르는가 |
| B 위험한 수확 | 2 | 2 | 9 | 3 | 수익을 보며 회복의 역할을 읽는가 |
| C 작은 눈 | 5 | 0 | 4 | 1 | 비용·대상 제약이 얼마나 답답한가 |
| D 출구 직전 | 7 | 0 | 4 | 3 | 쓰지 않는 선택을 납득하는가 |

A~D는 맥락을 달리한 진단 장면이므로 차이를 마나 하나의 효과로 해석하지 않는다. C 이후의 미래 수익은 실제로 시험하지 않는다.

추가로 A의 상태에서 **H0: G1/G2/R1/R2 ↔ H1: G1/G2/R1/S**를 비교한다. R2 한 장만 S로 바꾸어 공급 카드 접근성의 영향을 본다. 같은 문자 카드는 동일 효과의 별개 직원이며, 카드 수·마나·지도는 같다.

## 3. 진행 방법

1. 눈 확인 → 카드 사용 → 이동 순서를 설명한다. 참가자별 A~D 순서를 달리 배정한다.
2. 각 장면의 상태를 확인한 뒤 눈을 공개한다. 카드를 쓰거나 바로 이동하게 하고, 선택 이유를 받는다.
3. 이동 결과를 본 직후 Q1~Q7을 평가한다. 못 했던 행동과 그 이유가 손패·비용·대상 중 무엇이었는지 구체적으로 묻는다.
4. H0/H1을 순서를 나누어 진행하고 각각 평가한다. A에서 배운 내용이 있으므로 최초 발견이 아닌 접근성 비교로 기록한다.
5. 모든 평가 뒤 조건별 결과를 비교한다. ‘상황을 보고 판단한 장면’과 ‘할 일이 없거나 정해져 있던 장면’을 이유와 함께 고르게 한다.

한 장면은 이번 이동 종료까지다. 결과를 보고 다른 카드를 쓰는 재시도는 최초 선택과 구분한다. 피로하면 A~D와 H0/H1을 두 블록으로 나눈다.

## 4. 검증 UI 구성

| 화면 | 표시와 조작 | 연결 문항 |
| --- | --- | --- |
| 상황판 | 위치·불안·공포·부담/12, 현재 눈·마나·이동 경로·도착/출구 | Q1 |
| 손패 작업대 | 카드 비용·효과·대상·사용 불가 이유. 카드/대상 선택과 사용 확정, 바로 이동 | Q2, Q3, Q6 |
| 결과 복기 | 실제 카드와 타일 효과, 상태 변화, 생존/퇴장. 참가자가 바꾼 결과와 선택 이유를 돌아보기 | Q4, Q5 |
| 경험 평가 | Q1~Q7의 미선택 1~5점·N/A·이유/장면. 도움이 필요했다면 그 내용을 함께 기록 | 전체 |
| 진행자 비교 | 장면별 점수와 문항별 중앙값·1~2점 수·N/A 수. 사용 카드·의도적 미사용·막힌 행동을 함께 확인 | 핵심 Q3·Q4·Q7 |

참가자에게 추천 카드나 다른 조건의 해법을 먼저 보여주지 않는다. 점수 비교는 모든 조건 평가 뒤 공개한다. 공통 설문 방식은 [전체 계획](prototypes-main.md)을 따른다.

## 5. 경험 validation: 질문–점수

각 장면 직후 **1~5점의 `점수/5 + 이유 + 장면`**으로 답한다. 1은 전혀 그렇지 않다, 5는 매우 그렇다. 미경험 항목은 N/A다.

| ID | 평가 요소 | 참가자 질문 | 응답 |
| --- | --- | --- | --- |
| Q1 | 상황 이해 | 현재 눈을 보고 이번 이동에서 중요한 타일을 파악할 수 있었다. | __/5 |
| Q2 | 대응 수단 | 결과를 바꾸기 위해 필요하다고 느낀 행동을 실행할 수 있었다. | __/5 |
| Q3 | 선택의 재미 | 카드를 쓸지, 무엇을 쓸지 판단하는 과정이 흥미로웠다. | __/5 |
| Q4 | 영향력 | 내 카드 선택이 결과에 영향을 주었다고 느꼈다. | __/5 |
| Q5 | 결과 납득 | 카드를 사용하거나 사용하지 않은 결과를 납득할 수 있었다. | __/5 |
| Q6 | 조작 부담 | 카드 사용에 필요한 조작량은 적절했다. | __/5 |
| Q7 | 다음 판단 의향 | 다른 이동 상황에서도 카드 선택을 해보고 싶다. | __/5 |

핵심은 **Q3·Q4·Q7**이며, 의미 있는 개입이 가능한 A/B와 H1에서 문항별 중앙값 4/5 이상 및 이유·행동의 부합을 임시 진행 기준으로 삼는다. C/D는 개입이 적은 턴의 수용 여부를 보는 장면이므로 Q4가 낮다는 이유만으로 실패로 정하지 않는다. 1~2점 응답은 장면별로 따로 읽는다.

## 6. 결과를 읽고 다음 실험 정하기

| 점수·행동 패턴 | 원인 후보 | 다음 조치 |
| --- | --- | --- |
| H1에서 H0보다 Q2·Q4가 높아지고 공급 선택이 등장 | 필요한 카드에 접근하기 어려움 | [P3 덱 소진](prototype-3.md)에서 접근 기회가 사라지는 순간 비교 |
| A/B에서도 Q3가 낮고 같은 행동만 반복하며 이유가 없음 | 선택이 자명하거나 효과 차이가 빈약함 | 카드의 역할·대상 선택을 조정한 한 턴 재시험 |
| Q1·Q5는 높지만 Q6가 낮음 | 판단보다 조작이 부담 | 동일 효과를 유지하며 조작 단계를 줄여 비교 |
| C/D의 Q4는 낮아도 Q5·Q7이 높고 미사용 이유가 명확 | 자연스러운 쉬는 턴으로 수용 | [P11 반복 운영](prototype-11.md)에서 이런 턴의 빈도를 시험 |

상황 이해가 낮다면 영향력 부족과 구분해 판단을 유보한다. 클릭 수·사용 카드 수·수익을 경험 점수로 대체하지 않는다. 위험 때문에 회복만 고른다는 반응은 [P6 심장 부담](prototype-6.md)으로 연결한다.
