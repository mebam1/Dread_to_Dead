# P11 — 안정 운영의 반복, 처리 속도와 원인 표시

[전체 계획](prototypes-main.md) · 관련: [P1 배치](prototype-1.md), [P2 개입](prototype-2.md), [P10 상실](prototype-10.md) · v0.2 / 2026-10-29 / 실험 전

## 1. 확인할 경험

안정적으로 작동하는 호텔을 반복 운영할 때 **성과를 감상하는 즐거움이 남는가?** 자동 처리의 기다림과 결과 원인의 불명확함이 각각 재미를 낮출 수 있다. 속도 비교 A와 원인 표시 비교 B를 분리해 어떤 문제인지 확인한다.

근거: rules.md §5.2·§6.3·§8.6. 안정 운영 자체는 의도된 성취 구간이다. 모든 턴에 새 고민을 요구하거나 빠른 처리를 좋아한다는 이유로 전략이 불필요하다고 판단하지 않는다.

## 2. 공통 장면

입구 0, 슬롯 1~8, 출구 9. 새 손님은 불안·공포 0, 환청은 지정된 시작값으로 출발한다. 직원·소진·심장 부담·투자·보스는 제외한다. 비교 중 배치는 고정하고 종료 뒤 수정 기회를 준다. 아래 타일과 수치는 실험용이다.

| 슬롯 | 타일 | 통과 효과 | 도착 효과 |
| --- | --- | --- | --- |
| 1·2 | 속삭임 복도 2개 | 각각 환청 +1 | 없음 |
| 3 | 거울 방 | 환청 +1 | 환청이 2 이상이면 2 소비, 공포 +8. 부족하면 발동 없음 |
| 4 | 고해 통로 | 남은 환청 전부 소비, 1개당 불안 +2 | 없음 |
| 5 | 기록 벽 | 불안 +1 | 없음 |
| 6 | 초상화 방 | 없음 | 불안 전부 소비, 1개당 공포 +3 |
| 7·8 | 빈 슬롯 | 없음 | 없음 |

통과 효과는 도착 타일에도 먼저 적용한다. 일반 손님은 출구에서 퇴장하며 상태는 다음 손님에게 이월하지 않는다. 이동 결과는 배정된 시범 경로이고 무작위 수익성을 평가하지 않는다.

## 3. 비교 조건과 진행

### A. 처리 속도 — 1인 약 15~20분

| 조건 | 바꾸는 요소 | 고정할 요소 |
| --- | --- | --- |
| A1 | 상태 변화 사건당 표시 1.2초 | 호텔, 시작 환청 0, 손님 6명, 경로 3→3→3, 표시 내용, 진행 입력 수 |
| A2 | 같은 사건당 표시 0.3초 | A1과 동일. 이동·출구·화면 전환 시간도 동일 |

1. 연습 손님 1명으로 공급→일부 소비→잔여 변환→후속 수확을 경험한다. 참가자가 원인을 설명하는지 듣는다.
2. A1/A2 중 배정된 조건으로 6명을 연속 운영한다. 참가자마다 순서를 번갈아 배정하고, 반복 중에는 설문을 띄우지 않는다.
3. 블록 직후 A용 질문을 평가한다. 짧게 쉬고 다른 조건을 경험한 뒤 같은 질문에 답한다.
4. 모든 점수를 제출한 후 원하는 속도를 선택하고, 추가 영업/배치 수정/종료 중 하나를 실제로 선택하게 한다.

일시정지·지난 결과 보기는 양쪽에 제공한다. 비교 중 속도는 고정하고 자유 선택은 마지막에 둔다. 처리 시간이 짧아지는 것은 설정의 결과이며 재미 개선의 증거는 경험 응답과 행동에서 찾는다.

### B. 원인 표시 — 1인 약 12~18분

| 조건 | 사건 표시 | 고정할 요소 |
| --- | --- | --- |
| B1 변화값 | 환청 -2, 공포 +8처럼 수치 변화 중심 | 사건당 0.6초, 타일 상세, 현재 위치·상태, 실제 변화량 |
| B2 원인 연결 | 거울 방 → 환청 2 소비 → 공포 8처럼 원인과 결과를 연결 | B1과 동일한 사실. 추천 행동은 추가하지 않음 |

1. 처음에는 참가자를 B1/B2로 나눈다. 이미 A를 충분히 반복한 참가자는 피한다.
2. 기본 경로 3→3→3을 경험한다. 초기 환청 0/1 장면은 양 조건에 고르게 배정한다. 결과 뒤 “어떤 타일의 어떤 변화가 이 수확을 만들었나요?”라고 묻는다.
3. 초기 환청은 기본 장면과 같게 두고 처음 보는 경로 4→2→3으로 운영한다. 미래 눈 전체는 숨기고, 현재 눈이 공개될 때 이번 이동 뒤의 변화를 예상하게 한다. 거울에 도착하지 않는 상황에서도 원인을 적용하는지 본다.
4. B용 질문에 답한 뒤 선택적으로 다른 표시를 경험하고 선호를 받는다. 두 번째 표시의 응답은 학습 후 참고로 구분한다. 마지막에는 추가 영업/배치 수정/종료 중 실제 행동을 선택하게 한다.

B2 설명을 읽은 직후 같은 문구를 반복하는 것과 처음 보는 이동에서 관계를 적용하는 것을 구분한다. 새 경로에서 결과를 보기 전에 받는 예측도 기본 표시를 경험한 뒤의 전이 근거로 해석한다.

## 4. 검증 UI

| 화면 | 표시와 조작 | 연결되는 경험 |
| --- | --- | --- |
| 호텔·진행 | 슬롯, 현재 눈·상태, A의 손님 번호/6 또는 B의 기본 장면/새 경로, 현재·누적 공포. 다음 턴·다음 손님 진행 | 반복의 길이와 성과 감상 |
| 사건 보기 | A는 같은 정보를 다른 속도로, B는 같은 속도에서 표시 형식만 변경. 일시정지·지난 결과 열람 | Q1~Q4, 속도와 이해 부담 |
| 원인 설명 | B에서 현재 이동의 예상 변화 입력, 처리 후 원인 자유 설명. 아직 처리하지 않은 정답은 표시하지 않음 | Q3·Q7의 실제 이해 근거 |
| 조건별 설문 | 해당 질문마다 1~5점, 이유·기억나는 장면, N/A. 상대 조건 점수는 마지막에 공개 | 조건별 경험을 독립 평가 |
| 자유 선택 | 속도/표시 선호, 추가 영업/배치 수정/종료 선택 | Q6·Q8과 실제 행동 |
| 진행자 비교 | 문항별 점수, 선호 이유, 재확인·멈춤, 원인 설명, 첫 노출/학습 후 구분. 처리·재확인·설문 시간을 나란히 표시 | 빨라진 시간과 줄어든 체감 부담의 구분 |

공통 평가 화면과 기록 양식은 [전체 계획](prototypes-main.md)을 따른다. 참가자의 설명을 채점 정답으로 대체하거나 총 공포를 재미 점수로 사용하지 않는다.

## 5. 경험 validation — 질문과 5점 응답

1=전혀 그렇지 않다, 5=매우 그렇다. **점수마다 이유 한 줄과 해당 장면을 받는다.** 사용하지 않은 시험 문항은 N/A다.

| ID / 대상 | 평가 요소 | 참가자 질문 | 응답 |
| --- | --- | --- | --- |
| Q1 / A | 진행 속도 | 결과를 처리하는 속도가 내게 적절했다. | __/5 |
| Q2 / A·B | 변화 추적 | 화면에서 상태가 어떻게 바뀌는지 따라갈 수 있었다. | __/5 |
| Q3 / A·B | 원인 이해 | 어떤 타일이 공포를 만들었는지 이해할 수 있었다. | __/5 |
| Q4 / A·B | 확인 부담 | 결과를 이해하는 데 필요한 확인 노력이 감당할 만했다. | __/5 |
| Q5 / A | 성취감 | 호텔이 반복해서 수익을 내는 모습을 보며 성취감을 느꼈다. | __/5 |
| Q6 / A | 반복의 즐거움 | 같은 호텔이 작동하는 모습을 여러 번 보는 것이 즐거웠다. | __/5 |
| Q7 / B | 수정 가능성 | 결과를 보고 어떤 타일의 관계를 바꿔볼지 떠올릴 수 있었다. | __/5 |
| Q8 / A·B | 지속 의향 | 이 표시 방식으로 한 번 더 운영하고 싶다. | __/5 |

**A 핵심: Q1·Q2·Q6. B 핵심: Q3·Q7·Q8.** 각 중앙값 4/5 이상을 임시 진행 신호로 삼되 이유와 실제 선택을 함께 본다. B는 새 장면에서 원인을 설명하는지도 확인한다. 조건별 1~2점 응답을 별도로 보고하며, 평균 하나로 속도나 표시를 결정하지 않는다.

| 점수·행동 패턴 | 해석할 문제 | 다음 조정 |
| --- | --- | --- |
| A2에서 Q1·Q6 상승, Q2·Q3 유지 | 처리 대기가 반복의 즐거움을 낮췄을 가능성 | 더 큰 호텔에서도 속도 선택 비교 |
| A2에서 Q1 상승, Q2·Q4 하락·재확인 증가 | 빠른 처리와 이해 부담의 교환관계 | 핵심 효과 강조 또는 선택적 정지 |
| B2에서 Q3·Q7 상승, 새 장면 설명도 개선 | 원인 연결의 가독성이 부족했을 가능성 | [P1](prototype-1.md)·[P4](prototype-4.md)에 표시 방식 적용 검토 |
| Q2·Q3은 높지만 Q6·Q8은 낮음 | 이해보다 반복 길이·다음 결정의 부족 가능성 | [P7](prototype-7.md)의 다음 투자 시점과 짧게 결합 |

안정 수익 감상을 선호하면 성취 구간으로 유지할 여지가 있다. 반대로 학습·피로·진행자 설명이 조건 차이와 겹치면 결론을 유보하고 첫 노출 비교를 추가한다.
