# P1. 배치를 설계하고 고치는 재미

[전체 계획](prototypes-main.md) · **v0.2 / 2026-10-29 / 검증 전**  
기준: rules.md v0.4 §2.1~2.2, §5.1~5.2, §6.1~6.2. 예상 25~35분.

## 1. 질문과 재미 하락 위험

**타일 순서와 수확 위치를 바꾸는 일이 성취와 다음 시도를 만드는가?** 공급 타일을 앞에 몰아놓는 작업만 반복되거나, 도착 운에 따라 수확이 빗나가 설계의 의미를 느끼지 못할 수 있다. 안정적인 배치를 찾고 유지하는 선택은 허용한다.

직원·융합·경제·위험을 제외한 배치 실험이다. 장기 전략 다양성이나 실제 무작위 영업의 평균 수익까지 판단하지 않는다.

## 2. 장면과 비교 조건

아래 수치와 자산은 모두 실험용이다. 입구 0, 슬롯 1~8, 출구 9를 사용한다. 손님은 불안 0·공포 0으로 시작하고 출구 첫 도달에 퇴장한다. 배치 비용은 없으며, 직원 모듈 전체를 제외한다.

| 자산 | 개수 | 효과 |
| --- | ---: | --- |
| S1~S3 속삭임 | 3 | 통과: 불안 +1 |
| L1~L2 작은 거울 | 2 | 도착: 불안 2 이상이면 2 소비, 공포 +6 |
| J 큰 거울 | 1 | 도착: 불안 3 이상이면 3 소비, 공포 +12 |
| E1~E2 빈 슬롯 | 2 | 효과 없음 |

요구 불안이 부족하면 수확하지 않는다. 도착 타일에서도 통과 효과를 먼저 처리한다. 한 슬롯에 한 항목을 놓으며, 모든 항목을 한 번씩 사용한다. 첫 배열은 **S1 → S2 → L1 → E1 → S3 → J → L2 → E2**다.

| 비교 | 바꾸는 것 | 고정하는 것 / 읽을 결과 |
| --- | --- | --- |
| 최초 배열 ↔ 수정 배열 | 타일 위치 | 같은 타일·초기 상태·주사위 묶음. 수정 이유와 설계 영향의 체감 |
| 세트 A ↔ 세트 B | B의 작은 거울만 불안 2를 참조하고 소비하지 않음 | 수량·문턱·공포량·큰 거울은 동일. 소비 관계가 바뀌면 판단도 바뀌는지 |

B는 수익이 늘기 쉬우므로 공포량으로 A/B의 재미 우열을 정하지 않는다. 여러 참가자에게 A→B와 B→A 순서를 나누어 배정한다.

**진행자용 이동 묶음:** 참가자에게는 현재 눈만 공개한다.

| 용도 | 손님별 주사위 순서 |
| --- | --- |
| D: 첫 실행과 수정 비교 | D1: 2→2→2→3 / D2: 3→1→3→2 / D3: 1→4→2→2 |
| V: 배열 확정 후 처음 보는 이동 | V1: 4→1→1→3 / V2: 6→3 / V3: 5→4 |

## 3. 진행 방법

1. 통과·도착의 차이를 짧게 설명한다. 참가자가 첫 배열을 유지하거나 바꾸고, 기대하는 연결 한 가지를 말하게 한다.
2. D의 손님 3명을 운영한다. 결과를 보고 배열을 한 번 수정하거나 유지하게 하고 이유를 받는다. 같은 D로 수정 결과를 비교한다.
3. 배열을 확정한 뒤 V의 손님 3명을 운영한다. 도착이 달라졌을 때 자신의 배치를 어떻게 해석하는지 묻고, 아래 질문별 점수를 받는다.
4. 다른 세트의 달라진 효과만 알려주고 2~3단계와 동일하게 D 실행·수정·V 실행·평가를 반복한다. 두 번째 세트는 이미 본 이동에 새로운 관계를 적용한 자료로 구분한다. 세트별 첫 노출 점수를 주 비교로, 같은 사람의 두 조건 선호를 보조로 본다.
5. 두 평가를 마친 뒤 선호 조건과 이유를 묻는다. 추가 1회 시험 또는 종료를 선택하게 하고, 시험한다면 무엇을 바꿀지 기록한다.

각 조건의 최초 설명과 힌트 후 설명을 구분한다. 자발적 유지와 막혀서 아무것도 못 바꾼 경우는 이유로 구분한다.

## 4. 검증 UI 구성

| 화면 | 표시와 조작 | 연결 문항 |
| --- | --- | --- |
| 배치판 | 입구·출구·슬롯 번호, 타일별 통과/도착 효과. 타일 교환·효과 열람·배치 확정과 기대 문장 입력 | Q1, Q2 |
| 운영 화면 | 현재 눈·경로·불안·공포, 실제 발생한 공급·소비·수확. 이동 진행과 완료 사건 다시 보기 | Q1, Q3, Q5 |
| 결과 복기 | 최초/수정 배열, 손님별 수익, 수확한 타일, 남은 불안. 차이를 보고 수정 이유 입력 | Q3, Q4, Q6 |
| 경험 평가 | Q1~Q7 각각 미선택 1~5점, N/A, 이유·기억나는 장면. 제출 뒤 추가 시험/종료 선택 | 전체 |
| 진행자 비교 | 참가자×세트×문항 점수, 문항별 중앙값·1~2점 수·N/A 수. 수정 내용·발언·추가 시험을 함께 비교 | 핵심 Q3·Q4·Q7 |

미래 눈이나 추천 배치는 플레이 화면에 넣지 않는다. 이전 점수와 두 조건의 비교는 각 조건 평가를 모두 마친 뒤 보여준다. 공통 설문 조작과 기록 방식은 [전체 계획](prototypes-main.md)을 따른다.

## 5. 경험 validation: 질문–점수

조건 직후 각 문장에 **1~5점으로 응답하고 `점수/5 + 이유 + 장면`**을 남긴다. 1은 전혀 그렇지 않다, 5는 매우 그렇다. 경험하지 못한 항목은 N/A다. 아래 빈칸은 실제 연구에서 채운다.

| ID | 평가 요소 | 참가자 질문 | 응답 |
| --- | --- | --- | --- |
| Q1 | 인과 이해 | 앞 타일이 만든 불안이 뒤 타일에서 어떻게 쓰였는지 이해했다. | __/5 |
| Q2 | 선택의 의미 | 배치할 때 서로 다른 장점을 가진 대안을 고민할 수 있었다. | __/5 |
| Q3 | 설계 영향 | 내가 정한 타일 순서가 결과에 영향을 주었다고 느꼈다. | __/5 |
| Q4 | 성취 | 내가 설계한 연결이 작동하는 모습을 보는 것이 만족스러웠다. | __/5 |
| Q5 | 우연의 수용 | 수확 위치에 도착하지 못한 결과도 받아들일 만했다. | __/5 |
| Q6 | 개선 가능성 | 결과를 본 뒤 다음에 시험할 배치 아이디어가 떠올랐다. | __/5 |
| Q7 | 재시도 의향 | 다른 배치를 한 번 더 시험하고 싶다. | __/5 |

핵심은 **Q3·Q4·Q7**이다. 문항별 중앙값 4/5 이상과 구체적인 이유·행동의 부합을 다음 실험 진행의 임시 기준으로 삼는다. 각 문항의 1~2점 응답을 따로 읽고, 전체 평균 하나로 통과시키지 않는다.

## 6. 결과를 읽고 다음 실험 정하기

| 점수·행동 패턴 | 원인 후보 | 다음 조치 |
| --- | --- | --- |
| Q1이 낮고 공급/소비 설명도 불명확함 | 효과 관계를 읽기 어려움 | 실제 사건의 상태 변화 표시를 다듬고 새 참가자에게 반복 |
| Q1·Q3은 높지만 Q2·Q6·Q7이 낮음 | 선택을 이해했지만 더 탐색할 관계가 부족함 | 타일의 수치보다 공급·소비 관계를 바꿔 재시험 |
| Q5가 낮고 빗나간 손님 뒤 의욕이 꺾임 | 도착 운이 설계 성취를 가림 | 같은 배치에 [P2 직원 개입](prototype-2.md)을 붙여 대응 경험 비교 |
| Q4는 높고 Q7은 낮지만 유지 이유가 구체적임 | 만족스러운 안정화 또는 피로 | 종료 이유를 확인하고 [P11 반복 운영](prototype-11.md)에서 분리 |

설문과 행동이 어긋나거나 시간 때문에 중단했다면 결론을 유보한다. 높은 공포 수익 자체를 재미의 증거로 쓰지 않는다.
