# P4 — M4 중심 / M6 대조군 융합 실험

> 개정: 2026-10-29  
> 실험 구조: **M4를 주평가 대상으로 두고, M6는 대조군으로 비교**  
> 공통 전제: **직원 한 명을 선택하면, 현재 보유 직원·자원 안에서 그 직원을 포함해 만들 수 있는 괴이 목록을 보여준다.**

## 1. 실험 목적

이 실험의 핵심은 **플레이어가 직관적으로 “괴이를 합성한다”는 경험을 느끼는지** 확인하는 것이다.

현재 가설은 다음과 같다.

- **M4**는 직관적으로 괴이를 합성하는 느낌을 주기 쉽다.
- **M6**는 결과를 설계하는 느낌은 줄 수 있지만, 현재 형태로는 다소 프로그래밍적일 수 있다.

따라서 P4는 **M4를 중심으로 검증**한다. M6는 “계승 요소를 직접 고르게 하면 실제로 더 좋은 경험이 생기는가?”를 보기 위한 **대조군**으로 둔다. 이번 실험의 목표는 M4와 M6를 동등하게 경쟁시키는 것이 아니라, **M4가 실제로 핵심 제작 재미를 잘 만드는지 확인하고, M6가 그보다 나은 점이 있는지 비교하는 것**이다.

## 2. 이번 실험에서 확인할 질문

### 주질문

1. M4는 플레이어에게 **괴이를 만든다**는 직관적인 경험을 주는가?
2. M4에서도 현재 호텔에 맞는 괴이를 충분히 계획적으로 선택할 수 있는가?
3. M6의 추가 선택 과정은 실제 도움이 되는가, 아니면 같은 결과를 만들기 위한 절차 증가에 그치는가?

### 해석 원칙

- **제작 재미는 M4가 우세할 가능성**을 우선 확인한다.
- **전략적 활용은 M4에서도 가능한지** 먼저 본다.
- M6가 더 높은 평가를 받더라도, 그것을 곧바로 “최종 채택”으로 해석하지 않는다. 우선 **왜 더 높았는지**를 분해해 본다.

## 3. 비교 대상

| 구분 | M4 — 결과 후보 선택 | M6 — 능력 계승 선택 |
|---|---|---|
| 실험 내 역할 | **주평가 대상** | **대조군** |
| 제작 감각 | 완성된 괴이를 선택하고 합성 | 능력 요소를 고르며 결과를 구성 |
| 기대 강점 | 직관성, 즉각적인 제작 재미 | 관계 이해, 추가적 계획성 가능성 |
| 우려 | 단순 선택 메뉴로 느껴질 수 있음 | 절차가 길고 프로그래밍적으로 느껴질 수 있음 |

## 4. 공통 시작 상태

| 항목 | 내용 |
|---|---|
| 콘텐츠 규모 | 직원 8명, 재료 조합 12쌍, 결과 괴이 24종 |
| 결과 집합 | 같은 자원 상태에서 만들 수 있는 최종 괴이 집합은 M4와 M6가 동일 |
| 자원 | 보유 직원 풀과 추가 비용을 장면마다 고정 |
| 호텔 | 이미 일부 공급·수확 구조가 있는 작은 호텔 |
| 제작 횟수 | 장면당 최대 2회 |
| 자산 처리 | 제작 시 직원과 비용 소모, 제작 후 목록 갱신 |
| 공개 정보 | 괴이의 핵심 법칙, 필요한 상대 직원, 비용, 운용 조건은 양쪽 모두 공개 |

## 5. 공통 UI — 선택 직원 기준 제작 가능 괴이 목록

### 5.1 기본 흐름

1. 보유 직원 한 명을 선택한다.
2. 그 직원을 포함해 **현재 자원 안에서 제작 가능한 괴이 목록**이 뜬다.
3. 목록에서 각 괴이의 법칙, 필요한 상대 직원, 비용, 운용 조건을 본다.
4. 이후 M4와 M6는 다른 방식으로 제작을 확정한다.

### 5.2 목록 포함 기준

목록에는 다음을 모두 만족하는 괴이만 나온다.

- 선택한 직원이 재료에 포함된다.
- 필요한 상대 직원도 현재 보유 중이다.
- 필요한 수량을 충족한다.
- 현재 비용으로 제작 가능하다.

### 5.3 목록에서 보여줄 정보

| 항목 | 표시 내용 |
|---|---|
| 괴이 이름 | 이름과 한 줄 법칙 |
| 제작 조건 | 필요한 상대 직원, 수량, 추가 비용 |
| 역할 | 공급 / 변환 / 수확 / 지원 등 |
| 현재 호텔과의 관계 | 필요한 입력 상태, 현재 활용 가능 여부 |
| 제작 후 변화 | 소모될 직원과 비용, 제작 후 남는 자원 |

### 5.4 중요한 원칙

- **제작 가능**과 **현재 호텔에서 바로 잘 활용 가능**은 구분한다.
- 목록에 여러 괴이가 떠도, 그것은 각 괴이가 **지금 개별적으로 제작 가능**하다는 뜻이지 모두 동시에 만들 수 있다는 뜻은 아니다.
- 하나를 제작하면 남은 직원·자원 기준으로 목록을 다시 계산한다.
- 결과가 없을 때는 “이 직원을 포함해 현재 제작 가능한 괴이가 없음”과 이유를 함께 보여 준다.

## 6. M4와 M6의 차이

| 단계 | M4 — 결과 후보 선택 | M6 — 능력 계승 선택 |
|---|---|---|
| 시작 | 직원 1명 선택 → 제작 가능 목록 확인 | 동일 |
| 목록의 역할 | **제작 대상을 직접 고르는 핵심 화면** | 가능한 결과를 이해하는 참고 화면 |
| 핵심 선택 | 괴이 자체를 고름 | 상대 직원 + 계승 요소를 고름 |
| 상세 패널 | 괴이의 법칙과 소모 자산 확인 | 계승 요소에 따라 어떻게 결과가 달라지는지 확인 |
| 확정 | 선택한 괴이를 제작 | 계승 선택 결과를 제작 |

### M4

- 플레이어는 “이 직원으로 지금 만들 수 있는 괴이 중 무엇을 만들까?”를 고민한다.
- 실험에서 **가장 중요하게 볼 대상**이다.

### M6

- 플레이어는 결과를 아는 상태에서도 추가로 계승 요소를 선택한다.
- 이 과정이 실제로 이해를 돕는지, 아니면 **이미 보이는 괴이를 만들기 위해 클릭만 더 하는지**를 본다.
- 따라서 M6는 이번 실험에서 **대조군**이다.

## 7. 실험 절차

### A. 연습

- 직원 선택
- 제작 가능 괴이 목록 읽기
- 괴이 하나 제작하기
- 제작 후 자원 변화 보기

연습은 두 조건 모두 같은 수준으로 제공한다.

### B. 자유 제작

현재 자원 안에서 만들고 싶은 괴이를 자유롭게 고른다.

관찰 포인트:
- 어떤 직원을 먼저 눌러 보는가?
- 목록을 보고 다른 괴이도 탐색하는가?
- 첫 제작 뒤 남은 자원에 맞춰 두 번째 제작을 다시 계획하는가?

### C. 상황 기반 제작

같은 자원 구조에서 다음 두 상황을 준다.

| 상황 | 과제 |
|---|---|
| 공급과 수확의 불일치 | 현재 공급원을 활용하거나 바꿔서 더 잘 맞는 괴이를 제작 |
| 같은 상태의 사용 경쟁 | 앞쪽과 뒤쪽의 상태 사용 충돌을 줄일 수 있는 괴이를 제작 |

정답 괴이 이름은 주지 않는다. 현재 자원 안에서 여러 해법이 존재하도록 구성한다.

### D. 조건 순서

- 참가자를 **M4→M6 / M6→M4**로 나눈다.
- 두 조건의 시작 자원과 호텔 난도는 맞춘다.
- 한 조건에서 사용한 직원과 비용은 다음 조건으로 이월하지 않는다.

## 8. 경험 validation — 유저스터디 질문

모든 문항은 **1~5점**으로 답한다.  
기준: **1 전혀 아니다 / 2 아니다 / 3 보통 / 4 그렇다 / 5 매우 그렇다**

각 문항마다
- 점수: `__/5`
- 이유 한 줄
- 기억나는 장면 한 줄
을 함께 적는다.

### 8.1 핵심 문항

| 구분 | 질문 | M4 | M6 |
|---|---|---|---|
| F1 | 제작 과정 자체가 재미있었나요? | __/5 | __/5 |
| F2 | 두 직원을 합쳐 새로운 괴이를 만든다는 느낌이 들었나요? | __/5 | __/5 |
| F3 | 다른 조합도 계속 만들어 보고 싶었나요? | __/5 | __/5 |
| S1 | 현재 호텔에 맞는 괴이를 계획적으로 만들 수 있었나요? | __/5 | __/5 |
| S2 | 여러 괴이의 장단점을 비교해 선택할 수 있었나요? | __/5 | __/5 |
| U1 | 선택한 직원으로 지금 만들 수 있는 괴이를 파악하기 쉬웠나요? | __/5 | __/5 |
| C1 | 왜 이런 괴이가 나오는지 두 직원의 관계를 이해했나요? | __/5 | __/5 |
| B1 | 제작 과정의 조작이 의미 있는 선택으로 느껴졌나요? | __/5 | __/5 |

### 8.2 M6 대조군 해석용 추가 확인

| 구분 | 질문 | M6 |
|---|---|---|
| M6-A | 계승 요소를 고르는 과정이 결과 이해에 실제로 도움이 되었나요? | __/5 |
| M6-B | 계승 요소 선택이 괴이를 만드는 느낌보다 설정을 조립하는 느낌에 가까웠나요? | __/5 |

> M6-B는 역문항으로 해석한다. 점수가 높을수록 프로그래밍적이라는 인상이 강한 것이다.

## 9. 행동 관찰 포인트

| 영역 | 볼 것 |
|---|---|
| 목록 이해 | 선택 직원 기준으로 가능한 결과를 설명할 수 있는가? |
| 제작 재미 | 자발적으로 다른 괴이를 눌러 보고 비교하는가? |
| 전략적 활용 | 제작 전에 호텔과의 연결을 설명하고, 실제 배치에 반영하는가? |
| M6의 필요성 | M6에서 추가 선택이 판단에 도움을 줬는가, 아니면 동일 결과를 위한 절차 증가였는가? |

## 10. 판정 원칙

### 10.1 기본 원칙

- **P4의 1차 목적은 M4 검증**이다.
- 따라서 최종 정리는 “M4가 핵심 제작 재미를 충분히 만드는가?”를 중심으로 한다.
- M6는 “추가적인 계승 선택이 그 재미를 보완하는가, 해치는가?”를 보는 대조군이다.

### 10.2 해석 방법

- **M4의 F1·F2·F3가 높고**, 실제로 자발적 탐색이 나오면 → M4의 제작 재미 가설을 지지.
- **M4의 S1·S2도 충분히 높으면** → M4만으로도 전략적 활용성이 가능하다고 본다.
- **M6의 S1이 더 높더라도**, B1이 낮고 M6-B가 높으면 → 전략성 일부는 늘었지만 제작 경험은 악화된 것으로 해석한다.
- **M6-A가 높고 M6-B가 낮으며**, C1·S1이 함께 개선되면 → M6식 요소가 실제 보완 장치가 될 가능성을 남긴다.

### 10.3 보고 방식

보고서는 다음 형식으로 정리한다.

1. **M4의 제작 재미 검증 결과**
2. **M4의 전략적 활용 가능성**
3. **M6 대조군 비교 결과**
4. **M6가 추가 가치가 있었는지 / 절차만 늘렸는지**
5. **후속 결정**
   - M4 유지
   - M4 유지 + 일부 M6 요소만 차용 검토
   - M4 자체 보완 필요

## 11. 이번 변경의 의미

이번 개정으로 P4는 더 이상 “M4와 M6를 대등하게 경쟁시키는 실험”이 아니다.  
이제 P4는 **M4를 주된 후보로 검증하고, M6를 대조군으로 두어 M4의 장점과 한계를 더 분명하게 확인하는 실험**이다.

즉 핵심 질문은 다음과 같다.

> **플레이어는 괴이를 ‘프로그래밍’하기보다, 직관적으로 ‘합성’하는 경험을 원하고 있는가?**

이 질문에 답하는 것이 이번 P4의 목적이다.
