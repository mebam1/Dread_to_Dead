## 1. 확인할 질문

제한된 직원 공급 때문에 재설계가 막히는 것처럼 보여도, 실제 원인은 연결할 수 있는 괴이의 종류가 적기 때문일 수 있다. **결과 목록의 개수**와 **서로 다른 작동 관계의 다양성**을 나누어 비교한다. 새로운 조합이 선택권을 늘리는지, 설명을 읽는 부담만 늘리는지도 확인한다.

이미 일부가 파괴된 호텔에서 시작한다. 직접 만든 호텔을 잃는 감정, 복구 가격, 모집 대기는 제외한다. 같은 스타일을 유지하면서 다른 재료로 연결하는 선택도 유효하다. 전혀 다른 스타일로 바꾸는 것을 성공 조건으로 삼지 않는다.

## 2. 공통 장면과 자산

| 항목 | 실험 설정 |
| --- | --- |
| 호텔 | 입구 0, 슬롯 1~8, 출구 9. 슬롯당 한 타일. 운영 전 무료 재배치·보관 |
| 최초 배치 | 1·2: 불안 안내문, 3: 봉인 표식, 4: 잃어버린 전화기의 빈칸, 6: 메아리 수확기. 5·7·8 빈칸 |
| 남은 효과 | 안내문은 통과 시 각각 불안 +1. 표식은 통과 시 저주 +1. 수확기는 도착 시 환청 최대 2 소비, 개당 공포 4 |
| 잃은 기능 | 전화기의 통과 시 환청 +2. 원래 타일과 원래 제작 재료는 이번 시험에서 재공급하지 않음 |
| 손님 | 불안·환청·저주·공포 모두 0. 상태는 손님에게 유지되며 이번 시험에서 자연 감소 없음 |
| 점검 경로 | 6칸 이동 후 3칸 이동하여 퇴장. **처음부터 모든 조건에 공개**하여 도착 운의 영향을 제외 |
| 자원 | 아래 직원 8명 각 1명, 추가 지급 없음. 융합 최대 2회, 회당 직원 2명 소모, 별도 가격 없음 |
| 목표 | 점검 손님에게 공포 8을 얻을 재설계. 실패 벌점 없음. 영업 중 배치는 변경하지 않음 |
| 제외 | 직원 카드 사용·덱 순환·심장 부담·보스 공격·경영 정산. 도착 타일은 통과→도착 순서로 처리 |

고정 경로의 공개는 재설계 자체를 보기 위한 실험 조건이다. 정식 게임의 미래 주사위 공개를 결정하지 않는다. 융합도 **선택한 두 직원의 정확한 결과를 미리 조회하는 방식**으로 고정한다. P4의 최종 융합 방법을 채택했다는 뜻이 아니다.

### 직원 8명

직원 행동은 괴이의 법칙을 이해하기 위한 정보다. 이 실험에서 직원 카드를 직접 사용하지는 않는다.

| ID / 직원 | 직원 행동의 시험용 정의 |
| --- | --- |
| A / 고해 담당 | 손님의 불안을 최대 2 제거 |
| B / 방송 담당 | 손님에게 환청 1 부여 |
| C / 기록원 | 지정 타일의 이번 도착에 현재 불안 1개당 공포 2 추가. 불안은 소비하지 않음 |
| D / 소거 담당 | 불안·환청·저주 중 고른 상태를 최대 2 제거 |
| E / 봉인 담당 | 손님에게 저주 1 부여 |
| F / 조율 담당 | 손님의 상태 1개를 다른 종류 1개로 변환. 불안·환청·저주 중 선택 |
| G / 증폭 담당 | 지정 타일이 이번 이동에 처음 부여하는 상태의 양 +1 |
| H / 심문 담당 | 지정 타일에 이번 이동 중 도착했을 때 상태가 두 종류 이상이면 공포 4 추가 |

### 다양한 결과 조건의 융합 12종

모든 결과는 해당 직원 두 명을 소모해 타일 하나를 만든다. 적힌 효과 외에는 발동하지 않는다. 두 융합에 같은 직원을 중복 사용할 수 없다.

| 조합 / 괴이 | 효과 | 바뀌는 관계 |
| --- | --- | --- |
| A+B / 고해 방송실 | 통과: 불안 최대 2 제거 → 같은 수의 환청 부여 | 제거물을 기존 수확기의 입력으로 변환 |
| C+D / 빈 장부 | 제작 시 상태 한 종류 지정. 통과: 그 상태 최대 2 제거. 같은 이동이 이 타일에서 끝나면 방금 제거한 수 ×4의 공포 | 읽는 대상이 남은 상태에서 제거된 양으로 바뀜 |
| A+E / 봉인 고해소 | 통과: 불안 최대 2 제거 → 같은 수의 저주 부여 | 원래 수익 경로를 저주 경로로 우회 |
| C+E / 저주 장부 | 도착: 저주 최대 2 소비 → 개당 공포 4 | 기록원이 다른 상태를 읽는 수확기로 전환 |
| B+F / 교대 방송실 | 통과: 불안이 1 이상이면 불안 1 소비 → 환청 2 부여 | 적은 입력을 바꿔 공급하고 남은 불안은 보존 |
| B+G / 합창실 | 통과: 환청이 이미 1 이상이면 환청 1 추가 | 다른 공급원이 만든 소리를 증폭하는 보조 |
| B+D / 해제 방송실 | 통과: 저주 최대 2 제거 → 같은 수의 환청 부여 | 불안 대신 남은 저주를 기존 수확기에 연결 |
| F+H / 교차 심문실 | 도착: 불안·환청이 각각 1 이상이면 각각 1 소비 → 공포 8 | 같은 상태의 집중 대신 두 상태의 조합 요구 |
| D+F / 분리실 | 통과: 불안이 2 이상이면 2 소비 → 환청 1·저주 1 부여 | 한 종류의 입력을 두 종류의 후속 입력으로 분할 |
| B+H / 잡음 심문실 | 도착: 환청·저주가 각각 1 이상이면 각각 1 소비 → 공포 8 | 남은 저주와 새 소리를 한 번의 수확으로 묶음 |
| E+G / 부적 창구 | 통과: 저주 2 부여 | 새 공급원을 만들어 변환·수확의 출발점을 변경 |
| C+G / 증폭 장부 | 도착: 불안 최대 2 참조 → 개당 공포 4. 불안은 소비하지 않음 | 상태를 지출하지 않는 수확 경로 |

단순 공급, 변환, 조건부 증폭, 제거 사건 수확, 혼합 수확, 비소비 수확을 함께 둔다. 모든 결과가 모든 배치에서 유효할 필요는 없다. 조합을 만드는 직원이 사라져도 남은 타일이나 다른 재료의 괴이로 입력을 마련할 수 있게 한다.

## 3. 비교 조건

| 진행자용 조건 | 제공 결과 | 비교할 차이 |
| --- | --- | --- |
| N2 / 소수 결과 | A+B와 C+D 두 결과 | 기본 재설계의 경험 |
| N12 / 같은 기능의 많은 결과 | A+B 기능 6개, C+D 기능 6개. 이름만 구분하고 재료·효과·수치는 각각 동일 | 목록 개수 증가의 효과와 읽기 부담 |
| D12 / 서로 다른 결과 | 위 12종 전부 | 이름·개수 증가를 넘어선 연결 관계의 다양성 |

세 조건 모두 같은 직원 8명, 남은 타일, 최대 2회 융합, 공개 경로, 목표, 가격, 화면 형식을 사용한다. N12의 복제 결과들은 같은 직원을 요구하므로 여섯 개를 모두 제작할 수 있는 공급 증가가 아니다. N2/N12에서 결과가 없는 직원은 그대로 보유하되 이번 목록에 제작법이 없다고 표시한다.

참가자에게는 조건의 의도를 드러내지 않는 중립적인 세션 번호만 보여 준다. N12는 개수와 기능 다양성을 구별하기 위한 대조이며 정식 콘텐츠 제안이 아니다.

N2에서도 두 기본 해법으로 목표에 도달할 수 있다. 공개 경로에서 내부 도착은 한 번이고 모든 수확의 최대값은 8이므로, D12만 더 높은 최대 수익을 주는 비교가 아니다. 다만 조합에 따라 필요한 제작 횟수와 해법의 쉬움은 달라진다. 선호 이유가 편의성인지, 새로운 관계인지 함께 확인한다.

### 진행자 참고: 서로 겹치지 않는 제작 경로

아래는 계획의 예시다. 최초 참가자 화면에 추천 배치로 노출하지 않는다.

- **기존 수확기 유지:** 안내문 둘 → A+B → 위치 6 수확기. 또는 B+F로 불안 1만 환청 2로 바꾼다.
- **수확기 교체:** 위치 6에 불안을 지정한 C+D 또는 C+G를 둔다. 전자는 제거한 양, 후자는 남은 양을 사용한다.
- **저주로 우회:** 안내문 뒤 A+E → 저주를 지정한 C+D. A·E와 C·D는 서로 다른 직원이다.
- **분할 뒤 혼합:** D+F → 위치 6 B+H. 불안을 환청·저주로 나눈 뒤 함께 소비한다.
- **기존 저주 활용:** 봉인 표식 뒤 D+F → 위치 6 C+E. 표식의 저주 1과 새 저주 1을 합쳐 수확한다.
- **공급 연결 두 단계:** E+G → B+D → 기존 수확기. 또는 D+F → B+G → 기존 수확기.
- **순서를 바꿔 혼합:** 안내문 하나 → A+B → 다른 안내문 → 위치 6 F+H. 일부 불안을 환청으로 바꾼 뒤 불안을 다시 공급한다.

기존 수확기를 쓰지 않는 계획에서는 보관해도 된다. 예시 외의 유효한 배치도 허용하며, 같은 스타일을 유지했다는 이유로 낮게 평가하지 않는다.

## 4. 진행 방법

1. **상황 확인, 약 3분:** 사라진 기능, 재공급 없음, 이번 목표·경로·제작 제한을 소개한다. 추천 조합이나 남아 있는 해법 수는 알려 주지 않는다.
2. **독립 재설계, 약 6분:** 참가자가 결과 목록을 읽고 융합·배치를 계획한다. 확정 전 예약을 수정할 수 있다. 어떤 자산을 연결하려는지 짧게 말하게 한다.
3. **운영·복기, 약 3분:** 확정한 직원은 소모하고 점검 손님을 진행한다. 참가자에게 실제로 어떤 관계가 바뀌었는지 먼저 설명하게 한다.
4. **질문–점수 평가, 약 3분:** 아래 8문항 각각에 점수, 이유, 장면을 받는다. 성공·실패 여부와 재미 점수는 따로 기록한다.
5. **다음 행동, 약 3분:** 같은 구성 재운영 / 초기 자산의 새 복사 상태에서 다른 구성 / 종료 중 선택하게 한다. 자발적인 선택과 지시 후 과제를 구분한다.
6. **필요한 진단:** 막혔다면 정보 힌트를 주거나, 결과 목록을 확장하는 것 중 하나만 먼저 적용한다. 힌트 후·목록 확장 후 점수는 최초 평가와 나누어 기록한다.

최초 경험은 참가자별로 N2/N12/D12 중 하나만 배정한다. 탐색 표본 6~9명으로 시작하면 조건당 2~3명이며 문제 발견을 위한 규모다. 모든 사람에게 N2→N12→D12 순서로 제시하고 마지막 조건의 점수 상승을 다양성 효과로 해석하지 않는다. 추가 조건을 경험하면 학습 후 비교로 표시한다.

시간에 도달하거나 중단을 요청하면 먼저 이유를 받는다. 읽기 부담, 활용 관계를 못 찾음, 흥미 부족, 더 생각할 시간 부족을 나누어 기록한다. 다른 경로를 만들도록 강제하지 않는다.

| 진행자 비교 | 참가자×조건×문항 점수, 문항별 중앙값·1~2점 수·N/A 수, 사용 경로·힌트·다음 행동·근거 발언 | 개수·관계 다양성·읽기 부담 구분 |

흐름은 **손실 확인 → 목록 탐색 → 융합·배치 → 점검 운영 → 점수·이유 → 다음 행동**이다. 모든 조건에 같은 검색·필터 도구를 제공한다. 최적 연결 자동 추천은 하지 않는다. 목록 확장 전후에는 각각 평가하고, 이전 점수는 마지막 비교 때만 보여 준다.

## 7. 판단과 후속 실험

핵심 문항은 **Q2·Q5·Q7**이다. 각각 중앙값 4/5 이상이고 서로 다른 계획·구체적인 즐거움·다음 선택으로 뒷받침되면 후속 실험으로 진행한다. 문항별 1~2점과 Q6의 부담 사례는 별도로 본다. 작은 표본의 점수 차이만으로 일반적인 효과를 확정하지 않는다.

| 경험 패턴 | 해석 후보 | 다음 조치 |
| --- | --- | --- |
| N12는 N2와 비슷하고 D12의 Q2·Q5·Q7이 높음 | 목록 수보다 실제 연결 다양성이 막힘을 줄일 가능성 | 선택된 관계를 유지하고 [P10](prototype-10.md)의 소유·상실 장면에 결합 |
| D12의 Q2는 높지만 Q6이 낮고 읽다 중단 | 가능한 해법보다 설명 부담이 먼저 커짐 | 역할별 묶음·초기 제시량을 바꿔 별도 비교 |
| D12에서도 이해는 높지만 Q5·Q7이 낮음 | 다양성이 있어도 재설계 행위의 매력이 부족할 수 있음 | 복구 노동으로 느낀 단계와 원래 구성 선호의 이유를 구분 |
| 점수 상승이 빠른 완성·한 조합의 쉬움에 집중 | 관계의 다양성보다 쉬운 접근 경로가 효과적일 수 있음 | 그 경로를 남긴 작은 목록과 D12를 추가 비교 |

힌트 뒤에만 Q1·Q5가 오르면 정보 전달을 먼저 다룬다. 융합 절차가 재설계 판단을 방해하면 [P4](prototype-4.md)의 후보 방법과 결합한다. 직원 보존·소모 문제는 융합 방법을 정한 뒤 후속 분석으로 넘긴다.
