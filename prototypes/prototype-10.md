# P10 — 직접 만든 호텔의 상실과 재설계 의욕

[전체 계획](prototypes-main.md) · 선행: [P9 재설계](prototype-9.md) · v0.2 / 2026-10-29 / 실험 전

## 1. 확인할 경험

직접 만든 호텔이 성과를 낸 뒤 일부를 잃었을 때, **새 구성을 만드는 의욕이 유지되는가?** 대안이 있어도 이전 작업을 반복하는 기분이 들거나 다음 투자를 피할 수 있다. 재설계 자체의 가능성을 다루는 P9에 구축 이력과 상실 경험을 붙인다.

근거: rules.md §8.1·§8.5·§8.6. 손실 기간·복구 비용·파괴 주기는 미정이며, 아래 수치는 이 실험에만 적용한다. 직접 구축과 인계의 차이에는 소유감뿐 아니라 익숙함·학습·선택권도 포함된다.

## 2. 장면과 비교 조건

**1인 약 25~35분.** 입구 0, 슬롯 1~8, 출구 9. 새 손님은 불안·환청·공포 0으로 시작하고 출구에서 퇴장한다. 재배치는 무료이며 직원·심장 부담·보스 전투·장기 경제는 제외한다.

| 초기 자산 | 수량 | 효과 |
| --- | ---: | --- |
| 속삭임 복도 | 2 | 통과: 환청 +1 |
| 기록 벽 | 2 | 통과: 불안 +1 |
| 거울 괴이 | 1 | 도착: 환청 전부 소비, 1개당 공포 +4 |
| 초상화 괴이 | 1 | 도착: 불안 전부 소비, 1개당 공포 +4 |

| 조건 | 파괴 전 경험 | 비교에서 맞출 것 |
| --- | --- | --- |
| A 직접 구축 | 지급 자산으로 직접 배치한 뒤 손님 2명을 받음 | 확정 배치, 시범 이동 경로, 운영 횟수, 파괴 대상, 대체 자산·예산 |
| B 인계 | A 참가자가 만든 동일 배치를 받아 살핀 뒤 손님 2명을 받음 | 같은 내용을 별도 참가자에게 제공. 파괴 전 배치는 변경하지 않음 |

공급이 수확보다 앞에 오도록 구성하게 한다. 진행자는 배치 후 두 수확에 도착하는 1~6 눈의 시범 경로를 배정하고 A/B에 동일하게 사용한다. 이는 성취 뒤 손실을 보기 위한 연출이며 무작위 수익 실험이 아니다. 경로 전체는 공개하지 않고 현재 눈만 보여 준다. 파괴 후 재설계 결과까지 같게 맞추지는 않는다.

두 번째 손님이 퇴장하면 **거울 괴이만 제거**하고 슬롯·다른 자산·이미 얻은 공포를 유지한다. 시작 때 일부 기능 상실과 시험 중 복구 불가를 안내하고, 대상은 사건 때 공개한다. 재설계 예산 6으로 아래 중 하나를 구매한다.

| 대체 자산 | 가격 | 효과와 선택의 의미 |
| --- | ---: | --- |
| 낡은 종 | 6 | 도착: 환청 전부 소비, 1개당 공포 +3. 기존의 두 수확 지점을 유지 |
| 고해 통로 | 6 | 통과: 환청 전부를 같은 양의 불안으로 변환. 남은 초상화에 수확을 모음 |

선택 후 무료 재배치한다. 원래 거울과 추가 예산은 제공하지 않는다. 대안별 수익 차이가 있으므로 어느 자산을 골랐는지 자체를 의욕 점수로 취급하지 않는다.

## 3. 진행 방법

1. 목표·타일·손실 조건을 설명한다. A는 배치하고 B는 인계된 구조를 살펴본다. 두 수확의 입력을 자신의 말로 설명하게 한다.
2. 손님 2명으로 성과를 경험한다. **Q1~Q2**와 다음에 해보고 싶은 일을 받는다.
3. 거울을 제거하고 첫 반응을 자유롭게 듣는다. 대체 자산을 안내하기 전에 **Q3**을 받는다.
4. 예산과 대체 자산을 공개한다. 참가자가 선택·재배치한 뒤 새 손님 1명으로 영업한다. 배치된 수확 지점에 도착하는 시범 경로를 파괴 전과 같은 원칙으로 배정한다. 막히면 이유부터 듣고, 요청한 설명이나 힌트는 구분해 기록한다.
5. 결과를 복기한 뒤 **Q4~Q8**을 받는다. 한 번 더 구상하기/추가 영업/종료 중 실제 행동을 선택하게 하고 이유를 듣는다.
6. 양 조건에서 재설계가 이해된다면, 다음 회차에 A만으로 안정 운영 **1회/3회**를 비교한다. 손실량·복구 비용·공급 대기는 한 번에 하나씩 후속 비교한다.

추가 시도는 선택 사항이다. 중단은 피로·시간·과제 완료 때문일 수 있으므로 이유 없이 재미 실패로 분류하지 않는다. 파괴 전 구조를 이해하지 못한 경우도 남기되, 상실의 효과와 구분한다.

## 4. 검증 UI

| 화면 | 표시와 조작 | 연결되는 경험 |
| --- | --- | --- |
| 호텔·단계 | 구축→안정 운영→상실→재설계. 슬롯·타일·공포와 현재 눈 표시. A는 초기 배치, B는 초기 열람, 양쪽은 파괴 후 재배치 | Q1~Q2, 직접 만든 성과와 인계된 성과 |
| 손실 장면 | 잃은 거울, 남은 자산, 보존된 과거 공포를 함께 표시. 첫 느낌 입력 후 대체 후보로 이동 | Q3, 무엇을 잃었다고 느끼는가 |
| 재설계 작업대 | 예산 6, 후보 효과·가격, 배치 전후를 나란히 표시. 후보 선택·배치·영업·지난 결과 보기 | Q4~Q6, 원상복구와 새로운 연결의 차이 |
| 단계별 설문 | 해당 단계의 질문과 1~5점 선택, 이유·기억나는 장면 입력, N/A. 이전 점수는 최종 복기에서 공개 | Q1~Q8, 경험 변화 |
| 다음 행동 | 추가 구상/추가 영업/종료를 동등하게 제시. 선택과 이유 기록 | Q7~Q8, 말한 의향과 실제 선택 |
| 진행자 비교 | A/B의 짝지어진 시작 상태, 단계별 문항 점수, 발언·선택·도움 여부. 파괴 전 계획과 최종 계획을 연결 | 구축 경험, 손실, 재투자 의욕의 관계 |

UI는 정답 배치나 추천 구매를 먼저 제시하지 않는다. 설문은 [공통 5점 평가 방식](prototypes-main.md)을 따른다.

## 5. 경험 validation — 질문과 5점 응답

1=전혀 그렇지 않다, 5=매우 그렇다. **각 행에 점수와 이유 한 줄을 받는다.** N/A는 경험하지 못한 경우다.

| ID / 시점 | 평가 요소 | 참가자 질문 | 응답 |
| --- | --- | --- | --- |
| Q1 / 파괴 전 | 성취감 | 호텔이 공포를 생산하는 모습을 보며 성취감을 느꼈다. | __/5 |
| Q2 / 파괴 전 | 발전 의향 | 이 호텔을 더 발전시키고 싶었다. | __/5 |
| Q3 / 상실 직후 | 손실 수용 | 이번 손실을 감수하고도 계속 플레이할 만하다고 느꼈다. | __/5 |
| Q4 / 재설계 후 | 대안 발견 | 남은 자산으로 시도하고 싶은 구성을 떠올릴 수 있었다. | __/5 |
| Q5 / 재설계 후 | 새로운 설계의 즐거움 | 재설계에서 새로운 가능성을 찾는 과정이 즐거웠다. | __/5 |
| Q6 / 재설계 후 | 노력의 가치 | 재설계에 들인 노력은 가치가 있었다. | __/5 |
| Q7 / 재설계 후 | 운영 의향 | 새 호텔을 한 번 더 운영하고 싶다. | __/5 |
| Q8 / 재설계 후 | 재투자 의향 | 앞으로도 새로운 구성을 만드는 데 자원을 투자하고 싶다. | __/5 |

**핵심: Q5·Q7·Q8.** 각 중앙값 4/5 이상과 구체적인 이유·후속 행동이 함께 나타나면 다음 단계로 진행할 신호로 본다. Q3이 낮아도 이후 회복될 수 있으므로 상실 직후 점수만으로 탈락시키지 않는다. Q2와 Q8은 서로 다른 질문이므로 정확한 전후 변화량으로 빼서 계산하지 않는다.

| 점수·행동 패턴 | 해석할 문제 | 다음 조정 |
| --- | --- | --- |
| A/B 모두 Q4~Q5가 낮음 | 대안이나 연결 자체의 매력이 부족할 가능성 | [P9](prototype-9.md)에서 조합·정보 부담 확인 |
| A에서 Q5·Q8이 낮고 B는 유지 | 직접 구축 경험과 상실의 결합이 부담일 가능성 | 안정 수익 기간 1회/3회 비교 |
| Q4는 높고 Q5·Q6은 낮음 | 복구는 가능하나 반복 노동으로 경험 | 재설계 조작량 또는 대안의 관계 변화 중 하나 수정 |
| Q3은 낮지만 Q5·Q7·Q8은 높음 | 상실의 아쉬움과 재설계 즐거움이 공존 | 바로 손실을 없애지 말고 이유와 다음 투자 관찰 |

1~2점 응답과 도움 후의 변화는 따로 보고한다. 보스 공격이 부당하다는 반응은 [P8](prototype-8.md), 반복 조작 부담은 [P11](prototype-11.md)로 연결한다. 직원 보존·융합의 기회비용은 융합 방법이 정해진 뒤 후속 분석한다.
