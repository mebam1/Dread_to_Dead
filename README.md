# Dread-to-Dead: Fears Go Round

직원을 융합한 괴이로 원형 호텔을 설계하는 경영 게임. 괴이가 상태를 공급·수확해 손님을 처치하고, 직원은 괴이를 보호한다. 처치 고정 보상으로 투자하며 손님별 공격 패턴에 대응한다.
