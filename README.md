# Dread-to-Dead: Fears Go Round

엘리베이터로 층을 순환하는 기이한 호텔을 설계하는 경영 게임. 층마다 괴이 하나를 배치하고, 경유 층의 통과 효과와 최종 층의 도착 효과를 연결한다. 괴이가 공격·수비·지원·액티브를 모두 맡으며, 처치로 얻은 공포 재화로 블러드 웹의 괴이를 구매한다.

**확정**은 채택한 판정, **설계 방향**은 지향점이다. **제안·시험값**은 미확정이며, **과거 기록**은 현행 규칙의 검증을 뜻하지 않는다. [config 14의 AI 진행·분석](mvp_text_14/runs/playthrough.md)에서는 보호·충전과 후속 공격, 비활동·탈출의 경계를 확인했다. AI 시연은 인간의 재미 검증과 구분한다.
