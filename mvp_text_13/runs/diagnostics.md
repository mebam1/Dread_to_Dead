# Config 13 통제 판정 검사

D1~D4 네 군의 48개 단일 턴 분기와 D5의 7개 비교: **55개 통과**. D0 경계 검사는 `test_engine.py`에서 별도로 수행한다.

이는 명세의 확정 계산이며 정상 난수의 캠페인이나 도착 선호·재미의 증거가 아니다. 후속 7분기 운영은 별도 기록한다.

| D1 첫 선택 | 다음 턴 처치 가능한 눈 | 216개 주사위 묶음 중 처치 가능 |
|---|---|---:|
| MUG 눈1 | [2, 4] | 152/216 |
| MUG 눈3 | [6] | 91/216 |
| M0 눈1 | [] | 0/216 |

공급 준비가 다음 한 턴의 처치 기회를 넓히는 사례다. 전체 완주 확률이나 항상 우세한 전략을 뜻하지 않는다.
