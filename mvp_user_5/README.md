# 괴이 호텔 · 그래픽 MVP 5

Node.js 20 이상에서 [play.cmd](play.cmd)를 더블클릭하면 로컬 서버가 시작되고 기본 브라우저로 게임이 열린다. 터미널에서는 저장소 루트에서 아래 명령을 실행한 뒤 [괴이 호텔](http://127.0.0.1:4176)을 연다.

```sh
npm --prefix mvp_user_5 start
```

## 플레이

1. 새 판은 **모험 지도**에서 시작한다. 각 막의 지도에서 연결된 노드와 손님 정보를 확인하고, 세 막에 걸쳐 방문할 길을 고른다. 배치를 살펴보려면 **호텔 보기**, 경로로 돌아가려면 **모험 지도**를 누른다.
2. 전투 노드를 방문하면 전투 준비 화면에 호텔 보드가 열린다. 위 열 장은 손님 위치, 아래 열 장은 층별 괴이 배치다. 좁은 화면에서는 두 줄을 함께 가로로 넘긴다. 정비 중에는 괴이 카드를 빈 층으로 끌어 옮기거나 다른 괴이 위에 놓아 자리를 바꾼다. 키보드로는 **층 재배치**에서 출발층과 목적층을 선택한다.
3. 주사위 눈에 마우스를 올리거나 키보드 초점을 맞추면 위쪽 카드에서 경로와 층별 획득 예정 상태를 그림 ×수량으로 확인한다. 아래쪽 카드는 손님의 공격을 `공략도 +N`으로 예고한다. 방어가 피해를 흡수하면 실제 증가량을 하늘색으로 표시한다. 쓸 주사위를 한 번 클릭하거나 탭하면 바로 확정된다. 키보드에서는 원하는 주사위에 초점을 맞추고 Enter 또는 스페이스바를 누른다. 속공이나 탈출구를 설정한 후 이동을 누르면 손님 카드가 위쪽 칸을 지난다. 손님의 현재 공포/한계는 손님 카드와 보드 바로 아래에 표시된다.
4. 보상과 상점에서 받은 괴이는 빈층에 놓거나 버린다. 만실이면 교체할 카드를 고를 수 있다. 융합 노드에서 두 괴이의 본 효과를 한 층에 합친다. A의 층과 내구를 계승하고 B의 층은 빈다.

손님 카드나 입구 초상을 선택하면 공격 패턴, 고유 효과, 현재 상태를 확인할 수 있다. 보유 중인 상태 토큰을 누르면 그 뜻을 볼 수 있다. 괴이 카드를 선택하면 효과와 내구를, 상단의 **영업 기록**을 열면 지금까지의 결과를 확인할 수 있다. 전체 화면 사양은 [사용자 설정 5](../mvps/mvp-config-user-5.md), 게임 판정은 [텍스트 설정 17](../mvps/mvp-config-17.md)을 따른다.

속공은 괴이 카드 오른쪽 아래의 **밝은 금화**를 눌러 쓴다. 대상이 필요하면 강조된 괴이 카드를 고른다. 선택 중 **취소**나 **Esc**를 누르면 비용을 쓰지 않는다. 어두운 금화는 현재 쓸 수 없는 속공이다. 융합체에 금화가 두 개면 왼쪽은 원본 A, 오른쪽은 원본 B이며 누른 쪽의 효과와 비용만 적용한다.

## 저장과 재시작

확정한 결정은 `mvp_user_5/saves/current.json`에 자동 저장된다. 새로고침하거나 서버를 다시 켜면 저장된 막의 지도가 먼저 열린다. 전투나 다른 방문을 진행하던 중이었다면 해당 진행 탭에서 이어간다. 처음 판 번호는 `31001`이다. 우측 상단 **설정 및 새 판**에서 판 번호를 고르고 새 판 시작을 확정하면 현재 판을 교체한다. 별도 저장으로 실행하려면 서버 시작 전에 환경 변수 `USER5_SAVE`에 파일 경로를 지정한다. 서버 포트는 `PORT`로 바꿀 수 있다.

## 검증

저장소 루트에서 다음 명령을 실행한다.

```sh
npm --prefix mvp_text_17 test
npm --prefix mvp_user_5 test
node mvp_user_5/browser-smoke.mjs
```

첫 번째는 전투·캠페인 판정, 두 번째는 그래픽 화면의 결정과 저장·복구 API를 검사한다. 세 번째는 임시 저장 파일로 데스크톱과 모바일 크기의 실제 브라우저를 조작한다. 브라우저 검사는 Playwright Core와 Edge를 사용하며, `USER5_PLAYWRIGHT`로 모듈 위치를, `USER5_BROWSER`로 다른 Chromium 실행 파일을 지정할 수 있다.
