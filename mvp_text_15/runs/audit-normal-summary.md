# 정상 3판 명령 재생 검산

`node audit.mjs`로 재생한다. 각 원본의 `new Game(seed)`부터 기록된 명령만 합법 API로 다시 실행한다. 강제 눈·자산 지급·원본 state 주입은 하지 않는다. 각 명령 전후 공개 마커와 발생 이벤트, 마지막 전체 state를 JSON 직렬화 기준으로 대조한다. `new`·`note`·`checkpoint`는 엔진 효과 없는 장부 명령이다. `play`는 CLI와 동일하게 선택→명시 행동→아직 prepare이면 이동하며 손님 전환은 엔진이 수행한다. 원본은 읽기만 하고 SHA256 전후 일치를 검사한다.

| seed | 전체 검사 | 전체 state | 턴: 1막 / 2막 / 3막 | 영혼 검산 | 괴이 검산 |
|---|---|---|---|---|---|
| 31001 | PASS (22/22) | 일치 | 32 / 37 / 41 = 110 | 4+76−38=42 | 4+11+2+1−5−0=13 |
| 31002 | PASS (22/22) | 일치 | 25 / 41 / 33 = 99 | 4+70−45=29 | 4+10+5+0−1−0=18 |
| 31003 | PASS (22/22) | 일치 | 27 / 30 / 35 = 92 | 4+80−28=56 | 4+11+3+0−4−0=14 |

괴이 식은 초기+전투보상+상점구매+이벤트구매−파괴−희생이다. 모든 상점 가격·증설 가격·증설 영혼 전후값을 규칙 표와 대조했다. 노드별 턴·방문·완료, 개별 손님 턴 번호 연속성, 처치·탈출·파괴 통계와 8/8/8 진행도도 대조했다. 원본 SHA256과 노드별 상세 수치는 다음 JSON에 있다.

- [31001 상세](audit-normal-31001.json): 321개 명령, 12개 전투 노드, 원본 해시 불변.
- [31002 상세](audit-normal-31002.json): 289개 명령, 10개 전투 노드, 원본 해시 불변.
- [31003 상세](audit-normal-31003.json): 274개 명령, 11개 전투 노드, 원본 해시 불변.

이 검산은 기록된 선택이 현재 엔진의 합법 명령으로 재현되고 장부가 맞는다는 증거다. 플레이 중 숨김 정보를 보지 않았는지나 규칙 구현 자체가 의도와 완전히 같은지는 최종 상태 재생만으로 증명하지 않는다.
