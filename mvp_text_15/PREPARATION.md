# 설정 15 텍스트 실험 준비 상태

> 2026-11-01 · 준비 검사 기록. 이후 정상3판과 실제 체크포인트 통제까지 완료했으며 결과는 [증설 분석](runs/analysis.md)에 있다. 아래 합성 검사는 실제 플레이 결과와 구분한다.

당시 실행 조건은 [설정 15](../mvps/mvp-config-15.md)와 [엔진](engine.js), 실행법은 [README](README.md)와 [진행 절차](runbook.md)를 따른다. 기존 설정 14와 user-2 구현은 보존했다. 현행 user-3의 회복·강화·토큰 이월은 아래 준비 검사와 플레이에 포함하지 않는다.

## 준비한 기능

- 3막·7종 노드·영혼·괴이 3중 1·주사위 획득 제한을 처리하는 독립 텍스트 엔진.
- 현재 공개 정보·효과·합법 미리보기로 AI가 직접 한 수씩 판단하는 CLI, 선택 이유와 실제 결과 기록.
- 증설 구매 직전 체크포인트에서 실제 가격을 지불한 분기와 미증설 분기를 만드는 도구. 원본은 유지한다.
- 같은 노드·손님·턴의 두 체크포인트에서 216가지 면 조합을 계산하는 비교. 배치·장비·손님 상태 차이는 함께 표시한다.
- 추가 공간·빈층·장거리·짝수 이동·적 공격의 원인을 분리하는 합성 진단과, 미증설 재배치 대안.

## 실행한 확인

실행 환경은 Node.js v24.12.0이다. 외부 패키지를 설치하지 않았다.

| 검사 | 결과 | 의미 |
|---|---:|---|
| 엔진 경계 검사 | 25개 통과 | 지도·전투·보상·비용·복구·즉시 종료·난수·정보 경계 |
| 텍스트 CLI 검사 | 6개 통과 | 공개 출력·선택 이유·기록·체크포인트·덮어쓰기 거절·중단 복구 |
| 증설 비교 검사 | 9개 통과 | 216조합·보호 흡수·원본 불변·실제 가격·분기·같은 전투 경계 검증 |
| 합계 | **40개 통과, 실패 0개** | [원본 테스트 출력](runs/checks-preparation-v1.tap) |

엔진 검사의 전체 3막 전환은 공포 한계 등을 낮춘 **합성 경계 검사**다. 실제 규칙으로 66명을 처치한 정상 AI 플레이로 해석하지 않는다.

[최신 합성 진단](runs/diagnostics/mechanisms-preparation-v3/mechanisms.md)은 7개 비교를 포함한다. 각 상태에서 216가지 면 조합을 계산하며 실제 미래 눈이나 비활동 표적을 읽지 않는다.

- 추가 수확 괴이를 배치한 7층에서 한 턴 공포가 증가하는 사례를 재현했다.
- 같은 보유 자산을 6층에서 교체 배치하면 그 표면적 공포 이득이 사라지는 대안도 재현했다.
- 특정 짝수 주사위 배치에서는 7층 순환으로 수확 도착이 깨지는 사례를 재현했다.

이 사례들은 비교 도구가 서로 다른 결과를 구별한다는 확인이다. 영혼 투자 회수·다음 전투의 생존·전체 경로 선택의 결론은 아니다. 초기 진단 v1·v2는 준비 과정의 기록으로 보존하고 최신 지표·비교는 v3를 사용한다.

## 준비 후 실제 실행 결과

1. 31001·31002·31003을 공개 정보로 직접 플레이하고 선택 이유를 남겼다. 모두24노드·최종 보스·최종 괴이 선택까지 완료했다. 전투 턴은110·99·92다.
2. 세 판의 첫6→7층을 미증설·무료 재배치와 비교했고1막 종료까지 이어갔다. 31001은 빈7층/기존6층 비교도 진행했다.
3. 31001의 후기8→9는 다음 정예까지,9→10은 남은 정예와 최종 보스까지 비교했다. 후기10층은 전투 개선, 초기7층과 후기9층은 재배치 대체 사례가 나왔다.
4. 31001에서 일반전투 대신 이른 증설을 선택하는 별도 경로를1막 종료까지 진행해 보상·보충 구매·영혼 차이를 확인했다.
5. 정상3판은 초기 난수부터 모든 명령을 합법 API로 재생했다. 각22개 검사 통과, 최종 상태·가격·영혼·괴이 장부 일치, 원본 해시 불변이다. [검산 요약](runs/audit-normal-summary.md)

증설 가격이나 효과를 바꾸지 않고 user-3 규칙 그대로 관찰했다. 결과와 미측정 범위는 [전체 분석](runs/analysis.md)에 명시했다. 7→8 단독 비교·6층 고정 전체 캠페인·모든 대체 경로 비교는 수행하지 않았다.
