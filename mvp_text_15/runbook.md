# 증설 가치 텍스트 실험 — 진행자·플레이어 절차

기준은 [실험 명세](../mvps/mvp-config-15.md)의 당시 실행 조건과 [엔진](engine.js)이다. 현행 user-3의 회복·강화·토큰 이월은 이 실행기의 규칙이 아니다. 같은 AI가 진행과 플레이를 수행하므로 진행자만 알아야 하는 상태와 플레이어 판단에 사용한 정보를 기록에서 구분한다.

## 1. 실행 분류

| 분류 | 허용되는 입력 | 결과 해석 |
|---|---|---|
| 정상 AI 플레이 | `show`·`map`·현재 공개 눈·법적 행동만 사용 | 해당 AI가 실제 고른 경로·배치·증설·전투의 사례 |
| 판정 검사 | 강제 상태·강제 눈·경계 조건 | 규칙 구현 확인. 발생률·경제·완주 증거 아님 |
| 통제 비교 | 정상 증설 직전의 동일 스냅샷 또는 명시된 진단 상태 | 해당 상태에서 증설/스킵의 차이 |
| 분포 진단 | 공개된 장비의 여섯 면 전체 조합 | 가상 분포에서의 구조 차이. 실제 미래 턴 예측 아님 |

정상 판은 `normal_31001.json`·`normal_31002.json`·`normal_31003.json`으로 시작한다. 통제 분기와 스모크 파일은 원본을 덮어쓰지 않는다. 미래 눈·미방문 상점 재고·보상 후보·이벤트 내용을 알아보려고 원시 저장 파일이나 난수 키를 읽지 않는다.

## 2. 같은 AI의 두 역할

진행자는 엔진 명령으로 판정·자동 전환·기록을 수행한다. 플레이어는 직전 공개 출력만 보고 이유를 정해 명령한다. 전투 주사위는 실제 `roll` 직후에만 플레이어 정보가 된다.

1. 공개 상태를 읽는다.
2. 현재 결정의 대안과 예상 이익·비용을 한두 문장으로 적는다.
3. 실제 행동을 확정한다.
4. 실제 결과에서 예상과 다른 부분·괴이 손실·영혼 지출을 확인한다.
5. 다음 공개 상태로 진행한다.

선택 이유는 `--reason` 또는 앞선 `note`로 장부에 남긴다. UI에서 플레이어에게 매 턴 설문을 추가하라는 요구가 아니며, AI 시연을 재구성하기 위한 실험 기록이다. 같은 상태의 후보 미리보기는 허용하지만 다음 턴을 실제로 굴려 본 후 돌아오는 탐색은 하지 않는다.

## 3. 정상 판에서 증설 결정을 만났을 때

증설 노드 **구매 전** 공개 상태와 체크포인트를 기록한다.

- 현재 층 수·다음 가격·영혼 잔액·장착 주사위.
- 배치·보관 괴이와 생존 상태, 추가 층에 실제로 놓을 개체가 있는지.
- 지금 증설할 이유 또는 거절할 이유.
- 같은 깊이에서 선택하지 않은 연결 노드와 그때 공개된 기회. 해당 상점의 숨겨진 재고까지 기회비용으로 계산하지 않는다.

정상 선택은 그때 확정하고 계속 진행한다. 이후 통제에서 더 좋은 결과를 봤어도 원본 선택을 바꾸지 않는다. 정상 판에서 증설 기회가 없었거나 구매하지 않았다면 그대로 남긴다.

## 4. 비교를 세 가지로 나누기

### A. 순환·공격 대상 변화

증설 직전 상태에서 한 분기는 구매, 다른 분기는 스킵한다. 기존 괴이의 층·보관 상태는 두 분기에서 유지하고 새 층은 비운다. 같은 공개 눈과 같은 합법 행동을 적용해 경로·공급·수확·타격 대상·손실을 대조한다.

이 비교에서 나온 차이는 새 괴이의 공격력이 아니라 호텔 크기로 달라진 이동과 공격의 기여다. 빈층이 늘어 공급·수확 방문이 늦어지거나 유효 타격이 줄어드는 경우를 모두 기록한다.

### B. 실제 추가 배치의 이익

같은 출발점에서 구매 분기에는 이미 보유한 괴이를 새 층에 놓고, 스킵 분기는 기존 층 안에서 무료 교환·재배치를 허용한다. 두 분기의 자산 종류는 같고 배치 슬롯만 다르다.

추가 배치가 실제로 발동한 공포·불안·보호·수리를 기록한다. 새 층에 놓기만 하고 사용되지 않았다면 이익을 부여하지 않는다. 유리한 배치만 찾아냈다면 제한된 탐색 범위와 최적 보장이 없음을 함께 적는다.

### C. 경제와 노드 방문 기회

실제로 영혼을 결제한 구매 분기와 같은 영혼을 보존한 스킵 분기를 이후 공개 정보로 계속 진행한다. 상점·후속 증설에서 지출 여력이 달라져 어떤 선택을 했는지 기록한다.

증설 노드 대신 상점·엘리트·발견으로 간 분기는 별도 경로 비교다. 노드 방문·보상·적 구성이 함께 달라지므로 결과 차이 전체를 층 한 개의 인과 효과로 해석하지 않는다.

## 5. 같은 행동 재생이 불가능해지면

한 분기의 괴이가 먼저 파괴되거나 손님을 먼저 처치·탈출시키면 이후 같은 명령이 다른 의미를 가질 수 있다.

- 불가능해진 액티브를 억지로 실행하거나 제거한 괴이를 복구하지 않는다.
- 한쪽이 끝났는데 손님을 강제로 바꾸거나 다음 노드의 주사위를 맞추지 않는다.
- 고정 행동의 비교는 첫 불일치까지로 표시한다.
- 더 진행할 때는 두 분기 각각 현재 공개 정보로 다시 판단하고 `선택을 달리한 후속 비교`로 기록한다.

손님·턴·장착 자리별 난수는 경로와 독립 키를 사용한다. 두 분기의 실제 턴이 달라진 뒤 숫자 순서를 억지로 밀어 맞추지 않는다.

## 6. 관찰 중단과 결과

관찰 상한이나 반복으로 중단한 판을 게임상 패배로 표시하지 않는다. 실제 승리·전멸·보스 탈출·포기와 구분해 `관찰 중단`으로 기록한다. 도구 한계로 중단하면 입력·상태와 원인을 남긴다.

결과 보고에는 최소한 아래 내용을 넣는다.

| 항목 | 남길 내용 |
|---|---|
| 정상 선택 | 번호·막/노드·증설/스킵·이유·영혼·배치·장비 |
| 실제 사용 | 새 층/재배치 괴이의 발동과 보호·수리 기여 |
| 구조 차이 | 통과/도착·경로 길이·유효 타격·미스·파괴 차이 |
| 경제 | 실제 지출·남긴 영혼·포기하거나 가능해진 후속 구매 |
| 기회비용 | 증설 노드 방문으로 포기한 공개 경로. 숨겨진 보상 추정 제외 |
| 근거의 범위 | 정상 판 / 같은 행동 통제 / 후속 별도 선택 / 강제 진단 |
| 결론 | 도움이 된 조건·불리한 조건·관찰하지 못한 조건 |

‘증설 후 이겼다’만으로 증설의 필요성이나 가격 적정성을 결론내리지 않는다. 추가 슬롯이 실제로 쓸모 있었는지, 미증설에서도 다른 배치로 같은 결과가 가능했는지, 지출과 방문 기회를 회수했는지를 연결해 답한다.
