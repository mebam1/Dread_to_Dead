# Dread to Dead · 안개숲 원정 7

매 차례 세 눈을 굴린다. 각 눈의 왼쪽·오른쪽 주사위 중 하나를 동료에게 주면 그 방향으로 10칸 원형 전장을 걷는다. 어느 동료가 밀려나고 누구 곁에 도착할지 살펴보며 다음 동료의 공격·복사·반응을 준비한다. [사용자 설정 7](../mvps/mvp-config-user-7.md) · [전투 규칙 20](../mvps/mvp-config-20.md)

## 실행

Node.js 22 이상에서 Windows의 [play.cmd](play.cmd)를 열면 브라우저에서 원정이 시작된다. 터미널에서는 아래 명령으로 서버를 시작하고 [게임 열기](http://127.0.0.1:4177)를 누른다.

```powershell
cd mvp_user_7
npm start
```

## 첫 전투

1. 지도에서 첫 지점을 골라 적의 시작 칸, 첫 행동 라운드와 위력을 확인한다. **이 지점으로 이동**을 누른 뒤 동료의 자리를 정하고 **전투 시작**을 누른다.
2. **적 공격 예고**에서 각 적이 언제 어느 칸의 누구를 칠지 확인한다. 앞선 적의 이동으로 뒤의 적이 밀리면 예고에도 그 위치를 사용한다. 동료의 배치나 적의 생존 상태가 바뀌면 예고도 달라진다.
3. 세 슬롯 각각에 **같은 눈의 주사위 두 개**가 보인다. 이동할 방향은 각 주사위 **오른쪽 아래의 ←·→**로 확인한다. 원하는 주사위를 집어 동료 위에 올리면 경로가 보이고, **그 동료 카드에 놓는 즉시 이동한다.**
4. 클릭이나 탭으로는 방향 주사위를 먼저 고른다. 미리 보려면 동료를 가리키거나 **미리 볼 동료** 목록에서 고른다. 같은 슬롯의 반대 화살표로 바꾸면 다른 경로를 살펴볼 수 있다. **보드의 동료 카드를 누르면** 선택한 방향으로 즉시 이동한다. 키보드에서는 Tab으로 주사위에 초점을 두고 Enter 또는 Space로 선택한다. 동료 카드로 초점을 옮겨 예고를 읽고 Enter 또는 Space로 이동한다.
5. 경로에 표시된 **적 체력 피해**는 보호를 거쳐 실제로 깎일 체력이고, **실제 회복**은 각 동료의 최대 체력까지 채울 양이다. **발동 순서**에서 시종이 복사한 기술과 성가대원의 반응을, **이동 후 적 예고**에서 새 배치 때문에 달라지는 다음 공격을 확인한다. 무작위 선택이 있으면 가능한 결과를 나누어 보여 준다.
6. 이동 후 **직전 행동 결과**와 **원정 기록**에서 발동 순서와 각 대상의 체력 변화를 확인한다. 마지막 적을 쓰러뜨린 이동도 보상 화면에서 읽을 수 있다.

판 번호 **31900**에서 첫 지점의 **오른쪽 길**로 들어가 기본 배치로 전투를 시작하면 첫 주사위가 3·4·5다. 3번 슬롯의 **5←**와 **5→**로 3번 칸 성가대원의 경로를 차례로 미리 보자. 양쪽 모두 8번의 적을 처치한다. **5←**를 주면 1·2번의 성녀와 성기사도 밀려 다음 차례의 배치가 달라진다.

## 저장과 검사

기본 판 번호는 31001이다. 확정한 행동은 이 버전의 `saves/current.json`에 저장된다. 선택 도중 새로고침하면 같은 주사위로 다시 고를 수 있다. 이전 원정을 이어 하려면 서버를 끈 상태에서 MVP 6 저장 파일의 **복사본**을 MVP 7의 `saves/current.json`에 놓는다. 서버가 처음 읽을 때 규칙과 이전 이동 기록을 변환한다. 포트와 저장 경로는 각각 `PORT`와 `USER7_SAVE`로 지정할 수 있다.

```powershell
# mvp_user_7 폴더에서
npm test
npm run test:browser
```

브라우저 검사는 임시 저장으로 세 슬롯의 방향 주사위 여섯 개, 동료 드롭 즉시 이동, 모바일 탭과 키보드 조작, 방향별 예고, 마지막 행동과 재접속을 확인한다. Playwright Core와 Chromium 계열 브라우저가 필요하다. Windows에서는 기본으로 Edge를 사용한다. 필요하면 `USER7_PLAYWRIGHT`와 `USER7_BROWSER`로 경로를 지정한다.
