# Slay the Spire 사용자 경험과 호텔 설계 통찰

**핵심은 공통 규칙을 쉽게 재확인하게 하고, 현재 선택의 결과를 그 자리에서 비교하게 하는 것이다.** 반복 설명은 키워드와 일관된 정보 배치로 줄이고, 괴이마다 다른 수치·대상·비용·시점은 그대로 읽히게 한다. 공격 예고, 현재값 계산, 안전한 대상 선택을 연결하면 새 전투 규칙을 추가하지 않고도 플레이 경험을 개선할 수 있다.

**증설의 설계 가치는 일부 층이 방해받아도 공격을 이어갈 대체 전력과 여러 실행 경로를 확보하는 데서도 나온다.** 사서덱의 장단점에서 얻은 증설 통찰은 [8절](#expansion-library-deck)에 정리했다.

- 최초 조사: 2026-10-30 / 기존 카드·리뷰 조사: 2026-10-31 / 사용자 경험·사서덱과 증설 통찰 갱신: **2026-11-01**.
- 주 대상은 디지털 **Slay the Spire 1편**의 정보 전달과 조작이다. 2편의 과거 v0.107.1 카드 수치·협동 전용 효과는 이번 사용자 경험 적용 근거에서 제외한다.
- **1~7절은 사용자 설정 1 v1.1 당시의 UI 조사·구현 관찰·적용안**이다. [당시 명세](../mvps/mvp-config-user-1.md)의 웹 구매망·복구·진행 단위를 현행 규칙으로 사용하지 않는다. **8절은 [사용자 설정 3 v1.1](../mvps/mvp-config-user-3.md)의 상점 증설·토큰 이월·회복·강화를 기준**으로 한다. 실제 새 플레이의 판정에는 적용할 설정을 우선하고 [rules.md](../rules.md), [terms.md](../terms.md), [arts.md](../arts.md)를 함께 본다.
- 아래에서 **명세**는 이미 요구된 동작, **구현 관찰**은 현재 소스에서 확인한 동작, **보완 제안**은 추가 검토할 표현을 뜻한다. 화면 구현과 실제 인간의 이해·재미 검증은 구별한다.

## 1 Slay the Spire에서 확인한 사용자 친화적 요소

### 비교에 필요한 정보가 동시에 보인다

2019년 Nintendo 개발자 인터뷰에서 Anthony Giovannetti는 적을 클릭해 다음 행동의 긴 설명을 읽게 했던 중간 시안을 설명했다. 설명량이 많고 관전자에게도 정보가 부족해, 결국 모든 적의 다음 행동을 아이콘과 수치로 함께 보여주는 Intent로 바꿨다고 한다. 플레이어가 중요한 판단에 집중하도록 표현을 줄인 사례다. [Nintendo 공식 개발자 인터뷰](https://www.nintendo.com/jp/topics/article/1f6d2f1e-b7ea-11e9-b641-063b7ac45a6d)

우리 게임에서는 **어느 층에 도착하고, 어디가 몇 번 공격받고, 무엇이 파괴되는가**가 이에 해당한다. 뜻을 모를 때 여는 설명과, 선택할 때 매번 필요한 예고를 구분해야 한다. 핵심 위험을 상세 카드 안에서만 찾게 하면 여러 눈을 비교하기 어렵다.

### 키워드는 공통 설명을 다시 찾는 통로다

Slay the Spire는 카드에 쓰인 Poison·Exhaust 같은 용어를 카드 옆 툴팁에서 설명한다. 이 사례는 게임 화면을 수록한 다른 개발자의 UI 관찰 자료로 확인했다. 그 글에 이어지는 다단 툴팁 고정 기능은 Old World·Baldur's Gate 3 등의 사례이며 Slay the Spire의 기능으로 취급하지 않는다. [키워드 툴팁 화면과 관찰](https://khemitron-industries.net/quality-of-life-improvements-nested-tooltips/)

우리에게 필요한 것은 새로운 약어를 외우게 하는 작업이 아니다. 이미 쓰는 ‘통과’, ‘도착’, ‘이번 턴 보호’ 등에 같은 뜻과 설명을 연결하고, 서로 다른 괴이의 고유 능력을 빠르게 읽게 하는 것이다.

### 획득 전 설명과 조작 편의도 함께 개선한다

공식 V1.1 공지에는 획득 전 상점·보상 화면의 포션 툴팁, 최대 HP 손실의 실제 수치 표시, 터치 모드의 검토 후 확정, 넓어진 클릭 영역, Fast Mode의 연출 단축이 기록돼 있다. 이는 2019년 변경의 근거이며 모든 플랫폼의 현재 UI가 같다는 뜻은 아니다. [Mega Crit 공식 V1.1 공지](https://steamcommunity.com/games/646570/announcements/detail/1616144864288305862), [본문 확인](https://store.steampowered.com/news/posts/?appids=646570&enddate=1565896659&feed=steam_community_announcements)

| 확인한 요소 | 사용자 경험에 대한 해석 | 우리 프로토타입에 적용할 점 |
|---|---|---|
| Intent의 아이콘·수치 | 여러 위협을 한눈에 비교한다. | 층의 공격 표식을 `공략도 6 × 2`처럼 실제 타격 정보와 연결한다. |
| 카드 옆 키워드 설명 | 효과를 읽던 자리에서 공통 규칙을 확인한다. | 카드·층·도움말에서 같은 용어에 같은 설명을 연결한다. |
| 획득 전에도 상세 설명 제공 | 구매한 뒤에야 효과를 알게 되는 실수를 줄인다. | 웹·보관·배치된 층의 상세 카드 양식을 일치시킨다. 이 기반은 이미 있다. |
| 비율을 실제 손실량으로 표시 | 현재 상황에서 치를 비용이 직접 보인다. | `공포 최대 12`와 함께 `현재 불안 2라면 공포 8`을 보여준다. |
| 정보 검토와 실행의 분리 | 터치·클릭으로 설명을 보다가 자원을 쓰는 실수를 줄인다. | 정보 버튼과 구매·직접 사용 버튼을 분리하고, 대상 선택 취소를 유지한다. |
| 빠른 연출 | 익숙한 사건의 반복 시간을 줄인다. | 기존 빠름 옵션을 유지하면서 심장 제거·영구 파괴·종료 이유를 기록에 남긴다. |

이 표의 오른쪽 두 열은 원작 기능에서 도출한 적용 해석이다. Slay the Spire가 우리 게임과 같은 경로 시뮬레이션이나 전투 상세 로그를 제공한다는 주장은 아니다.

## 2 사용자 설정 1에서 지켜야 할 규칙과 표현

[사용자 설정 1](../mvps/mvp-config-user-1.md)의 결정에 맞춰 아래를 적용한다. 공통 문서에 미정으로 남은 부분도 이번 프로토타입에서는 실행값이 정해져 있다.

## 3 반복 설명을 줄이는 키워드와 정보 배치

### 고유 효과와 공통 판정의 역할을 나눈다

사용자 설정 §9.3은 카드에 수치·대상·비용·횟수·조건·지속시간을 표시하고, ‘수확’이라는 제목만 보여주지 않도록 요구한다. **키워드화는 이 정보를 삭제하는 변경이 아니다.** 반복되는 공통 판정을 같은 용어에서 확인하게 하는 보완이다.

| 정보 위치 | 남길 내용 | 예 |
|---|---|---|
| 층 박스 | 전체 이름, 핵심 효과 수치, 현재 공략도·파훼 토큰·잔량, 주요 위험 | `도착: 불안 최대 3 → 공포 최대 12` |
| 공통 상세 카드 | 통과·도착·직접 사용, 고유 수치·대상·비용·조건·수명, 현재값 계산 | `손님 불안 최대 3 소비 → 소비한 불안 1당 공포 4, 최대 12를 한 번에 부여` |
| 용어 설명 | 여러 카드가 공유하는 정의·판정·경계 | `심장마비: 한 공포 효과로 최대 한 번. 공포 초기화와 초과분 소멸` |
| 경로·타격 상세 | 이번 선택에서 실제 발생할 사건의 순서와 계산 | `불안 0→2 → 불안 2 소비 → 공포 8 → 생존 손님 공격` |

카드에는 항상 고유 효과가 읽혀야 한다. 짧은 층 요약을 상세 카드의 유일한 설명으로 재사용하지 않는다. ‘이번 턴’, ‘다음 턴부터’, ‘생존 배치 괴이 하나’, ‘자기 자신 가능’처럼 선택 결과를 바꾸는 정보도 해당 효과 근처에 둔다.

### 우선 재사용할 용어

새 용어를 늘리기보다 현재 쓰는 단어를 먼저 일치시킨다. 아래는 사용자 설정 1에 대한 설명안이다.

| 용어 | 공통 설명의 핵심 | 개별 효과에 계속 남길 정보 |
|---|---|---|
| 통과 / 도착 | 중간 방문 / 마지막 방문에서 각각 해당 효과만 발생 | 이번 경로의 층 번호·방문 순서·실제 효과 |
| 직접 사용 | 눈 확정 뒤 이동 전에 사용. 사용할 때마다 비용·조건 검사 | 효과 이름·사용자·대상·잔량·비용·불가 사유 |
| 불안 수확 | 손님의 불안을 소비해 공포로 전환 | 최대 소비3, 소비1당 공포4, 한 번에 부여 |
| 이번 턴 보호 | 지정 괴이에 대한 총량 흡수. 타격 순서대로 잔량 소비, 손님 공격 뒤 또는 손님 종료 때 남은 양 제거 | 대상 범위·자기 지정·흡수6·사용 횟수 비용 |
| 충전 | 해당 괴이의 직접 사용 잔량을 늘림 | 자기 방어 횟수+1·상한2·새 충전 다음 턴 사용 |
| 공략도 수리 | 공략도를 낮추며 파훼 토큰·파괴 개체는 복구하지 않음 | 불안2 비용·공략도 최대6 감소·공략도 있는 생존 대상 |
| 심장마비 / 파훼 | 공포 효과와 개별 타격·공략도 추가에서 각각 한계 판정, 초과분 소멸 | 현재 공포·남은 심장 / 공략도·파훼 토큰. 두 자산을 같은 아이콘으로 혼동시키지 않음 |

용어는 밑줄·정보 표식과 일관된 문구로 식별하고, 호버·키보드 초점·탭으로 같은 설명을 연다. 기존 상세 카드 고정과 ESC 해제를 활용하되, 우선은 카드 옆에 공통 설명 하나를 읽는 정도로 시작한다. 여러 단계의 중첩 팝업은 도입 필요성을 확인한 뒤 검토한다.

### 실제 효과 문구 예시

다음은 상세 카드의 **효과 영역** 예시다. 이름·역할·공략 한계·파훼 토큰·실제 잔량 등 나머지 카드 정보는 기존 양식대로 유지한다.

**이름을 부르는 객실**

- 통과할 때: 효과 없음.
- 도착할 때 — 불안 수확: 손님 불안 최대3 소비 → 소비한 불안1당 공포4, 최대12를 한 번에 부여.
- 직접 사용: 효과 없음.
- 현재값 예: `현재 불안2 → 불안2 소비 · 공포8`. ‘심장마비’ 설명에서 한 효과당 최대 한 번과 초과분 소멸을 확인한다.

**닫히지 않는 방화문**

- 통과할 때: 효과 없음.
- 도착할 때 — 충전: 자기 방어 횟수+1 · 최대2회 · 새 충전은 다음 턴부터 사용.
- 직접 사용 — 이번 턴 보호: 살아 있는 배치 괴이 하나가 받는 공략도6 흡수 · 자기 자신 가능 · 사용마다1회 소비.
- 잔량 옆에는 `새 영업 시작 시 2회로 복구`를 유지한다. 상한 상태의 현재값은 `남은2/2회 → 추가 충전0`으로 구분한다.

**벽을 꿰매는 그림자**

- 통과할 때 / 도착할 때: 각각 효과 없음.
- 직접 사용 — 공략도 수리: 손님 불안2 소비 → 살아 있는 배치 괴이 하나의 공략도 최대6 감소 · 공략도1 이상 필요 · 자기 자신 가능 · 파훼 토큰 복구 없음.
- 대상 확인 예: `공략도4→0 · 불안3→1`. 대상 선택 중에는 선택할 층과 지불할 비용을 함께 보여준다.

## 5 선택 결과를 이해하게 하는 구체적 표시

### 고정 능력과 현재값과 경로 결과를 구분한다

객실 카드의 `현재 불안2라면 공포8`은 **지금의 불안만으로 계산한 참고값**이다. 실제 경로에서 먼저 문틈의 속삭임을 통과하면 소비할 불안이 달라질 수 있다. 따라오는 발자국도 현재 불안0에서는 증가가 없지만, 앞에서 공급을 받으면 작동한다. 선택 경로의 결과는 반드시 방문 순서대로 계산한다.

기본 배치·입장 전·불안0에서 눈3을 고를 수 있다면 다음처럼 설명할 수 있다. 직접 사용 없이 이동하고 첫 손님을 상대하는 예다.

`1층 문틈의 속삭임 통과: 불안0→2 → 2층 빈층 → 3층 이름을 부르는 객실 도착: 불안2 소비·공포8`

첫 손님의 공포 한계12에 아직 못 닿으므로 공격은 취소되지 않는다. 객실이 공략도0·파훼 토큰2에서 시작했다면 공략도6 두 타격 뒤 공략도0·파훼 토큰1이 된다. **공포가 얼마나 늘었는지와, 그 결과 공격을 취소했는지**를 별도로 보여줘야 한다.

### 요약과 상세가 같은 선택을 가리키게 한다

각 눈을 검토할 때 요약 필드는 `도착층 → 공포·심장 변화 → 손실 위험 → 충전·잔량 변화`처럼 같은 순서로 둔다. 큰 상태 변화만 먼저 보이고, 필요한 경우 해당 층과 사건을 펼쳐 확인한다. 같은 눈이 여러 개면 같은 결과임을 표시해 중복 계산을 줄이되 실제 주사위 세 개와 선택 규칙은 유지한다.

눈 확정 전 예고는 현재까지 완료한 행동을 기준으로 계산한다. 눈 확정 뒤 직접 사용을 하면 그 고정된 경로의 예고를 갱신한다. 예고 확인만으로 비용·주사위·미래 웹·패널티 추첨을 진행하지 않는다.

### 위험과 경계는 해당 조작 옆에 둔다

| 조작·상태 | 가까이 보여줄 문구·결과 |
|---|---|
| 보호6과 다단 공격 | `첫 타격6 흡수 → 보호0 → 두 번째 타격6 적용`. 총량 흡수와 타격마다 감소를 구별한다. |
| 수리로 불안 소비 | 감소할 공략도와 남을 불안, 그 불안을 반영한 선택 경로의 수확 결과를 함께 표시한다. |
| 방화문 도착 | `충전 후1/2회 · 다음 턴부터 사용`. 이번 이동 뒤 공격을 막는 보호처럼 표시하지 않는다. |
| 같은 영업 다음 손님 | `공략도0 · 파훼 토큰과 남은 사용 유지`. 이번 턴 보호는 넘기지 않는다. |
| 다음 영업 시작 | `생존 개체만 복구 · 방화문/호출벨 남은 사용2회로`. 영구 손실을 되돌리지 않는다. |
| 탈출구 설치 | 실제 접촉할 층·접촉 이후 중단되는 경로·포기할 보상 범위. 최종 보스에서는 `탈출 시 패배`. |
| 마지막 배치 괴이 파괴 | `전멸 패배`. 보관함의 괴이로 즉시 구조하거나 빈층 출구로 계속 진행할 수 있는 것처럼 표시하지 않는다. |
| 비활동 패널티 예정 | 발동까지 남은 턴·공략도12·가능한 대상. 정상 공격 뒤 남은 생존자에 따라 달라지며 실제 무작위 표적은 미공개다. |

구매 화면에서도 같은 원칙을 적용한다. 가격·남은 경로 비용·현재 보유 개수에 더해 호텔의 빈층과 교체할 개체를 쉽게 확인하게 한다. 구매 보류와 재배치도 정상적인 선택이며, 구매를 강제하는 튜토리얼이나 추천 정답을 기본으로 넣지 않는다. 웹 리셋에는 보유 자산 유지와 옛 지출 미환급을 표시한다.

## 7 인간 플레이에서 확인할 경험

기존 Steam 리뷰 조사에서 얻었던 학습·통제감·초기 선택 비용의 질문은 아래 관찰에 활용한다. 당시 6건의 목적 표집을 전체 이용자의 평가나 새 UI의 개선 효과로 일반화하지 않는다.

| 장면 | 관찰할 경험 | 개선을 지지할 근거 |
|---|---|---|
| 처음 보는 괴이 | 이름과 효과를 읽고 필요한 때 공통 설명을 찾아본다. | ‘수확’만 외운 것이 아니라 실제 불안 소비량과 공포 결과를 예측한다. |
| 통과·도착 선택 | 도착층의 통과 효과를 더하지 않고 경로를 비교한다. | 예고와 실제 결과가 맞았다고 설명하고 다른 눈을 선택할 근거를 찾는다. |
| 보호·수리·충전 | 버튼과 대상, 비용·수명을 구별한다. | 충전을 즉시 보호로 오해하거나 수리로 토큰이 돌아온다고 예상하는 일이 줄어든다. |
| 구매·중복·재배치 | 구매한 새 개체와 기존 개체, 정확한 선행 노드를 구별한다. | 구매 후 보관함에서 찾고 원하는 층에 배치하며 손실 뒤 대체 구매를 이해한다. |
| 영구 손실·경계 | 다음 손님과 다음 영업의 복구 차이를 이해한다. | 사라진 개체가 돌아올 것으로 기대하지 않고, 남은 토큰·횟수로 다음 대응을 계획한다. |
| 빠른 반복과 패배 | 짧은 연출 뒤에도 손실·종료 원인을 기록에서 확인한다. | 무슨 일이 있었는지 재구성하고 다음 판에 바꿀 배치·사용 순서를 스스로 제안한다. |
| 정보 확인과 실행 | 호버·초점·탭으로 읽고, 미완료 선택을 취소한다. | 설명을 보려다 구매·비용 소비가 발생하는 실수 없이 조작한다. |

플레이 중 매 턴 이유를 쓰거나 정답 퀴즈에 답하게 하지 않는다. 첫 자발적 플레이를 먼저 관찰하고 구간 뒤 짧게 예상·결과·다음 시도를 묻는다. 설명을 추가로 해 준 뒤의 선택은 첫 이해와 구분한다.

보완 전후에는 설명 재탐색, 오해한 예측, 취소·잘못 누른 행동, 결과를 찾지 못한 장면을 같은 기준으로 기록한다. 읽는 시간이 짧아져도 조건을 놓치면 개선으로 판정하지 않는다. 같은 사람의 재플레이는 학습 영향을 구분하고, 자동 판정 검사·완주 성공을 인간의 이해나 재미의 증거로 대신하지 않는다.

## 8 사서덱에서 얻는 user-3 증설 통찰

**증설의 보상을 ‘일부 층이 막혀도 공급·수확·지원을 이어갈 수 있는 여유’로 설계한다.** 사용자가 제시한 사서덱의 ‘두꺼운 덱은 상태이상 카드의 비중이 낮지만 원하는 카드에 접근하기 어려울 수 있다’는 설명을 호텔의 공간·이동·역할 분배에 연결한 해석이다. 사서덱이라는 용어의 유래나 1·2편의 상대적 성능 평가는 이 설계 논거에 포함하지 않는다. 사용자 제공 참고 토론: [사서덱 운영 글](https://m.dcinside.com/board/slay/495376), [관련 토론](https://gall.dcinside.com/mgallery/board/view/?id=slay&no=280044).

아래는 **설계 통찰·후보이며 채택된 새 효과나 검증 결과가 아니다.** 현행 user-3의 손님은 공략 타격 중심이다. 봉인·침묵·구금에 대한 저항력은 [새 손님 후보](../designs/guests.md)를 도입할 때 특히 선명해질 장점이다.

### 8.1 증설과 두꺼운 덱의 대응 관계

| 사서덱 비유의 요소 | 호텔에서 대응하는 요소 | 증설의 가치가 생길 조건 |
|---|---|---|
| 상태이상 카드가 차지하는 비중 감소 | 일부 괴이의 봉인·침묵·구금이 전체 전력에서 차지하는 비중 감소 | 추가 층에 실제 대체 기능을 배치하고 방해가 고정된 수의 개체에 적용됨 |
| 다양한 상황에 쓸 카드 확보 | 공급·수확·보호·정화 등 함께 운용할 역할 증가 | 새 괴이가 기존 조합의 부족한 대응을 채움 |
| 핵심 카드를 늦게 뽑을 위험 | 핵심 층 재방문 지연·한 턴에 도달할 수 없는 거리 발생 | 특정 도착 하나에 의존하는 정도와 실제 이동 경로에 따라 달라짐 |
| 드로우·에너지로 두꺼운 덱을 운용 | 통과 효과·원격 직접 사용·복수 목적지·거리 조절로 큰 호텔을 운용 | 늘어난 층을 이용할 수단과 공급 순서가 함께 마련됨 |

두 구조는 같지 않다. 호텔은 카드를 무작위로 뽑는 대신 공개된 층을 순서대로 이동하며, 생존 배치 괴이의 직접 사용은 도착하지 않아도 가능하다. 비유는 **기능의 폭과 접근 비용을 함께 설계하는 원리**로 활용한다.

user-3에는 이를 받치는 기반이 있다. 전투 완승마다 괴이 하나를 무료로 얻고 동종 중복 배치도 가능하다. 상점 증설은 보관 중인 추가 괴이를 기존 역할과 함께 운용할 공간을 제공한다. 다만 증설은 빈층만 추가하며 새 괴이·토큰·사용 횟수를 지급하지 않는다. 실제로 어떤 괴이를 더 배치했는지까지 봐야 한다. [현행 시작 자산·보상·상점 규칙](../mvps/mvp-config-user-3.md)

### 8.2 상태 이상에 대한 저항력은 방해의 범위에서 결정된다

| 손님의 방해 설계 예 | 큰 호텔이 얻을 수 있는 이점 | 조건·한계 |
|---|---|---|
| 생존 괴이 하나의 도착 효과 봉인 | 다른 수확층에서 공격을 이어감 | 대체 수확자와 그곳에 공급할 경로가 필요 |
| 생존 괴이 두 개의 직접 사용 금지 | 다른 보호자·수리자·정화자가 역할을 대신함 | 방해받지 않은 개체의 잔량·비용도 남아 있어야 함 |
| 인접한 두 층의 효과 약화 | 핵심 기능을 떨어뜨려 배치할 공간 확보 | 증설 뒤 재배치가 실제로 약화 범위를 분리해야 함 |
| 손님의 불안 전체 제거 | 층 수 자체로는 희석되지 않음 | 재공급·다른 공격 자원·즉시 수확이 대응 수단 |
| 모든 괴이의 도착 효과 봉인 | 늘어난 개체도 함께 막힘 | 통과 공격·직접 사용처럼 다른 실행 경로가 있어야 함 |

**개체 수가 늘어도 방해 대상 수는 고정되는 손님**은 넓은 호텔의 대체 전력을 드러내기 좋다. 반대로 모든 괴이·특정 역할 전체·손님의 공통 상태를 건드리는 방해는 단순한 개체 수 증가로 희석되지 않는다.

무작위 표적의 모집단도 중요하다. 생존 배치 괴이 중 하나를 고르는 효과라면 **빈층만 늘려도 표적 확률은 바뀌지 않는다.** 강한 괴이만 골라 공격하는 손님에게는 무관한 개체를 추가하는 것만으로 미끼가 생기지 않는다. 필요한 기능을 복수로 배치하거나 표적 선정 조건을 바꿀 수 있어야 한다.

따라서 ‘상태 이상에 강한 큰 호텔’은 **슬롯 증가 + 대체 역할 배치 + 그 역할에 접근할 수단**의 결합이다. 정화 괴이도 좋은 증설 목적이다. 기존 공급·수확·보호를 유지하면서 정화를 함께 배치하면 봉인 뒤 공격을 복원할 수 있다.

### 8.3 원하는 한 칸과 유효한 도착지 여러 곳을 구분한다

일반 주사위 세 개를 쓸 때, 현재 위치에서 앞으로1~6칸 안에 있는 특정 층의 눈이 한 번 이상 나올 확률은 층 수만으로 낮아지지 않는다. 층이 늘어나면 **핵심 층이 그 범위 밖으로 멀어지거나 재방문이 늦어질 수 있다.** 현재 위치·층 순서·장비에 따라 접근 비용이 달라진다.

반대로 추가 공간에 공급→수확 연결을 여러 곳 만들면 유효한 도착지가 늘어난다. 다음은 일반 주사위3개의 독립 굴림에서, 서로 다른 눈에 대응하는 목적지들이 모두 앞으로1~6칸 안에 있는 경우의 계산이다.

| 이번 턴 유효한 목적지에 대응하는 눈의 수 | 하나 이상 공개될 확률 |
|---|---:|
| 1개 | `1−(5/6)^3 = 91/216`, 약42.1% |
| 2개 | `1−(4/6)^3 = 152/216`, 약70.4% |

이는 **그 목적지에서 필요한 공급과 효과 조건까지 충족한다는 가정**의 도달 기회 계산이다. 층을 하나 사면 도달률이 자동으로 이만큼 오른다는 뜻이나 처치율·승률 계산이 아니다. 봉인된 수확자, 불안이 부족한 수확자, 도착 전에 공급이 끊기는 경로는 유효한 목적지로 세지 않는다. 특수 주사위는 실제 면 구성으로 따로 계산해야 한다.

핵심은 추가 공간을 **여러 실행 경로**로 바꾸는 것이다. 수확자 하나가 먼 경우에도 다른 수확자·도착 공급·충전 목적지를 고를 수 있으면 큰 호텔의 이동이 계획의 전환으로 이어진다.

### 8.4 큰 호텔을 굴리는 지원 기능

| 기능 | 증설과 연결되는 가치 | 현재 기준과 후보 구분 |
|---|---|---|
| 원격 직접 사용 | 그 층에 도착하지 않아도 보호·수리·공격으로 기여 | 방화문·그림자·호출벨에 이미 있음. 추가 배치도 각 개체의 잔량·자원을 사용 |
| 통과 효과 | 최종 목적지가 아니어도 경로 중 기여 | 기존 공급·증폭을 활용. 도착층의 통과 효과까지 합산하지 않음 |
| 복수의 공급·수확 지점 | 봉인·불리한 눈에도 다른 연결 선택 | 동종 중복 배치로 가능하지만 실제 층 순서·불안 소비를 반영해야 함 |
| 거리·방향 조절 | 늘어난 호텔에서 필요한 연결에 접근 | 현행 장거리 주사위는 면 구성이 다른 선택지. 추가 거리 조절·방향 전환은 별도 괴이 후보 |
| 정화·행동 차단 | 막힌 핵심 기능을 복원하거나 방해를 사전에 끊음 | [린넨실·인터폰 등 지원 후보](../designs/creatures.md). 현행 여섯 괴이에는 없는 확장 |

추가 층에 도착형 공격자만 넣을 필요는 없다. **도착을 요구하지 않는 지원층**이 큰 호텔의 운용을 받칠 수 있다. 특히 방화문·그림자는 먼 층에서도 현재 공격을 보호할 수 있어, 증설로 얻은 자리가 매 턴 기여할 경로를 이미 가진다. 직접 사용 시점은 여전히 눈 확정 뒤·첫 이동 전이며, 이동 중 얻을 불안을 앞당겨 쓰지는 못한다.

장거리 주사위도 이름만으로 큰 호텔의 정답이 되지는 않는다. 일반 주사위의6 대신8이 들어가므로 추가되는 거리와 사라지는 거리를 현재 배치에서 함께 비교한다.

### 8.5 개체 강화와 증설을 서로 다른 성장 방향으로 삼는다

user-3 v1.1의 강화는 **생존 개체 하나의 정해진 효과를 한 번 개선**한다. 증설은 **여러 개체와 연결을 동시에 운용할 공간**을 늘린다. 이를 통해 강화한 핵심 개체에 집중하는 호텔과, 기능을 분산하고 대체 전력을 마련하는 호텔에 서로 다른 장점을 줄 수 있다.

파훼 토큰이 전투·막 사이에 이월되고 파괴는 영구 손실이므로 대체 전력의 의미도 커진다. 다만 보관 괴이도 보유할 수 있으므로, **비전투 중 교체할 예비 자산**과 **같은 전투 안에서 즉시 기능을 대신할 배치 전력**을 구별한다. 증설은 후자의 운용 폭을 넓힌다.

회복은 방문당 호텔 전체 합계2토큰이며 강화와 택일이다. 괴이가 늘어도 회복 예산은 늘지 않는다. 큰 호텔은 손상·방해를 분산할 수 있는 대신, 피해를 광범위하게 받으면 같은 회복량으로 관리할 개체도 많아진다. 추가 개체의 토큰을 호텔 전체가 자유롭게 나눠 쓰는 공동 체력처럼 계산하지 않는다.

이 방향에서 증설을 원하는 이유는 **‘그 층이 막혀도 다른 수확자·지원자·경로로 이번 공격을 계속할 수 있기 때문’**이 된다. 고정 대상 수의 방해, 역할의 대체 가능성, 여러 유효 도착지, 큰 호텔을 지원하는 능력이 함께 있을 때 사서덱 비유가 실제 선택으로 연결될 수 있다.
