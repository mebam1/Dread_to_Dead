# Dread to Dead · 텍스트 21

동료 한 명과 목적지를 골라 1~10번 직선 전장에서 싸우는 한국어 텍스트 게임이다. 규칙 버전은 `text-21-v1.1`이다. [핵심 규칙과 동료 도감](../rules.md) · [용어집](../terms.md) · [설정 21의 배치 예시](../mvps/mvp-config-21.md)

## 시작

Node.js 22 이상에서 Windows의 [play.cmd](play.cmd)를 실행한다. 터미널에서는 저장소의 `mvp_text_21` 폴더에서 다음 명령을 쓴다.

```sh
node cli.mjs play
```

기본 판 번호는 31001이다. `runs/my_game.json`에 매 행동을 자동 저장하며, 같은 명령으로 이어서 플레이한다. 진행 중 `상태`로 현재 배치와 적의 예고를, `도움말`로 현재 사용할 수 있는 명령을 읽는다. `종료`는 대화창을 닫고 `원정포기`는 원정을 패배로 끝낸다.

## 첫 전투

새 기본 판에서는 1번 성녀 `c2`, 2번 성기사 `c1`, 3번 성가대원 `c3`로 시작한다. 대화창에 아래 명령을 한 줄씩 입력한다.

```text
방문 1
시작
검토 #C3
검토 #C3 8
이동 #C3 8
기록 12
```

`방문 1`은 첫 번째 선택지인 `1-1-좌`에 들어간다. `검토 #C3`은 성가대원이 갈 수 있는 아홉 목적지를 요약한다. `검토 #C3 8`은 3→4→5→6→7→8 경로, 도착 공격과 해당 이동 직후의 결과를 상세히 보여 준다. `이동 #C3 8`에서 한 수가 확정된다. 영문으로 같은 조작을 하려면 `visit 1`, `start`, `preview c3`, `preview c3 8`, `move c3 8`, `journal 12`를 사용한다.

기본 이웃은 같은 행에서 한 칸 차이다. 목적지는 빈칸과 점유된 동료 칸 모두 가능하다. 점유자는 걸음마다 이동자가 방금 떠난 칸으로 밀린다. 누가 밀리고 어디서 통과·도착·복사·반응이 발동하는지, 방어·보호 뒤에 남는 실제 체력 피해와 최대 체력까지의 회복량을 확인한다.

위 예시의 첫 이동에서 성가대원이 8번 적 `E3`의 체력을 30에서 20으로 낮춘다. 다음 수에 `검토 c3 2`를 입력하면 2번 성기사가 3번으로 밀리고, 이번에 만료되는 `E1`이 성가대원을 노린다. 성기사가 피해 19를 대신 받아 방어 10을 소모하고 실제 체력은 60에서 51로 줄어드는 결과를 볼 수 있다.

## 적 행동 예고

이동을 한 번 확정할 때마다 행동 수가 증가한다. 적마다 첫 카운터와 반복 주기가 있다. 카운터가 1이면 **이번 이동 직후** 그 적이 행동한다. 동시에 만료되는 적은 처음 편성된 순서로 처리한다. 이동과 밀림으로 바뀐 칸, 새 표적, 방어와 실제 체력 변화를 순서대로 볼 수 있다.

| 패턴 | 예고에서 확인할 내용 | 1·2·3막 기본 수치 |
|---|---|---|
| 추격 타격 | 가장 가까운 동료의 정면까지 가는 방향과 거리, 그 자리에서 한 번 칠 대상 | 타격당 17 / 25 / 34 |
| 반사 경로 공격 | 좌우 중 진행 방향, 끝에서 방향을 바꾸며 실제로 방문할 세 칸과 각 타격. 한 칸을 재방문하면 그 칸의 두 번째 타격도 표시한다. | 타격당 14 / 21 / 28 |
| 추격 광역 공격 | 가장 가까운 동료의 정면까지 이동한 뒤, 도착 칸의 왼쪽·정면·오른쪽 중 보드 안에 있는 타격 칸 | 타격당 14 / 21 / 28 |
| 이동 치유 | 가장 먼 다른 적의 칸까지 걷는 경로, 밀림이 끝난 뒤 양옆 적이 실제로 회복할 체력 | 대상당 회복력 8 / 12 / 16 |

`검토 동료ID 목적지`의 맨 위 ‘동료 체력 피해’와 ‘실제 회복’은 **지금 고른 한 수**의 합계다. 이 수에 0이 된 적의 반격과 독·탈진·가스 정산까지 포함한다. 맨 아래 **‘이동 후 다음 예고’**는 그 이후 동료 배치가 그대로일 때의 결과다. 예를 들어 위에 ‘동료 체력 피해 0’, 아래에 ‘다음 예고 … 체력 피해 9’가 보이면 지금 9를 받는 것이 아니다. 다음에 다른 카드를 옮기면 예고도 달라진다.

속공·철수 지점 설치와 예고 조회는 이동 횟수를 쓰지 않는다. 성기사의 대신 받기 한도와 방어, 독 치료사의 속공은 전투 시작과 이후 매 3번째 이동의 적 행동·정산 뒤 갱신한다.

## 별도 저장과 단발 실행

비교할 원정은 새 경로에 만들거나 `분기 새파일`로 현재 진행을 복사한다. 판 번호와 파일 경로를 지정하려면 다음과 같이 실행한다.

```sh
node cli.mjs --save runs/forest.json 플레이 31001
node cli.mjs --save runs/forest.json --text 상태
node cli.mjs --save runs/forest.json --json show
```

단발 명령은 기본으로 JSON을 출력하고 `--text`를 붙이면 대화창처럼 읽을 수 있다. 매번 반환하는 `revision`은 저장 진행 번호다. 다른 창이나 스크립트와 같은 저장을 사용할 때 `--revision`에 마지막으로 확인한 번호를 넣으면 그 상태에서만 입력을 확정한다. 대화창은 이를 자동으로 적용한다. 선택 이유를 기록하려면 `--reason "성가대원 반응 준비"`를 덧붙인다. 21판은 전용 저장 형식과 규칙 버전을 확인한다.

### 중단된 저장 복구

저장 도중 프로세스를 강제 종료하면 `.lock` 파일이 남을 수 있다. CLI가 종료된 소유자 PID를 알리면 이 저장을 사용하는 다른 CLI와 자동 실행을 먼저 닫는다. 기본 저장을 예로 든 아래 PowerShell 명령은 잠금 파일에서 읽은 PID가 현재 프로세스 목록에 없을 때 해당 잠금 파일 하나만 지운다. 별도 저장을 사용했다면 첫 줄에 해당 저장의 `.lock` 경로를 지정한다.

```powershell
$gameLock = Resolve-Path -LiteralPath '.\runs\my_game.json.lock' -ErrorAction Stop
$gameOwnerId = [int](Get-Content -LiteralPath $gameLock -Raw -ErrorAction Stop)
$runningIds = (Get-Process -ErrorAction Stop).Id
if ($gameOwnerId -gt 0 -and $runningIds -notcontains $gameOwnerId) {
    Remove-Item -LiteralPath $gameLock
}
```

이어서 `node cli.mjs play`로 재개한다. `.next`와 `.commit`이 있으면 CLI가 완료된 저장을 읽고 다음 확정 입력에서 원래 파일로 복구한다.

## 검증

```sh
npm test
npm run verify:balance
```

첫 명령은 규칙·CLI 회귀 검사를 실행한다. 두 번째 명령은 각 막에서 만피·미강화 동료 11종이 세 공격 패턴에 한 번씩 적중당하는 33개 장면을 계산한다. 자신의 방어와 남은 체력 상한을 적용하고 외부 지원과 대신 받기를 제외한 평균 체력 손실은 1막 **40.3%**, 2막 **60.6%**, 3막 **80.1%**다.

기본 판 31001에서 매 수 목적지별 예고를 비교한 자동 플레이 한 판은 129번 이동해 54개 지점과 27전투를 거쳐 3막 보스를 처치했다. 방어·대신 받기·남은 체력을 포함해 실제 수신자의 최대 체력 대비 줄어든 HP를 집계한 결과는 아래와 같다. 한 타격이 나뉘면 수신자마다 한 건으로 세고, 전부 흡수한 타격도 0으로 포함했다.

| | 1막 | 2막 | 3막 |
|---|---:|---:|---:|
| 자동 원정의 적 공격 명중 수 | 7 | 8 | 18 |
| 피해를 받은 동료 기준 건수 | 7 | 8 | 20 |
| 수신자당 평균 체력 손실 | 21.7% | 40.1% | 52.2% |
