# Dread-to-Dead: Fears Go Round — 사용자 설정 3

> v1.1 · 2026-11-01 · 3막 분기 모험·발견 보상·영혼 경제에 상점 증설·회복 노드·파훼 토큰 이월·개체 강화를 반영한 user-3의 현행 제작 명세다. 이 파일에서 기존 명세를 대체한다. 최신 사용자용 웹 프로토타입은 `mvp_user_2`이며, `mvp_text_15`의 기존 구현·플레이 결과는 이번 변경을 검증한 결과가 아니다.

## 1. 목표와 적용 기준

**주사위와 호텔 배치의 재미를 유지하면서, 다음에 어떤 기회를 방문할지 선택하는 한 판**을 만든다. 사용자가 재미있게 플레이한 user-2의 전투를 기준으로, 매번 전투 뒤 구매를 반복하던 진행과 블러드 웹 경제를 교체한다. 적·괴이의 대규모 증량은 이번 변경의 필수 조건이 아니다.

- 기본 자산·전투는 [텍스트 실험 15](../mvp_text_15/README.md)의 기존 규칙을 비교 기준으로 유지한다. 그 이전 기준은 [사용자 설정 2 v1.1](mvp-config-user-2.md)과 [프로토타입 2](../mvp_user_2/engine.js)다. 충돌 시 이 문서의 변경을 우선한다.
- 공통 전투 판정은 [핵심 규칙](../rules.md)을 따른다. 다만 블러드 웹·공포 재화·자동 구매 화면 전환·보스 주사위 보상·파훼 토큰 자동 복구처럼 이 명세와 충돌하는 부분은 아래 규칙으로 대체한다. 기존 전역 문서나 과거 구현의 해당 표현을 user-3의 권한으로 사용하지 않는다.
- 다음 전투 준비 최초 진입 때 **공략도 초기화·직접 사용 잔량 복구**는 유지하고, **파훼 토큰은 복구하지 않는다.** 토큰 회복은 회복 노드에서 명시적으로 선택할 때만 가능하다. 선택 없는 손님·보상 전환은 자동 진행한다.
- 사용자 요청으로 확정된 방향과 명세 작성을 위해 채운 실험값을 구분한다. 실험값은 이번 제작의 기본값이며 사용자에게서 직접 지정받은 수치나 검증된 밸런스가 아니다.
- 규칙을 먼저 이 문서에 고정한 뒤, 사용할 화면과 전환은 [모험 UI 설계](../ui/adventure.md), 호텔 조작은 [준비 UI](../ui/prepare.md), 전투 조작은 [전투 UI](../ui/battle.md)에 맞춘다.

### 1.2. 이번 명세에서 고정하는 실험값

일반 전투의 손님 3명, 괴이 보상 건너뛰기 미제공, 상점 중복 재고, 한 상점 방문의 복수 증설 구매, 엘리트의 주사위 1개 제시, 적 수치·보상액, 이벤트 3종은 기존 제작 기본값을 유지한다. 지도는 팝업에서 확정한 공통 회복 구조와 깊이 3·6 회복 배치를 적용한다. 후보 수·인원·경제를 플레이 도중 결과에 맞춰 바꾸지 않는다.

### 1.3. 기존 규칙과 변경 범위

기존 user-3와 `mvp_text_15`는 증설을 별도 노드에서 구매하고 전투 준비마다 파훼 토큰을 초기값으로 복구했다. v1.1은 그 두 권한을 상점 증설과 회복 노드 선택으로 바꾼다. 기본 괴이 수치·손님·주사위·시작 자산·전투 보상·증설 가격은 유지하며, 강화된 개체에만 §8.3의 효과를 적용한다.

막당 전체 지도는 22개에서 20개로, 일반 전투만 고르는 경로의 최대 상대 수는 66명에서 57명으로 바뀐다. 방문 수는 여전히 막당 8개·완주 24개다. 기존 텍스트 15의 검사·정상 플레이·증설 분석은 v1.0의 기록으로 보존하고 이번 변경의 실적에 합산하지 않는다.

## 2. 한 판과 노드의 단위

### 2.1. 전체 진행

새 판·초기 배치 확인 → 1막 깊이 1~6 경로 선택 → 7번째 공통 회복 → 8번째 보스 승리·괴이 선택 → 2막에서 같은 8회 진행 → 3막에서 같은 8회 진행 → 최종 괴이 선택 → 승리 결과.

- **한 막은 보스를 포함해 정확히 8개 노드를 방문**한다. 완주 시 총 24개다. 보상 화면·전투 준비·지도 재열기·막 전환은 방문 수에 더하지 않는다.
- 매 막 7번째 회복과 8번째 보스는 모든 경로가 방문한다. 회복에서 아무 효과도 받지 않고 스킵해도 회복 방문 1회가 완료되며, 6번째에서 보스로 바로 건너뛰지 않는다.
- 일반 전투는 손님 3명을 연속 상대하는 기존 영업 1회다. 엘리트·보스는 각각 손님 1명이다. 노드 방문 수·전투 노드 수·처치 손님 수를 별도로 집계한다.
- 지도의 시작점은 선택 위치일 뿐 방문 노드가 아니다. 최초 상점·증설·무료 주사위를 별도로 붙이지 않는다.
- 노드 선택을 확정하면 해당 노드 방문을 시작하며, 그 노드를 해결하거나 명시적으로 떠나기 전에는 다른 노드로 갈 수 없다. 전투 준비에 들어간 뒤 지도로 취소해 다른 갈래를 고르지 못한다.
- 화면에는 `1막 / 3 · 방문 완료 2 / 8 · 현재 3번째: 상점`처럼 완료 수와 진행 중 방문을 구분한다. 떠나기·스킵도 그 노드의 방문 완료로 센다.
- 전투 사이에 상점을 자동으로 붙이지 않는다. 지도에서 상점으로 연결된 길을 골라야 구매할 수 있다.

### 2.2. 상태의 이월과 종료

- 막을 넘어도 영혼·생존 괴이와 개체별 남은 파훼 토큰·강화 여부·보관함·배치·호텔 층 수·장착 주사위를 유지한다. 막 전환 자체는 별도 보상·복구·주사위 획득을 만들지 않는다.
- 모든 막의 보스를 처치해야 다음 막 또는 최종 승리로 간다. **어느 막이든 보스 탈출은 패배**다. 기존 중간 보스 탈출 후 계속 진행 규칙은 폐기한다.
- 일반·엘리트에서 탈출하면 해당 노드는 탈출 완료로 처리해 다음 지도 선택으로 간다. 이미 처치한 손님의 영혼만 유지하며, 미처치·미등장 손님과 노드 완료 괴이·엘리트 주사위는 지급하지 않는다.
- 배치된 마지막 생존 괴이가 파괴되면 보관함에 괴이가 남아도 즉시 전멸 패배다. 이후 전투 보상이나 복구로 구조하지 않는다.
- 최종 보스의 마지막 심장 제거로 전투 승리를 확정하고 잔여 공격을 중단한다. 이번 요청의 모든 전투 보상을 일관되게 적용해 **최종 괴이 3중 1 선택까지 마친 뒤 승리 결과**로 간다. 이 괴이는 최종 보유 목록에만 반영되며 추가 전투·구매·다음 판 이월은 없다.
- 고정 턴 제한·생산 불능 자동 패배는 두지 않는다. 최종 보스 전투 승리 전까지는 모든 진행 화면에서 포기할 수 있으며 패배로 기록한다. 최종 보스 처치 뒤 마지막 괴이 보상에서는 포기 조작을 제거하고 승리 확정 상태를 유지한다.

## 3. 3막 분기 지도

### 3.1. 깊이와 연결

이번 지도 생성 기본값은 다음과 같다. 여기서 깊이는 모험 방문 순서이며 호텔 층 번호와 다르다.

- 막마다 깊이 1~6에 3개씩, 깊이 7에 공통 회복 1개, 깊이 8에 보스 1개를 둔다. **막당 전체 20개·3막 전체 60개 중 한 경로의 24개를 방문**한다.
- 깊이 1~6의 열은 왼쪽·가운데·오른쪽 3개다. 시작점에서 깊이 1의 세 노드를 모두 선택할 수 있다.
- 깊이 1~5의 각 노드는 바로 다음 깊이의 **같은 열과 바로 옆 열**에 연결한다. 왼쪽에서 다음 오른쪽으로 한 번에 건너가는 연결은 없다. 가운데에서는 다음 세 열을 모두 고를 수 있다.
- 깊이 6의 세 노드는 모두 깊이 7의 공통 회복에 합류하고, 그 회복만 깊이 8의 보스에 연결한다. 회복은 별도 추가 방문이 아니라 기존 7번째 방문을 대체한다.
- 역행·동일 깊이 횡이동·재방문·깊이 건너뛰기는 없다. 선택하지 않은 같은 깊이 노드는 그 판의 방문 대상에서 제외된다.
- 이 연결은 모든 노드의 도달 가능성과 회복을 거친 보스로의 진행 가능성을 보장한다. 깊이 1~6의 가운데 일반 전투를 따라가는 경로도 항상 남긴다.

### 3.2. 노드 종류 배치

| 깊이 | 가운데 | 양옆 두 노드의 종류 |
|---|---|---|
| 1 | 일반 손님 전투 | 일반 손님 전투 / 일반 손님 전투 |
| 2 | 일반 손님 전투 | 이벤트 / 주사위 발견 |
| 3 | 일반 손님 전투 | 상점 / 회복 |
| 4 | 일반 손님 전투 | 엘리트 전투 / 이벤트 |
| 5 | 일반 손님 전투 | 주사위 발견 / 상점 |
| 6 | 일반 손님 전투 | 회복 / 엘리트 전투 |
| 7 | 공통 회복 1개 | 없음 |
| 8 | 보스 전투 1개 | 없음 |

- 깊이 2~6의 양옆 종류는 해당 두 종류를 왼쪽·오른쪽에 무작위로 배정한다. 각 막은 독립적으로 생성한다. 깊이 7·8에는 종류·열 추첨을 하지 않는다.
- 깊이 3·6의 회복은 선택 가능하며 깊이 7은 필수 경유다. 한 경로에서 막당 회복 방문은 최소 1회·최대 3회다. 상점·주사위 발견·이벤트·엘리트 방문은 의무화하지 않는다.
- 노드와 연결선·일반/엘리트의 손님 구성·해당 막 보스 정보를 막 시작부터 공개한다. 상점 재고·발견 주사위·이벤트 내용·보상 후보는 해당 노드 또는 보상 화면에 진입할 때 공개하며, 지도 호버로 미리 추첨하거나 엿보지 않는다.
- 기존 6종 괴이와 적 패턴을 사용하므로, 초기에는 지도의 좌우 배치·진행 선택·보상·이벤트 차이를 먼저 평가한다. 새로운 막마다 완전히 다른 적 콘텐츠를 갖춘 것으로 표시하지 않는다.

### 4.1. 괴이 6종

### 4.2. 턴과 즉시 종료

1. 장착 주사위 3개를 독립적으로 굴리고 이름·눈·선택 효과를 공개한다.
2. 하나를 확정해 해당 주사위의 선택 효과를 즉시 한 번 적용한다.
3. 직접 사용·대상 선택·탈출구 설치를 하고 이동을 실행한다.
4. 한 층씩 이동하며 탈출구 접촉 우선 확인 → 해당 방문의 통과 또는 도착 효과 → 공포 효과별 심장 판정을 처리한다.
5. 손님이 살아 있으면 개별 타격별 보호·공략도·파훼를 처리한 뒤 비활동 판정으로 간다.

- 꼭대기 다음은 현재 호텔의 1층이다. 이동 거리를 층 수로 자르지 않으며 재방문도 별개 방문·타격으로 센다.
- 최종 방문은 도착 효과만 적용한다. 공포 효과 하나당 심장 최대 1개, 개별 타격 하나당 파훼 토큰 최대 1개를 제거하고 한계 초과분은 버린다.
- 마지막 심장 제거·탈출구 접촉·전멸 중 실제 순서상 먼저 발생한 종료를 즉시 적용한다. 이후 효과·이동·공격·패널티를 진행하지 않는다.
- 직접 사용은 눈 확정 뒤·첫 이동 전만 가능하다. 같은 턴 반복 사용도 매번 비용·잔량·대상을 검사한다. 이동 중 얻을 불안을 먼저 쓰지 못한다.
- 탈출구는 이 구간에 전투 노드당 한 번, 빈층 한 곳에 무료 설치한다. 설치 뒤 위치 변경·철거·추가 설치는 없다. 접촉해야 전투 노드가 끝나고, 빈층이 없으면 설치할 수 없다. 현재 손님이 있는 빈층에도 설치할 수 있지만 설치 자체는 접촉이 아니며 이후 실제로 재방문해야 한다. 손님이 바뀌어도 같은 노드의 출구는 유지하며 노드 종료 때 제거한다.
- 비활동은 첫 연속 3턴, 이후 계속 비활동이면 2턴마다 생존 배치 괴이 하나에 보호를 무시하는 공략도 12를 준다. 실제 상태 증가·공포 부여·적법한 직접 사용은 활동, 도착 충전·출구 설치·상한에 막힌 증가 0은 활동이 아니다. 활동이 생기면 유예를 3턴으로 되돌린다.

- 준비 화면은 공략도·직접 사용 복구와 **이월한 현재/최대 파훼 토큰·강화 여부**를 구별해 표시한다. 파훼 토큰의 감소는 회복을 실제 선택하지 않는 한 이후 전투와 막에 남는다.

- 생존 배치 괴이가 하나 이상이어야 영업을 시작할 수 있다. 모두 보관했다면 보유 괴이를 배치할 수 있으며, 전투 중 전멸을 보관함으로 무효화하지 않는다.
- 같은 전투의 다음 손님은 경계 정리 후 자동 입장한다. 완승 후에는 선택 보상으로 자동 전환한다. 정산 확인·다음 손님·다음 화면 승인만을 위한 버튼은 두지 않는다.

### 5.3. 공포와 영혼의 분리

- `현재 공포 F / 공포 한계 T / 남은 심장`은 처치 진행, `보유 영혼`은 구매 잔액이다. 내부 상태·로그·화면에서도 별도로 저장·표시한다.
- 마지막 심장 제거 때만 처치 영혼을 한 번 지급한다. 중간 심장마비·초과 공포·미처치·미등장에는 영혼을 주지 않는다. 괴이의 공포 효과는 영혼 수입이 아니다.
- 영혼은 상점의 괴이 구매·층 증설과 명시된 이벤트에 사용한다. 회복·강화는 무료이며 전투 중 직접 사용은 기존 잔량·불안만 사용한다.
- 새 캠페인은 경로마다 전투·이벤트 수가 달라진다. 과거의 최대 20명·전체 처치 수입 52·최종 보스 전 총 예산 46을 재사용하지 않는다. 각 판에서 실제 경로의 수입·지출과 구매 시점 잔액을 기록한다.

## 6. 전투 승리의 괴이 3중 1 발견

1. 전투 노드 완승을 확정한다. 일반은 세 손님 전원 처치, 엘리트·보스는 해당 한 명 처치다.
2. 강화 전 기본 괴이 6종에서 **서로 다른 3종을 균등 비복원 추첨**해 세 카드로 공개한다. 보유 중인 종류도 후보가 될 수 있지만 강화형은 추첨하지 않는다.
3. 각 카드의 전체 이름·효과·공략 한계·초기 파훼 토큰·보유 수를 비교한다. 구매 가격은 선택 비용이 아니므로 보상 카드의 가격으로 표시하지 않는다.
4. 하나를 골라 `이 괴이 획득`을 확정하면 무료로 새 개체 1개를 보관함에 넣고 나머지 둘은 버린다. **이번 설정에서는 괴이 보상 건너뛰기를 제공하지 않는다.**
5. 엘리트는 주사위 결정으로, 다른 전투는 지도·다음 막·승리 결과로 자동 전환한다.

- 손님 한 명마다 세 후보를 주지 않는다. 후보 검토·미확정 선택 취소·세부 정보 재열기는 지급이나 재추첨을 일으키지 않는다. 획득 확정 뒤에는 취소·다른 후보 교환이 없다.
- 선택 화면에서 실제 획득 전에는 보관함·배치를 바꾸지 않는다. 확정한 획득은 전투 노드 ID별 한 번만 처리한다.
- 일단 획득한 괴이를 지도·다음 준비에서 자유롭게 배치할 수 있다. 같은 종류의 기존 괴이와 상태를 합치거나 기존 개체를 회복시키지 않는다.

## 7. 상점 노드

- 방문하면 괴이 **8개 상품 슬롯**과 **별도의 층 증설 영역**을 제공한다. 증설은 괴이 8슬롯을 차지하지 않는다. 블러드 웹 연결·선행 구매·경로 비용·리셋권은 없다.
- 8슬롯은 강화 전 기본 괴이 6종에서 각각 균등 독립 추첨한다. **동종 중복을 허용**하며 8종의 서로 다른 괴이가 있다고 표시하지 않는다. 보유 여부도 제외 조건으로 사용하지 않는다. 강화형은 재고에 등장하지 않는다.
- 각 슬롯은 재고 1개, §4.1의 고정 영혼 가격을 사용한다. 충분한 영혼이 있으면 여러 슬롯을 구매할 수 있다.
- 구매 확정 시 영혼 차감·새 괴이 보관함 추가·그 슬롯 품절을 함께 한 번 처리한다. 같은 종류의 다른 슬롯은 별도로 살 수 있다.
- 방문 중 재고 갱신·재추첨·환급·판매·주사위 판매는 없다. 구매 정보 열기와 취소는 무과금이다.
- 같은 상점 방문 안에서 괴이 구매와 층 구매를 원하는 순서로 각각 여러 번 할 수 있다. 두 구매는 같은 영혼 잔액을 사용한다. 증설 후 괴이 재고를 다시 추첨하거나 추가하지 않는다.
- `상점 떠나기`로 방문을 완료한다. 괴이·층을 모두 사지 않아도 되고 층만 또는 괴이만 사도 된다. 남은 상품은 사라지며 다음 상점은 새 노드의 독립 재고다.
- 지하 제조 설비의 연출은 구매 결과를 표현하는 장치로 유지한다. 영혼 외 재료·포획·대기·추가 확인 단계를 만들지 않는다.

### 7.1. 상점의 층 증설

| 구매 | 영혼 비용 | 6층부터 누적 |
|---|---:|---:|
| 6 → 7층 | 4 | 4 |
| 7 → 8층 | 6 | 10 |
| 8 → 9층 | 8 | 18 |
| 9 → 10층 | 10 | 28 |

- **상점 노드를 방문하는 동안만** 꼭대기 빈층을 구매한다. 독립 증설 노드는 생성하지 않는다. 일반 준비·지도·회복·발견·이벤트·막 전환에서는 증설 정보를 볼 수 있지만 구매하지 못한다.
- 한 방문에 영혼이 허용하는 만큼 여러 층을 순차 구매할 수 있다. 매번 다음 가격을 적용하고 10층 상한을 지킨다.
- 확정 전 현재·증설 후 층 수, 비용·잔액, 새 빈층, 달라질 꼭대기→1층 연결과 같은 가상 조건의 경로 비교를 보여준다. 비교·취소는 무과금이다.
- 확정하면 비용을 한 번 차감하고 빈층 하나를 추가한다. 기존 개체·층 번호·상태는 유지한다. 증설은 괴이·보호·토큰·직접 사용 잔량을 주지 않는다.
- 구매 후 자유롭게 재배치할 수 있다. 증설 비교를 닫거나 층 구매를 건너뛰면 같은 상점으로 돌아간다. **증설 조작만으로 상점 방문을 완료하지 않는다.** `상점 떠나기`만 해당 방문을 끝낸다. 영혼 부족·10층에서도 괴이 구매 또는 퇴장이 가능하다.
- 비용 환급·층 철거·상한 돌파·다른 노드에서의 원격 증설은 없다.

## 8. 회복 노드

### 8.1. 방문당 선택

- 진입하면 **회복 / 강화 / 아무것도 하지 않고 떠나기**를 제시한다. 회복과 강화는 모두 영혼을 지불하지 않는다.
- 한 방문에서 회복 또는 강화 중 하나만 실제 확정할 수 있다. 회복을 1개만 배분했거나 남은 양을 버렸어도 강화로 전환해 함께 받지 않는다. 강화 뒤 추가 회복도 없다.
- 대상은 **보관 중인 개체를 포함한 생존 보유 괴이**다. 배치 여부가 자격을 바꾸지 않으며 이미 파괴·제거된 개체는 대상 목록에 없다.
- 효과를 확정하기 전 검토·취소·선택지 전환은 상태를 바꾸지 않는다. 효과 적용과 사용한 선택·노드 완료를 한 번에 확정한다. 재열기·중복 클릭으로 재사용하지 않는다.
- 유효한 대상이 없어도 노드를 스킵할 수 있다. 깊이 7의 필수 회복도 선택 효과는 강제하지 않는다. 스킵은 방문 완료 1회이고 영혼·토큰·강화를 지급하지 않는다.
- 회복 노드에서 주사위·새 괴이·영혼·층 구매를 제공하지 않는다. 회복은 아래 파훼 토큰 회복을 뜻하며 공략도·직접 사용 횟수를 채우는 기능과 구별한다.

### 8.2. 호텔 전체 합계 2토큰 배분

- 회복을 선택하면 이번 방문 예산 2를 **1토큰 단위**로 생존 개체들에 배분한다. 개체당 2개가 아니라 호텔 전체 합계 최대 2개다. 보관 개체에 쓴 양도 같은 예산에서 차감한다.
- 개체의 현재 토큰에 배분량을 더하되 §4.1의 개체별 최대 토큰을 초과하지 못한다. 실제로 잃은 토큰만 채우며 최대 토큰 자체는 증가하지 않는다.
- 예를 들어 최대 2·현재 1인 생존 괴이 두 개에 1개씩 배분할 수 있다. 하나만 회복 가능하면 1개를 적용하고 남은 1개를 버릴 수 있다. 최대 1인 괴이는 생존 중이면 이미 1이므로 회복으로 2가 되지 않는다.
- 배분 검토 중에는 개체별 현재→회복 후 토큰·남은 예산을 보여준다. `회복 확정` 때만 배분안을 실제 적용한다. 2개를 다 쓰지 않으면 버릴 양을 표시하고 **남은 양 스킵과 회복 완료를 함께 확정**한다.
- 미사용 예산은 노드 완료 때 소멸한다. 다음 회복 방문·막·다른 자원으로 이월하거나 영혼으로 바꾸지 않는다.
- 강화된 개체도 같은 기본 최대 토큰으로 회복할 수 있다. 회복은 강화 여부와 공략도·직접 사용 잔량을 바꾸지 않는다.

### 8.3. 생존 괴이 1개 강화

- 강화는 **아직 강화하지 않은 생존 개체 1개**의 정해진 효과를 1회 바꾼다. 종류 전체·같은 이름의 다른 개체에는 적용하지 않는다. 강화된 개체는 다시 강화할 수 없고 이름을 `{괴이 이름}+`로 표시한다.
- 현재 토큰을 회복하거나 최대 토큰을 늘리지 않는다. 공략도와 현재 직접 사용 잔량도 즉시 복구하지 않는다. 호출벨+의 3회 초기화는 **다음 전투 준비 최초 진입**부터 적용한다.
- 강화는 해당 개체와 함께 보관·재배치·막 전환에 유지되고, 파괴·영구 제거되면 함께 소멸한다. 다른 개체로 이전·추출·환급하지 않는다.
- 상점·전투 무료 보상·이벤트의 새 개체는 기본형만 제공한다. 기존 강화 개체가 파괴된 뒤 같은 종류를 얻어도 강화되지 않는다.

| 강화 개체 | 해당 개체에만 적용하는 변경 | 함께 유지하는 효과·제한 |
|---|---|---|
| 문틈의 속삭임+ | 통과 불안 2 → 3 | 도착 불안 4·전체 불안 상한 9 유지 |
| 이름을 부르는 객실+ | 도착 시 소비 불안 상한 3 → 4, 최대 공포 12 → 16 | 소비 불안 1당 공포 4를 한 번에 부여. 공포 효과 하나당 심장 최대 1개 |
| 빈 프런트의 호출벨+ | 전투당 직접 사용 초기 횟수 2 → 3 | 도착·직접 공포 3 유지. 일반 전투의 손님 사이에는 사용 잔량 이월 |
| 닫히지 않는 방화문+ | 직접 사용의 이번 턴 보호 6 → 8 | 전투당 초기 2회·도착 충전 1회·잔량 상한 2·새 충전은 다음 턴부터 유지 |
| 따라오는 발자국+ | 도착 불안 1 → 3 | 통과 시 현재 불안만큼 추가·전체 불안 상한 9 유지 |
| 벽을 꿰매는 그림자+ | 직접 사용의 공략도 최대 감소량 6 → 10 | 불안 비용 2·자신 포함 생존 배치 대상·공략도 있는 대상만·토큰 복구 없음 |

위 변경 외 가격·공략 한계 12·기본 최대 파훼 토큰·직접 사용 시점·대상 규칙은 바꾸지 않는다. 강화 효과·현재/최대 토큰·현재/전투당 직접 사용 횟수를 개체 단위로 표시한다.

## 9. 주사위 획득과 교체

### 9.1. 장비와 획득처

| 주사위 | 여섯 면 | 실제 선택 시 추가 효과 |
|---|---|---|
| 일반 | 1 · 2 · 3 · 4 · 5 · 6 | 없음 |
| 장거리 | 1 · 2 · 3 · 4 · 5 · 8 | 없음 |
| 짝수 | 2 · 2 · 4 · 4 · 6 · 6 | 없음 |
| 불안 | 1 · 1 · 3 · 3 · 5 · 5 | 눈 3을 고르면 손님 불안 +1, 상한 9 |

- 각 면은 1/6 확률이다. 같은 눈의 면은 같은 효과를 가진다. 실제 선택은 눈만이 아니라 주사위 자리·종류·면을 구분한다.
- 시작 일반 3개 이후 **발견 노드·엘리트 승리 보상·명시된 이벤트에서만** 새 주사위를 얻는다. 일반 전투·보스·상점·회복·막 시작은 지급하지 않는다.
- 획득 후보 풀은 장거리·짝수·불안 3종이며 한 기회마다 1종을 같은 확률로 추첨한다. 보유 중인 종류도 다시 나올 수 있다. 일반 주사위는 획득 후보에서 제외한다.
- 총 장착은 항상 3개다. 특수 주사위는 여러 기회를 거쳐 최대 3개까지 장착 가능하며 동종 중복도 허용한다. 이전의 특수 주사위 최대 1개 제한은 폐기한다.
- 주사위 보관함·구매·강화·판매·획득 화면 밖의 임의 재장착은 없다. 교체된 기존 주사위는 폐기한다.

### 9.2. 발견 노드와 공통 교체 흐름

1. 주사위 발견에 들어가면 고정된 랜덤 특수 주사위 **1개**의 이름·모든 면·효과를 공개한다.
2. 현재 세 주사위와 나란히 비교한다. 가져가려면 교체할 한 자리를 선택한다. 일반뿐 아니라 기존 특수 주사위도 교체할 수 있다.
3. `이 주사위로 교체`를 확정할 때만 그 자리에 새 주사위를 넣고 기존 하나를 제거한다.
4. `주사위 건너뛰기`를 누르면 기존 장비를 유지하고 노드를 완료한다. **어느 쪽이든 영혼을 받거나 지불하지 않는다.**

- 엘리트의 추가 주사위도 이 무료 1개 제시·교체 또는 건너뛰기 흐름을 사용한다. 엘리트 처치 영혼 6은 이미 별도 지급한 것이며 주사위를 거절해도 되돌리지 않는다.
- 후보·교체 대상 검토 중 Esc·취소는 미완료 선택만 해제한다. 노드를 자동으로 건너뛰거나 기존 주사위를 먼저 버리지 않는다.
- 반복 획득 기회라도 반드시 받게 하지 않는다. 교체한 장비는 이번 판의 다음 획득 기회까지 유지하며, 획득 화면 밖에서는 되돌리지 못한다. 새 판에는 일반 주사위 3개로 돌아간다.

## 10. 이벤트 노드

이벤트 3종 중 하나를 균등 추첨해 내용·제시물을 고정한다. 같은 이벤트가 다른 노드에서 다시 나올 수 있다. 이벤트 한 번에서는 아래 선택 하나만 최종 적용한다.

| 이벤트 | 공개하는 선택과 결과 |
|---|---|
| 잊힌 투숙객의 짐 | 공개된 랜덤 특수 주사위 1개를 무료 교체 / 영혼 4 획득 / 떠나기 |
| 봉인된 객실 | 공개된 랜덤 괴이 1개를 영혼 3으로 획득 / 떠나기 |
| 지하 계약 | 살아 있는 보유 괴이 하나를 영구 제거하고 영혼 4 획득 / 떠나기 |

- 짐의 주사위는 §9 후보 풀을 사용한다. 주사위 교체를 확정하거나 영혼 수령을 확정하면 다른 선택은 닫힌다. 교체 비교 중 취소하면 이벤트 선택으로 돌아갈 수 있으며 주사위 후보는 바뀌지 않는다. 떠나기는 아무 보상도 없다.
- 봉인된 객실의 괴이는 6종 균등 추첨이다. 가격 3은 이 이벤트의 명시적 거래값이며 상점 가격을 바꾸지 않는다. 잔액 부족이면 선택 불가 사유를 보여주고 떠날 수 있다. 무료 전투 보상 3중 1과 구별한다.
- 지하 계약은 보관·배치 괴이 중 선택한다. 제거 후 살아 있는 보유 괴이가 최소 1개 남아야 한다. 대상 이름·강화 여부·배치 위치·영구 제거·영혼 전후를 보여준 뒤 확정한다. 강화 개체를 제거하면 그 강화도 소멸한다. 제거는 손상·파훼 토큰 소모가 아니며 복구되지 않는다. 제거한 층은 빈층이 되고 남은 보유 괴이를 배치할 수 있다.
- 이벤트에서 복구·층 증설·임의 재고 갱신은 제공하지 않는다. 단순 떠나기도 정상적인 방문 완료다.
- 이벤트는 주사위 획득이 가능한 세 출처 중 하나지만 모든 이벤트가 주사위를 주는 것은 아니다. 발견 노드에 이벤트의 영혼 선택을 붙이지 않는다.

## 12. 생성·중복 실행·기록 계약

- 판의 난수 번호와 안정된 막·깊이·열의 노드 ID를 사용한다. 지도 배치, 적 묶음, 괴이 보상, 상점 재고, 발견 주사위, 이벤트, 전투 주사위, 비활동 표적의 난수 흐름을 분리한다.
- 후보·재고·이벤트는 노드 ID에 대응해 한 번 결정·저장한다. 공개 전에도 내용이 일관되게 결정되도록 하되 플레이어에게는 지정 시점에만 보인다. 같은 판·노드에서 호버·준비 재열기·미리보기·비교 취소로 바뀌지 않는다.
- 괴이 보상은 전투마다 한 세트, 엘리트 주사위도 한 개다. 중복 클릭·연출 완료 재호출로 영혼·괴이·주사위를 다시 지급하지 않는다.
- 상점 괴이 구매·층 증설·이벤트 거래·괴이 획득·주사위 교체는 비용과 결과를 함께 확정한다. 회복·강화는 대상 개체·개체 상태·선택 종류·버린 예산·노드 완료를 함께 한 번 처리한다. 미확정 대상 선택으로 상태를 먼저 바꾸지 않는다.
- 주사위 추첨은 전투 노드·손님 순번·턴·장착 자리별로 정한다. 다른 노드 방문이나 보상 비교가 다음 전투 눈을 밀지 않는다. 장비 교체는 같은 면 인덱스의 눈·효과만 바꾼다.
- 미래 전투 눈·미발생 패널티 표적은 숨긴다. 미리보기는 사본에서 실제 처리 순서를 재사용하며, 선택 효과·완료한 직접 사용을 반복 적용하지 않는다.
- 웹 게임에서 판 진행은 이번에도 메모리 상태로 유지한다. 새로고침은 새 판이며 이어하기·세이브 조작은 이번 범위가 아니다. 옵션·설명 이력의 저장은 기존 방식을 유지한다.

### 13.2. 정상 플레이에서 볼 경험

- 제작 후 시작 난수 번호 31001·31002·31003으로 각각 한 판씩 진행한다. 실패·탈출·주사위 거절·증설 스킵도 그대로 남긴다. 완주한 번호만 선택해 보고하지 않는다.
- 전투 위주의 길, 상점의 괴이/증설 투자 길, 선택 회복을 통한 토큰 관리/강화 길, 엘리트·발견·이벤트를 통한 주사위 확보 길을 진단한다. 임의 자산 지급 검사는 정상 플레이와 구분한다.
- 완주 24번 중 필수 회복이 3번이다. 깊이 1~6을 일반 전투만 고르면 일반 손님 54명과 보스 3명으로 최대 57명을 상대한다. 막별 손님 수·턴 수·시간·반복감과 전투 간 토큰 소모를 기록한다. 손님 3명 구성을 유지해 길어지면 다음 개정에서 인원·지도 길이를 함께 검토한다.
- 무료 괴이와 처치 영혼을 함께 주므로 상점 구매가 항상 불필요해지거나, 반대로 상점·선택 회복·주사위 노드에 갈 여유가 사라지는지 본다. 기존 가격이 새 경제에서도 적절하다고 단정하지 않는다.
- 노드 선택 이유, 보상으로 바뀐 배치, 영혼을 저축하거나 사용한 시점, 특수 주사위 수락·교체·거절 이유를 실제 장면과 연결한다. 최대 증설·최대 주사위 확보·전원 처치를 플레이 성공 조건으로 강요하지 않는다.
- 파훼 토큰 이월이 회복/강화 선택과 상점의 대체 괴이/증설 구매에 주는 영향을 기록한다. 배치 공간 부족과 토큰 손실을 구분하고 강화 효과·실제 회복·영구 파괴·무료 보충을 개체별 추적한다. 강화를 받았다는 사실만으로 선택 이익을 확정하지 않는다.
- 사용자의 user-2 재미 평가는 출발점으로 유지한다. 판정 검사·자동 완주가 새 진행 구조의 반복감 개선이나 재미를 입증한 것으로 보고하지 않는다.

## 14. 제작 범위

이번 산출물은 **user-3 규칙 명세와 그 규칙에 맞춘 UI 문서**다. `mvp_user_2`를 덮어쓰거나 완료되지 않은 user-3 구현을 최신 플레이 가능 버전으로 표시하지 않는다. 실제 제작 시에는 별도 `mvp_user_3`에서 위 지도·보상·노드별 권한·자동 전환을 연결하고, 규칙 검사와 실제 화면 확인을 마친 뒤 구현 상태를 별도로 기록한다.
