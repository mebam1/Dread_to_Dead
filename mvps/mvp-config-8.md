# 사이비 호텔 MVP 설정 8 — 1d6 세 개 중 하나 선택·직원 카드 비용 복원

설정 버전: 8 · 문서 개정: v0.1 · 작성일: 2026년 10월 29일  
적용: 직원 5종·괴이 30종의 첫 MVP. 이 파일의 수치와 운영 전제를 함께 적용한다.

**이번 변경:** 일반 손님과 보스 모두 **독립적인 공정한 1d6 주사위 세 개를 동시에 굴리고, 플레이어가 그중 하나를 선택한 다음 직원 카드를 사용**한다. 선택한 눈 r만 실제 이동 r칸과 이번 턴 마나 r에 적용한다. **직원 카드 비용은 전부 2마나로 복원한다.** 직원 모집 가격은 별도로 1명당 4를 유지한다.

**시험 의도:** 도착할 방·통과할 공급 시설·카드에 쓸 마나·보스에게 공격받을 타일을 함께 보고 주사위를 고르는 일이 의미 있는 선택을 만드는지 확인한다. 최종 판단은 여전히 플레이어가 융합의 관계를 자기 말로 설명하고 다음 조합을 궁금해하는가에 둔다.

**비교 기준:** 설정 1과 비교하면 시작 자산·카드 비용·효과량·경제·보스 수치는 같고, 이동 결과를 1개 자동 적용하는 절차가 **세 후보 중 하나를 고르는 절차**로 바뀐다. 설정 7과 비교하면 주사위 방식과 카드 비용이 함께 달라진다. 따라서 설정 7보다 결과가 달라졌다는 사실만으로 주사위 선택만의 효과를 분리하지 않는다. 설정 2~6의 다른 변형값은 합치지 않는다.

표기: **기존 확정**은 rules.md의 확정 규칙, **기존 MVP값**은 기존 MVP 제안·시험값, **시험값**은 미정 수치에 배정한 최초값, **운영 전제**는 시험을 위해 선택한 판정이다. 별도 표시 없는 수치 표는 시험값이다. 주사위 선택 절차는 이번 사용자 지정이며 기존 규칙 문서의 자동 개정은 아니다. 이 문서는 실제 참가자의 플레이 검증 결과가 아니다.

직원 5종의 실제 행동·괴이 30종의 법칙·상태 이름은 여기서 새로 설계하지 않는다. 아래는 해당 효과를 채택할 때 쓰는 공통 수치이며, 모든 괴이에 같은 효과를 강제하지 않는다. 텍스트 재시연은 직전 시연의 임시 직원·괴이 능력을 재사용할 수 있으나, 그 능력이 전체 30종의 확정 명세가 되지는 않는다.

## 1. 변경값과 선택 절차

| 항목 | 설정 1 | 설정 7 | 설정 8 |
|---|---|---|---|
| 굴리는 주사위 | 1d6 하나 | 1d2 하나 | **1d6 세 개, 서로 독립** |
| 실제 적용 | 나온 눈 자동 적용 | 나온 눈 자동 적용 | **굴린 세 개 중 하나를 선택** |
| 직원 카드 비용 | 모두 2 | 모두 0 | **모두 2로 복원** |
| 이동·마나 | 같은 눈 r 적용 | 같은 눈 r 적용 | 선택한 주사위의 같은 눈 r 적용 |
| 기본 드로우·손패 이월 | 2장·이월 없음 | 동일 | 동일 |
| 슬롯·효과량·가격·보스 | 기준값 | 기준값 | 기준값 |

### 1.1 한 턴의 정확한 순서

1. **직원 카드 드로우와 소진 처리.** 기본 2장을 뽑는다. 소진이 발생하면 일반 손님 부담 +2 또는 보스의 이번 턴 추가 피해 +1을 먼저 적용한다. 일반 손님이 사망하면 이 턴의 이후 절차를 진행하지 않는다.
2. **1d6 세 개 동시 굴림.** 세 눈과 현재 손패를 함께 확인한다. 이 시점에는 직원 카드를 플레이하지 않는다.
3. **주사위 하나 선택·확정.** 각 후보의 도착 예정 위치, 통과 경로, 얻을 마나를 확인하고 한 개체를 선택한다. 보스전에서는 각 후보의 공격 예정 타일과 이번 턴 피해도 함께 확인한다. 선택한 눈을 r로 확정하고 이동 예정 거리와 마나를 각각 r로 둔다.
4. **직원 카드 플레이.** 선택을 확정한 뒤 손패·마나·유효 조건이 허용하는 만큼 준비·강화·변환·회복을 사용한다. 카드 한 장마다 마나 2를 지불한다.
5. **선택한 r칸 이동·타일 효과.** 경로상의 통과 효과와 마지막 도착 효과를 순서대로 처리한다. 일반 손님은 출구에서 종료하며, 보스는 루프를 계속 돈다. 사망·목표 달성 등 종료 조건은 즉시 적용한다.
6. **보스 공격과 턴 종료.** 보스 목표 미달이면 선택 단계에서 확정한 도착 슬롯을 공격한다. 이어 남은 손패를 버리고 마나를 제거한다. 보스 8턴째 목표 미달이면 공격 처리 후 시간 초과로 종료한다.

플레이어가 직접 조작하는 핵심 순서는 **주사위 굴림 → 주사위 선택 → 카드 플레이**다. 앞의 드로우는 기존 턴 시작 절차로 유지되므로, 주사위를 고를 때 이번 손패와 소진 여부를 이미 알고 있다. 선택 전에 카드 사용 계획을 생각하는 것은 가능하지만 효과를 먼저 발동할 수는 없다.

### 1.2 선택의 범위와 중복 눈

| 항목 | 적용 판정 |
|---|---|
| 선택 개수·비용 | 매 턴 나온 주사위 **정확히 1개**, 선택 자체의 별도 비용 0 |
| 같은 눈 중복 | 허용. 예: 2·2·5가 나오면 실제 이동 선택지는 2와 5. 같은 눈을 고른 효과는 동일 |
| 전부 같은 눈 | 예: 4·4·4면 실제 결과는 4로 같음. 중복이라는 이유로 다시 굴리지 않음 |
| 적용 값 | 선택한 주사위 한 개의 눈만 사용. 합산·평균·차이·여러 주사위 순차 적용 없음 |
| 선택 확정 후 | 이번 턴에는 변경 불가. 카드를 사용한 뒤 다른 주사위로 바꾸거나 효과를 되돌리지 않음 |
| 선택하지 않은 두 개 | 이번 턴에 사용하지 않고 폐기. 마나·추가 이동·다음 턴 보관으로 전환하지 않음 |
| 재굴림·추가 굴림 | 0회. 세 결과가 마음에 들지 않아도 한 개를 골라 진행 |
| 건너뛰기·정지 | 주사위 미선택으로 턴을 넘기거나 0칸 정지하는 기능 없음 |
| 후보 정보 | 현재 상태와 손패, 도착 위치·통과 경로·선택 시 마나를 확인. 보스 공격 타일·피해도 후보별 예고 |
| 보스 공격의 귀속 | 이동용 주사위와 공격 대상용 주사위를 따로 고르지 않음. 선택한 이동의 도착 슬롯이 공격 대상 |

세 개를 굴려도 한 턴의 드로우·이동·보스 공격 횟수가 세 배가 되지 않는다. 주사위와 카드는 같은 턴 안에서 한 번의 이동을 준비한다. 빈 슬롯 도착을 선택해 공격을 피할 수 있지만, 그 이동에서 얻을 수확과 남은 보스 턴을 함께 포기할 수 있다.

### 1.3 확인할 질문

- 원하는 수확 칸에 갈 수 있는 후보가 실제로 늘어나고, 입력 준비·강화와 연결되는가.
- 작은 눈의 좋은 도착 지점과 큰 눈의 많은 마나 사이에서 선택 이유가 생기는가.
- 같은 주사위 후보라도 손패·상태·타일 손상에 따라 선택이 달라지는가.
- 보스에서 수확을 위해 공격을 감수하거나, 공격을 피하기 위해 당장의 수확을 미루는 판단이 생기는가.
- 항상 가장 작은 눈 또는 가장 큰 눈만 고르게 되거나, 선택 화면이 뻔한 확인 절차로 남지는 않는가.

이번 한 판은 시작 자원·직원·괴이·슬롯·방문 횟수·의심도·타일 손상을 모두 초기화한다. 이전 판의 잔액·모집 직원·괴이·확장을 가져오지 않는다.

## 2. 유지하는 규칙과 MVP 범위

| 항목 | 값과 구분 |
|---|---|
| 콘텐츠 | 기존 MVP값: 팩션 1, 직원 5종, 이종 조합 10쌍, 괴이 후보 30종, 기본 시설 4종, 상태 4종 우선·최대 5종, 일반 손님 1종, 보스 1종 우선·2종째 후속 선택 |
| 융합 | 기존 확정: 직원 2명 소모 → 고정 후보 3종 중 1종 선택·1개 획득. A+B와 B+A 동일. 같은 조합의 후보를 재추첨하지 않음 |
| 융합 운영 | 기존 MVP값: 경영 중 이종끼리 융합, 보유 쌍 선택 시 후보 효과 공개, 확정 전 무료 취소, 확정 시 두 개체만 소모. 동종 융합 제외 |
| 덱과 사용 횟수 | 기존 확정: 0~20장, 영업·보스 시작 전에만 편성. 최소 3장·턴당 1장 같은 추가 제한 없음. 손패·마나가 실제 사용량 제한 |
| 턴 순서 | 기존 확정 순서에 선택 단계를 추가: 드로우·소진 → 1d6 3개 동시 굴림 → 1개 선택 확정 → 직원 카드 → 이동·효과. 선택한 눈 r이 이동 r칸과 마나 r. 도착 타일도 통과 효과 후 도착 효과 |
| 일반 영업 | 기존 확정: 출구 첫 도달·통과에 퇴장, 두 번째 회전 없음. 보스는 종료 조건까지 같은 호텔을 반복 이동 |
| 공간 | 기존 MVP값: 슬롯당 시설 또는 괴이 1개. 경영 중 무료 보관·재배치, 일반 영업·보스 도중 변경 불가. 확장은 빈 슬롯만 제공 |
| 한 판 | 기존 MVP값: 시작 경영 → 일반 손님 3명 → 보스 1회 → 재설계 → 일반 손님 2명 → 완주 |
| 초기 직원·모집량 | 기존 MVP값: 종류별 1명, 총 5명. 단계별 후보 3명 중 최대 2명 모집. 후보가 이종 3명이라는 보장은 아래의 운영 전제 |
| 경찰 의심도 | 기존 MVP값: 사망당 +1, 누적 3에 판 종료. 사망 수익 0, 이전 정산 수익 보존 |
| 보스 공통 | 기존 MVP값: 공격 턴당 1회, 최대 8턴. 소진 추가 피해 해당 턴 +1, 이월 없음. 목표 공포 달성 즉시 승리·남은 이동/공격 중단 |
| 상태 수명·이월 | 기존 MVP값: 자연 감소 0, 별도 상태 타이머 없음. 일반 손님 퇴장·사망 또는 보스 전투 종료 시 제거. 기존 확정: 마나 이월 0, 남은 손패는 턴 끝에 버림 |

보스 패배·포기·의심도 한계는 판 종료다. 생산 불능은 직원·남은 능력을 포함해 확실할 때만 조기 판정하며, 수확 타일이 없다는 이유만으로 단정하지 않는다. 판단이 어려운 교착은 8턴 상한으로 종료한다.

## 3. 시작 자산과 카드 수치

| 항목 | 적용 값 |
|---|---|
| 초기 / 확장 / 최대 배치 슬롯 | 6칸 / +2칸 / 12칸. 6 → 8 → 10 → 12. 최대 3회 확장, 이번 MVP의 화면·시험 범위 |
| 시작 시설·괴이·별도 보관 자산 | 시설 4개: A 공급·B 공급·기본 수확·위험 관리 각 1개. 괴이 0개, 별도 보관 자산 0개. 각 시설 지급은 운영 전제 |
| 시작 경영 자원 / 영업 성과 / 의심도 | 16 / 0 / 0. 지원금 16과 보스 보상은 영업 성과 누계에서 제외. 의심도는 보스 승리에도 유지 |
| 방문자 초기 수치 | 일반 손님 공포·심장 부담·모든 상태 0. 보스 목표 공포 게이지·모든 상태 0. 각 입장 시 덱 전체 셔플, 손패·마나 초기화 |
| 보유·보관 상한 | 직원 풀, 같은 종류 직원·타일, 보관함의 별도 수량 상한 없음. 배치는 슬롯 수, 공급은 모집·재고·비용에 제한 |
| 최초 편성 / 개체당 편성 | 5명 전원 5장으로 시작, 영업 전 자유 수정. 보유 개체당 1장, 종류별 추가 한도 없음, 전체 20장 유지 |
| 주사위 | **독립적인 공정한 1d6 3개를 동시에 굴려 그중 1개 선택**. 각 주사위의 각 눈은 1/6, 중복 눈 허용. 선택 전 합산·재굴림·눈 보정 없음 |
| 기본 드로우 / 별도 손패 상한 | 턴 시작 2장 / 별도 상한 없음. 이 설정에는 추가 드로우가 없어 받는 손패는 최대 2장 |
| 직원 5종 마나 비용 | **모두 2로 복원**. 설정 7의 무료 사용을 적용하지 않음. 각 카드의 실제 행동은 동일한 콘텐츠 명세로 별도 정의 |
| 기본 카드 대상·준비 횟수 | 대상 1, 유효 발동 1회. 준비·강화의 수명과 중첩은 §7을 적용 |
| 추가 드로우·마나 증감·선택 외 주사위 조작 | 최초 콘텐츠에서 0. 눈 변경·재굴림·선택 후 교체·추가 이동 카드는 이 설정에 포함하지 않음 |

## 8. 조건부 산술 검산

아래는 독립적인 공정한 1d6 세 개, 중복 허용이라는 전제의 직접 계산이다. 실제 수입·승률·재미의 측정치가 아니다. 순서 있는 주사위 결과는 6³=216개이며 각각 같은 확률이다.

### 8.1 후보가 제시될 확률

굴리기 전에 정한 특정 눈 r이 적어도 하나 나올 확률은 **1−(5/6)³=91/216≈42.13%**다. 굴리기 전에 정한 서로 다른 유효 눈 k개 중 하나라도 제시될 확률은 **1−((6−k)/6)³**다.

| 원하는 눈의 수 k | 예시 | 후보가 하나 이상 나올 확률 |
|---|---|---|
| 1 | 특정 방에 닿는 눈 하나 | 91/216 ≈ 42.13% |
| 2 | 두 수확 방 중 하나에 닿는 서로 다른 눈 | 19/27 ≈ 70.37% |
| 3 | 세 수확 방 중 하나에 닿는 서로 다른 눈 | 7/8 = 87.50% |
| 4 | 네 가지 서로 다른 눈 | 26/27 ≈ 96.30% |
| 5 | 1을 제외한 모든 눈 | 215/216 ≈ 99.54% |
| 6 | 어떤 눈이든 허용 | 100% |

이는 **후보 제시 확률**이다. 그 눈을 실제로 선택할 확률이나 수확 성공 확률은 아니다. 수확에 도착해도 입력 상태·카드 비용·생존 조건이 맞아야 한다. 일반 손님의 여러 큰 눈이 모두 퇴장으로 이어질 수도 있으므로, 서로 다른 숫자 개수와 서로 다른 의미 있는 행동 개수도 구분한다.

| 마나 선택 가능성 | 계산 | 해석 |
|---|---|---|
| 2 이상인 눈이 하나라도 제시됨 | 1−(1/6)³ = 215/216 ≈ 99.54% | 카드 한 장의 비용을 낼 수 있는 이동 후보가 있음 |
| 4 이상인 눈이 하나라도 제시됨 | 1−(3/6)³ = 7/8 = 87.50% | 카드 두 장의 비용을 낼 수 있는 이동 후보가 있음 |
| 세 주사위가 모두 1 | 1/216 ≈ 0.46% | 어떤 후보를 골라도 기본 직원 카드를 못 씀 |

마나가 많은 후보를 선택하면 원하는 방을 지나치거나, 일반 손님을 퇴장시키거나, 손상된 타일이 공격받을 수 있다. 따라서 위 확률을 실제 카드 사용률로 보고하지 않는다. 세 주사위 중 눈 1을 자발적으로 골랐다면 다른 후보에 마나가 충분했는지도 함께 기록한다.

### 8.2 중복과 선택 전략

| 항목 | 값 | 의미 |
|---|---|---|
| 모두 같은 눈 | 6/216 = 1/36 ≈ 2.78% | 숫자로 구분되는 이동 선택지가 하나 |
| 정확히 두 종류의 눈 | 90/216 = 5/12 ≈ 41.67% | 두 주사위가 같고 하나가 다름 |
| 세 종류 모두 다른 눈 | 120/216 = 5/9 ≈ 55.56% | 서로 다른 숫자 선택지 세 개 |
| 서로 다른 눈의 기대 개수 | 6×91/216 = 91/36 ≈ 2.528개 | 세 개를 굴려도 항상 세 가지 다른 결과는 아님 |
| 매번 최솟값만 선택할 때 평균 이동 | 49/24 ≈ 2.042칸 | 이 전략을 고정했을 때의 계산 |
| 매번 최댓값만 선택할 때 평균 이동 | 119/24 ≈ 4.958칸 | 이 전략을 고정했을 때의 계산 |
| 결과를 보지 않고 세 개 중 하나를 무작위 선택할 때 평균 이동 | 3.5칸 | 선택된 눈이 공정한 1d6와 같은 분포인 조건 |

실제 플레이는 손패·위치·상태·공격을 보고 선택하므로, 선택된 눈의 평균과 일반 손님의 체류 턴은 **플레이어의 선택 방식에 따라 달라진다.** 설정 1 또는 7의 기대 턴 표를 이 설정에 그대로 적용하지 않는다. 작은 눈을 고르면 일반적으로 더 오래 머물 수 있으나 소진 기회도 늘고, 큰 눈을 고르면 더 많은 마나를 얻지만 수확 지점을 지나칠 수 있다. 보스도 같은 최대 8턴 동안 어떤 거리를 선택했는지에 따라 만나는 수확 구간이 달라진다.

### 8.3 덱 소진과 조건부 예산

| 덱 | 첫 8턴 손패 | 소진 턴 |
|---|---|---|
| 0 | 0,0,0,0,0,0,0,0 | 매 턴 |
| 1 | 1,0,1,0,1,0,1,0 | 매 턴 |
| 2 | 2,0,2,0,2,0,2,0 | 2·4·6·8 |
| 3 | 2,1,2,0,2,1,2,0 | 2·4·6·8 |
| 5 | 2,2,1,2,2,0,2,2 | 3·6 |

다른 부담·회복이 없으면 0~1장 덱은 소진 +2를 매 턴 받아 6턴째 드로우에서 사망한다. 실제 사망 여부는 선택한 경로의 체류 턴과 다른 부담·회복 효과를 함께 계산한다. 보스는 같은 소진 턴 공격 피해가 3이 되며 심장마비로 끝나지 않는다.

| 예산 항목 | 손님마다 공포4 | 손님마다 공포8 |
|---|---|---|
| 시작 자원 | 16 | 16 |
| 일반 손님 5명 수입 | 20 | 40 |
| 격퇴 보상 | 20 | 20 |
| 누적 사용 가능 자원 | 56 | 76 |
| 직원 6명 | −24 | −24 |
| 첫 확장 | −8 | −8 |
| 격퇴 후 시설 2개 | −12 | −12 |
| 합계 지출 | 44 | 44 |
| 구매 후 잔액 | 12 | 32 |

이는 보스 승리와 일반 손님 5명 생존을 가정한 예산 시나리오이며 공포4·8을 실제 평균으로 가정하지 않는다. 공포4 시나리오의 시간 순서는 시작16 → 손님1 수입 뒤20, 모집2명 뒤12 → 손님2 수입 뒤16, 모집2명·첫 확장 뒤0 → 손님3 수입 뒤4 → 격퇴 보상 뒤24 → 모집2명·시설2개 뒤4 → 재영업 두 번 뒤12다. 미래 수익을 앞당겨 쓰지 않는다.

이 표는 고정된 구매 묶음의 계산이다. 실제 수입·구매 순서·남은 자산에 따라 모집·시설·확장의 기회비용과 추가 자금의 쓰임은 달라진다.

융합을 4회 하고 직원 3명을 남기는 공급 예시는 5+6−2×4=3이다. 시작 융합1회 → 손님1 뒤 모집2·융합1 → 손님2 뒤 모집2·융합1 → 격퇴 뒤 모집2·융합1로 배치할 수 있다. 3~4회는 관찰 기회의 목표이며 강제 횟수·최소 덱 규칙이 아니다. 후보는 이종3명이므로 새 재료 두 종류는 살 수 있으나 원하는 특정 조합은 보장하지 않는다.

격퇴 직전 잔액0이어도 보상20에서 **A 공급6 + 기본 수확6 + 직원2명 8 = 20**를 지출하면 **0**가 남는다. 이는 시설 진열·재고·후보의 이종 구성 전제에 의존하며 다음 수입이나 모든 괴이의 공급을 보장하지 않는다.

## 9. 관찰과 판단

### 9.1 턴마다 남길 기록

| 항목 | 기록 방법 | 구분할 문제 |
|---|---|---|
| 주사위 후보 | 나온 세 눈을 그대로 기록. 중복도 남김 | 선택지가 없었던 턴과 여러 후보가 있던 턴 |
| 선택 결과 | 선택한 주사위·눈, 이동 예정 위치, 얻은 마나 | 최솟값·최댓값 선택과 특정 방을 겨냥한 선택 |
| 선택 이유 | 선택한 이유와 포기한 다른 후보의 이점 | 수확·마나·생존·공격·다음 위치 중 무엇을 고려했는가 |
| 선택 전 손패·상태 | 손패, 입력 상태, 부담, 타일 손상, 소진 여부 | 주사위가 같아도 판단이 달라지는 근거 |

| 수확 도착·실수확 | 수확 타일 도착 횟수와 실제 공포 발생 횟수 각각 기록 | 도착 실패와 도착 후 입력 실패 |

| 보스 선택 | 후보별 공격 타일·피해, 선택 뒤 실제 손실·회복·종료 | 공격 회피가 가능한 정도와 목표 달성의 기회비용 |
| 융합·배치 | 후보 선택 이유와 얻은 괴이 전후 배치·직원 보존 | 주사위 선택이 신규 괴이의 활용 폭을 늘렸는가 |

총 수확·카드 사용 횟수와 함께 **턴당 값**도 본다. 수입이 늘어도 단순히 턴이 길어진 결과일 수 있다. 카드 사용 0회인 턴도 선택 이유를 남긴다. 좋은 수확실에 가기 위해 눈 1을 선택하거나, 손패가 비어 있어도 타일만으로 수확하는 판단일 수 있다.

### 9.2 결과를 어떻게 해석할 것인가

| 관찰 | 해석과 다음 확인 |
|---|---|
| 같은 후보 눈에서도 손패·상태·손상에 따라 선택이 달라짐 | 선택 단계가 현재 호텔과 연결되는 신호. 각 대안의 비용을 플레이어가 설명하는지 확인 |
| 좋은 도착을 위해 마나를 포기하거나, 필요한 카드 사용을 위해 다른 도착을 선택 | 이동·마나의 동시 결정이 실제 판단을 만드는지 관찰 |
| 후보에 수확 지점이 자주 있는데도 입력이 없어 실패 | 선택권 증가만으로 해결되지 않는 공급·직원·괴이 연결을 점검 |
| 늘 최솟값만 선택 | 장기 체류가 일방적으로 유리한지, 소진·퇴장·후방 생산의 차이가 있는지 확인. 작은 눈 선택 자체를 실패로 단정하지 않음 |
| 늘 최댓값만 선택 | 마나나 빠른 진행이 다른 선택을 압도하는지 확인. 현재 호텔에 다른 후보가 가치 없었을 가능성도 구분 |
| 여러 숫자가 나와도 모두 퇴장·무효 수확 등 같은 결과 | 숫자 선택지와 실제 선택의 다양성을 구분. 타일 밀도·배치·남은 경로를 점검 |
| 공격을 피하는 선택만 반복하거나 보스가 너무 빨리 끝남 | 파괴와 재설계를 경험할 여지가 줄었는지 확인. 수확 포기·8턴 상한이 실제 대가인지 기록 |
| 큰 눈을 고른 뒤 카드로 대응해 손실을 줄임 | 선택·마나·회복의 연결을 기록하되, 회복 타일이 이후 맞지 않았다면 손실 방지로 과장하지 않음 |
| 수입·카드 사용은 늘었지만 선택 이유가 없거나 절차가 번거로움 | 수치 개선과 의미 있는 판단·조작 부담을 분리해 봄 |
| 무손실 승리·보스 패배·다음 재료 부족 | 각각 부분 파괴 미경험·재설계 미경험·다음 조합 탐색 기회 부족으로 기록 |

세 눈이 모두 같아 선택할 여지가 없는 턴은 규칙상 허용된 결과이며, 그 한 번만으로 설계 실패라고 판정하지 않는다. 반대로 서로 다른 눈이 많다는 사실만으로 의미 있는 선택을 검증했다고 보지 않는다. 원하는 방을 골랐다는 설명에 더해 **그 방에서 왜 현재 직원·괴이의 법칙을 활용할 수 있었는지**를 확인한다.

최종 성공 신호는 같은 플레이어에게서 융합의 관계를 자기 말로 설명하는 모습과 다음 조합을 자발적으로 궁금해하는 행동이 함께 나타나는 것이다. 주사위 선택 횟수·수입·승률은 그 경험을 대신하지 않는다.

### 9.3 비교 운영과 해석 범위

**주사위 선택의 효과를 볼 기본 비교는 설정 1 대 설정 8**이다. 두 조건 모두 직원 카드 비용 2와 같은 능력 명세·초기 자산·안내를 사용한다. 설정 7과의 비교는 이동 방식과 카드 비용이 함께 달라진 후속 시연으로 기록한다. 설정 8은 후보가 늘어 선택권이 생기고 그 선택으로 이동 분포도 달라지는 방식이므로, 단일 주사위의 분산만 낮춘 실험이라고 표현하지 않는다.

짧은 비교에서는 매 턴 같은 세 주사위 묶음을 마련하고, 설정 1은 미리 정한 한 위치의 주사위만 자동 적용하며 설정 8은 세 개를 모두 보고 고르게 할 수 있다. 설정 1에 나머지 두 눈을 추가로 보여 주지는 않는다. 선택 때문에 방문 횟수·셔플 시점·직원 풀·자산·배치가 달라지는 전체 진행은 그대로 기록하고 억지로 일치시키지 않는다. 동일 시작 장면의 짧은 비교와 처음부터 경영한 한 판의 경험은 구분한다.

텍스트 시연에서는 미래 눈을 먼저 보고 배치·모집·카드를 정하지 않으며, 유리한 결과가 나올 때까지 난수를 바꾸지 않는다. 각 턴에 세 후보를 모두 확인한 뒤 한 개를 확정하고 카드를 사용한다. 새 판의 시작 배치를 변경했다면 그 차이도 적는다.

같은 사람이 여러 조건을 경험하면 경험 순서와 학습 영향을 기록한다. 처음 접하는 사람의 이해·호기심을 보려면 새 참가자에게 확인한다. 초기 4~6명 정도의 시험은 문제 발견용이며 통계적 우열·시장성을 입증하지 않는다. 조건별 실제 경험 인원과 도움·중단·미경험을 함께 적고, 보스를 이긴 사람만 골라 전체 완주율이 개선된 것처럼 설명하지 않는다.

관찰자가 기록하면 되며 게임 안 설문·통계 기능을 추가할 필요는 없다. 이번 텍스트 한 판은 규칙상 작동과 병목을 살피는 예시다. 실제 플레이어의 재미·호기심·장기 균형을 검증한 결과로 승격하지 않는다.
