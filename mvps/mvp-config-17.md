# Dread-to-Dead — 설정 17 · 10층 호텔과 괴이 융합

> 2026-11-06 · 텍스트 플레이 규칙 `text-17-v1.1`. 진행자와 플레이어가 이 문서 한 개로 새 판을 시작하고 마지막 보상까지 정산한다.

[텍스트 실행기와 명령 안내](../mvp_text_17/README.md) · 프로젝트 루트에서 `npm --prefix mvp_text_17 start`로 시작하거나 저장한 판을 이어간다.

## 1. 목표와 시작 장부

**목표는 1막에 호텔을 채워 가고, 객실이 찬 뒤에도 어느 괴이를 남기고 융합할지 고민하게 하는 것이다.** 세 막의 보스를 처치하고 3막 보스의 괴이 보상 처분까지 확정하면 승리한다. 한 막은 8회 방문, 한 판은 24회 방문이다.

괴이·상태·패치 판정은 [17판 노션 표](https://app.notion.com/p/408a909087e98029860df9b122be22a9)와 이번 사용자 지정값을 따른다. 손님의 내구·공격과 초기 네 괴이는 [사용자 설정 4 v1.2](mvp-config-user-4.md), 주사위·탈출과 지도의 공통 구조는 [공식 룰](../rules.md), 진행자 장부와 플레이어의 정보 구분은 [텍스트 설정 16](mvp-config-16.md)에서 가져왔다. 융합 노드의 방문당 횟수·비용과 막별 영혼 지급 방식은 **17판 진행 기본값**이다.

| 새 판 항목 | 시작값 |
|---|---|
| 진행과 재화 | 1막 지도, 방문 완료 0회, 영혼 2, 막 추가 수입 0/9, 일반 주사위 3개 |
| 호텔 | 1층부터 10층까지 모두 개방. 10층 다음은 1층. 증설과 층 비용은 폐지한다. |
| 배치 | 1층 문틈의 시선 · 3층 시선의 주인 · 5층 룬 문자 벽 · 6층 유혹하는 금고. 2·4·7·8·9·10층은 빈층 |
| 개체 | 시작 괴이 각각 1개. 서로 다른 ID, 미강화, 미융합, 현재 공략도 0, 파훼 토큰 최대, 봉인·잠복 0 |
| 소유 | 호텔 각 층에 생존 괴이 최대 1개. 소유 수는 점유층 수와 같고 같은 종류를 여러 층에 놓을 수 있다. |

손님은 입장 전 위치에서 1층 방향으로 한 칸씩 이동한다. 층을 가로로 `1 → 2 → … → 10 → 1` 순서로 읽는다. 9층에서 3칸이면 **10층 통과 → 1층 통과 → 2층 도착**이다. 빈층도 이동 거리에 포함한다. 한 바퀴를 돌아도 손님은 같은 개체다.

## 2. 지도·경제·보상

각 막의 깊이 1~6에 좌·중·우 세 노드, 깊이 7·8에 하나씩 두어 총 20개를 만든다. 가운데는 항상 일반 전투다. 양끝의 서로 다른 종류는 막을 만들 때 깊이별로 좌우를 추첨한다.

| 깊이 | 가운데 | 양끝에 하나씩 |
|---|---|---|
| 1 | 일반 전투 | 일반 전투 / 일반 전투 |
| 2 | 일반 전투 | 이벤트 / 융합 |
| 3 | 일반 전투 | 상점 / 회복 |
| 4 | 일반 전투 | 엘리트 / 이벤트 |
| 5 | 일반 전투 | 융합 / 상점 |
| 6 | 일반 전투 | 회복 / 엘리트 |
| 7 → 8 | 공통 회복 → 보스 | 모든 깊이 6 노드에서 같은 회복으로 연결 |

첫 노드는 자유 선택한다. 깊이 1~5에서 다음 깊이의 같은 열 또는 인접 열로 갈 수 있다. 방문 확정 뒤에는 노드를 마쳐야 전진한다. 같은 깊이의 다른 갈래와 지난 노드는 닫힌다. 지도에서 손님 구성·수치·패턴을 미리 볼 수 있다. 상점 재고와 이벤트 제시물은 방문 확정 때 공개한다. 지도에서 융합 노드와 보유 재료를 검토할 수 있고, 실행은 그 노드에 방문을 확정한 뒤에만 가능하다. 취소·재열람은 다시 뽑는 행동이 아니다.

|---|---|
| 일반 전투 | 준비 후 영업 시작. 일반 손님 한 명당 영혼 1(막 추가 수입 한도 적용). 셋을 차례로 처치하면 무료 괴이 보상 1회. |
| 엘리트 | 손님 1명, 처치 영혼 3(같은 한도 적용). 무료 괴이 보상 처리 뒤 특수 주사위 하나와 기존 한 자리를 비교해 교체하거나 건너뛴다. |

| 상점 | §4 기본 15종에서 8슬롯 독립 균등 추첨, 중복 허용. 표시 가격으로 슬롯당 한 번 구매한다. 구매 즉시 §3으로 처분하고 재고로 돌아온다. 품절 슬롯은 유지하며 `떠나기`로 종료한다. |
| 융합 | §3.2에 따라 생존 미융합 괴이 한 쌍을 무료로 융합하거나 건너뛴다. 한 번 확정하면 방문 완료. 재료가 두 개 미만이면 건너뛴다. |

| 봉인된 객실 | 15종에서 균등 추첨해 공개한 기본 괴이 한 개를 영혼 3에 구매해 즉시 처분 / 떠나기 |
| 교단의 계약 | 생존 개체 하나를 영구 제거하고 영혼 2(같은 한도 적용) / 떠나기. 제거 후 최소 한 개체가 남아야 한다. 융합체도 한 개체로 계약한다. |

### 막당 카드 세 장의 구매력

기본 15종의 가격은 3영혼 7종, 4영혼 6종, 5영혼 2종이다. 균등 추첨한 **카드 세 장의 평균 가격은 11영혼**이다. 각 막에서 새로 조달할 수 있는 금액을 **시작 자금 2 + 처치·이벤트 수입 최대 9 = 최대 11영혼**으로 정한다.

- 1막은 영혼 2로 시작한다. 2·3막의 시작 자금 2는 **바로 전 보스가 지급한 2**다. 막 진입 때 장부의 추가 수입만 0/9로 초기화하며 영혼 2를 다시 주지 않는다. 안 쓴 지갑 잔액은 전부 이월한다.
- 일반 손님·엘리트 처치와 두 이벤트의 현금은 `실제 지급 = min(표의 지급액, 9 − 이번 막 추가 수입)`이다. 실제 지급만 지갑과 수입 장부에 더한다. 구매해도 수입 한도가 되살아나지 않는다. 이벤트는 확정 전에 실제 금액을 공개하고, 0이면 현금 선택과 계약 제거를 닫는다. 보스의 다음 막 자금은 이 계산과 별도로 한 번만 지급한다.
- 예를 들어 1막 깊이 1·2 일반 완승 후 지갑은 **8**이다. 깊이 3 상점에서 4영혼짜리 둘을 구매하면 잔액 0, 추가 수입은 여전히 6/9다. 깊이 4 일반 또는 엘리트 완승으로 3을 받아, 연결된 깊이 5 상점에서 3영혼짜리 하나를 더 살 수 있다. 이월금이 있으면 한 막에 세 장을 넘길 수 있고, 고가 상품을 고르거나 수입 노드를 피하면 두 장 이하일 수도 있다. 무료 괴이 보상은 별도다.
- **1막 점유 상한**은 깊이 1·2·3·4 완료 직후 각각 **5·6·8·9층**이다. 1막 깊이 3 상점 도착 전에는 최대 8영혼이므로 최저가 3인 상품도 두 개까지만 살 수 있다. 별도 구매 수량 제한은 없다. 손실 없이 깊이 3에서 두 개 구매하고 깊이 4·5에서 완승해 무료 괴이를 배치하면 깊이 5에 처음 만실이 가능하다. 열 층은 처음부터 모두 쓸 수 있다.

## 3. 보관함 없는 획득과 융합

### 3.1 획득을 끝내는 법

지도·전투 준비·비전투 노드의 정비 중에는 배치 개체를 빈층으로 옮기거나 점유층끼리 무료로 맞바꿀 수 있다. 이동·교환은 손상과 상태를 보존한다. 전투 중이나 보상·교체·대상·거래를 확정하는 동안에는 일반 재배치를 잠그고 현재 선택만 처리한다.

전투 노드 완승 때 **서로 다른 기본 3종**을 균등하게 제시한다. 보유 종류도 나온다. 하나를 반드시 선택한 뒤 아래 처분까지 마친다. 구매·이벤트는 거래 확정 전에 취소할 수 있다. 확정한 거래의 영혼·슬롯은 새 개체를 버려도 돌려받지 않는다.

| 획득 시점의 호텔 | 지금 확정할 행동 | 결과 |
|---|---|---|
| 빈층이 있음 | 새 괴이를 지정한 빈층에 배치 / 새 괴이 폐기 | 한 층이 차거나, 기존 배치 그대로 획득 종료 |
| 10층 만실 | 지정한 층의 기존 괴이를 폐기하고 그 층에 새 괴이 배치 / 새 괴이 폐기 | 어느 쪽이든 10개체. 폐기한 개체와 그 강화·융합 효과는 영구 소멸 |

새 괴이는 새 ID·미강화·미융합·공략도 0·최대 토큰·상태 0으로 시작한다. 처분 대기 중에는 다음 후보 선택, 재배치, 융합, 다른 구매, 다음 노드 진행을 잠근다. 거절한 후보와 폐기한 개체는 나중에 꺼낼 수 없다. 마지막 보스도 **후보 선택 → 배치·교체·폐기 확정 → 승리** 순서다. 새 개체 폐기도 정상적인 보상 처리다.

### 3.2 두 개체의 융합

**융합은 융합 노드에서만 가능하다.** 각 막의 깊이 2·5에 한 곳씩 있다. 방문당 한 쌍, 비용 0영혼을 17판 진행 기본값으로 한다. 방문 후에는 확정 전까지 A·B와 방향을 바꿔 볼 수 있다. 융합 확정 또는 `건너뛰기`로 노드가 끝나고, 기회는 이월되지 않는다. 만실에서 보상 자리를 미리 만들려면 보상을 얻기 앞서 융합 노드를 거치는 경로를 골라야 한다.

1. 호텔에서 **살아 있는 미융합 괴이 두 개체**를 고른다. 먼저 고른 괴이가 본체 A, 다음 괴이가 B다. 같은 종류라도 ID가 다르면 고를 수 있고, 강화한 괴이도 쓸 수 있다.
2. **융합체 C는 A와 B의 본 효과를 한 층에서 모두 사용한다.** 각 효과는 원래의 발동 조건·비용·대상을 따르고, 융합 전에 받은 효과 강화까지 적용한다. 확정 전에는 A와 B를 바꿔 결과를 비교하거나 취소할 수 있다.
3. 확정하면 A와 B의 ID를 소모하고 새 ID의 C를 A의 층에 놓는다. B의 층은 빈다. C의 강화 여부, 공략 한계, 현재 공략도, 현재·최대 파훼 토큰, 남아 있는 개체 상태는 모두 A의 값을 이어받는다.
4. C의 이름은 **`{수식어} 융합체`**다. 확정 때 `속삭이는 / 빛바랜 / 떨리는 / 그을린 / 뒤틀린 / 잠들지 않는` 중 하나를 균등 추첨한다. 이름이 같아도 ID로 구분한다. 썸네일은 왼쪽 절반에 **원본 A**의 왼쪽 절반, 오른쪽에 **원본 B**의 오른쪽 절반을 표시한다. 텍스트에서는 `[왼쪽: A | 오른쪽: B]`로 두 원본을 보존한다.
5. C는 다시 A나 B 자리에 넣어 융합할 수 없고 분해할 수도 없다. 회복·재배치·폐기·파괴 대상은 C 한 개체다. A가 미강화였다면 이후 회복에서 A의 강화만 한 번 적용할 수 있다. 이미 강화된 A로 만든 C와 B에서 온 효과에는 추가 강화가 없다.

**같은 시점에 발동하는 자동 효과는 A → B 순서**로 각각 끝까지 판정한다. 같은 종류의 효과도 별개이며, 앞 효과가 쓴 자원은 뒤 효과가 다시 쓸 수 없다. 봉인은 두 쪽에 똑같이 적용한다. 마지막 심장이 제거되면 뒤 효과를 실행하지 않는다.

**융합체에 속공이 두 개 있으면 원본 A와 B의 속공에 발동 버튼을 하나씩 둔다.** 주사위 확정 후 플레이어가 원하는 속공의 버튼을 누르면 그 효과만 발동하고 그 비용만 지불한다. 대상이 필요한 속공은 사용할 때 대상을 고른다. 같은 턴에 둘 다 쓰려면 원하는 순서로 각 버튼을 누르며, 발동 조건과 남은 자원은 매번 따로 확인한다.

예를 들어 3층의 **시선의 주인+**(공략도 7/13, 토큰 1/2)를 A, 8층의 **문틈의 시선+**를 B로 확정하면 C는 3층에 있고 8층이 빈다. C는 공략도 7/13·토큰 1/2에 **도착 시 불안 전부 수확**과 **통과 시 불안 +5**를 갖는다. 반대로 고르면 같은 두 효과를 8층에서 사용하고 문틈의 내구를 계승한다. 미강화 문틈 두 개라면 한 번 통과할 때 4씩 두 번, 총 불안 8을 얻는다.

## 4. 괴이 15종

내구는 **공략 한계 / 최대 파훼 토큰**이다. 각 표의 **본 효과**는 그 괴이가 단독으로 배치되거나 융합되었을 때 쓰는 능력이다. 강화 칸에는 강화 시 달라지는 효과나 내구를 적었다. `동일`은 노션 강화란에도 같은 효과가 명시된 경우로, 미리보기에는 수치 변화가 없다고 표시한다. 융합체의 내구에는 본체 A의 내구 강화만 반영한다.

## 5. 한 턴의 진행

| 장착 주사위 | 같은 확률의 여섯 면 | 그 주사위를 선택했을 때 |
|---|---|---|
| 일반 | 1·2·3·4·5·6 | 눈만 확정 |
| 장거리 | 1·2·3·4·5·8 | 눈만 확정 |
| 짝수 | 2·2·4·4·6·6 | 눈만 확정 |
| 불안 | 1·1·3·3·5·5 | 원래 눈 3을 고르면 이동 전 불안 +1 |

특수 주사위는 장거리·짝수·불안 세 종류다. 지도에는 주사위 노드가 없다. 엘리트 완승이나 ‘잊힌 투숙객의 짐’에서 세 종류 중 하나를 균등하게 제시한다. 무료로 장착 한 자리를 교체하면 기존 주사위는 폐기한다. 중복 장착할 수 있고, 교체하지 않고 떠날 수도 있다.

1. **굴림·선택.** 세 주사위의 눈을 전부 공개하고 하나를 선택해 그 주사위의 선택 효과를 한 번 적용한다. 손님 자원은 불안·탐욕·예언이며 각각 0~99다. 예언은 괴이의 지불 자원이다. 주사위 선택이나 이동 완료에 따른 자동 공포는 없다.
2. **준비.** 확정 후에만 속공과 탈출구 설치를 원하는 순서로 실행한다. 속공의 주체는 미봉인 생존 괴이다. 비용과 대상 조건을 미리 충족해야 한다. 초상화와 사마라의 눈 변경은 선택 효과를 반복하지 않는다. 눈의 하한은 1, 상한은 없다. 확정 눈이 1이면 사마라를 사용할 수 없고 비용도 들지 않는다. 예언가를 쓰면 이미 결제한 비용·방어·상태·설치물·당턴 불안 누계를 유지한다. 세 주사위를 새로 굴리고 하나를 다시 선택하며 이전 눈 수정은 소멸한다. 환급은 없다.
3. **이동.** 최종 눈만큼 실제로 한 층씩 방문하며 현재 위치를 갱신한다. 매 방문 때 출구 접촉을 먼저 판정한다. 중간 방문은 통과 효과만, 마지막은 도착 효과만 적용한다. 되방문도 별도 방문이다. 자동 효과의 비용이 부족하면 그 효과만 건너뛴다. 룬·룰렛은 이동 직전의 최종 눈을 읽는다.
4. **이동 완료와 잠복.** 손님이 살아 있으면 따개비가 예약한 방어를 실제 통과층에 지급한다. 이어 잠복이 양수인 생존 개체마다 1층부터 순서대로 1 줄이고, 0이 된 개체의 해제 효과를 즉시 판정한다. 그 턴에 잠복을 얻은 개체도 포함한다.
5. **손님 공격.** 실제 도착층과 경로로 §7의 개별 타격을 순서대로 처리한다. 타격마다 유효한 대리 수신자 결정 → 수신자 방어 소모 → 남은 피해만큼 공략도 증가 → 토큰·파괴 판정 → 생존 시 피격 효과 순이다. 빈층에 대한 타격은 빗나간다.
6. **턴말.** 남은 방어·대리 지정·따개비 예약을 정리하고 비활동을 판정한다. 생존 개체의 봉인을 각각 1 줄인 뒤 손님이 살아 있으면 다음 턴이다. 잠복의 자연 감소는 4단계에서만 한다.

공포는 효과 하나마다 판정한다. 현재 공포가 한계에 닿으면 심장 하나를 없애고 공포를 0으로 돌린다. 초과분은 버린다. 심장이 남으면 같은 손님의 자원과 위치를 유지하고 다음 효과를 계속한다. 마지막 심장이 사라지면 처치 영혼을 **한 번만** 지급하고 그 손님의 나머지 이동·효과·반격·턴말을 중단한다. 같은 영업의 다음 손님이 있으면 §8의 상태로 입장한다.

## 6. 효과 해석과 경계 사례

**불안 획득과 발소리.** 턴 시작 때 손님의 ‘이번 턴 획득 불안’을 0으로 놓는다. 실제로 증가한 양을 더하며 나중에 지불해도 빼지 않는다. 예컨대 불안 97에서 +4면 누계에는 2를 더한다. 쥐 왕의 비용은 보유 불안에서 내고 공포는 누계로 계산한다.

발소리를 통과하면 이번 이동에서 **뒤이어 다른 괴이가 실제로 불안을 생성할 때마다** 그 발소리의 도착 공급량이 1씩 늘어난다. 불안 +4 한 번은 한 건이고, 상한에서 +0이면 0건이다. 여러 번 통과했다면 통과 순서대로 누적한다. 발소리 두 개를 융합했다면 A와 B가 각각 누적하고, 도착할 때도 A → B 순서로 각각 기본 1과 자기 누적분을 지급한다. 감지는 이번 이동이 끝날 때 닫히고 **이미 얻은 도착 공급량은 해당 영업 종료까지 유지**한다. 다음 손님도 혜택을 받는다. 예를 들어 발소리 통과 후 문틈에서 불안 +4를 얻었다면, 다음에 그 발소리에 도착할 때 기본 1과 누적 1을 합쳐 불안 2를 얻는다.

**봉인과 잠복.** 둘 다 개체별 0~99다. 봉인 중에는 통과·도착·속공·피격 지속·잠복 해제 효과가 양쪽 모두 모두 무효다. 이미 확정한 방어·대리 지정은 기한까지 유지한다. 잠복 자체는 이동·피격·다른 효과 사용을 막지 않는다. 잠복이 **양수에서 0으로 변한 한 번**만 해제한다. 직접 감소면 즉시, 자연 감소면 공격 전에 발동한다. 봉인 중에도 수치는 내려가며, 봉인 때문에 무효가 된 해제는 예약하지 않는다. 손님 교체나 영업 종료의 상태 정리는 해제 발동이 아니다.

- 금고가 잠복 99를 얻은 뒤 그 금고에 도착하면 도착 −99로 즉시 공포 2(강화 3). 이미 0인 금고 도착은 공포 0이다. 잠복 99에서 효과 없는 속공 반복은 처리하지 않는다.
- 예언된 방문은 비용을 낸 통과에서만 1~10층 전체(빈층 포함) 중 하나를 균등 지정하고 즉시 공개한다. 같은 효과가 다시 발동하면 잠복은 합산하고 해당 효과의 표적을 새 층으로 교체한다. 융합체는 잠복을 공유하되, 예언된 방문 둘은 각자 표적을 기억하고 해제 때 A → B 순서로 판정한다. 해제 때 손님의 실제 위치가 표적과 같을 때만 공포를 주고 표식을 지운다. 예컨대 이번 턴 잠복 2를 얻으면 이동 뒤 1, 다음 턴 이동 뒤 0이므로 **다음 도착 위치**를 확인하고 손님 공격에 앞서 판정한다.

**수리·방어·대리 피격.** 방어는 이번 턴의 흡수량이고 토큰 회복과 별개다. 생쥐의 인접층은 1↔10을 포함한 좌우 바로 한 층이다. 빈층이나 자신은 대상이 될 수 없다. 공략도는 최소 0까지 줄이고 같은 대상에 봉인 2를 더한다. 수집가는 **미봉인 생존 개체 하나**(자신 포함)만 고른다. 비용·횟수 제한은 없고 방어를 준 직후 그 대상을 봉인하므로 같은 봉인 대상에 반복할 수 없다. 다른 미봉인 대상은 다시 고를 수 있다.

- 따개비는 속공을 실제 사용한 횟수마다 이동 후 **실제 통과한 각 점유층**에 방어 2를 한 번씩 준다. 같은 층을 두 번 통과해도 한 사용에서 한 번, 최종 도착층은 제외한다. 따개비를 방문하지 않아도 적용되며, 자신이 통과층에 있으면 자신도 방어를 받는다.
- 네펜데스는 자신을 고르면 방어만 얻는다. 다른 대상을 고르면 개체당 한 대상을 맡고 재지정하면 앞 지정을 해제한다. 한 대상의 보호자는 마지막 지정이 우선한다. 대리 사슬의 고리는 비용을 내기 전에 거절한다. 최종 수신자의 방어만 소모한다. 보호자가 파괴되면 연결을 지우고 다음 타격의 수신자를 다시 찾는다.
- 금고·네펜데스·따개비의 피격 탐욕은 방어 후 **양수 피해를 받고 생존한 수신자**가 해당 원본 하나당 탐욕 1을 얻는다. 두 원본이 모두 이 효과를 가지면 같은 피격에 각각 발동한다. 토큰 손실 후 생존, 대리 피격, 비활동 피해도 해당한다. 전부 막거나 그 타격에 파괴되거나 봉인 중이면 얻지 않는다.
- 한 타격으로 현재 공략도가 개체 한계 이상이 되면 토큰 하나를 잃고 공략도는 0이 된다. 초과분은 버린다. 토큰이 0이면 즉시 영구 파괴되고 그 층이 빈다. 마지막 개체였다면 즉시 패배한다. 강화로 한계가 높아질 때 현재 공략도와 토큰을 보존한다. 발소리의 토큰 강화만 현재·최대를 함께 1 늘린다.

**비활동과 탈출.** 실제 양수 자원 증가, 양수 공포 부여, 자원을 지불한 적법한 속공 중 하나라도 있으면 활동이다. 무비용 속공이나 출구 설치 자체는 활동으로 세지 않는다. 처음 연속 3턴 비활동이면 살아 있는 괴이 하나를 균등 추첨해 대리·방어를 무시하고 공략도 12를 더한다. 이후 계속 비활동이면 2턴마다 반복한다. 활동이 생기면 연속 횟수 0, 다음 기준 3으로 돌아간다. 패널티 피격으로 탐욕이 실제 증가한 경우도 복귀한다. 새 손님은 0회·기준 3으로 시작한다.

탈출구는 주사위 확정 후 빈층 한 곳에 무료로, 영업당 한 번 설치한다. 만실이면 설치할 수 없다. 위치는 고정되고 같은 영업의 다음 손님에게도 남는다. 통과·도착으로 접촉하면 일반·엘리트는 즉시 노드를 마치고 앞서 처치한 손님의 영혼만 유지한다. 완승 괴이·주사위는 받지 않는다. 보스가 탈출하거나 플레이어가 포기하면 패배한다. 턴 수만으로 패배하지 않는다.

## 7. 손님과 공격표

표의 세 수는 **공포 한계 / 심장 수 / 개별 타격 위력**이다. 처치 영혼은 §2를 따른다. 패턴의 각 화살표는 별도 타격이다. 이웃·거울은 도착층에서 아래(−)·위(+)로 계산한 뒤 **1~10층 안의 대상만** 순서대로 친다. 범위 밖 타격은 생략하고, 범위 안 빈층은 빗나감으로 기록한다. 거울 감찰관이 1층에 도착하면 3층만, 10층에 도착하면 8층만 공격한다.

| 패턴 | 타격 순서 |
|---|---|
| 연타 | 도착층 → 도착층 |

## 8. 상태를 유지하고 지우는 시점

**영업**은 전투 노드 하나 전체다. 일반 전투의 세 손님은 한 영업에 속한다.

| 항목 | 같은 영업의 다음 손님 | 영업 종료 / 다음 준비 | 1·2막 보스 보상 처리 뒤 |
|---|---|---|---|
| 손님 공포·자원·위치·심장·턴 | 공포·불안·탐욕·예언 0, 입장 전, 자신의 최대 심장, 1턴 | 첫 손님도 같은 초기값 | 이전 손님 정리 |
| 공략도·토큰 | 공략도 0, 토큰 유지 | 다음 전투 준비 최초 진입 때 공략도 0, 토큰 유지 | 생존 개체의 토큰만 최대치로 복구 |
| 봉인·잠복·표적·방어·대리·당턴 누계와 예약 | 전부 정리 | 영업 종료 시 정리 | 추가 발동 없음 |
| 발소리의 도착 누적·설치한 출구 | 유지 | 영업 종료 시 정리 | 새 영업에 이월하지 않음 |
| 배치·개체 ID·강화·융합 계보·영혼·주사위 | 유지 | 유지 | 유지 |
| 막 추가 수입(0~9) | 유지 | 유지 | 0/9로 초기화. 보스가 준 다음 막 자금 2는 이미 지갑에 포함 |

준비 화면을 다시 열거나 미리보기·재배치를 해도 복구를 반복하지 않는다. 3막 보스 마지막 심장을 제거하면 전투 승리가 잠기고 포기할 수 없다. §3.1을 마치면 최종 승리이며 토큰을 추가로 복구하지 않는다. 패배는 전투 중 마지막 괴이 파괴, 보스 탈출, 포기다. 재시작은 §1부터 새로 시작한다.

## 9. 진행자와 플레이어의 텍스트 플레이

한 사람이 두 역할을 맡아도 아래 순서로 진행한다. **진행자는 판정하고, 플레이어는 그 시점에 공개된 정보로 선택하고 이유를 남긴다.** 별도 구현 없이 장부·표·균등 난수 도구로 진행한다.

| 결정 시점 | 진행자가 먼저 공개할 정보 | 플레이어가 확정할 내용 |
|---|---|---|
| 지도와 전투 준비 | 막·깊이·연결·공개 손님 표, 지갑 잔액과 막 추가 수입(획득량/9), 세 주사위, 1~10층의 ID·원본·내구·상태 | 방문할 노드 / 재배치 / 영업 시작 |
| 전투 턴 | 손님 위치·심장·공포·자원과 비활동, 굴림 3개. 현재 눈의 실제 통과·도착, 잠복 해제, 공격층·토큰 손실 미리보기 | 주사위 한 자리, 속공의 주체·효과·대상, 출구, 이동 실행 |
| 괴이 획득 | 세 후보 또는 구매품의 기본·강화 효과, 빈층, 교체로 잃을 개체 | 후보 하나와 놓을 층·교체할 ID 또는 새 개체 폐기 |
| 융합 노드 방문 후 | 양쪽 ID·층·강화·내구, A와 B의 본 효과, 결과 수치, 비게 될 층 | A·B 순서를 정해 확정 / 비교 취소 / 방문 건너뛰기 |
| 회복·교체·구매 | 예산·가격·대상, 변경 전후와 포기할 대안 | 토큰 배분 / 강화할 ID / 주사위 교체 자리 / 구매 슬롯 / 건너뛰기 |

융합 노드·보상·전투에서의 입력 예시는 각각 `융합 A=#03 B=#08 확정`, `보상 2번 선택 → 7층 #14 폐기·교체`, `주사위 2번 → #09 수집가 속공 대상=#04 → 이동`이다. 불법 입력이면 사유와 합법 선택을 표시하고 직전 결정으로 돌아간다. 여러 행동을 이어 썼을 때 이미 확정된 앞 행동은 유지한다. 검토·비교·취소·효과 미리보기는 사본에서 계산하고 비용·상태·난수를 소비하지 않는다. 재굴림의 미래 눈, 잠복의 미추첨 표적, 비활동 피격 대상은 가능한 범위만 예고한다. 선택이 없는 처치 정산·다음 손님·노드 종료는 자동 진행한다.

**난수와 장부.** 기본 시험 번호는 31001·31002·31003이다. 재현하려면 `번호|막|깊이|열|용도|회차`를 UTF-8로 해시(SHA-256)하고 앞 8자리 16진수를 정수 x로 읽는다. n개 중 균등 선택은 `x < 2³² − (2³² mod n)`이면 `x mod n`(0부터), 그 밖은 회차를 올려 다시 뽑는다. 열은 좌·중·우·공통을 쓰고, 좌우 배치 추첨은 공통을 쓴다. 회차는 같은 키에서 1부터 실제 추첨마다 올린다. 용도는 지도좌우·손님묶음·상점·괴이보상·엘리트주사위·이벤트종류·이벤트제시물·굴림·잠복표적·비활동표적·융합수식어로 구분한다. 상점은 복원 추첨, 괴이 보상은 뽑은 종류를 후보 목록에서 제거해 세 번 추첨한다. 목록은 표 순서, 후보층은 낮은 층부터, 굴림은 장착 1→2→3번 순서다. 지도 좌우 추첨값 0이면 지도 표의 양끝 순서를 유지한다. 텍스트 플레이어는 미공개 난수를 계산하거나 진행자 장부를 열어 선택하지 않는다.

진행자는 판 번호·규칙 버전, 방문 경로, 굴림/재굴림, 선택 이유, 개체 ID별 획득 출처·배치·강화·교체·폐기·파괴, 융합 때 고른 두 원본의 순서(A → B)와 결과 개체 C, 개별 효과·공포·실제 피해·막 복구·승패를 남긴다. 같은 체크포인트에서 다른 선택을 시험하면 원본 장부를 보존하고 비교 분기로 표시한다.

## 10. 성장 목표를 판정할 기록

| 확인할 질문 | 기록할 근거 |
|---|---|
| 초반에 새 괴이를 고를 이유가 있었나? | 방문별 점유 수, 최초 만실 깊이, 새로 채운 층이 다음 영업에서 실제로 공급·수확·방어한 양. 만실로 출구를 잃은 선택도 기록한다. |
| 막당 세 장 정도의 구매력이 있었나? | 막별 시작 자금·이월 잔액·추가 수입과 각 상점 도착 시 지갑, 실제 재고로 살 수 있었던 세 장의 가격, 구매액과 구매 수를 남긴다. 무료 보상·이벤트 구매와 상점 구매를 구분한다. |
| 만실 이후에도 보상이 선택을 만들었나? | 제시한 세 후보와 포기한 역할, 새 개체 폐기·기존 개체 교체 선택, 보상에 앞서 융합 노드를 경유했는지, 그 뒤 1~2전투에서 달라진 경로·처치 턴·토큰 손실. |
| 융합이 두 층을 유지하는 것보다 나았나? | 융합 노드를 골라 포기한 다른 노드, A의 보존 가치, 양쪽 본 효과의 실제 발동과 위치가 겹쳐 놓친 기회, 비게 된 층의 후속 활용. 같은 장부에서 역할을 바꾸거나 두 개체를 유지한 분기와 비교할 수 있다. |
| 2·3막에서도 성장이 필요했나? | 막별 마지막 유효한 구매·강화·융합·교체와 이후 전투 기여. 1막 이후 추가 성장을 모두 포기한 비교 분기는 별도 집계한다. 최종 보스 뒤 괴이의 후속 전투 기여는 평가에서 제외한다. |

이 문서의 수치는 **17판 첫 텍스트 플레이의 입력값**이다. 위 점유 상한은 노드별 획득 수로 계산한 값이다. 17판의 완주율·후반 성장 필요성·융합 밸런스는 실제 플레이 기록으로 검증한다.
