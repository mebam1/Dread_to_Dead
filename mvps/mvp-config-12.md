# Dread-to-Dead: Fears Go Round — 설정 12 괴이 액티브·블러드 웹·초기화 실험

> v0.1 · 2026-10-31 · **실행 전 시험안.** [현행 규칙](../rules.md)을 적용하며 모든 시험 수치·콘텐츠·임시 운영은 [설정 12 명세](../undecided.md#u-mvp12)에 둔다. 과거 config 11의 성능·도착 처리·직원 체계는 이번 실험의 근거로 합산하지 않는다.

## 1. 검증 질문

**현재 손님을 안전하게 넘기는 선택이 다음 손님에게 남길 괴이·액티브와 다음 구매 계획을 바꾸는가?**

| 가설 | 실제 선택으로 볼 근거 |
|---|---|
| 액티브의 집중·보존 | 같은 효과를 한 턴에 여러 번 쓰는 현재 이익과 다음 손님의 대응 부족을 비교해 사용 횟수를 바꿈 |
| 블러드 웹의 구매 경로 | 같은 예산에서 수비·증폭·후속 노드를 비교하고, 산 괴이를 배치해 실제 효과를 사용 |
| 손님·영업 초기화 | C가 사라져도 남는 P 손실·액티브 소모를 설명하고, 다음 손님 유무에 따라 행동을 바꿈 |
| 층의 경유·도착 | 최종 층의 통과 효과가 생략되는 것을 이용해 다른 눈이나 층 순서를 선택 |

동작이 발동했다는 사실과 선택이 의미 있었다는 판단을 나눈다. 과거 설정 11의 ‘파훼0’와 ‘처치 전 회복 지연’은 새 시험을 설계한 배경이며, 새 규칙의 개선 결과가 아니다.

## 2. 범위와 명세

| 항목 | 실행 기준 |
|---|---|
| 시작 자산·경영 창·P0 복귀·종료 | [운영 명세](../undecided.md#u-mvp12-setup) |
| 통과·도착·액티브와 내구 | [괴이 6종](../undecided.md#u-mvp12-content) |
| 사용 시점·반복 비용·방어·처치 중단 | [세부 판정](../undecided.md#u-mvp12-active) |
| 공개 구매망·선행 조건·가격 | [블러드 웹](../undecided.md#u-mvp12-web) |
| 영업 A/B의 연속 손님 | [방문자](../undecided.md#u-mvp12-visitors) |

본 실험은 **영업 횟수형 B/G와 상태 비용형 R**을 비교한다. 조건부 횟수 초기화는 범위에서 제외한다. P0 괴이의 다음 영업 복귀는 이번 시험의 임시 운영이며 공통 규칙의 확정이 아니다. 영업 B 이후 지출처가 없으므로 마지막 구매의 저축은 **무구매 대조군**이다. 최종 잔액만으로 장기 저축의 가치를 판정하지 않는다.

## 3. 진행

### A. 판정 사전 점검

진행자는 D1~D6의 확정 계산과 경계를 먼저 검사한다. 최종 방문의 도착 전용 발동, 반복 사용의 매회 비용, 액티브 처치 즉시 중단, C/P·횟수·재화의 서로 다른 초기화를 확인한다. 오류가 있으면 선택의 효과를 분석하기 전에 수정한다.

진단의 손상·공개 눈·경영 저장점은 실험을 위한 통제 입력이다. 자연 발생 저장점·정상 난수 표본·실제 획득 보상으로 집계하지 않는다. D2/D4의 명시된 초기 눈 이후, D3의 생존 분기와 D5의 영업은 정상 굴림으로 진행한다.

### B. 첫 구매와 연속 영업

시작 자산과 두 갈래의 전체 가격·효과, 앞으로 상대할 손님 목록을 공개한다. 참가자가 G/E 구매 또는 보류, 층 배치를 직접 정한다. 구매를 마친 뒤 선택 이유와 예상 작동을 먼저 듣는다.

영업 A의 V1→V2를 진행한다. 손님 사이에는 C만 초기화하고 P·액티브를 유지하며 구매·재배치를 허용하지 않는다. 매 손님 종료 시 다음 손님을 위해 남긴 것과 실제로 잃은 것을 확인한다.

성공 후 경영에서는 획득한 고정 보상으로 다음 노드·반대 갈래·저축을 선택한다. 새 영업 시작의 P·횟수 복구를 미리 보여주고 배치를 확정한 뒤 V3→V4를 진행한다. 상한·생산 불능·중단은 미완주이며 보상을 가산하거나 다음 영업으로 넘기지 않는다.

### C. 같은 조건의 선택 비교

- **D2:** G0/1/2회와 그 다음 손님까지 비교한다. 보호한 현재 수확자와 잃을 수 있는 다음 증폭자가 실제 운영에 미치는 영향을 기록한다. 영업 마지막 손님 변형은 별도로 비교한다.
- **D3:** T12/T16만 바꾸고 C 회복/미사용을 비교한다. 즉시 처치 장면의 회복은 초기화 이해 검사이며, 결과가 같다면 전략적 이득으로 세지 않는다. 반격 장면에서는 보존한 P와 소비한 A를 함께 본다.
- **D4:** 같은 재화·배치·눈에서 G/E 구매를 비교하고, T만 바꿔 다시 관찰한다. 첫 턴 계산으로 승자를 정하지 않고 같은 영업의 다음 손님까지 추적한다.
- **D5:** 같은 첫 구매 뒤 R/E/저축의 실제 영업 B를 비교한다. 구매 화면에서 선호를 말한 것만으로 검증을 끝내지 않는다.

안내 전 첫 선택과 비교 요청 후의 변경을 분리한다. 인간 참가자의 비교 순서는 교차 배정하고, 같은 사람이 이유를 설명하고 행동을 바꾸는지 본다. 처음부터 답안을 공개해 따라 한 행동을 자발적 탐색으로 세지 않는다. 시간 때문에 못한 분기는 미실행으로 남긴다.

### D. 난수와 평가 범위

정상 플레이는 매 턴 실제 독립 주사위를 굴리고 현재 눈만 공개한다. 짝 비교는 같은 손님·같은 턴에 같은 주사위 묶음을 배정해 앞선 분기의 턴 수가 이후 손님의 난수를 밀지 않게 한다. seed·버전을 시작 전에 고정·기록하며 결과에 맞춰 다시 고르지 않는다. 이전 분기에서 본 미래 눈을 다음 분기의 선택 근거로 쓰지 않는다.

자동 시연은 판정과 가능한 전략을 확인하는 용도다. 인간의 이해·재미·구매 욕구는 별도 관찰한다. 서로 다른 난수·구매·배치를 사용한 완주 턴 수만으로 괴이의 우열을 결론내리지 않는다.

영업 시작 복구로 손실 기록을 지우지 않는다. 현재 손님 안의 파훼, 다음 손님까지 남은 P, 새 영업 복구를 각각 기록한다. 구매했지만 보관한 괴이는 사용 효과의 근거로 세지 않는다.

## 5. 판단과 수정 순서

| 관찰 | 해석·다음 수정 |
|---|---|
| 집중 사용과 보존이 손님·경계에 따라 달라짐 | 사용으로 보존한 자산과 다음 손님의 비용을 구체 사례로 기록 |
| 같은 영업의 다음 손님이 남아도 항상 몰아 쓰기가 우세 | 손님 압력·액티브 총량·획득 역할 중 한 변수씩 조정 |
| 한 손님 안의 파훼가 전혀 없어 수비 선택이 결과를 바꾸지 않음 | 방어 역할 가설은 미검증. L·위력·타격 수 중 하나만 바꿔 재시험 |
| 구매를 바꿔도 같은 층·눈·액티브를 사용 | 노드 수를 늘리기 전에 괴이 역할·경로 비용·후속 수요를 수정 |
| R/E 또는 공격/수비 경로 한쪽만 항상 유효 | 안전·처치 속도·P·잔여 자원으로 지배 관계를 확인하고 한 변수 조정 |
| 초기화로 끝나는 손상을 막으려고 반복 대기 | 다음 손님에 남는 이익이 실제 있는지와 표시 이해를 분리 |
| 판정은 맞지만 선택을 설명하거나 바꾸지 못함 | 정보량·능력 차이·경로 예고를 점검하고 인간 검증을 계속 대기로 둠 |

완료는 실행한 범위의 판정 일치와 선택의 원인·결과가 기록된 상태를 뜻한다. **이번 문서는 실행 전**이며 완주·밸런스·재미의 통과 결과를 미리 기입하지 않는다.
