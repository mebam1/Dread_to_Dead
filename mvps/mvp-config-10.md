# Dread-to-Dead: Fears Go Round — 설정 10 융합과 사건 설계 실험

> v0.1 · 2026-10-30 작성 · **과거 config**(2026-10-31 분류). 융합·사건 설계 실험의 당시 절차이며 수치는 [과거 명세](legacy-specs-9-10.md#u-mvp10)를 따른다. 현행 역할·보상·공략/파훼·카드 사용·소진 규칙으로 실행하려면 새 명세가 필요하다.

## 1. 목적과 범위

핵심 질문은 **“융합을 이해한 플레이어가 배치·도착·직원 사용을 바꾸고, 다음 연결을 스스로 시험하는가?”**이다.

[Boardlike 조사](../competing_products/boardlike.md)의 계승에 대한 애착·전략 수렴, [Deck of Haunts 조사](../competing_products/deck_of_haunts.md)의 역할 경험·건축 수렴·보상 때문에 전투를 늘이는 반응에서 도출한 실험이다. 경쟁작의 현재 결함이나 시장에서의 유일성을 전제하지 않는다.

| 가설 | 관찰할 증거 | 실패·보완 신호 |
|---|---|---|
| 직원의 행동이 괴이의 법칙으로 이어진다 | 두 직원의 기여와 변형 관계를 자기 말로 설명하고, 유지한 카드와 소모한 직원의 차이를 안다 | 설명문을 되풀이하거나 높은 수치만 기억한다 |
| 융합이 실제 계획을 바꾼다 | 후보·배치에 따라 목표 도착 칸, 상태 소비·보존, 카드 대상이 달라진다 | 같은 계획이 후보와 호텔 상태에 관계없이 유리하다 |
| 발견이 다음 설계를 부른다 | 유도하기 전에 다른 배치·후보·직원쌍을 시험하며 그 이유를 말한다 | 도감 내용만 더 보려 하거나 진행자의 지시를 수행한다 |
| 수익을 노리는 행동에도 판단이 남는다 | 처치 시점과 자산 위험을 함께 비교한다 | 안전하게 기다리는 절차가 늘 같은 이득을 주고 반복만 늘어난다 |

설정 9의 전체 영업·보스·재건 완주는 이번 필수 범위가 아니다. 10번의 보스 장면은 공격 범위에 따른 지연 비용만 진단한다. 부분 파괴 뒤 재설계 의욕과 장기 경제는 후속 실험으로 남긴다.

## 2. 실행 명세와 준비

| 항목 | 기준 위치 |
|---|---|
| 버전·계승 판정·전체 범위 | [설정 10 공통 조건](legacy-specs-9-10.md#u-mvp10-common) |
| 시작 직원·시설·융합 후보·방문자 | [학습과 자유 선택](legacy-specs-9-10.md#u-mvp10-main) |
| 같은 자산의 순서 비교 | [공간 진단 저장점](legacy-specs-9-10.md#u-mvp10-space) |
| 즉시 처치와 지연 비교 | [수익 지연 진단 저장점](legacy-specs-9-10.md#u-mvp10-economy) |

진행자는 실행 전에 config와 참조 명세의 버전 또는 파일 해시를 기록한다. 계승 콘텐츠가 달라지면 설정 10도 버전을 올린다. 결과에 맞춰 진행 중 수치·난수·자산을 변경하지 않는다.

카드에는 직원 행동, 괴이에는 법칙 한 문장·손님이 겪는 사건·통과/도착·입출력·대체 공급을 표시한다. 특히 SR3는 자체 공포가 없으며 기록원의 도착 효과로 기시감을 수확한다. 소모되는 두 직원과 남는 풀·실제 덱을 별도로 표시한다.

현재 공개된 눈마다 경로·도착·마나를 보여주고, 카드를 예약하면 실제 효과 순서·토큰·초과 재화·생존 시 공격을 갱신한다. 미래 주사위·덱 순서는 공개하지 않는다. 후보의 추천 순위와 진행자의 해법은 제시하지 않는다.

## 3. 진행 순서

### L 직원 행동 학습

학습 시작 상태를 불러와 접객원과 녹음기사의 개별 행동을 경험하게 한다. 규칙과 조작 질문에는 답하되 어느 융합이 좋다는 설명은 하지 않는다. 사용하지 않은 직원은 짧은 별도 시연으로 소개하고, 자발적 사용과 안내 후 사용을 구분한다.

방문자 종료 또는 관찰 상한에 도달하면 학습을 끝낸다. L의 자산·재화·손상은 F로 이월하지 않는다. 이는 독립 시험의 초기화이며 게임 안의 무료 복구·직원 부활이 아니다.

### F 보존 또는 융합을 선택하고 실행

F 시작 상태에서 직원 보존과 S+R 융합을 모두 허용한다. 융합을 택하면 고정 후보를 비교하고 직접 선택·배치·편성하게 한다. 보존을 택한 것도 유효한 관찰이다. “융합을 선택하지 않음”을 실패로 처리하지 않는다.

영업 중에는 플레이어가 주사위와 카드 사용을 결정한다. 후보의 가치는 한 턴 공포뿐 아니라 이후 남은 상태, 필요한 카드, 공격 피해와 함께 기록한다. 덱 규모 변화로 소진 주기가 달라진 영향도 별도로 적는다.

첫 실행 뒤 “방금 어떤 일이 일어났나요?”라고만 묻고, 자유 탐색 시간을 준다. 배치 편집·후보 비교·직원쌍 살펴보기 메뉴를 사용할 수 있게 하되 다음 융합을 하라고 지시하지 않는다. 스스로 무엇을 시험하고 왜 바꾸려 하는지를 먼저 기록한다.

자발적 관찰이 끝난 뒤에는 다른 후보와의 비교 플레이를 제안할 수 있다. 처음에 보존을 선택했다면 별도 분기에서 융합 시연을 제안할 수 있다. 이때 나온 설명·탐색은 **안내 후 반응**으로 분리한다. 후보마다 독립적으로 초기화한 F 상태에서 재료를 실제 소모한다. 한 판 안에서 괴이를 무료 교체하거나 직원을 되살리지 않는다.

다른 직원쌍을 시험하고 싶다면 선택적 확장 상태를 사용한다. 초기 F는 S+R만 실행할 수 있으므로, 다른 쌍에 대한 관심만으로 실제 조합 탐색을 완료했다고 쓰지 않는다.

### C 같은 자산으로 사건 바꾸기

공간 진단 A/B를 참가자별로 교차 순서로 제시한다. 먼저 행동을 선택하고 예상 결과를 말하게 한 뒤 처리한다. 같은 타일·손패·현재 눈에서 순서만 달라졌을 때 어디에서 입력이 생기거나 끊기는지 관찰한다.

미리보기 확인 전의 예측과 미리보기를 읽은 뒤의 설명을 구분한다. 미리보기를 이미 봤다면 자력 예측으로 집계하지 않고, 왜 그 결과가 생기는지의 원인 설명을 관찰한다.

두 상태를 경험한 뒤 경영 상태에서 자유 재배치를 허용하고 새 계획을 실행하게 한다. 전투 중 영구 타일을 옮기는 기능은 제공하지 않는다. 계산을 이해한 반응과 스스로 다른 사건을 설계한 반응을 따로 기록한다.

### E 지금 처치하거나 더 큰 수익 준비하기

수익 진단의 일반/보스 상태를 참가자별로 교차 순서로 제시한다. 첫 선택의 예상 수익·공격·손실을 말하게 하고, 선택 후 방문자 종료 또는 관찰 상한까지 진행한다.

즉시 처치와 지연을 같은 시작 상태의 독립 분기에서 비교한다. 현재 공개된 눈 이후에는 실제로 굴리고 기록한다. 분기마다 미래 난수가 다르면 총수익 차이를 선택 하나의 인과 효과로 단정하지 않는다.

일반 손님의 빈칸 도착과 보스의 경로 공격을 구별하는지, 기다리며 새로운 판단을 하는지 본다. 생존 중 무위험으로 큰 초과 수익을 준비할 수 있으면 그대로 기록한다. 진행자가 공격이나 페널티를 임의로 추가하지 않는다.

## 4. 기록 양식

각 실행은 독립된 기록으로 남긴다. 이번 문서 작성으로 실행 결과 파일을 만들거나 성공을 기입하지 않는다.

```text
실행 ID / 날짜 / config 버전 / 참조 명세 버전 또는 해시:
모드: 인간 플레이 / 자동 판정 시연
참가자 익명 ID / 경험 여부 / 제시 순서:
단계·분기 / 초기화 여부 / 시작 풀·실제 덱·배치·내구·잔액:
융합: 보존 또는 재료 개체 / 고정 후보 / 선택·포기 이유 / 남은 풀:
턴: 위치, F/T/H, 상태, 손패·덱·버림, 소진, 실제 눈, 선택 눈·마나
예약: 카드 개체, 칸, 참조 상태, 비용, 사용 순서
예측·설명: 플레이어의 말 그대로 / 미리보기 확인 전·후 / 힌트·질문 여부
결과: 실제 경로와 효과 순서, 상태 변화, 토큰, 초과 재화, 공격·파괴
다음 결정: 배치·카드·목표 도착의 변화와 이유
종료: 처치 / 관찰 상한 / 생산 불능 / 참가자 중단 / 판정 오류
합계: 턴 수, 초과 재화, 피해·파괴, 카드·소진, 초기화 제공 자산
자유 설명 / 자발적 탐색 행동 / 안내 후 반응:
판정과 근거 / 다음 버전에서 바꿀 변수:
```

회전·심장마비 뒤 남은 상태, 마지막 토큰 제거 시 중단한 효과·공격, 미발동 카드도 기록한다. 설명과 행동이 서로 다른 참가자에게서 나왔다면 하나의 성공 사례로 합치지 않는다.

## 5. 판정과 다음 단계

| 판정 대상 | 관찰됨으로 기록할 기준 | 보완할 때 먼저 바꿀 것 |
|---|---|---|
| 인과 이해 | 재료 행동과 괴이의 작동 관계를 자기 말로 설명한다 | 직원 행동·법칙 문장·발동 표현 |
| 설계 변화 | 입력·소비·보존·도착을 이유로 실제 배치나 카드 계획을 바꾼다 | 후보의 작동 차이·연결 조건 |
| 자발적 탐색 | 안내 전에 다음 시도와 목적을 정하고 조작하거나 실행한다 | 발견할 관계·다음 선택의 접근성 |
| 수익 판단 | 기다림의 추가 수익과 자산 위험을 구별한다 | 위험을 없애는 조건, 보상·내구·피해 중 원인 변수 |

핵심 경험은 **같은 사람에게 인과 이해·설계 변화·자발적 탐색이 함께 관찰될 때** 유망한 사례로 기록한다. “재미있다”는 답, 최대 눈 선택률, 카드 사용률, 자동 완주만으로 대체하지 않는다. 첫 참가자 집단의 문제를 수정한 뒤 새 참가자에게 재현되는지 확인한다.

법칙을 이해해도 매번 같은 계획이면 후보 수를 늘리기 전에 작동 방식을 수정한다. 상태 소비·보존의 차이를 이해하지 못했다면 정보 전달과 법칙 복잡도를 먼저 분리 점검한다. 지원 후보의 입력 경로가 있다는 사실만으로 경쟁력이 있다고 판정하지 않는다.

E의 경제 문제가 드러나도 F/C에서 관찰한 발견의 재미를 자동 부정하지 않는다. 반대로 수익·피해 균형이 맞아도 고유한 경험이 검증된 것은 아니다. 자동 시연은 판정 오류와 가능한 선택을 찾는 용도로만 사용한다.
