최초 작성일: 2026년 10월 29일 · 개정일: 2026년 10월 30일  
문서명: `mvp-1.md`  
문서 목적: 필요한 기능과 콘텐츠, 제작 순서, 단계별 완료 조건, 확장 판단 기준을 정한다. 구체적인 코딩 방법은 다루지 않는다.  
이번 개정 근거: `rules.md` v0.8, `mvp-config-8.md`, 해당 설정으로 초기화해 완주한 텍스트 시연 1회. 시연의 결과와 주요 장면은 §12에 보존한다.

## 1. MVP의 목표

**플레이어가 융합 결과를 자기 말로 설명하고, 다음 조합을 궁금해하는지 확인한다.** 이 경험을 중심으로 경영, 영업, 보스, 재설계가 연결되는 짧은 한 판을 완성한다.

최종 범위는 **팩션 1개, 직원 5종, 조합 10쌍, 괴이 후보 30종, 보스 1종을 기본으로 한다.** 보스 2종째와 상태 5종째는 첫 구성이 충분한지 확인한 뒤 추가한다. 표현은 2D 카드와 고정 카메라의 간단한 테이블로 시작한다.

제작은 **대표 3쌍·괴이 9종으로 첫 판단 → 경영·보스·재설계 연결 → 10쌍·괴이 30종으로 확장** 순서로 진행한다. 중간 검증용 9종과 최종 MVP 목표 30종을 구분한다.

### 1.1 가장 먼저 확인할 두 가지

1. **관계의 이해:** 두 직원이 각각 하던 일이 괴이 안에서 어떻게 연결되거나 변형되었는지 설명한다.
2. **다음 조합에 대한 호기심:** 다른 직원을 골라 보거나, 후보를 비교하거나, 다음 융합을 위해 모집·보존을 계획한다.

두 행동이 같은 플레이어에게 함께 나타나는지를 본다. 설명을 잘한 사람과 다른 조합을 찾아본 사람이 서로 다르다면 그 차이도 기록한다. 이 기준은 능력 체크리스트 23항과 연결된다.[R2]

### 1.2 이어서 확인할 네 가지

| 가설 | 확인할 실제 경험 |
|---|---|
| 후보 3종 중 하나를 고르는 일이 의미 있다 | 현재 호텔에 필요한 이유를 들어 선택하고, 포기한 후보의 장단점도 설명한다 |
| 괴이 획득이 호텔 설계를 바꾼다 | 배치 순서, 상태 공급, 수확 위치, 직원 덱이나 카드 사용이 달라진다 |
| 주사위 선택과 유료 카드 사용이 함께 의미 있는 판단을 만든다 | 후보별 도착 위치·마나·수확 기회를 비교해 하나를 고르고, 그 뒤 카드의 대상·순서·사용 여부와 포기한 대안을 설명한다 |
| 보스의 부분 파괴가 재설계 동기를 준다 | 남은 자산을 다른 방식으로 연결하고 다시 영업해 본다 |

효과가 정상적으로 발동한 것과 재미가 검증된 것을 구분한다. 체크리스트 23~24항은 실제 플레이 관찰이 쌓인 범위에서만 판단을 갱신한다.[R2]

### 1.3 이 단계에서 판단하지 않는 것

- 장기적인 리플레이성과 대규모 콘텐츠의 유지 가능성.
- 판매량, 적정 가격, 시장 수요, 상업적 성공 가능성.
- 풀 3D 테이블이나 공간 탐험이 더해 주는 매력.
- 여러 팩션의 조합, 장기 메타 성장, 다수의 보스가 만드는 다양성.

이 계획에서는 완성 확률이나 판매 확률을 임의의 백분율로 제시하지 않는다. 얻으려는 결과는 **어떤 경험이 작동하고, 무엇을 고쳐야 하며, 다음 제작에 투자할 근거가 있는지**에 관한 관찰이다.

### 1.4 설정 8 시연 이후의 판단

**한 판의 규칙상 순환과 선택 장면은 텍스트로 확인했다. 다음 제작의 우선순위는 그 선택을 사람이 이해하고 즐기는지 확인할 수 있는 기능을 갖추는 것이다.** 이번 시연을 실제 게임 구현 완료나 인간 플레이 검증 통과로 기록하지 않는다.[R9]

| 항목 | 이번 시연에서 확인한 범위 | 다음에 확인할 것 |
|---|---|---|
| 경영 → 영업 → 보스 → 재구성 → 재영업 | 일반 손님 5명·보스 1회를 총 20턴에 완주 | 실제 화면에서 안내 없이 진행할 수 있는가 |
| 주사위 선택·카드 비용 | 수확 위치 때문에 작은 눈을 고르거나, 강화·회복을 함께 쓰기 위해 큰 눈을 고르는 장면 | 사람이 대안의 이점과 포기한 것을 설명하며 재미를 느끼는가 |
| 융합·배치 | 3개 조합에서 4회 융합. 같은 조합의 다른 후보를 얻고 공급·수확 순서를 변경 | 두 직원의 기여를 이해하고 다음 조합을 자발적으로 탐색하는가 |
| 직원 공급 | 시작 5명에 9명을 모집하고, 4회 융합 후 6명 유지 | 다른 모집·수익 경로에서도 필요한 조합과 카드 활용이 가능한가 |
| 보스·부분 손실 | 3턴 격퇴. 회복으로 실제 파괴 1건을 막았으나 최종 파괴는 0개 | 위협의 적정성과 부분 손실 뒤 재설계 동기. 이번 판에서는 미경험 |
| 콘텐츠·표현 | 임시 괴이 4종을 획득·배치, 상태 A·B 사용, 직원 카드는 3종 사용 | 대표 후보 9종·전체 30종, 직원 5종의 행동, 상태 4종, 실제 표현과 조작 |

**규칙의 채택과 시험값은 구분한다.** 1dX 주사위 K개 중 하나를 고르는 방식과 **굴림 → 선택 → 카드 플레이** 순서는 정식 채택되었다. X·K와 카드별 비용의 구체적인 값은 미정이며, 설정 8의 **X=6, K=3, 카드 비용 2**를 다음 관찰의 출발값으로 사용한다.[R1 §4.4, R8]

## 2. 최종 제작 범위

아래 표는 이번 MVP의 기능 범위다. 기존 규칙에 없던 수량·운영 방식은 MVP 제안으로 다룬다.

| 항목 | 최종 MVP 범위 | 범위 관리 기준 |
|---|---|---|
| 팩션 | 1개 | 팩션 선택·해금·상성은 후속 단계 |
| 직원 | 서로 다른 직원 5종 | 실제 보유 인원은 모집으로 보충할 수 있음 |
| 융합 조합 | 서로 다른 종류끼리 10쌍 | 같은 종류끼리의 융합은 이번 범위에서 제외 |
| 괴이 | 조합별 고정 후보 3종, 총 30종 | 1회 융합에서 실제 획득하는 것은 선택한 1종 |
| 시설 | 기본 시설 4종을 시작안으로 설정 | 상태 공급·기본 수확·위험 관리가 가능하도록 역할 배분 |
| 상태 효과 | 4종 우선, 최대 5종 | 다섯 번째 상태는 기존 상태로 표현하기 어려운 필요가 있을 때 추가 |
| 일반 손님 | 기본 유형 1종 | 다수의 특성·면역·등급은 후속 단계 |
| 보스 | 1종 필수, 2종째 선택 | 첫 보스 이후 재설계가 성립한 뒤 추가 |
| 호텔 | 순서가 있는 1D 루프 1개 | 배치·보관·빈 슬롯 확장 지원 |
| 주사위 선택 | 1dX K개 동시 굴림 → 하나 선택 → 유료 카드 사용 | X·K는 미정. 후보별 경로·도착·마나 비교가 필수 |
| 표현 | 2D 카드, 고정 카메라, 테이블 배경 1개 | 조명·그림자·작은 카메라 움직임으로 입체감 표현 |
| 한 판 | 경영 → 일반 영업 → 보스 → 재설계 → 재영업 | 재설계한 호텔이 실제로 작동하는 장면까지 포함 |
| 기본 편의 | 짧은 안내, 상세 보기, 처리 속도 조절, 재시작·이어하기 | 별도 도감·업적·설문 대시보드는 필수 기능에서 제외 |

### 2.1 직원 5종과 보유 직원 5명을 구분한다

직원 5종의 서로 다른 두 종류를 모두 조합하면 `5 × 4 ÷ 2 = 10쌍`이고, 각 조합의 후보가 3종이면 전체 후보는 30종이다. 이 계산은 **동종 융합을 제외한다는 MVP 제안**을 전제로 한다.

시작 직원은 각 종류 1명씩 총 5명으로 둔다. 모집으로 같은 종류의 다른 직원을 확보할 수 있게 하고, 융합할 때는 선택한 직원 두 명만 소모한다. 같은 종류의 다른 보유 직원까지 함께 사라지지는 않는다.

보충 없이 5명만 제공하면 융합은 최대 2회다. 직원 공급은 다음 조합에 대한 호기심을 실제 행동으로 이어 주는 필수 기능이다.

예를 들어 시작 5명에서 **융합 4회 후 직원 3명을 남기려면 최소 6명을 추가 모집**해야 한다. `5 + 6 - 2 × 4 = 3`이기 때문이다. 이는 공급량을 점검하기 위한 예시이며, 최소 덱 3장을 강제하는 규칙은 아니다. 실제로는 모집 비용과 필요한 종류의 확보도 함께 가능해야 한다.

직원 부족이 나타나면 모집량·가격·갱신 주기를 먼저 조정한다. 직원 종류를 7~8종으로 늘리면서 모든 이종 조합에 후보 3종을 유지하면 전체 괴이는 각각 63종·84종으로 증가한다.

설정 8 시연에서는 **`5 + 9 − 2 × 4 = 6`**으로, 9명을 모집해 4회 융합한 뒤 직원 6명을 남겼다. 모집을 통한 보충으로 여러 번 융합하면서 덱을 유지한 사례다. 한 판의 성공 경로이므로 모든 모집 후보와 수익 상황에서 공급이 충분하다고 일반화하지 않는다.[R9 §12.2]

## 3. 제작에 적용할 진행과 종료 규칙

현재 규칙에는 **보스의 목표 공포를 채우면 승리한다**는 조건과 **K개의 1dX 중 하나를 선택한 뒤 카드를 사용하는 순서**가 확정되어 있다. 공격·실패 종료·손실·복구는 rules.md의 MVP 제안 지위를 유지하고, 실제 시험에 사용할 수치와 판정은 config로 구체화한다.[R1 §4.4·§8]

아래 MVP 운영안은 설정 8에서 텍스트 한 판에 적용했다. 이번 결과로 모든 수치가 적정하다고 확정하지 않으며, §6.1의 현재 시험값과 §7의 인간 플레이 관찰을 기준으로 조정한다.[R8, R9]

### 3.1 짧은 한 판의 범위

1. 시작 직원과 기본 시설을 받고 호텔을 구성한다.
2. 일반 손님 3명을 순서대로 받는다. 손님 사이에 경영·모집·융합·재배치가 가능하다.
3. 보스 1회에 도전한다.
4. 보스 격퇴 후 남은 자산을 확인하고, 모집·융합·재배치로 호텔을 재설계한다.
5. 일반 손님 2명을 더 받아 재설계의 성과를 확인한다.
6. 결과 화면에서 공포 수익, 선택한 괴이, 손실과 재설계 내용을 확인한다.

이 구성은 첫 완주 범위다. 일반 손님 수와 진행 길이는 플레이 중 기다림·학습 부담을 보고 조정한다. 장기 캠페인이나 메타 성장 없이도 한 번의 구축과 한 번의 재설계를 경험할 수 있어야 한다.

### 3.2 보스 종료 조건

| 상황 | MVP 제안 판정 | 다음 진행 |
|---|---|---|
| 목표 공포 달성 | 즉시 격퇴 성공 | 남은 이동·공격을 중단하고 손실 정산 후 재설계 |
| 공포 생산 수단이 확실히 모두 사라짐 | 생산 불능으로 보스전 패배 | 이번 판 종료 및 이유 표시 |
| 8턴을 마쳐도 목표 미달 | 시간 초과로 보스전 패배 | 이번 판 종료 및 이유 표시 |
| 플레이어가 전투 포기를 선택 | 포기로 종료 | 이번 판 종료 |
| 보스 격퇴 뒤 재영업 2회 완료 | MVP 완주 | 성과 확인과 새 판 시작 |

**8턴은 최초 시험값이다.** 보스전 시작 전에 목표 공포, 최대 턴, 현재 턴을 보여 준다. 마지막 턴에도 공포 목표 달성 여부를 먼저 판정하고, 목표를 못 채웠을 때 공격·시간 초과를 처리한다.

생산 불능은 단순히 수확 타일이 없다는 이유만으로 판단하지 않는다. 직원이나 남은 능력으로 공포 생산을 다시 만들 수 있다면 진행 가능성이 남는다. 확실한 불능만 조기 종료하고, 그 외 장기 교착은 턴 상한으로 끝낸다.

이번 안에서는 보스전 패배가 판 종료다. 따라서 **패배해서 재설계를 경험하지 못한 참가자를 재설계 가설의 실패 사례로 집계하지 않는다.** 원인 분석이 필요하면 별도의 보스 직후 장면을 제공하고, 정상 한 판의 결과와 구분한다.

### 3.3 보스 한 턴에 필요한 정보와 순서

- 직원 카드를 드로우하고 덱 소진을 처리한다.
- **1dX 주사위 K개를 동시에 굴리고 모든 결과를 보여 준다.**
- 각 후보의 통과 경로·도착 예정 위치·획득 마나를 현재 손패·상태·타일 내구도와 함께 비교한다.
- **플레이어가 주사위 하나를 선택·확정**한다. 선택한 같은 눈으로 이동 거리와 획득 마나를 결정한다.
- 카드 사용 전에 공격 대상과 피해량을 확인한다. 설정 8처럼 선택한 이동이 공격 대상을 정하는 시험에서는 선택 전에도 후보별 공격 대상을 비교할 수 있게 한다.
- 플레이어가 **마나 비용을 지불해 직원 카드를 사용**하거나 사용하지 않기로 결정한다.
- 보스가 이동하며 통과·도착 효과를 받는다.
- 목표 공포를 채우면 즉시 승리한다.
- 목표 미달이면 예고한 공격을 실행하고 파괴·종료 여부를 확인한다.

선택한 주사위는 카드 사용 후 바꾸지 않는다. **설정 8의 ‘도착 슬롯 공격’은 해당 시험의 운영 전제**이며, 정식 보스 공격 대상 선정 방식은 여전히 미정이다. 후보 정보를 보여 주는 기능과 공격 대상을 정하는 규칙을 구분한다.[R1 §4.4·§8.5, R8 §1·§6]

공격은 첫 보스에서 턴당 한 번으로 제한한다. 공포를 더 얻을지, 타일을 회복해 다음 수확을 지킬지 판단할 수 있어야 한다. 이는 P8의 수확·승리 확인 후 공격하는 시험 조건을 MVP 규칙으로 채택한 제안이다.[R5]

보스전의 덱 소진은 **셔플 후 해당 드로우 중단**을 유지하고, 일반 손님의 심장 부담 대신 **그 턴의 예고 공격 피해 +1**을 적용하는 안으로 시작한다. 보스는 심장마비로 쓰러지지 않는다. 이 추가 피해는 턴을 넘겨 누적하지 않으며 카드 선택 전에 표시한다.

### 3.4 손실과 복구의 범위

- 시설과 괴이는 내구도가 0이 되면 이번 판에서 제거한다.
- 파괴된 타일의 슬롯은 빈칸으로 남는다. 슬롯, 다른 타일, 직원 풀, 남은 경영 자원은 보존한다.
- 파괴되지 않은 타일의 손상은 보스전 종료 후 회복하는 안으로 시작한다. 장기간의 수리 비용 관리는 후속 과제다.
- 전투 중 회복은 살아 있는 타일만 대상으로 한다. 파괴된 타일의 부활은 이번 범위에서 제외한다.
- 보스가 끝나도 파괴된 자산을 자동으로 원상복구하지 않는다.
- 재설계 단계에서는 남은 타일을 무료로 보관·재배치할 수 있게 한다.

부분 파괴를 보기 위해 매번 정해진 수의 타일을 강제로 지우지는 않는다. 무손실 승리도 허용하고, 그 참가자의 부분 파괴 경험은 미경험으로 기록한다. 별도 손실 장면은 진단에 사용할 수 있으나 자연스럽게 발생한 손실과 합쳐 평가하지 않는다.

**설정 8의 현재 상태는 ‘보스 격퇴·회복의 작동 확인, 부분 파괴 후 재설계는 미경험’이다.** 보스 이후 배치 변경은 새 괴이·시설 확보에 따른 재구성이었으며, 잃은 자산을 대체한 사례로 집계하지 않는다.[R9 §12.2~§12.3]

### 3.5 일반 영업의 사망과 정산

일반 손님은 출구를 처음 통과하면 퇴장한다. 심장 부담 한계에 도달하면 사망하고 경찰 의심도가 증가한다는 기존 규칙을 유지한다.[R1 §5]

MVP 정산안은 다음과 같다.

- 생존 퇴장: 해당 손님에게 수집한 공포를 경영 자원으로 받는다.
- 사망: 그 손님의 공포 수익은 받지 못하고 경찰 의심도가 1 증가한다. 이전 수익은 유지한다.
- 경찰 의심도 3 도달: 이번 판을 종료한다.
- 사망·퇴장·판 종료가 일어나면 그 손님에 대한 남은 이동과 효과를 중단한다.

의심도 3은 시작값이며, 일반 손님의 심장 부담 한계·덱 소진 부담량과 함께 조정한다. 실패 이유와 사라지는 수익을 선택 전에 알 수 있어야 한다.

## 4. 반드시 필요한 기능

### 4.1 직원 보유와 모집

**목적:** 직원을 카드로 남겨 둘지, 융합 재료로 사용할지 선택하고 이후 융합을 계속할 수 있게 한다.

필요한 기능:

- 직원 5종 각각의 핵심 행동과 특성을 확인한다.
- 보유 직원과 현재 편성한 직원 덱을 구분해 본다.
- 같은 종류의 직원을 추가로 모집하고 여러 명 보유할 수 있다.
- 경영 단계에서 모집 후보와 비용을 확인한다.
- 융합 후 보유 직원과 편성 가능 카드가 어떻게 달라지는지 확인한다.

**모집 시작안:** 각 경영 단계에 후보 3명을 제시하고 최대 2명을 모집할 수 있게 한다. 영업 결과 정산 후 후보를 갱신하며, 같은 경영 단계에서 무료로 계속 갱신할 수는 없다. 후보는 다섯 종류 안에서 공급하고 원하는 종류의 상시 지명 구매는 제공하지 않는다.

모집 비용은 시설 획득·호텔 확장과 같은 자원을 사용한다. 첫 테스트에서는 한 판에 융합을 여러 번 하고 직원 카드도 써 볼 수 있는 자금과 공급량을 확보한다. 공급 수량만 충분하고 필요한 종류가 전혀 연결되지 않는 경우도 별도로 확인한다.[R1 §4.1·§4.6·§7]

**완료 조건:** 초기 직원으로 융합한 뒤에도 모집을 통해 다른 조합을 시도할 수 있고, 직원 보존과 융합이 모두 선택지로 남는다.

**시연 반영:** 설정 8에서는 4회 융합과 직원 6명 유지가 가능했다. 이후에는 모집 횟수만 세지 않고, 원하는 쌍을 구성할 종류·자금·구매 시점이 함께 마련되는지 본다. 단순히 직원 종류를 늘리는 것을 우선 해법으로 삼지 않는다.[R9 §12.2]

### 4.2 융합과 후보 비교

**목적:** 직원 두 명의 행동이 새로운 괴이의 법칙으로 이어지고, 현재 호텔에 맞는 결과를 고르게 한다.

필요한 기능:

- 보유 직원 두 명을 선택한다.
- 조합마다 고정된 후보 3종을 나란히 비교한다.
- 각 후보의 핵심 법칙, 필요한 입력, 통과·도착 효과, 주요 위험을 확인한다.
- 소모될 직원 두 명과 획득할 괴이 한 종을 확인한다.
- 최종 선택을 확정하면 두 직원을 소모하고 괴이 하나를 얻는다.
- 획득한 괴이를 보관하거나 호텔에 배치한다.

직원 선택 순서에 따라 후보가 달라지지 않고, 같은 조합을 다시 선택해도 동일한 후보 3종을 제시한다. 후보를 무작위로 바꾸는 기능은 필요하지 않다.[R1 §3.5]

**공개·소모 시작안:** 보유 직원 쌍을 선택하면 세 후보의 효과를 모두 보여 준다. 최종 제작 전에는 무료로 취소할 수 있고, 확정할 때 직원 두 명을 소모한다. 추가 융합 화폐는 두지 않는다. 직원 확보 비용과 카드 활용 기회가 융합의 비용이 된다.

**완료 조건:** 플레이어가 후보의 차이를 설명하고 현재 호텔에 필요한 이유로 하나를 고를 수 있다. 세 후보의 선택률이 반드시 같아야 하는 것은 아니다.

**시연 반영:** 같은 접객원+녹음기사 조합에서 처음에는 상태를 소비하는 ‘대답하는 벽’, 나중에는 상태를 남기는 ‘금지된 안내방송’을 선택했다. 같은 고정 후보라도 호텔의 필요에 따라 다른 이유로 고르는 장면을 사람에게 확인한다. 이 이름과 능력은 임시 시연 콘텐츠이며, 최종 30종 명세로 확정된 것은 아니다.[R9 §12.3]

### 4.3 호텔 배치와 확장

**목적:** 괴이를 얻은 결과가 실제 호텔 구성의 변화로 드러나게 한다.

필요한 기능:

- 이동 방향과 입구·출구가 명확한 1D 루프를 본다.
- 시설·괴이를 슬롯에 배치하고, 순서를 바꾸거나 보관한다.
- 빈 슬롯과 설치된 타일을 구분한다.
- 타일의 통과 효과와 도착 효과를 따로 확인한다.
- 현재 위치에서 각 수확 타일까지의 거리와, 그 눈을 선택했을 때 얻을 마나를 읽을 수 있다.
- 공통 경영 자원을 사용해 빈 슬롯을 늘린다.
- 괴이 획득 전후, 보스 파괴 전후의 배치를 비교한다.

**배치 시작안:** 슬롯당 타일 하나, 경영 중 무료 재배치·보관, 영업·보스전 중 배치 변경 불가로 시작한다. 확장은 빈 슬롯만 제공하며 시설·괴이를 자동 지급하지 않는다.[R1 §2·§7]

**완료 조건:** 새 괴이 때문에 공급·변환·수확의 위치나 기존 자산의 쓰임을 바꿀 이유가 생긴다. 재배치 횟수가 많다는 사실만으로 성공으로 판단하지 않는다.

**시연 반영:** 최종 호텔은 B 공급 시설 두 개 뒤에 비소비 참조형을 두고, 이후 소비형과 변환·소비형을 연결했다. 배치 평가에는 공급 순서뿐 아니라 **다음 수확실까지의 이동 거리와 그때의 카드 사용 여력**도 포함한다. 모든 방에 원하는 순서로 도착할 수 있다고 가정하지 않는다.[R9 §12.3]

### 4.4 일반 영업과 직원 카드

**목적:** 자신의 호텔이 공포를 생산하는 성취와, 주사위 후보·손패·상태를 함께 보고 이동과 카드 사용을 결정하는 판단을 제공한다.

필요한 기능:

- 보유 직원에서 0~20장으로 덱을 편성한다. 영업·보스전 시작 후에는 편성을 잠근다.
- 매 턴 새 손패를 받고 카드 비용·대상·사용 가능 여부를 확인한다.
- **1dX 주사위 K개를 동시에 굴리고 모든 후보를 확인한다.** 같은 눈의 중복도 허용한다.
- 후보별 통과 경로, 도착 예정 타일 또는 퇴장 여부, 얻을 마나를 비교한다.
- **그중 하나를 선택·확정한 뒤** 선택한 눈만 이동 거리와 마나에 함께 적용한다.
- 이동 전에 카드 비용을 마나로 지불해 직원 카드를 사용한다. 사용하지 않는 선택도 가능하다.
- 카드가 없는 경우, 마나 부족, 입력·대상 부재, 회복할 손상 없음 등 서로 다른 사용 제한을 알 수 있다.
- 선택한 주사위와 남은 마나를 구분하고, 카드 사용 후 주사위를 다시 고르지 않는다.
- 손님이 지나간 타일의 통과 효과를 받고, 도착 타일에서는 통과 효과 후 도착 효과를 받는다.
- 출구 첫 통과 시 영업을 종료하고 수익·위험을 정산한다.
- 턴이 끝나면 남은 손패를 버리고 남은 마나를 이월하지 않는다.

**영업 시작안:** 각 일반 영업·보스전 시작 때 편성한 덱 전체를 새로 섞고 손패와 마나를 초기화한다. 일반 손님은 상태와 심장 부담이 0인 상태로 입장한다. 이전 손님의 위험이나 남은 손패를 다음 손님에게 이어 주지 않는다.

**덱 소진:** 뽑을 카드가 없으면 심장 부담 증가, 버린 카드 셔플, 해당 드로우 중단 순서로 처리한다. 셔플 직후 부족한 손패를 이어서 채우지 않는다. 0장 덱도 허용하되, 빈 덱과 빈 버림 더미 때문에 턴 진행이 멈추지 않아야 한다.[R1 §4.2~§5.4]

필수 정보는 **이번에 굴린 K개의 눈, 선택한 주사위, 후보별 경로·도착·획득 마나, 현재 손패·상태·심장 부담, 카드 사용 후 남은 마나**다. 현재 공개된 결과로 알 수 있는 정보와 아직 굴리지 않은 다음 턴의 가능성을 구분한다. 미래 주사위나 최적 선택을 자동으로 알려 주는 기능은 필수 범위가 아니다.[R1 §4.4, R8 §1]

**완료 조건:** 플레이어가 어떤 방과 마나를 선택했고 무엇을 포기했는지 설명하며, 그 선택에 맞춰 카드의 대상·순서·사용 여부를 판단한다. 손패가 비어 있어도 타일 활용을 위한 이동 선택이 가능해야 한다. 후보들이 모두 같은 결과라면 이를 의미 있는 선택으로 세지 않는다.

**시연 반영:** 일반 영업 17턴 중 카드 사용은 5회였지만, 마지막 손님의 빈손 턴에는 눈 1을 골라 공포 8을 추가 수확했다. 카드 미사용을 모두 실패로 집계하거나, 사용 횟수를 늘리기 위해 비용부터 내리지 않는다. 비용 부족·입력 부족·대상 없음·이미 충분함·의도적 미사용을 구분한다.[R9 §12.2~§12.3]

### 4.5 상태와 효과의 이해

**목적:** 앞선 타일의 작동이 뒤쪽 타일의 결과로 이어지는 이유를 이해하게 한다.

필요한 기능:

- 손님이 가진 상태의 종류와 중첩 수를 확인한다.
- 상태를 부여·참조·소비·변환하는 차이를 읽을 수 있다.
- 효과를 일으킨 타일과 상태·공포 변화가 연결되어 보인다.
- 입력 상태가 부족하거나 대상이 없어 발동하지 않은 이유를 확인한다.
- 참조 수확 뒤 남은 상태와, 뒤쪽 소비·변환 타일에서 달라진 상태를 구분해 확인한다.
- 처음 본 효과는 천천히 확인하고, 익숙한 처리 과정은 빠르게 볼 수 있다.

**상태 시작안:** 비음수 정수 중첩을 사용하고, 상태별 자연 감소·별도 타이머는 두지 않는다. 일반 손님의 상태는 퇴장·사망 시 사라지고, 보스의 상태는 전투 중 회전이 바뀌어도 유지되며 전투 종료 때 사라진다. 첫 통합 관찰은 §6.1과 설정 8의 중첩 상한·입력 부족 판정을 적용하고, 이후 결과에 따라 조정한다.

상태 4~5종은 손님에게 붙는 효과의 종류 수다. 공포, 마나, 심장 부담, 경찰 의심도는 각각 수익·사용 자원·위험을 나타내는 별도 값으로 구분한다. 기존 문서의 불안·환청·저주는 예시이며 실제 상태명과 역할은 콘텐츠 설계에서 정한다.[R1 §6, R3 §7]

**완료 조건:** 효과 문장을 다시 읽는 것에 그치지 않고, 어떤 입력이 어떤 결과로 이어졌는지 플레이어가 설명할 수 있다.

**시연 반영:** 마지막 손님의 ‘참조 수확 → 소비 수확 → 변환·소비 수확’ 연결을 대표 확인 장면으로 사용한다. 같은 즉시 수익을 얻더라도 상태를 남기는 카드·후보가 다음 수확을 어떻게 바꾸는지 설명하는지 본다. 이번 시연에서 사용한 A·B 두 상태만으로 최종 상태 4종의 역할까지 검증했다고 보지 않는다.[R9 §12.3]

### 4.6 경영과 투자

**목적:** 번 공포를 다음 호텔과 다음 융합에 어떻게 쓸지 선택하게 한다.

필요한 기능:

- 영업 결과와 사용할 수 있는 경영 자원을 확인한다.
- 직원 모집, 시설 획득, 빈 슬롯 확장 사이에서 자원을 배분한다.
- 현재 구매할 수 있는 것과 비용을 확인한다.
- 다음 영업·보스 전에 덱과 배치를 수정한다.
- 보스를 준비할 수 있도록 등장 시점을 미리 확인한다.

**경제 시작안:** 수집한 공포를 그대로 공통 경영 자원으로 사용한다. 성과로서의 누적 공포와 지출 가능한 잔액을 구분해 표시한다. 보스의 공포 목표 게이지는 해당 전투에서 새로 채우며 보유 잔액과 혼동하지 않게 한다. 보스전의 목표 공포는 일반 영업 수익으로 정산하지 않고, 격퇴 시 정해진 경영 자원 보상만 받는다.

별도 화폐, 유지비, 복잡한 시설 개선 단계는 추가하지 않는다. 호텔 확장은 의도된 성장으로 유지하고, 한쪽 투자만 계속 선택된다면 가격·공급·투자 회수 시점을 먼저 확인한다.[R1 §7]

**완료 조건:** 자원이 모이는 즉시 항상 같은 구매만 하는지, 현재 호텔의 필요에 따라 투자 우선순위가 달라지는지 관찰할 수 있다.

**시연 반영:** 손님별 수입은 **8·0·16·24·32**, 총 80이었다. 손님당 고정 수입을 보장 예산으로 삼지 않고, 각 경영 단계에서 실제로 쓸 수 있었던 돈·구매 후보·포기한 투자를 기록한다. 최종 잔액 66에는 이후 구매 단계가 없는 마지막 수입 32가 포함되므로, 잔액만으로 경제가 지나치게 느슨하다고 판단하지 않는다.[R9 §12.2]

### 4.7 보스와 파괴 후 재설계

**목적:** 구축한 엔진을 위기 속에서 운용하고, 남은 자산으로 다음 구성을 만들게 한다.

필요한 기능:

- 보스 목표 공포, 턴 제한, 공격 예고, 타일 내구도를 확인한다.
- 선택 가능한 이동과 마나를 비교하고, 이번 공격·회복 후의 내구도와 공포 목표까지 남은 양을 함께 읽는다.
- 직원 카드로 이번 수확을 강화하거나 살아 있는 타일을 회복한다.
- 파괴된 타일과 남은 생산 경로를 구분한다.
- 승리·패배·포기와 그 이유를 명확히 확인한다.
- 격퇴 후 남은 자산, 빈 슬롯, 새 모집 후보를 함께 본다.
- 새로운 괴이를 확보하고 호텔을 재배치한 뒤 일반 영업을 다시 한다.

재설계는 이전 호텔을 그대로 복구하는 것만 요구하지 않는다. 같은 스타일을 유지하면서 재료·순서·상태 연결을 바꿔도 의미 있는 재설계다.[R1 §8.6, R2 §24, R6]

**재영업 가능 조건:** 새 손님은 상태가 0에서 시작하므로 수확 타일만 남아 있다고 생산이 보장되지는 않는다. 기본 시설의 구매 경로와 격퇴 보상을 정할 때, 원래 직원을 다시 뽑지 못하더라도 적어도 한 가지 공포 생산 경로를 마련할 자산·구매 여력이 남는지 확인한다. 특정 괴이를 자동 복원하지 않으면서도 재영업 자체가 막히지 않아야 한다.

**완료 조건:** 파괴 후 다른 연결을 찾아 다시 운영하고 싶은 이유가 생긴다. 원래 재료만 나올 때까지 기다리거나, 잃은 것을 채우는 반복 작업으로만 느낀다면 공급·대체 관계·손실량을 점검한다.

**시연 반영:** 보스 2턴에 내구도 2인 고해실을 4까지 회복한 뒤 같은 타일이 피해 2를 받아 살아남았다. 회복의 실질적 용도는 확인했지만, 보스가 3턴에 끝나 파괴 후 재설계는 경험하지 않았다. **수확·회복·손실의 선택이 성립하는지**와 **실제 손실 뒤 재영업을 하고 싶은지**를 별도 검증 항목으로 둔다. 회복이 승리 자체를 가능하게 했다고까지 해석하지 않는다.[R9 §12.3]

### 4.8 표현과 기본 편의

**목적:** 적은 아트 자산으로도 카드의 법칙과 호텔의 변화를 읽을 수 있게 한다.

필요한 기능:

- 2D 카드가 놓인 단일 테이블 화면과 고정 시점을 제공한다.
- 카드의 선택·이동·도착·파괴를 짧게 표현한다.
- 조명, 그림자, 작은 시점 움직임으로 입체감을 준다.
- 이동 방향, 도착 예정 위치, 효과 대상과 원인을 강조한다.
- 주사위 후보와 확정한 하나를 구분하고, 후보별 도착·마나를 손패와 함께 읽을 수 있게 한다.
- 서로 다른 눈도 모두 퇴장으로 이어지는 경우처럼 실질적으로 결과가 같은 상황을 쉽게 확인한다.
- 카드 상세 보기, 상태 설명, 보스 종료 이유를 확인한다.
- 첫 영업에 필요한 짧은 안내, 처리 속도 조절, 음량 조절, 재시작을 제공한다.
- 경영 구간에서 저장하고 이어할 수 있게 한다. 전투 도중 저장은 후순위다.

괴이마다 긴 영상이나 고유한 전신 애니메이션은 필요하지 않다. 직원의 행동이 괴이의 사건 안에서 이어진다는 최소 표현은 첫 검증부터 필요하다. 단순한 숫자 팝업만으로 모든 괴이를 표현하면 인과적 융합의 전달을 평가하기 어렵다.[R3 §2·§4·§5·§7]

**완료 조건:** 처음 접한 사람이 진행자의 지속적인 설명 없이 한 판을 진행하고, 결과가 발생한 이유를 확인할 수 있다.

**시연 반영:** 전체 20턴 중 5턴은 모든 주사위 후보가 퇴장으로 이어졌다. 이때 선택 확인과 효과 진행이 불필요하게 길어지는지 관찰하고, 정보 표시·처리 속도로 부담을 줄인다. 이 결과만으로 자동 선택·재굴림·선택 단계 생략 규칙을 추가하지 않는다. 나머지 15턴 모두가 의미 있었다는 뜻도 아니다.[R9 §12.2]

## 5. 콘텐츠를 만드는 순서

### 5.1 첫 판단용 묶음

**직원 3종, 서로 다른 조합 3쌍, 조합마다 후보 3종, 총 괴이 9종**을 준비한다. 상태는 2종부터 시작해도 된다. 최종 목표인 직원 5종·괴이 30종을 줄인다는 뜻은 아니다.

직원 3종을 사용하면 같은 직원이 다른 상대와 융합하는 차이를 보여 줄 수 있다. 한 조합의 후보 3종만 제공하는 것보다 다음 조합에 대한 호기심을 행동으로 확인하기 쉽다.

첫 묶음에 필요한 조건:

- 두 직원의 행동을 융합 전에 실제로 사용해 볼 수 있다.
- 후보 셋이 현재 호텔에서 서로 다른 활용 이유를 가진다.
- 얻은 괴이를 배치하고 손님에게 작동시킬 수 있다.
- 다른 직원이나 시설로 입력을 마련할 수 있다.
- 남은 직원이나 새로 제공되는 직원으로 다음 조합을 살펴볼 수 있다.

첫 장면에서는 모집 경제·보스·긴 진행을 모두 갖출 필요는 없다. 해당 장면에서 제공한 직원과 자원, 제외한 시스템을 밝혀 해석한다.

**현재 시연과의 구분:** 설정 8의 임시 3쌍은 접객원+녹음기사, 교환원+기록원, 봉합사+접객원으로 **직원 5종에 걸친 구성**이다. 위의 직원 3종·3쌍 첫 묶음과 같지 않으며, 실제 획득·배치한 괴이는 4종이다. 임시 후보 9종이 모두 검증되었다고 표시하지 않는다. 이 소재는 다음 통합 관찰에 재사용할 수 있으나, 첫 관계 이해 검증은 재료 직원의 행동을 직접 경험하는 데서 시작한다.[R9 §12.1]

### 5.2 완주에 필요한 연결을 추가한다

첫 묶음의 반응을 확인한 뒤 직원 5종, 모집, 경영, 일반 영업, 보스 1종, 재설계를 연결한다. 이 단계에서 필요한 대체 경로가 부족하면 해당 조합부터 추가한다.

설정 8은 이 연결을 **텍스트로 완주한 선행 시연**으로 활용한다. 실제 기능·표현을 갖춘 결과물과 인간 관찰은 별도로 필요하다. 이번에 카드로 한 번도 사용하지 않은 녹음기사·교환원의 행동과, 선택하지 않은 후보의 활용 관계도 확인해야 한다.[R9 §12.1]

괴이 수는 9종에서 필요한 만큼 늘리되, 모든 30종의 최종 표현을 끝내는 것보다 다음 두 장면을 우선한다.

1. 주사위 후보와 유료 카드 사용으로 자신의 호텔에서 수확 기회를 만드는 장면.
2. 일부 자산을 실제로 잃은 뒤 다른 연결로 다시 영업하는 장면. 이번 설정 8 시연에서는 미경험이다.

### 5.3 전체 10쌍과 30종을 채운다

최종 조합은 직원 A~E의 서로 다른 쌍인 **AB, AC, AD, AE, BC, BD, BE, CD, CE, DE**다. 각 쌍에 서로 다른 후보 3종을 배정한다. A~E는 수량을 설명하기 위한 표기이며 직원 이름을 확정한 것이 아니다.

각 후보는 다음 내용을 갖춰야 한다.

- 재료 직원 두 명의 핵심 행동.
- 그 행동이 어떤 관계로 바뀌었는지를 설명하는 한 문장.
- 괴이가 손님에게 일으키는 구체적인 사건.
- 입력 상태, 통과·도착 효과, 출력과 위험.
- 현재 호텔에서 이 후보를 고를 이유와 포기할 이유.
- 재료 직원이 소모된 뒤에도 사용할 수 있는 입력 공급 경로.
- 얻었을 때 달라질 배치·직원 카드 사용·상태 소비 중 적어도 한 가지.

모든 후보를 똑같이 공급형·수확형·안전형으로 나눌 필요는 없다. 같은 조합의 후보들이 수치만 다른 상위·하위 버전이 되지 않는지가 중요하다. 새로운 괴이마다 별도 자원이나 새로운 플레이 단계를 늘리지 않는다.[R1 §3.4·§6.3·§10.6, R2 §4~§14]

## 6. 단계별 제작 계획

주차보다 아래의 **사용 가능한 기능과 판단 기준**을 다음 단계 진입 조건으로 사용한다. 실제 작업 속도는 첫 묶음을 완성한 뒤 확인하고, 아직 제작·검증되지 않은 콘텐츠를 일정상 완료로 처리하지 않는다.

| 단계 | 있어야 하는 기능과 결과 | 완료 조건 | 다음 단계로 갈 판단 |
|---|---|---|---|
| 1. 최소 규칙 정리 | 한 판 범위, K개 중 하나 선택, 유료 카드, 직원 공급, 상태·보스·손실 처리 | 정식 규칙과 적용 config를 구분하고 진행·종료를 모호함 없이 설명 | 텍스트 완주 결과와 실제 기능 확인을 구분함 |
| 2. 융합 첫 경험 | 직원 3종, 3쌍·9종, 후보 비교, 작은 호텔, 주사위 선택과 작동 표현 | 직원 사용 → 융합 → 배치 → 영업을 경험 가능 | 같은 사람에게 자기 설명과 다음 조합 탐색이 함께 나타남 |
| 3. 경영과 일반 영업 | 직원 5종, 제한된 모집, 덱 편성, 후보별 경로·도착·마나, 선택 후 유료 카드, 공통 자원 투자 | 융합 이후에도 모집과 영업을 반복하고 선택·미사용 이유를 읽을 수 있음 | 괴이 때문에 배치·주사위·카드·투자가 달라지고 조작 부담이 수용됨 |
| 4. 보스와 재설계 | 보스 1종, 공격·내구도 비교, 파괴·종료, 남은 자산 활용, 재영업 | 완주 가능 여부와 실제 부분 손실 뒤 재영업 가능 여부를 각각 확인 | 손실을 경험한 사람이 다른 구성을 다시 운영하려 함. 무손실 사례는 이 판단에서 구분 |
| 5. 최종 콘텐츠 확장 | 10쌍·괴이 30종, 상태 4종 중심, 공통 테이블 표현 | 모든 조합에서 후보 3종을 비교·획득·사용 가능 | 목록 증가가 새로운 선택과 연결로 이어짐 |
| 6. 처음 접하는 플레이어의 완주 | 안내, 정보 표시, 속도 조절, 결과 확인, 저장·이어하기 | 진행자의 지속 도움 없이 짧은 한 판 진행 | 핵심 이해·호기심과 루프 경험이 새 참가자에게도 반복됨 |

**단계 2에서 핵심 반응이 없으면 단계 5의 콘텐츠 확대를 진행하지 않는다.** 직원 행동, 융합 법칙, 후보의 차이, 작동 표현 중 원인이 의심되는 부분을 고치고 다시 본다.

**단계 4에서 재설계가 막히면 보스 2종째를 추가하지 않는다.** 대체 조합, 직원 공급, 남는 자산, 손실량부터 점검한다.

### 6.1 현재 시험값과 다음 조정 대상

최초 수치가 없는 상태는 지났다. 다음 통합 관찰은 **설정 8의 값**에서 시작하며, 전체 운영 전제는 해당 config를 따른다. 아래 값은 시험을 재현하기 위한 것이며 정식 수치 확정이나 균형 검증 완료를 뜻하지 않는다. 특히 **X·K와 카드별 비용의 최종값은 계속 미정**이다.[R1 §4.4, R8]

| 항목 | 설정 8의 현재 시험값 | 다음에 확인할 문제 |
|---|---|---|
| 호텔 | 시작 6칸, 확장 +2칸, 시험 상한 12칸 | 수확실 간 거리·빈 슬롯·공급 경로가 선택을 바꾸는가 |
| 주사위 | **X=6, K=3**, 그중 하나 선택 | 좋은 도착과 마나 사이의 판단, 결과가 같은 후보의 비중 |
| 손패·카드 | 턴 시작 2장 드로우, 직원 5종 모두 비용 2 | 비용 부족과 입력·대상·손패 부족을 구분할 수 있는가 |
| 일반 손님 | 부담 한계 12, 덱 소진 부담 +2, 사망 시 의심도 +1, 의심도 3에 종료 | 작은 눈으로 체류할 때 수확과 소진 위험이 함께 생기는가 |
| 상태 | 상한 9, 자연 감소 없음. 최대 n개 소비는 보유량 내에서, 정확히 n개 요구는 부족 시 불발 | 공급·참조·소비·변환과 다음 수확에 남는 입력을 이해하는가 |
| 경제 | 시작 16, 직원 4, 시설 6, 확장 순서대로 8·12·16, 보스 보상 20 | 매 경영 단계에서 서로 경쟁하는 투자가 실제로 남는가 |
| 모집 | 단계별 서로 다른 3종의 후보, 최대 2명 모집 | 다음 조합에 필요한 종류와 구매 여력을 함께 얻는가 |
| 보스 목표·공격 | 목표 공포 24, 최대 8턴, 기본 피해 2·소진 턴 3, 도착 슬롯 공격 | 빠른 격퇴·회복·공격 회피가 위협과 손실 경험을 어떻게 바꾸는가 |
| 내구·회복 | 타일 내구 4, 회복 +2, 생존 타일은 전투 후 4로 회복 | 회복이 실제 손실을 막는가, 부분 손실 뒤 대체 연결이 가능한가 |

‘서로 다른 모집 후보’와 ‘도착 슬롯 공격’은 설정 8의 운영 전제이며, rules.md의 해당 미정 규칙을 이 문서로 정식 확정하지 않는다. 개별 직원·괴이의 능력은 별도 콘텐츠 명세가 필요하다. 조정할 때에는 원인이 확인된 값부터 바꾸고, X·K·카드 비용·보스 피해 등을 한꺼번에 바꾸어 결과를 해석하지 않는다.

### 6.2 이번 시연 다음의 검증 순서

| 순서 | 우선 갖출 기능·장면 | 볼 것 | 결과에 따른 다음 행동 |
|---|---|---|---|
| 1. 선택을 읽는 짧은 영업 | 후보별 경로·도착·마나, 손패 비용, 상태·불발 이유 | 좋은 도착을 위해 마나를 포기한 이유와 카드 미사용 이유를 설명하는가 | 읽지 못하면 정보 전달부터 보완. 이해해도 늘 같은 답이면 배치·입력·비용의 차이를 점검 |
| 2. 융합의 이해와 다른 후보 | 직원 행동 경험, 같은 조합의 다른 후보, 획득 전후 배치 | 참조로 상태를 남기거나 변환으로 다음 입력을 만드는 법칙을 설명하고 다음 조합을 찾는가 | 핵심 반응이 없으면 후보 법칙·직원 기여·표현을 수정. 전체 30종 확대는 보류 |

| 5. 콘텐츠 확장 | 검증을 통과한 관계를 바탕으로 나머지 조합·후보 추가 | 늘어난 후보가 새로운 활용을 만드는가 | 첫 경험 참가자에게 핵심 반응이 반복된 범위에서 10쌍·30종으로 확대 |

이 순서는 **필요한 기능과 관찰의 우선순위**이며 구현 절차가 아니다. 설정 8의 시연만으로 어느 단계도 제작 완료 또는 인간 검증 완료로 표시하지 않는다.

## 7. 플레이 판단 방법

### 7.1 첫 테스트의 진행

기존 프로토타입 계획처럼 소수의 첫 경험 참가자부터 시작한다. **처음에는 4~6명 정도를 문제 발견용으로 모집**하고, 수정 후에는 새 참가자에게 같은 경험이 나타나는지 확인한다. 이는 시장성을 입증하는 표본 규모가 아니다.[R4 §4~§7]

진행 순서:

1. 직원의 행동을 직접 사용하게 한다.
2. 두 직원을 고르고 후보 3종 중 하나를 선택하게 한다.
3. 호텔에 배치하고 주사위 후보 비교·선택과 유료 카드 사용을 거쳐 실제 작동을 보게 한다.
4. “방금 무엇이 달라졌나요?”처럼 자유롭게 설명할 기회를 준다.
5. 다음 행동을 자유롭게 선택하게 하고 다른 조합을 찾아보는지 관찰한다.
6. 이후에 선택 이유와 좋았거나 불편했던 장면을 묻는다.

다음 조합을 시험할 직원·자원 또는 검증용 새 시작 기회를 제공해야 한다. 궁금하지만 재료가 없어 행동하지 못한 경우를 흥미 부족으로 분류하지 않는다.

### 7.2 설명과 호기심을 구분해 기록한다

| 관찰 | 해석 |
|---|---|
| “둘이 합쳐져서 더 세졌어요” | 관계 이해의 근거가 아직 부족함 |
| 두 직원의 원래 행동을 각각 설명함 | 재료는 이해했지만 새 관계의 이해는 추가 확인 필요 |
| 무엇이 무엇의 입력으로 바뀌었고 어디에 쓰는지 설명함 | 융합의 법칙과 호텔 활용이 연결됨 |
| 다른 직원이나 조합을 스스로 살펴봄 | 다음 조합에 대한 행동 근거가 있음 |
| 다음 융합을 위해 특정 직원을 보존·모집함 | 호기심이 경영의 선택으로 이어짐 |
| “다른 것도 궁금하죠?”에 긍정적으로 답함 | 유도된 응답이므로 자발적 행동과 분리 |

정확한 결과를 사전에 맞히는 능력을 요구하지 않는다. 결과를 경험한 뒤 관계를 납득하고 설명하는지를 본다.[R2 §23]

### 7.3 확장 판단

**진행:** 서로 다른 첫 경험 참가자에게서 자기 설명과 자발적인 다음 조합 탐색이 함께 반복되고, 현재 호텔에 후보를 선택한 이유도 확인된다. 다음 단계의 소규모 제작으로 진행한다.

**보완:** 이해·호기심·실제 활용 중 일부만 나타난다. 아래 원인표에 따라 먼저 한 가지를 고치고 다시 본다.

**유보:** 진행자의 설명을 많이 들었거나, 재료 부족·조작 문제·시간 부족으로 판단할 경험을 하지 못했다. 부족했던 장면을 보완한 뒤 다시 평가한다.

표본이 작을 때 단 한 사람의 강한 반응이나 평균 재미 점수 하나로 투자 결정을 내리지 않는다. 설명·행동·막힌 이유를 함께 보고, 수정 후 새 참가자에게 반복되는지도 확인한다.

### 7.4 네 가지 후속 가설의 관찰

| 가설 | 관찰할 장면 | 성공으로 대신 세지 않을 것 |
|---|---|---|
| 후보 선택 | 서로 다른 호텔 필요에 따라 후보 선택과 이유가 달라짐 | 후보별 선택률이 정확히 3분의 1임 |
| 배치 변화 | 획득 전후의 입력·수확 순서와 자산 역할이 바뀜 | 재배치 클릭 횟수가 많음 |
| 주사위 선택·카드 개입 | 후보별 도착·마나를 비교하고, 선택 뒤 카드의 대상·순서·사용 여부와 포기한 대안을 설명함 | 큰 눈이나 작은 눈을 자주 고름, 매 턴 카드를 최대한 많이 사용함 |
| 재설계 동기 | 손실 뒤 대체 연결을 만들고 재영업을 선택함 | 이전 스타일을 완전히 버림 |

카드 개입·재설계의 의미를 설명하더라도 재미있다고 느끼는지는 별도로 묻는다. 능숙한 플레이만으로 즐거움을 추정하지 않는다.

카드를 쓰지 않은 턴도 확인한다. **빈손이어도 타일을 활용할 이동 선택이 있었는지**, 여러 눈이 모두 퇴장·동일 결과여서 실제로 고를 이유가 없었는지를 구분한다. 장면별 선택 이유와 별도로 선택 화면이 번거로웠는지 묻는다.[R8 §9, R9 §12.3]

### 7.5 기록할 최소 내용

- 어떤 직원·조합·괴이를 경험했는가.
- 융합 결과를 자신의 말로 어떻게 설명했는가.
- 후보를 선택한 이유와 포기한 후보의 장단점은 무엇인가.
- 다음에 무엇을 자발적으로 살펴보거나 시도했는가.
- 괴이 획득 후 배치·카드·투자가 어떻게 달라졌는가.
- 매 턴 어떤 K개의 눈이 나왔고 무엇을 선택했으며, 다른 후보의 어떤 이점을 포기했는가.
- 선택 당시 위치·손패·상태·손상, 후보별 도착·마나·해당 시험의 공격 정보는 무엇이었는가.
- 카드 사용·순서·대상과 미사용 이유는 무엇이며, 실제 수확 또는 손실 방지로 이어졌는가.
- 손님별 체류 턴·실제 수확 횟수·수익, 카드 사용 횟수·카드를 쓴 턴 수, 같은 결과인 후보 묶음은 얼마인가.
- 각 경영 단계에서 실제 쓸 수 있는 자금, 구입한 자산과 포기한 투자는 무엇인가.
- 부분 파괴 후 무엇을 남기고 무엇을 새로 만들었는가.
- 진행자의 도움, 경험하지 못한 항목, 중단 이유는 무엇인가.

초기에는 관찰자가 기록해도 된다. 게임 안에 설문·통계 관리 기능까지 만드는 것은 MVP 필수 범위가 아니다.

수입·카드·수확은 한 판 총량과 턴당 값을 함께 본다. **카드 사용 횟수와 카드를 사용한 턴 수는 다르다.** 실제 소요 시간과 선택에 걸린 시간은 사람이 플레이할 때 기록하며, 텍스트의 턴 수로 대신하지 않는다. 설정 1·7·8의 기존 시연은 난수·선택·모집·배치가 달라 통제 비교가 아니고, 특히 설정 7과는 카드 비용도 다르다. 이번 결과를 주사위 선택만의 개선 효과나 적정 X·K의 증명으로 해석하지 않는다.[R8 §9.3, R9]

## 8. 결과에 따른 수정 방향

| 관찰 결과 | 먼저 확인할 문제 | 다음 제작에서 바꿀 것 |
|---|---|---|

## 9. 1인 개발을 위한 범위 관리

### 9.1 일정이 늘어날 때 먼저 미룰 것

1. 보스 2종째와 상태 5종째.
2. 괴이별 긴 융합 영상과 고유한 장시간 애니메이션.
3. 카메라 움직임의 종류, 테이블 주변 장식, 방 단위 배경.
4. 추가 손님 유형, 희귀도, 이벤트, 장기 메타 성장.
5. 복제·소환·임시 타일·대리 도착 등 별도 규칙이 필요한 능력.
6. 전체 도감, 업적, 게임 안 설문·통계 화면.

### 9.2 끝까지 남길 것

- 조합별 고정 후보 세 가지를 이해하고 비교하는 기능.
- 직원 소모와 모집, 직원 카드 활용의 기회비용.
- 괴이 획득 후 실제 배치·운용을 바꾸는 기능.
- 주사위 후보의 경로·도착·마나 비교, 하나 선택·확정 후 비용을 지불하는 카드 사용.
- 보스의 종료 이유와 실제 자산 손실.
- 남은 자산으로 재설계하고 다시 영업하는 구간.
- 융합 결과를 설명하고 다음 행동을 선택할 기회.
- 통과·도착·상태 변화·발동 실패의 원인을 읽는 정보.

최종 30종을 만들기 전에 검증을 중단하는 것은 가능하다. 다만 그 결과는 **첫 검증용 빌드**로 기록하고, 30종 MVP가 완성되었다고 표현하지 않는다.

### 9.3 풀 3D 전환은 별도 판단으로 남긴다

현재 MVP에서 확인하는 것은 2D 카드와 간단한 테이블에서도 융합·배치·재설계가 매력적으로 느껴지는지다. 이 반응이 좋으면 다음 콘텐츠 제작의 근거가 생긴다.

풀 3D 공간으로의 전환은 별도의 시각 시안을 통해 분위기, 판독성, 제작 부담을 비교한 뒤 결정한다. 이번 MVP의 긍정 반응만으로 풀 3D 제작을 자동으로 시작하지 않는다.

## 12. 설정 8 텍스트 시연 기록

### 12.1 조건과 실제 경험한 콘텐츠

`mvp-config-8.md`를 적용해 시작 자산부터 초기화한 **텍스트 시연 1회**다. 주사위는 공정한 1d6 세 개 중 하나 선택, 직원 카드 비용은 모두 2였다. 매 턴 현재 후보를 공개한 뒤 선택하고 카드를 사용했으며, 다음 턴의 눈을 미리 보고 배치·구매를 정하거나 유리한 결과를 위해 다시 굴리지 않았다. 시연에 쓰인 임시 능력은 최종 콘텐츠의 확정 명세가 아니다.

| 임시 직원 | 시연에서 사용한 능력 명세 | 실제 카드 사용 |
|---|---|---:|
| 접객원 S | 현재 방문자에게 A 상태 +2 | 4회 |
| 녹음기사 R | 현재 방문자에게 B 상태 +2 | 0회 |
| 기록원 K | 지정 타일의 이번 이동 첫 유효 수확에 공포 +4 | 3회 |
| 봉합사 H | 일반 손님 부담 −2 또는 살아 있는 타일 내구 +2, 최대 4 | 1회. 보스 타일 회복에 사용 |
| 교환원 C | A 최대 2개를 B로 1:1 변환 | 0회 |

융합은 **접객원+녹음기사, 교환원+기록원, 봉합사+접객원**의 세 조합에서 총 4회 진행했다. 접객원+녹음기사를 다시 융합하면서 다른 후보를 선택했다. 세 조합의 고정 후보 9종은 임시 정의했지만, 실제 획득·배치한 괴이는 **대답하는 벽, 반송되는 고해실, 봉합된 비상구, 금지된 안내방송의 4종**이다. 실제 누적·활용한 상태는 A·B 두 종류다.

따라서 이번 기록은 직원 5종의 모든 카드 행동, 후보 9종 전체, 최종 괴이 30종, 상태 4종의 검증 완료를 뜻하지 않는다. 특히 녹음기사·교환원은 융합 재료로 사용했어도 카드 행동을 실제로 발동하지 않았다.

### 12.5 해석의 범위

이번 시연은 **정해진 임시 콘텐츠와 선택 경로에서 한 판이 완주되고, 설명할 수 있는 선택 장면이 생겼다는 근거**다. 사용자의 별도 채택으로 주사위 선택 방식은 정식 규칙이 되었지만, 그 사실이 재미 검증을 대신하지 않는다.

실제 참가자의 융합 이해·다음 조합에 대한 호기심, 선택의 재미와 피로, 실제 플레이 시간, 보스 위협의 적정성, 부분 손실 뒤 재설계 동기, 장기 균형·리플레이성·상업성은 이 기록으로 판정하지 않는다. 특히 다른 설정의 한 판과 수익을 비교해 개선율이나 인과 효과를 계산하지 않는다. 다음 투자 판단은 §1.1과 §7의 사람에 대한 관찰을 따른다.
