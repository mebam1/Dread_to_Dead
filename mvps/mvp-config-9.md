> **진행 상태:** 텍스트 시연 준비용 명세 / 이 설정으로 진행한 시연 없음  
> **기준:** `rules.md` v0.9, `ability_checklist.md` v0.2, `mvp-1.md`의 2026-10-30 개정본, `mvp-config-8.md` 문서 v0.1

이 파일은 다음 텍스트 게임에서 사용할 **하나의 완결된 시험 설정안**이다. 직원 5종, 이종 조합 10쌍, 조합별 고정 후보 3종씩 총 30종의 이름·행동·수치를 여기에 고정한다. 진행 도중 유리한 후보를 즉석에서 추가하거나, 이미 공개한 능력을 바꾸지 않는다. 실제로 획득하는 괴이는 융합 한 번당 선택한 1개다.

기존 기록에서 재사용하는 직원 이름은 **접객원·녹음기사·기록원·봉합사·교환원**이다. 괴이 이름 중 **대답하는 벽·금지된 안내방송·반송되는 고해실·봉합된 비상구**도 재사용하지만, **정확한 효과는 본 문서의 새 명세를 따른다.** 예전 시연의 성능을 그대로 계승했다고 보지 않는다. 나머지 후보 이름과 능력은 이번에 작성한 제안이며, 기존 문서에 이미 완성된 30종 목록이 있었다고 주장하지 않는다.

직전 논의에서 제시된 **33장 드로우 중 카드 사용 8회**는 변경의 계기다. 자동 타일과의 역할 중복, 이동 전 즉시 처리, 수확 상한 등을 원인 후보로 본다. 이 관찰만으로 원인을 입증했거나 새 방식이 해결했다고 판단하지 않는다. 설정 9는 직원 발동 방식뿐 아니라 콘텐츠·보스 목표도 달라지므로, 설정 8과의 단순 결과 차이는 단일 변경의 인과 효과가 아니다.

## 1. 이번 텍스트 MVP의 범위

| 항목 | 적용 범위 |
|---|---|
| 팩션 | 단일 호텔 교단 1개. 별도의 팩션 선택·상성·해금 없음 |
| 직원 | 5종. 시작에는 각 1명, 모집으로 같은 종류의 다른 개체 추가 가능 |
| 융합 | 서로 다른 종류의 모든 쌍 10개. 각 쌍 고정 후보 3종, 총 30종 |
| 시설 | 기본 시설 4종 |
| 상태 | 불안·환청·기시감·봉인 4종 |
| 방문자 | 일반 투숙객 1종, 보스 ‘호텔 감찰관’ 1종. 명칭은 임시 |
| 한 판 | 시작 경영 → 일반 손님 3명 → 보스 1회 → 격퇴 후 재설계 → 일반 손님 2명 → 완주 |
| 이번에 제외 | 동종 융합, 추가 팩션·보스, 메타 성장, 판매·환불, 직원·타일 복제, 독립 소환물, 별도 임시 타일, 추가 이동·재굴림·이동 중 카드 사용 |

30종은 **후보 목록의 크기**이지 한 판에 모두 만들거나 시험해야 한다는 뜻이 아니다. 어느 한 판에서 경험하지 않은 직원 행동·괴이·부분 손실은 미경험으로 남긴다. 첫 관계 이해를 별도로 볼 때의 3종·3쌍·9종 실험과, 이 파일의 5종·10쌍·30종 통합 설정을 구분한다.

## 2. 주사위·덱·턴·직원 효과

### 2.1 고정할 시험값

| 항목 | 이번 값 |
|---|---|
| 주사위 X / K | **6 / 3**. 서로 독립적인 공정한 1d6 세 개 중 정확히 하나 선택 |
| 결과 적용 | 선택한 눈 r만 이동 r칸과 마나 r에 함께 적용. 합산·분리 선택·미선택 눈 보관 없음 |
| 중복 눈 | 허용. 2·2·5도 그대로 제시, 중복을 이유로 재굴림하지 않음 |
| 선택 변경 | 주사위 선택 확정 후 교체 불가. 카드를 사용한 뒤 다른 눈으로 바꾸지 않음 |
| 직원 카드 비용 | **5종 모두 2마나** |
| 기본 드로우 | 턴 시작 2장. 추가 드로우·마나 증감 없음 |
| 덱 편성 | 보유 직원 중 0~20장. 보유 개체당 카드 1장, 같은 종류의 다른 개체는 각각 편성 가능 |
| 덱 잠금 | 일반 영업·보스전 시작 전 편성 가능, 진행 중 변경 불가 |
| 손패·마나 | 남은 손패는 턴말 버림, 마나는 이월하지 않음 |
| 시작 초기화 | 방문자마다 편성 덱 전체 셔플. 손패·마나·방문자 상태 초기화 |

선택한 눈 1이면 카드를 사용할 마나가 없고, 2~3이면 한 장, 4~6이면 기본 손패 두 장의 비용을 낼 수 있다. **턴당 두 장 제한을 추가한 것은 아니다.** 이 설정에 추가 드로우가 없어서 생기는 실제 손패 한계다.

### 2.2 한 턴의 순서

1. **드로우·소진:** 2장을 뽑는다. 빈 덱에서 더 뽑으려 할 때 소진 페널티 → 버림 더미 셔플 → 이번 드로우 중단. 손님이 사망하면 이후 절차를 진행하지 않는다.
2. **굴림:** 1d6 세 개를 동시에 굴려 현재 결과와 손패를 공개한다. 아직 직원 카드는 사용하지 않는다.
3. **선택:** 후보별 경로·도착·획득 마나를 확인하고 한 눈을 확정한다. 보스전은 후보별 공격 슬롯·피해도 함께 제시한다.
4. **직원 효과 부여:** 사용 카드마다 2마나를 지불하고 슬롯 하나를 고른다. 필요한 카드별 선택도 이때 확정한다. 카드를 쓰지 않고 이동할 수도 있다.
5. **이동·발동:** 선택한 거리만큼 이동하며 실제로 방문한 칸의 통과 효과와 최종 도착 효과를 처리한다. 종료 조건이 발생하면 중단한다.
6. **보스 공격:** 보스 목표 미달일 때만 예고한 공격을 실행한다. 일반 손님에게는 이 단계가 없다.
7. **턴 종료:** 모든 직원 부착 효과를 제거하고 남은 손패를 버린 뒤 마나를 제거한다. 보스의 8턴째에는 공격 후 목표 미달이면 시간 초과로 종료한다.

**[확정 규칙]** 카드 사용은 효과를 부여하는 행동이지 즉시 공급·수확·회복하는 행동이 아니다. 현재 서 있는 칸에 붙여도 그 사실만으로 통과·도착하지 않는다. 이동 중 추가 카드 사용이나 대상 변경은 없다.

### 2.3 같은 칸의 처리 순서 — MVP 운영안

**시설·괴이 통과 → 직원 통과 → 시설·괴이 도착 → 직원 도착.** 도착 두 단계는 실제로 이번 이동이 끝나는 칸에서만 처리한다. 같은 단계의 직원 효과는 카드 사용 순서대로 처리한다. 중간 칸은 통과 두 단계만 처리한다.

빈칸은 시설·괴이 단계가 없을 뿐 직원 효과는 작동한다. 부착 효과는 독립 자산이 아니며, 내구도나 별도 보스 공격 대상이 생기지 않는다. 시설·괴이를 이동·교체하는 것도 아니다.

카드에 통과 효과만 있다면 도착 효과가 추가되지 않는다. 플레이어가 카드의 통과형·도착형을 마음대로 바꾸지 않는다.

### 2.4 사용 가능·중첩·불발 — 설정 9의 명시적 운영안

| 항목 | 판정 |
|---|---|
| 부여 조건 | 해당 카드가 손패에 있고 마나가 충분하며 현재 루프의 슬롯 1~N 중 하나를 지정함. 기록원의 참조 상태 등 카드별 선택도 유효해야 함 |
| 입력 판정 | **실제 발동 시점**의 상태·내구도·부담을 사용. 사용 시점에 입력 0이어도 이후 공급을 기대해 부여 가능 |
| 방문하지 않는 칸 | 부여는 가능하지만 발동하지 않음. 현재 공개된 이동으로 불발이 확실하면 그 이유를 안내 |
| 회복 대상 | 실제 발동 때 살아 있는 타일·손님에게만 작용. 보스에게 붙인 봉합사의 회복 대상은 부착한 칸의 살아 있는 시설·괴이 |
| 변화가 없는 효과 | 최대 내구도·부담 0·상태 부족·빈 회복 대상이면 해당 작용은 0. 예측 가능한 경우 경고하되 자동으로 유용한 대상으로 옮기지 않음 |
| 동일 종류 중첩 | **다른 카드 개체라면 같은 칸에도 함께 부여 가능.** 사용 순서대로 각각 발동. 상태·내구도 상한은 계속 적용 |
| 카드 버림 | 부여를 확정하고 비용을 낸 직후 카드를 버림 더미로 보냄. 부착 효과는 별도로 턴말까지 유지 |
| 비용 환급 | 확정 전 잘못된 마나·슬롯 선택은 소모 없이 수정. **확정 뒤의 불발·미방문·중도 종료에는 환급 없음** |
| 보유 직원 | 사용·버림·부착 만료로 직원 풀에서 제거하지 않음. 영구 소모는 융합에서만 발생 |

이는 config 8의 ‘현재 유효 변화가 없으면 사용 불가’ 판정을 그대로 적용하지 않는다는 뜻이다. 현재 입력이 0인 카드와 이동 중에도 끝내 입력이 생기지 않는 카드를 구분해서 안내한다. 무의미한 사용도 가능하므로 **단순 사용 횟수 증가를 성공으로 보지 않는다.**

### 2.5 재통과와 효과 수명

**한 턴 안의 반복 발동 횟수는 정식으로 미정인 상태를 유지한다.** 이 설정은 이동 최대 6칸, 루프 최소 6칸, 추가 이동 없음이므로 한 이동에서 같은 슬롯을 두 번 방문하지 않는다. 따라서 재통과 예외를 정하지 않아도 이번 시연은 판정할 수 있다. 보스가 현재 칸에서 정확히 한 바퀴를 돌면 그 칸을 끝에 한 번 방문하며, 출발 자체를 통과로 세지 않는다.

부착 효과는 보스 공격까지 처리한 뒤 턴말에 제거한다. ‘턴 동안 유지’가 ‘한 번 발동하면 즉시 제거’를 뜻하지 않는다. 이미 생성한 방문자 상태, 획득한 공포, 회복한 내구도는 부착 효과 제거로 되돌리지 않는다. 상태는 방문자 종료 시까지, 내구도는 실제 이후 피해·전투 후 정산까지 유지된다.

사망·퇴장·승리·패배·포기 때에는 남은 이동·발동·공격을 중단하고 임시 효과를 정리한다. 정리 자체가 발동 사건을 만들지는 않는다.

### 2.6 덱 소진

일반 손님은 소진 1회당 **심장 부담 +2**. 보스전은 부담 대신 **이번 턴 예고 공격 피해 +1**이다. 소진은 ‘덱의 마지막 카드를 뽑았다’가 아니라 **더 뽑으려는데 뽑을 덱이 비었다**는 사건이다.

버림 더미만 섞으며 현재 손패는 포함하지 않는다. 셔플 직후 부족한 드로우를 보충하지 않는다. 0장 덱·빈 버림 더미도 소진을 처리하고 이번 드로우를 끝낸 뒤 다음 단계로 넘어간다. 보스의 추가 피해는 다음 턴으로 누적하지 않는다.

### 3.4 공간과 공개 범위

한 슬롯에는 시설 또는 괴이 하나만 배치한다. 경영 중 보관·재배치는 무료, 영업·보스전 중 영구 자산의 배치 변경은 불가다. 직원 부착은 그 예외가 아니라 별도의 한 턴 효과다. 타일 파괴로 슬롯 수나 다른 슬롯의 번호는 줄지 않는다.

일반 손님은 입장 경계 0에서 슬롯 1로 들어가며, 슬롯 N 다음 한 칸이 출구다. **슬롯 N에 정확히 도착하면 아직 퇴장하지 않는다.** 다음 이동에서 출구를 넘는 즉시 남은 이동·도착 효과를 중단한다. 보스는 슬롯 N 다음에 바로 슬롯 1로 이동하며 출구용 칸을 추가하지 않는다.

**[MVP 운영안]** 후보의 이름·법칙·효과·위험은 모두 공개한다. 보유 쌍을 고르면 해당 3종을 비교하며, 확정 전 취소는 무료다. 미보유 쌍도 이 문서로 열람할 수 있으나 제작 가능 표시와 구분한다. 숨겨진 해금·희귀도·재료 순서 차이는 없다. 영업 전에 덱 구성은 확인할 수 있지만 셔플된 미래 드로우 순서·미래 주사위·다음 모집 후보는 공개하지 않는다.

## 4. 상태와 공통 효과 판정

### 4.1 상태 4종 — 콘텐츠 제안

| 상태 | 사건상의 뜻 | 기본적인 활용과 공급 경로 |
|---|---|---|
| **불안** | 아직 일어나지 않은 일을 예고받아 남은 걱정 | 접객원·안내판이 공급. 직접 수확, 환청·기시감·봉인으로 전환 |
| **환청** | 출처를 확인할 수 없는 목소리가 남음 | 녹음기사·라디오가 공급. 목소리 수확, 과거의 증거·봉합 재료로 전환 |
| **기시감** | 처음 겪는 일을 이미 겪었거나 기록된 것처럼 느낌 | 예고·목소리를 기록한 괴이 등이 공급. 남겨 두고 참조하거나 다른 상태의 재료로 사용 |
| **봉인** | 걱정·목소리·기억을 봉합해 잠시 가둔 흔적 | 봉합 관련 괴이가 공급. 안전한 수확, 다시 열기, 회복에 사용 |

각 상태는 방문자에게 귀속하는 **0~9의 비음수 정수**다. 상태 이름만으로 자연 피해·감소·보호·이동 제한이 생기지 않는다. 실제 기능은 카드와 타일 명세에만 있다. 특히 **봉인은 자동 보호막이 아니며, 기시감은 자동 반복 발동이 아니다.**

모든 상태는 자연 감소하지 않는다. 일반 손님 퇴장·사망 또는 보스전 종료 때 제거한다. 보스의 다음 회전과 같은 방문자의 다음 턴에는 유지한다. 공포·마나·부담·의심도·내구도는 이 네 상태와 별개다.

### 4.2 부분 소비·변환·조건

| 표기 | 판정 |
|---|---|
| 최대 n개 소비·제거 | 현재 보유량과 n 중 작은 양. 0이면 그 소비에 연동된 보상·위험도 0 |
| 정확히 1개 또는 2개 요구 | 요구량이 모두 있어야 함. 부족하면 입력을 전혀 소비하지 않고 해당 효과 불발 |
| 두 종류를 함께 요구 | 두 조건을 모두 만족해야 함. 한쪽만 소비하지 않음 |
| 참조 | 값을 읽을 뿐 줄이지 않음. 같은 상태를 후속 타일에서 다시 사용할 수 있음 |
| 직접 +n 부여 | 9를 넘는 부분만 버림. 다른 보너스 없음 |
| 1:1 변환 | 입력·처리 상한·출력 상태의 빈 용량 중 가능한 양만 소비·생성 |
| 1→2 변환 | 출력 두 개를 받을 공간이 있는 **완전한 묶음**만 처리. 공간 1이면 입력 1을 소비하지 않음 |
| 1→두 종류 각 1 | 두 출력에 각각 공간 1 이상 필요. 한쪽만 만들거나 먼저 입력을 버리지 않음 |
| 회복 | 일반 부담은 0 아래로 내리지 않음. 타일 내구는 4 초과 불가, 파괴된 타일 부활 불가 |
| 조건부 보상 | ‘실제로 변환·제거·회복한 양’은 해당 효과가 실제로 바꾼 양만 셈. 직원이나 다른 타일의 변화까지 합치지 않음 |

수확이 `공포 +값, 부담 +1`로 쓰여 있으면 **그 수확이 공포를 실제로 만들었을 때 한 번 +1**이다. 소비한 상태마다 +1이 아니다. 별도 부담 표기가 없으면 +0이며 공포 획득 자체가 부담을 자동 증가시키지 않는다. 보스에게 부담 증감은 적용하지 않는다.

### 4.3 처리의 원자 단위와 종료

각 표의 통과 효과와 도착 효과는 별도 사건이다. 효과 내부의 입력 조건을 먼저 판정하고, 소비·변환을 처리한 뒤 명시된 수확과 그 부담을 한 묶음으로 반영한다. 회복·상태 생성 뒤 수확한다고 적힌 복합 효과는 그 순서를 따른다. 각 효과가 끝날 때 즉시 사망·승리 여부를 확인하고, 종료되면 다음 직원·타일 효과를 진행하지 않는다.

부담 12에 도달한 손님을 이후 효과로 되살리지 않는다. 예를 들어 시설·괴이 도착 수확에서 사망하면 그 뒤의 직원 도착 효과는 발생하지 않는다. 통과 회복을 그 수확 전에 배치하는 것과 결과가 다르다.

일부 괴이의 `q`는 **그 칸의 이번 방문에서 자기 통과 효과가 실제로 바꾼 양**이다. 같은 방문이 그 칸에서 끝나면 도착 효과에 사용한다. 새로운 상태·화폐가 아니며 다음 턴이나 다음 방문으로 저장하지 않는다. 후속 직원 통과 효과가 바꾼 양을 앞선 타일의 q에 소급해 더하지 않는다.

| **K 기록원** | **기록·대조:** 지금 남은 징후를 기록으로 확인시킨다. 장부·대조 표시 | 없음 | **부착 때 지정한 상태 한 종류를 최대 2 참조 → 1개당 공포 2**, 소비 0·부담 0 | 수확실에 닿지 못한 빈칸에서도 남은 상태로 작은 수확. 영구 타일이 상태를 소비한 뒤에는 불발할 수 있음 |
| **H 봉합사** | **봉합:** 무너지는 몸이나 방을 꿰맨다. 바늘·봉합선 | 일반: **부담 −2**. 보스: **부착한 칸의 살아 있는 시설·괴이 내구 +2**, 최대 4 | 없음 | 위험한 수확 전에 회복하거나, 이번 경로 안의 공격 대상 타일을 보존 |
| **C 교환원** | **전환·중계:** 손님의 걱정을 내선의 목소리로 돌린다. 교환대·연결선 | **불안 최대 2를 환청으로 1:1 변환** | 없음 | 앞에서 새로 공급된 불안을 뒤의 환청 수확과 연결. 불안 수확을 먼저 할지 전환부터 할지 선택 |

기록원의 상태 선택은 **불안·환청·기시감·봉인 중 한 종류**이며 부착 시 고정한다. 발동 직전에 가장 큰 상태로 자동 변경하지 않는다. 참조량은 도착 시점에 계산한다. 같은 칸에 기록원 두 개체를 쓰면 비용을 각각 내고 각자 정한 상태로 차례로 수확한다.

봉합사는 보스의 부담을 줄이지 않는다. 빈칸·이미 파괴된 타일에는 내구 회복이 없으며, 최대 내구도에 미리 사용해도 보호막으로 저장하지 않는다. 부착 칸을 지나지 않고 멀리 있는 타일을 즉시 수리할 수 없다.

**기록원의 직접 수확은 이번 콘텐츠 제안이지 rules v0.9의 자동 결론이 아니다.** 기존의 ‘첫 유효 수확 공포 +4’는 이 카드에서 제거하며 두 능력을 동시에 주지 않는다. 빈칸 개입이 영구 괴이의 역할을 지나치게 대체하는지는 별도로 관찰한다.

## 6. 고정 융합 조합 10쌍·괴이 30종

모든 괴이는 **영구 배치 자산**, 슬롯 1개, 시작·최대 내구도 **4**다. 매번 실제 방문 시 명세대로 작동하며, 직원처럼 턴말 제거되지 않는다. 공급형·지원형이 도착 효과를 갖지 않아도 허용한다. 표에 없는 효과·추가 소비·이동·소환·부활은 없다.

**획득:** 각 쌍에서 선택한 한 종류의 타일 1개. 직원 선택 순서는 무관하고 같은 쌍의 후보를 재추첨하지 않는다. 같은 괴이를 다시 제작할 수 있지만 매번 새로운 직원 두 개체를 소모한다.

| 조합 | 고정 후보 ① | 고정 후보 ② | 고정 후보 ③ |
|---|---|---|---|
| **S+R 접객원+녹음기사** | SR1 대답하는 벽 | SR2 금지된 안내방송 | SR3 오지 않은 호출 |
| **S+K 접객원+기록원** | SK1 미리 적힌 투숙기록 | SK2 빈 이름의 명부 | SK3 반복되는 첫날 |
| **S+H 접객원+봉합사** | SH1 봉합된 비상구 | SH2 안심을 꿰매는 손 | SH3 문밖에 남은 불안 |
| **S+C 접객원+교환원** | SC1 잘못 연결된 프런트 | SC2 먼저 접수된 민원 | SC3 나에게 돌아온 안내 |
| **R+K 녹음기사+기록원** | RK1 목소리의 투숙대장 | RK2 삭제된 녹취록 | RK3 원본 없는 증언 |
| **R+H 녹음기사+봉합사** | RH1 입을 꿰맨 라디오 | RH2 봉합선의 합창 | RH3 무음 치료실 |
| **R+C 녹음기사+교환원** | RC1 혼선 교환대 | RC2 수신자 없는 통화 | RC3 지난밤의 발신자 |
| **K+H 기록원+봉합사** | KH1 봉합 진료기록 | KH2 흉터 보관함 | KH3 지워지지 않는 병력 |
| **K+C 기록원+교환원** | KC1 반송되는 고해실 | KC2 수취인이 바뀐 장부 | KC3 접수되지 않은 고백 |
| **H+C 봉합사+교환원** | HC1 통증 교환실 | HC2 감각이 바뀐 치료실 | HC3 이송되는 봉합선 |

아래는 모두 **시연용 신규 명세**다. 법칙·사건 설명은 판정 외의 숨은 효과를 추가하지 않는다. 과거 기록에 등장한 이름도 여기의 입력·수치·발동으로 다시 평가한다.

### 6.1 S+R — 예고가 손님의 목소리로 재생된다

접객원의 ‘앞으로 겪을 일’이 녹음기사의 재생 내용이 된다. **걱정을 목소리로 바꿔 수확할지, 목소리를 남겨 둘지, 이미 겪은 기억으로 넘길지**가 후보의 차이다.

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **SR1 대답하는 벽** — 안내받고 걱정한 일을 벽 속 자신의 목소리가 대답한다 | 불안 **정확히 1** 소비 → 환청 **2**. 출력 공간 2 필요 | 환청 최대 2 소비 → 1개당 공포 4, 수확 시 부담 +1 | 불안에서 바로 환청 수확으로 연결. 후방에 남길 환청은 소비될 수 있음 |
| **SR2 금지된 안내방송** — 걱정하던 경고가 이미 들었던 안내방송으로 확인된다 | 없음 | **불안 1 이상일 때** 환청 최대 2 참조 → 1개당 공포 2. 두 상태 모두 소비 없음, 부담 0 | 작은 수익을 얻고 두 입력을 다음 방에 보존. 불안과 환청을 따로 마련해야 함 |
| **SR3 오지 않은 호출** — 아직 받지 않은 호출을 이미 들었다는 기억이 생긴다 | 불안 **1과 환청 1**을 함께 소비 → 기시감 **2**. 두 입력·출력 공간 모두 필요 | 없음 | 기본 두 상태로 기시감 경로 개방. 자체 수확 없음 |

입력은 안내판·라디오로 마련할 수 있다. SR3을 만드는 데 두 공급 직원이 사라져도 이 시설들은 남는다. SR2의 불안 조건은 참조이므로 불안을 1개 소비하는 것으로 처리하지 않는다.

### 6.2 S+K — 예고가 이미 기록된 사실이 된다

접객원의 예고를 기록원이 대조 가능한 과거로 확정한다. **불안을 기록으로 저장하거나, 기록되지 않은 불안만 드러내거나, 기록을 다시 미래의 걱정으로 돌린다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **SK1 미리 적힌 투숙기록** — 처음 방문했는데 장부에는 이미 머문 기록이 있다 | 불안 최대 2 → 기시감 1:1 변환 | 없음 | 안내판으로 기시감 공급 가능. 당장의 불안 수확 입력을 줄이며 자체 수확은 없음 |
| **SK2 빈 이름의 명부** — 장부로 설명되지 않는 걱정만 빈 이름을 채운다 | 없음 | `n = min(2, max(불안−기시감, 0))`. 불안 n 소비 → 공포 4n, n>0이면 부담 +1 | 기시감보다 많은 불안을 수익으로 사용. 기시감을 앞에서 늘리면 수확 가능량 감소 |
| **SK3 반복되는 첫날** — 기록된 첫날을 읽자 같은 일이 다시 일어날 것이라 예상한다 | 없음 | 기시감 최대 2 참조하여 n 결정 → **불안 +n**, 이어 공포 **2n**. 기시감 소비 없음·부담 0 | 기시감을 보존하며 후방 불안 수확을 준비. 기시감 공급원이 없으면 작동하지 않음 |

SK2는 불안과 기시감을 둘 다 소비하는 카드가 아니다. SK3의 불안은 직접 부여이므로 상한 초과분만 버리며, 불안 상한 때문에 참조 수익을 취소하지 않는다. 기시감은 SR3·RK1·SC2 등 다른 쌍에서도 마련할 수 있다.

### 6.3 S+H — 예고받은 걱정을 봉합한다

봉합사가 접객원의 예고를 없애는 대신 형태를 갖춘 봉인으로 꿰맨다. **봉인을 열어 수확하거나, 실제 회복의 흔적으로 남기거나, 아직 남은 불안과 함께 대면한다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **SH1 봉합된 비상구** — 걱정을 문틈에 꿰맸는데 나가려 하자 안쪽에서 열린다 | 불안 최대 2 → 봉인 1:1 변환 | 봉인 최대 2 소비 → 1개당 공포 4, 수확 시 부담 +1 | 기본 불안 공급만으로 봉인 수확까지 연결. 봉인을 후방에 남기는 선택과 경쟁 |
| **SH2 안심을 꿰매는 손** — 걱정을 실제로 달랜 만큼만 봉합 흔적이 남는다 | **불안 최대 2를 회복 가능한 양만큼 소비**하여 같은 양 회복·봉인 부여. 아래 상세식 적용 | 없음 | 위험 관리와 봉인 준비를 연결. 부담·손상이 없으면 공급도 하지 못함 |
| **SH3 문밖에 남은 불안** — 꿰매 넣었던 걱정과 아직 남은 걱정이 문 양쪽에서 만난다 | 없음 | 불안 **1과 봉인 1**을 함께 소비 → 공포 **8**, 부담 **0** | 혼합 입력으로 부담 없는 수확. 봉인만 많이 공급해서는 작동하지 않음 |

**SH2 상세:** 일반 손님은 `n=min(2, 불안, 현재 부담, 9−봉인)`. 불안 n 소비 → 부담 n 감소 → 봉인 n 부여. 보스전은 현재 부담 대신 **이 괴이 자신의 잃은 내구도(4−현재 내구도)**를 사용하고, 내구 n 회복 → 봉인 n 부여한다. 출력 공간이나 회복 여지가 없으면 불안도 소비하지 않는다.

SH1은 자기 통과 변환으로 불안을 모두 없앨 수 있다. 그 뒤 SH3까지 연결하려면 불안 재공급이나 남길 양이 필요하다. ‘같은 테마의 괴이’라는 이유로 자동 연계된다고 보지 않는다.

### 6.4 S+C — 안내가 잘못된 수신자에게 돌아온다

접객원의 안내가 교환원의 연결로 다른 의미를 갖는다. **들린 목소리를 다시 걱정으로 돌리거나, 걱정 하나를 목소리와 기억으로 나누거나, 두 흔적을 함께 대면한다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **SC1 잘못 연결된 프런트** — 남의 목소리인 줄 알았던 안내가 자신의 예정된 일로 연결된다 | 환청 최대 2 → 불안 1:1 변환 | 없음 | 라디오 입력을 기본 불안 수확에 연결. 환청 수확보다 앞에 놓으면 그 입력을 빼앗음 |
| **SC2 먼저 접수된 민원** — 아직 말하지 않은 걱정이 자기 목소리의 ‘이미 접수된 민원’으로 돌아온다 | 불안 **1** 소비 → 환청 **1**과 기시감 **1**. 두 출력 모두 공간 필요 | 없음 | 한 입력을 두 종류로 분할해 혼합·참조 경로 준비. 직접 수확은 없고 한 번에 하나의 묶음만 처리 |
| **SC3 나에게 돌아온 안내** — 자신에게 건넨 경고를 내선 끝의 자신이 대답한다 | 없음 | 불안 **1과 환청 1**을 함께 소비 → 공포 **8**, 수확 시 부담 +1 | 두 기본 시설만으로 혼합 수확 가능. 한 종류만 남기는 변환과 충돌 |

SC2는 다른 방의 사건을 재현하거나 다음 칸에 원격 발동하는 능력이 아니다. 현재 방문자의 상태만 바꾸며, 새 상태는 방문자가 실제 이동하면서 가져간다.

### 6.5 R+K — 목소리가 기록과 대조된다

녹음기사의 소리를 기록원이 과거의 증거로 다룬다. **목소리를 기억으로 바꾸거나, 지워진 목소리를 수확하거나, 남아 있는 두 증거의 일치를 참조한다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **RK1 목소리의 투숙대장** — 낯선 목소리가 자신의 과거 투숙 기록으로 정리된다 | 환청 최대 2 → 기시감 1:1 변환 | 없음 | 라디오에서 기시감 경로 개방. 환청은 줄어들며 자체 수확 없음 |
| **RK2 삭제된 녹취록** — 지웠다는 기록만 남은 목소리를 손님이 다시 알아듣는다 | 환청 최대 2 제거. **실제 제거량 q** 기록 | **이번 방문의 q×4** 공포, q>0이면 부담 +1 | 현재 남은 환청이 아니라 지운 양을 수확. 도착하지 않고 지나치면 제거만 일어남 |
| **RK3 원본 없는 증언** — 들리는 목소리와 자기 기억이 일치하지만 원본은 존재하지 않는다 | 없음 | `n=min(2, 환청, 기시감)`을 참조 → 공포 **3n**. 두 상태 소비 없음·부담 0 | 두 입력을 보존하는 혼합 참조, 최대 6. 환청이나 기시감 한쪽만 있으면 불발 |

RK2에서 녹음기사 효과를 **같은 칸**에 붙이면 괴이의 제거가 먼저, 직원의 환청 공급이 나중이다. 따라서 그 직원이 새로 만든 환청은 이번 q에 포함되지 않는다. 제거량을 늘리려면 실제 경로의 더 앞칸에 공급해야 한다.

### 6.6 R+H — 봉합한 목소리와 사라진 소리를 재생한다

봉합사가 소리를 가두고, 녹음기사는 봉합선이나 회복 뒤의 침묵을 재생한다. **목소리를 보관하거나, 보관물을 열어 수확하거나, 실제 회복을 새로운 소리의 원인으로 만든다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **RH1 입을 꿰맨 라디오** — 재생되는 목소리를 봉합선 안에 가둔다 | 환청 최대 2 → 봉인 1:1 변환 | 없음 | 라디오를 봉인 공급으로 전환. 자체 수확 없음 |
| **RH2 봉합선의 합창** — 봉합선을 열자 가둔 목소리가 여러 곳에서 돌아온다 | 없음 | 봉인 최대 2 → 환청 1:1 변환. **실제 변환량 n당 공포 3**, n>0이면 부담 +1 | 수확하면서 후방 환청을 준비. 환청이 상한이면 변환·연동 수익 감소 |
| **RH3 무음 치료실** — 몸이나 방이 회복되자 그때 사라졌던 소리가 들린다 | 일반 부담 또는 보스전 **자신의 내구도**를 최대 2 회복. 실제 회복량 q만큼 **환청 +q** | 없음 | 회복이 필요한 상황에서 공급까지 확보. 이미 온전하면 회복·환청 모두 0 |

RH3은 회복이 먼저이며 환청의 초과분은 버린다. 환청 상한을 이유로 이미 가능한 회복을 막지는 않는다. RH2는 반대로 봉인이 환청으로 **변환되는 능력**이므로 출력 공간만큼만 입력을 소비한다.

### 6.7 R+C — 재생과 연결이 소리의 출처를 바꾼다

교환원이 넘긴 입력을 녹음기사가 여러 목소리로 재생하거나, 되돌아온 통화를 다른 상태로 받는다. **입력을 소비해 증폭하거나, 음성을 걱정으로 반송하며 수확하거나, 기억을 보존한 반복 공급을 만든다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **RC1 혼선 교환대** — 한 사람의 걱정이 서로 다른 두 발신자의 목소리로 분리된다 | 불안 최대 2 소비, **1개당 환청 2**. 출력 두 개가 들어가는 묶음만 처리 | 없음 | 불안에서 많은 환청을 빠르게 준비. 불안 수확 입력을 소모하며 자체 수확은 없음 |
| **RC2 수신자 없는 통화** — 듣던 목소리를 돌려보냈더니 아직 일어나지 않은 자기 일의 경고가 된다 | 없음 | 환청 최대 2 → 불안 1:1 변환. **실제 변환량 n당 공포 3**, n>0이면 부담 +1 | 환청 수확과 후방 불안 공급을 연결. 불안이 상한이면 입력·수익 제한 |
| **RC3 지난밤의 발신자** — 이미 겪은 기억을 지우지 않고 그때의 목소리만 다시 연결한다 | 기시감 최대 2 참조 → 같은 양 환청 부여. 기시감 소비 없음 | 없음 | 기시감을 남기는 반복 공급 경로. 먼저 기시감 공급원이 있어야 하며 자체 수확은 없음 |

RC3은 과거 효과·카드를 복제하지 않는다. 현재 기시감 수만 참조해 환청을 생성하는 한 번의 통과 효과다. 실제 별도 발신자나 소환물도 생기지 않는다.

### 6.8 K+H — 회복하거나 봉합한 흔적이 기록으로 남는다

봉합사가 없애거나 가둔 것이 기록원의 증거가 된다. **실제 회복량을 수확하거나, 기억을 봉인하거나, 기억과 봉합 흔적을 함께 읽는다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **KH1 봉합 진료기록** — 나았던 부분이 장부에 적힐수록 무엇이 다쳤는지 깨닫는다 | 일반 부담 또는 보스전 **자신의 내구도**를 최대 2 회복. 실제 회복량 q 기록 | **이번 방문의 q×4** 공포, 부담 0 | 위험·손상을 줄인 실제 양으로 수확. 회복 여지가 없거나 도착하지 않으면 공포 0 |
| **KH2 흉터 보관함** — 과거의 기억을 꿰매어 몸에 남는 흔적으로 보관한다 | 기시감 최대 2 → 봉인 1:1 변환 | 없음 | 기시감 엔진을 봉인 엔진으로 연결. 자체 수확 없음 |
| **KH3 지워지지 않는 병력** — 기억과 봉합 흔적이 같은 사건을 가리키자 지워진 상처가 증명된다 | 없음 | 기시감 **1과 봉인 1**을 함께 소비 → 공포 **8**, 부담 0 | 두 심화 상태로 안전 수확. 두 상태의 공급을 각각 확보해야 함 |

KH1의 q에는 같은 칸에 붙인 봉합사 카드의 후속 회복을 합산하지 않는다. 직원 회복을 더 앞칸에 쓰면 오히려 KH1이 회복·수확할 양을 줄일 수 있다. 이 상충도 명세대로 처리한다.

### 6.9 K+C — 연결된 기록과 연결되지 않은 기록을 다르게 처리한다

교환원의 전달을 기록원이 결과·수신자·누락으로 대조한다. **실제 전달한 양을 수확하거나, 상태의 수신자를 바꾸거나, 전달되지 않은 차이만 읽는다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **KC1 반송되는 고해실** — 넘겨버린 걱정이 자신의 목소리와 접수 기록으로 돌아온다 | 불안 최대 2 → 환청 1:1 변환. 실제 변환량 q 기록 | **이번 방문의 q×4** 공포, q>0이면 부담 +1. 환청 추가 소비 없음 | 변환 과정 자체를 수확하고 환청은 후방에 남김. 이미 가진 환청만으로는 도착 수확하지 못함 |
| **KC2 수취인이 바뀐 장부** — 장부의 두 수신자가 바뀌어 걱정과 목소리의 양이 뒤바뀐다 | 현재 **불안과 환청의 수량을 동시에 교환** | 없음 | 두 상태 비율을 크게 뒤집어 기존 경로 재활용. 적합한 공급 순서를 되돌려 버릴 수도 있음 |
| **KC3 접수되지 않은 고백** — 목소리로 전달되지 못한 걱정의 차이만 장부에 남는다 | 없음 | `n=min(2, max(불안−환청, 0))` 참조 → 공포 **3n**. 상태 소비 없음·부담 0 | 불안을 남기며 초과분 수확. 환청을 앞에서 많이 공급·변환하면 오히려 수익 감소 |

**KC2의 값 교환은 이 괴이만의 콘텐츠 제안**이다. 교환 전 불안 3·환청 1이면 이후 불안 1·환청 3이다. 둘 다 0~9라 별도 초과가 없고 합계는 유지된다. 입력·출력을 두 번 순차 대입하거나 복제하는 처리가 아니며, 기시감·봉인은 바꾸지 않는다. 같은 효과를 두 번 연속 받으면 원래 비율로 돌아갈 수 있다.

**KC1은 예전 이름을 재사용했지만 새 명세다.** 예전 시연의 ‘변환 후 환청 소비 수확’을 혼용하지 않는다. 여기서는 자기 통과 변환량 q로 수확하고 그 환청은 소비하지 않는다.

### 6.10 H+C — 봉합한 것을 다른 상태·대상으로 넘긴다

교환원이 봉합사의 처리 대상과 결과를 옮긴다. **봉인을 걱정으로 풀거나, 목소리를 봉합 재료로 바꾸어 회복하거나, 봉합선을 다음 타일에 전달한다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **HC1 통증 교환실** — 가둔 흔적을 풀었더니 앞으로 겪을 일의 걱정으로 바뀐다 | 봉인 최대 2 소비, **1개당 불안 2**. 출력 두 개가 들어가는 묶음만 처리 | 없음 | 봉인 경로를 기본 불안 수확에 다시 연결. 봉인을 쓰는 다른 후속 효과와 경쟁 |
| **HC2 감각이 바뀐 치료실** — 들리던 목소리를 꿰맬 상처로 바꾸자 몸이나 방이 회복된다 | 환청 **정확히 2** 소비 → 봉인 **1**, 이어 일반 부담 또는 보스전 **자신의 내구도** 최대 2 회복 | 없음 | 목소리를 쓰는 회복·봉인 공급. 환청 1개로는 불발하며 RH1보다 봉인 수율이 낮음 |
| **HC3 이송되는 봉합선** — 자신에게 쓰일 봉합선을 다른 곳으로 연결한다 | 일반: 봉인 **1** 소비 → 부담 최대 2 감소. 보스: 봉인 **1** 소비 → **바로 다음 슬롯의 살아 있는 타일** 내구 최대 2 회복. 실제 회복 대상·여지 필요 | 없음 | 보스전에서 자신이 아니라 다음 타일을 보존. 봉인 공급이 필요하고 수익은 직접 만들지 않음 |

HC2는 환청 2와 봉인 공간 1이 모두 있어야 전체 효과를 실행한다. 회복할 손상이 없어도 변환은 가능하다. 반대로 변환할 수 없으면 회복만 무료로 실행하지 않는다.

**HC3의 인접 회복은 이 괴이만의 콘텐츠 제안**이다. 보스전의 ‘바로 다음’은 이동 방향으로 다음 슬롯 하나이며 N 다음은 1이다. 빈칸·온전한 타일·파괴된 타일이면 봉인을 소비하지 않는다. 건너뛰어 다른 타일을 찾지 않으며, 타일을 회복해도 방문자의 위치·이동·도착·공격 대상을 바꾸지 않는다. 일반 영업에서는 다음 타일을 수리하지 않고 현재 손님의 부담만 줄인다. 부담 0이면 봉인을 소비하지 않는다.

### 6.11 입력 공급과 재료 소모의 점검

| 필요한 입력 | 재료 직원을 다시 확보하지 않고도 사용할 경로의 예 |
|---|---|
| 불안 | 기본 안내판 / SC1의 환청→불안 / RC2의 도착 변환 / SK3·HC1 |
| 환청 | 기본 라디오 / SR1·RC1·KC1의 불안 변환 / RH2·RH3·RC3 |
| 기시감 | 안내판→SK1 / 라디오→RK1 / 두 기본 상태→SR3 / 불안→SC2 |
| 봉인 | 안내판→SH1 / 라디오→RH1 / 기시감→KH2 / RH·HC 관련 경로 중 조건을 충족하는 것 |
| 부담·손상 | 실제 덱 소진·수확 부담·보스 공격에서 발생. 수익을 위해 임의로 만들어 주지 않음 |

이 표는 **목록 전체에 대체 경로가 있다는 구조 점검**이다. 한 판에서 모든 타일이 무료로 제공되거나 항상 제작 가능하다는 보장은 아니다. 필요한 쌍·자금·슬롯·모집 기회가 실제로 남는지 따로 확인한다. 기시감·봉인을 사용하는 후보를 보여 줄 때에는 현재 호텔에 입력이 있는지와 아직 필요한 자산을 함께 알린다.

30종의 형식을 채웠다는 사실만으로 24개 체크리스트를 모두 충족했다고 표시하지 않는다. 특히 두 직원의 기여가 플레이어에게 납득되는지, 서로 다른 후보가 실질적인 대안인지, 제작 후 호텔이 달라지는지는 **플레이 검증 대기**다.

## 7. 일반 손님·보스·종료와 손실

### 7.1 일반 영업

일반 손님은 입구부터 출구까지 한 번만 진행한다. 시작 부담 0, 한계 **12**, 최솟값 0이다. 덱 소진 +2와 각 수확의 명시된 부담을 함께 계산한다. 일반 영업 중 시설·괴이에 피해를 가하는 방문자 능력은 없다.

생존 퇴장 시 해당 손님에게 모은 공포 전액을 경영 자원으로 받는다. 사망 시 그 손님의 수입은 **0**, 이전 정산 수익은 보존하고 경찰 의심도 **+1**. 의심도 **3**이면 판 종료다. 마지막 손님이라도 의심도 3 도달은 완주보다 실패를 우선한다.

| 승리 | 공포 **45 이상**이면 즉시 격퇴. 남은 이동·효과·공격 중단 |
| 격퇴 보상 | 경영 자원 **20**만 지급. 전투 공포를 다시 잔액에 더하지 않음 |
| 보스의 부담 | 없음. 부담 증감은 무시하되 각 카드의 명시된 보스 회복 분기를 사용 |

목표만 **24→45**로 올리고 턴 제한·피해·내구도·회복 기준량·보상은 config 8 값을 유지했다. 공포를 매번 정확히 8씩 얻는 경로라면 5회는 40으로 부족하고 6회는 48로 도달한다. 이것은 산술 예시이며 **6턴 승리 보장**이 아니다. 같은 턴의 직원 수확, 서로 다른 수확량, 불발, 경로, 파괴에 따라 달라진다.

목표 증가가 실제로 공격·손실·판단을 늘리는지는 아직 시험하지 않았다. 보스전을 길게 만든 것 자체를 재미 개선이나 재설계 경험의 증거로 보지 않는다. 승리를 위해 피해를 낮추거나 목표를 몰래 바꾸지 않는다.

### 7.3 보스 패배와 ‘생산 불능’

| 종료 | 판정 |
|---|---|
| 시간 초과 | 8턴째 수확으로도 45 미달이면 예고 공격을 처리한 뒤 패배 |
| 생산 불능 | 현재 직원 덱과 살아 있는 타일을 포함해 공포 생산 가능성이 **확실히 모두 사라진 경우만** 조기 패배 |
| 포기 | 플레이어가 전투 포기를 선택하면 판 종료 |
| 승리 후 | 보상·손실 정산 → 경영·재설계 → 일반 손님 2명 |

**기록원이 빈칸에서 수확할 수 있으므로 ‘수확 타일이 없다’는 것만으로 생산 불능을 선언하지 않는다.** 해당 전투에서 잠긴 덱의 직원, 남은 상태·공급 수단을 포함한다. 반대로 덱 밖의 직원 풀이나 전투 중 구매·융합으로 구조할 수 있다고 가정하지 않는다. 명확하지 않은 교착은 8턴 상한으로 처리하며, ‘이번 손패가 나쁘다’를 불능으로 오인하지 않는다.

### 7.4 손실·복구·재설계

파괴된 시설·괴이는 **이번 판에서 제거**한다. 슬롯·다른 타일·직원 풀·남은 경영 자원은 보존한다. 격퇴 뒤 살아남은 타일은 내구도 **4**로 회복하지만, 파괴된 타일은 자동 복원하지 않는다. 전투 중 회복도 살아 있는 타일만 대상으로 한다.

격퇴 보상을 지급하고 새 모집·시설 재고를 제시한 뒤 무료 보관·재배치와 유료 구매·융합을 진행한다. 원래 조합의 재구매를 보장하지 않는다. 기본 시설로 최소 생산 경로를 다시 마련할 수 있는지 실제 자금과 재고로 점검한다. 예를 들어 잔액이 0이어도 격퇴 보상 20에서 **안내판 6 + 닫힌 객실 6 + 직원 2명 8 = 20**을 쓸 수 있지만, 그 선택을 강요하거나 다음 수입까지 보장하지 않는다.

부분 손실을 보이기 위해 타일을 강제 삭제하지 않는다. **무손실 승리는 유효한 결과**이고, 그 판의 부분 파괴 후 재설계는 미경험이다. 보스 패배로 재설계에 도달하지 못한 경우도 ‘재설계가 재미없었다’는 결과와 구분한다.

## 8. 텍스트 진행 방식과 공개 정보

### 8.1 진행자와 선택

기본 진행자는 규칙·난수·상태·정산을 관리하고, 사용자는 **경영·융합·배치·덱 편성·주사위 선택·직원 사용**을 결정한다. 사용자가 자동 시연을 요청한 경우에만 진행자가 선택도 대신하며, 그때는 진행자의 선택 이유와 결과를 기록하고 인간의 자발적인 선택으로 해석하지 않는다.

지금 파일을 만들었다는 이유로 첫 모집 추첨이나 주사위 굴림을 미리 진행하지 않는다. 실제 시작 지시 때 §3의 자산으로 초기화한다. 이전 판의 자산·잔액·직원·경로를 이월하지 않는다.

### 8.2 경영 화면

현재 잔액·누적 성과·방문 단계·보스까지 남은 손님 수, 슬롯별 타일·빈칸, 보관 자산, 직원 풀·편성 덱, 이번 모집 후보·남은 모집 한도·시설 재고를 보여 준다.

융합 화면은 해당 3종의 **법칙 한 문장 / 통과·도착 / 입력 / 수익·위험 / 현재 호텔의 공급 여부 / 소모 직원**을 함께 제시한다. 능력에 없는 자동 연계를 장점으로 설명하지 않는다. 특정 후보가 정답이라고 먼저 추천하지 않는다.

### 8.3 턴의 제시 순서

| 시점 | 공개할 정보 |
|---|---|
| 드로우 직후 | 현재 손패와 비용, 덱·버림 더미 장수, 소진 발생 여부, 현재 상태·부담 또는 보스 피해 |
| 주사위 선택 전 | 나온 세 눈을 그대로 표시. 각 후보의 실제 경로·도착/퇴장·마나, 보스라면 공격 대상·피해 |
| 선택 확정 뒤 | 확정한 r, 남은 마나, 카드별 대상 슬롯·기록원 지정 상태·현재 예상 불발 이유 |
| 이동 전 | 사용 카드와 사용 순서, 슬롯별 직원 부착 목록. 확정된 이동·효과 계획을 복기 |
| 이동 처리 | 슬롯 순서대로 영구 통과→직원 통과→해당 시 영구 도착→직원 도착. 실제 입력·소비·출력·불발을 기록 |
| 턴말·종료 | 실제 공포·상태·부담·내구도, 보스 공격·파괴, 효과 제거, 계속/퇴장/사망/승리/패배와 이유 |

현재 공개된 상태로 계산 가능한 결과는 보여 줄 수 있지만 **다음 턴의 눈·카드·모집 후보는 보여 주거나 선택에 사용하지 않는다.** 설명하지 않은 최적 행동을 자동 실행하지 않는다. 여러 눈이 모두 퇴장하더라도 남은 경로의 통과 효과와 쓸 수 있는 마나가 다를 수 있으므로 숫자만으로 동등하다고 판정하지 않는다. 실제 결과·카드 기회가 같을 때만 동등 후보로 묶는다.

### 8.4 난수·기록·중도 변경

주사위는 실제 난수 도구로 현재 턴에 굴리고, 덱 셔플·모집 추첨도 지정한 분포로 수행한다. 결과가 마음에 들지 않는다는 이유로 다시 뽑지 않는다. 진행자가 유리한 눈이나 필요한 직원을 골라 ‘무작위 결과’로 제시하지 않는다.

영업·보스가 시작하면 배치·덱·적용 설정을 잠근다. 경영 선택은 다음 손님의 주사위를 보기 전에 끝낸다. 공개된 사실을 바탕으로 사용자가 다음 카드의 계획을 생각하는 것과 미공개 난수를 이용하는 것은 구분한다.

명세 공백이나 계산 오류가 발견되면 해당 지점과 영향을 기록한다. 이미 공개된 난수를 바꾸어 결과를 맞추지 않는다. 새 판정·수치를 도입하는 경우 설정 버전과 적용 시작점을 명시하고, 기존 기록을 수정 전후가 구분되지 않는 한 판으로 보고하지 않는다.

## 9. 이 설정에서 확인할 것

### 9.1 직원 개입의 시험 의도

| 확인할 장면 | 확인할 문제 | 성공으로 대신 세지 않을 것 |
|---|---|---|
| 공급 시설 뒤에 교환원 부착 | 사용 때 입력 0이어도 실제 공급 뒤 변환이 연결되는가 | 사용 가능 버튼이 늘어남 |
| RK2보다 앞칸에 녹음기사 부착 | 같은 도착 칸에 붙이는 것과 앞칸의 효과 순서가 다른 이유를 이해하는가 | 카드를 항상 도착 칸에 배치함 |
| 빈칸에 기록원 부착 | 영구 수확실을 놓친 경로에 제한된 수확 선택이 생기는가 | 매 턴 공포 4를 반복해서 누름 |
| 영구 수확실에 기록원 부착 | 영구 효과가 먼저 상태를 소비해 직원 참조 입력이 줄어드는가 | 충분한 마나가 있으면 무조건 모두 사용 |
| 회복을 더 앞칸/같은 칸에 부착 | 수확 전 생존 확보와 KH1의 회복량 수확 사이의 상충을 읽는가 | 회복 수치가 증가함 |
| 자동 공급으로 상한이 이미 찬 경로 | 부착만으로 과잉 공급 문제가 해결되지 않았음을 구분하는가 | 카드 사용률 증가 자체 |

직원의 빈칸 수확이 괴이의 필요성을 없애는지, 매번 도착 칸 부착이 최선인지, 기록원만 남기고 다른 직원을 융합하는 선택으로 굳는지도 살핀다. 반대로 모든 턴에 카드를 쓰게 하거나 모든 직원의 사용률을 같게 만드는 것을 목표로 삼지 않는다.

### 9.2 융합 이해와 다음 조합

직원 행동 경험 → 고정 후보 비교 → 융합·배치 → 실제 발동 뒤 **자유 설명** 순서로 본다. 먼저 ‘무슨 일이 일어났나, 두 직원의 일이 어떻게 이어졌나’를 자신의 말로 설명할 기회를 준다. 정확한 결과를 처음부터 예측할 것을 요구하지 않는다.

이어 다음 행동을 자유롭게 선택하게 하고, **다른 쌍 열람·후보 비교·특정 직원의 보존·모집 계획**을 기록한다. ‘다른 조합도 궁금하죠?’처럼 긍정 답을 유도한 질문과 자발적 행동을 구분한다. 재료·자금이 없어서 시도하지 못한 경우를 호기심 부족으로 처리하지 않는다.

관계 이해와 다음 조합 탐색이 **같은 플레이어에게 함께** 나타나는지가 중심이다. 한 사람은 잘 설명하고 다른 사람만 탐색했다면 이를 한 사람의 성공 경험으로 합치지 않는다.

### 9.3 최소 기록 항목

| 구분 | 남길 내용 |
|---|---|
| 적용 조건 | config 9 문서 버전, rules v0.9, 사용자 지정 목표 45, 자동 시연인지 사용자 선택인지 |
| 턴 시작 | 방문자·턴·위치·상태·부담/보스 공포·내구도, 손패·덱/버림 수, 소진 |
| 주사위 | 후보 세 눈, 선택한 r, 포기한 후보의 이점, 실제로 결과가 동등했는지 |
| 직원 | 사용 카드 개체·부착 슬롯·순서·지정 상태·마나, 부착과 발동을 각각 기록 |
| 발동 | 실제 입력·소비·변환·공포·위험·회복, 무발동·0효과·미방문·중도 종료의 이유 |
| 공급·경제 | 실제 수입, 각 구매 시점 잔액·후보·재고, 모집·융합·확장·포기한 투자 |
| 융합 | 쌍·고정 후보·선택한 괴이, 법칙에 대한 자유 설명, 제작 전후 배치·덱 변화 |
| 보스·재설계 | 실제 공격·파괴·손실 방지·종료 이유, 남은 자산과 새로운 연결, 손실 미경험 여부 |
| 핵심 반응 | 자유 설명 원문, 자발적 다음 탐색, 도움·유도·재시도·막힌 이유 |

**드로우된 카드 수 / 사용한 카드 수 / 카드를 사용한 턴 수 / 실제 발동 수 / 실질적인 상태·수익·생존 변화가 있었던 수**는 서로 다르다. 같은 종류가 여러 번 드로우되면 드로우 횟수로 각각 세되, 보유 직원 수와 섞지 않는다. 미사용 이유도 마나·손패·입력·대상·이미 충분함·의도적인 보존 순서 등으로 구분한다.

### 9.4 결과 해석의 한계

텍스트 시연은 명세의 작동, 자원 정산, 설명 가능한 선택과 막힌 조건을 점검하는 자료다. **진행자가 전부 선택한 시연을 인간의 재미·호기심 검증으로 취급하지 않는다.** 사용자가 직접 참여한 경우에도 그 한 번의 텍스트 경험은 그 참가자·매체에 한정하며, 실제 화면의 조작 부담·연출·다수 플레이어의 재미까지 일반화하지 않는다.

높은 공포, 보스 승리, 많은 카드 사용, 30종 후보 제시는 핵심 반응을 대신하지 않는다. 선택하지 않은 후보·사용하지 않은 직원·실제 발생하지 않은 부분 손실은 검증 완료로 표시하지 않는다. 현재 문서는 모든 경험 평가를 **검증 대기**로 둔다.

설정 8과는 발동 시점·기록원 역할·상태·괴이 명세·목표 공포가 함께 달라졌다. 원인을 분리하려는 후속 비교에서는 시작 조건과 콘텐츠를 맞추고 한 변경만 다르게 해야 한다. 이번 한 판 수익 차이로 ‘부착 방식이 몇 % 개선했다’고 계산하지 않는다.

위 체크는 **문서에 명세가 있다는 뜻**이며 기능 구현이나 인간 검증 통과 표시가 아니다.

### 10.2 아직 확인하지 않은 것

- [ ] 이 설정으로 텍스트 한 판을 시작·완주했다.
- [ ] 실제 30종 각각의 유효한 활용과 편중·지배적 선택 여부를 경험했다.
- [ ] 새 직원 방식에서 의미 있는 위치·순서·마나 선택을 관찰했다.
- [ ] 같은 플레이어에게 융합의 자유 설명과 다음 조합 탐색이 함께 나타났다.
- [ ] 보스 목표 45에서 위협·시간·손실·회복의 대가가 적절했다.
- [ ] 실제 부분 손실 이후 재설계·재영업을 경험했다.

### 10.3 정식 게임에서는 계속 미정인 것

X·K, 카드별 비용·효과량, 드로우·상태 상한·경제 수치, 최종 직원·괴이·상태 이름, 보스 목표·공격 대상·피해·회복량 등은 **이번 시험값을 정식 최종값으로 승격하지 않는다.** 사용자의 목표 45 지정도 이번 MVP 설정에 대한 값으로 기록한다.

같은 턴에 한 칸을 여러 번 방문하는 예외는 이번 이동 범위 밖이라 미정으로 유지한다. 향후 X·루프 최소 길이·추가 이동이 바뀌면, 반복 발동 횟수를 먼저 별도 명세해야 한다. 소환·복제·사건 재현·이동 중 반응 등 제외된 기능도 이 파일을 근거로 자동 허용하지 않는다.
