## 2. 진행과 공개 정보

공통 [턴 순서](legacy-specs-9-10.md#legacy-rules)대로 진행한다. 난수는 현재 단계에서만 뽑고 미래 덱·주사위·모집 후보는 공개하지 않는다. 이미 공개한 결과를 유리하게 다시 뽑지 않는다. 사용자 플레이에서는 사용자가 경영·융합·배치·주사위·카드를 선택한다. 자동 시연에서는 진행자의 선택 근거를 기록한다.

| 시점 | 기록·공개할 정보 |
|---|---|
| 시작 | 방문자, F/T·남은 토큰·상태·위치, 타일/내구, 덱·버림 수 |
| 드로우 | 실제 카드, 소진·셔플·보충 드로우, 이번 주사위 개수 |
| 주사위 | 모든 후보 눈, 경로·도착·마나, 공격 방문 순서·중복 횟수 |
| 카드 | 직원 개체·비용·부착 칸·선택 상태·발동 조건·남은 마나 |
| 이동 | 적용한 효과 순서, 실제 상태·공포·내구 변화 |
| 심장마비 | 직전 F/T, 제거 토큰, 초과 공포와 재화 증가, F=0, 계속/즉시 종료 여부 |
| 공격·턴말 | 공격별 피해·파괴, 사망/격퇴/실패, 임시 효과·손패·마나 정리 |
| 경영 | 초과 수익·보스 보너스·잔액을 분리, 구매/융합 비용·직원 소모·손실·새 배치 |

## 3. 확인할 장면

- 정확히 한계에 닿으면 재화 0, 초과분이 있으면 그만큼 획득하는지.
- 토큰이 남은 심장마비 뒤에는 공격하고, 마지막 토큰 제거 즉시 남은 효과·이동·공격이 멈추는지.
- N→1 회전에서 공포·상태가 유지되고, 일반 도착 공격과 보스 매 방문 공격을 구별하는지.
- 보스 재방문은 반복 공격하되 도착의 통과/도착 효과를 두 번의 공격으로 세지 않는지.
- 덱 소진 뒤 보충 드로우는 이어지고 이번 턴 주사위 후보만 줄어드는지.
- 회복이 실제 자산 손실을 막는지, 초과 공포 수익으로 투자를 지속할 수 있는지.
- 같은 플레이어가 융합 인과를 자기 말로 설명하고 다음 조합을 자발적으로 찾는지.

**검증 대기:** 전체 한 판 완주, 위 판정의 실제 검산, 모든 후보의 적정성, 인간의 설명·탐색. 자동 시연의 정상 발동·높은 카드 사용률·수익·완주를 인간 재미의 증거로 대신하지 않는다.

## 4. 과거 버전과의 구별

설정 9 v0.1은 rules v0.9와 단일 보스 목표 45로 진행한 **27턴 자동 시연**이다. 당시 일반 손님 퇴장·심장 부담·카드·소진·수익 모델은 현재와 다르다. 과거 로그 `mvp-config-9-auto-play-01.md/.json`은 이 저장소에 없으며, 현재 검증 결과나 수익 개선율로 재해석하지 않는다.

v0.2는 2026-10-30의 반복 순환·심장 토큰·초과 재화·공격·소진 변경에 맞춘 시험안이다. 옛 목표 45의 재해석과 부담 연계 능력 개정도 미확정 명세에 포함되어 있다.
