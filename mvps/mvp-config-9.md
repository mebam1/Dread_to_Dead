## 0. 이번 개정의 우선순위와 폐기

**완전히 폐기:** 심장 부담 게이지, 심장 부담 관련 효과·사망, 경찰 의심도, 일반 손님의 출구 퇴장, 생존 정산, 죽으면 공포 몰수, 공포 발생량의 자동 경영 화폐 환산, 소진 시 드로우 중단·부담 +2·보스 피해 +1, 보스의 도착 한 칸만 공격.

**유지:** 직원 **5종**, 이종 직원 쌍 **10쌍**, 쌍마다 고정 **3후보=총30괴이**, 기본 4시설, 4상태(불안/환청/기시감/봉인), 1D 원형 호텔, 0~20장 덱, 직원 한 턴 임시 슬롯 효과, 카드 비용·유형 및 이동·마나의 관계, 경영·모집·융합·재배치의 기본 단계.

## 2. 주사위·손패·덱 소진·임시 직원 효과

### 2.1 이번 시험 숫자

| 항목 | 시험값 |
|---|---|
| 주사위 기본값 | **X=6 / K=3**. 각각 공정한 독립 1d6, 같은 눈 중복 가능 |
| 선택 | 실제 굴린 결과 중 하나 확정; 선택 눈 `r` = 이동 `r`칸 = 이번 턴 마나 `r` |
| 직원 카드 비용 | 모두 **2마나**. 카드 수 사용 제한 없음(현재 손패와 마나만 제한) |
| 기본 드로우 | 턴 시작 **2장**, 추가 드로우 없음 |
| 편성 | 직원 풀에서 0~20장, 보유 개체당 1장, 영업 전 잠금 |
| 덱 소진 페널티 | **이번 턴 주사위 개수 −1**. 기본 K=3이면 소진 턴 주사위 **2개**, 다음 턴 3개 복귀 |
| 재보충 | 버린 카드 셔플 후 **부족한 드로우 계속 뽑기**. 현재 손패는 버림 더미에 포함하지 않음 |
| 턴말 | 임시 직원 부착 전부 제거, 미사용 손패 버림, 남은 마나 제거 |

**[MVP 임시 예외 — 사용자가 아직 확정하지 않음]** 이번 시험에는 추가 드로우가 없으므로 한 턴 덱 소진 페널티는 **최초 소진 시 1회만** 적용하고, 같은 턴에 재차 덱이 비어도 주사위 수를 더 줄이지 않는다. 버린 더미까지 비어 부족분을 보충할 수 없으면 남은 드로우만 중지하고 턴을 계속한다. 기본 K=3에서 최소 2개를 굴릴 수 있도록 둔 **운영안**이며, 정식 `K=1`/중복 소진 규칙을 확정하지 않는다.

**예시:** 2장 드로우 중 한 장만 뽑고 덱이 비었으나 버린 카드가 있다면 `소진 → 이번 주사위 3→2개 → 버린 카드 셔플 → 두 번째 카드 보충`. **손패 접근은 유지하고 이동·마나 선택지만 감소**한다.

### 2.2 공통 한 턴 순서

1. 덱·버림 더미에서 이번 **2장 드로우**(소진 시 셔플하고 부족분 보충); 그 턴 실제 주사위 개수를 확정한다.
2. 그 개수만큼 `1d6` 굴려 후보 **눈/경로/도착/마나/호텔 피해 대상**을 공개한다.
3. 주사위 하나를 **선택·확정**한다.
4. 손패와 마나 범위에서 직원 카드를 임의 슬롯에 **이번 턴의 통과·도착 효과**로 부착한다. 카드가 필요로 하는 상태 종류 등도 이때 지정한다.
5. 선택 거리만큼 **순환 이동**하며 `영구 타일 통과 → 직원 통과 → (최종 도착이라면) 영구 타일 도착 → 직원 도착`을 순서대로 판정한다.
6. 공포를 발생시키는 각 효과 직후 **♥ 파괴·초과 재화·공포 0 리셋**을 확인한다. 마지막 ♥가 없어지면 그 즉시 나머지 이동·효과·공격을 중단한다.
7. **♥가 남아 있다면** 일반 손님은 최종 도착 1칸, 보스는 이번 방문 경로 전체의 각 실제 방문(반복 방문 포함)에 공격을 실행한다.
8. 파괴·종료를 확인한 뒤 이번 턴 직원 부착 효과와 손패·마나를 정리한다.

**[MVP 판정]** 동일 슬롯의 직원 여러 효과는 사용한 순서대로 발동한다. 카드 부착 당시에는 입력이 0이어도 이후 상태를 공급하면 실제 발동 시 사용한다. 부착된 칸을 방문하지 않으면 불발하며 환급하지 않는다. 기본 직원 부착 효과의 재통과 발동 횟수는 정식 미정이므로 이번 설정에서는 **한 방문에 한 번, 실제 방문할 때마다 재차 발동**하도록 시험한다. **공격의 재방문 반복 판정은 확정이고 이 직원 재발동은 임시 시험안**이다.

### 2.3 공포·♥ 및 재화의 즉시 정산

방문자별 현재 공포 `F`, 공포 한계 `T`, 남은 심장 토큰 `H`를 사용한다.

- 공포 효과 후 `F < T`이면 공포만 남긴다.
- `F ≥ T`이면 **심장마비** → **♥ 하나 제거** → **초과 공포 `F−T`만 경영 재화로 즉시 지급** → **F=0**. 초과분은 다음 게이지로 이월하지 않는다.
- 토큰이 남으면 **이번 턴 공격을 포함해 계속 진행**한다. 마지막 토큰이 없어지면 그 자리에서 손님 사망/보스 격퇴, 공격 취소.
- **[MVP 임시 판정]** 한 번의 공포 발생 효과는 토큰을 최대 하나만 제거한다. 하나의 이동에 별도 효과가 연속 발동하면 서로 다른 심장마비 사건은 발생할 수 있다.
- **심장마비와 ♡ 제거가 이루어져도 불안·환청·기시감·봉인은 자동으로 0이 되지 않는다.** 방문자 종료 시에만 모두 정리한다.

### 3.2 시작 시설(개정 제안)

시설은 각 1칸 차지, 시작 내구·최대 내구 **4**, 구매 가격 **6**이다.

| 시설 | 통과 | 도착 | 비고 |
|---|---|---|---|
| **수상한 안내판** | 불안 +1 | 없음 | 불안 공급 |
| **벽 속 라디오** | 환청 +1 | 없음 | 환청 공급 |
| **닫힌 객실** | 없음 | 불안 최대 2 소비, 1개당 **공포 +4** | **기존 심장 부담 +1 삭제** |
| **휴게실** | **바로 다음 슬롯의 살아 있는 시설·괴이 내구 +1(최대4)** | 없음 | **신규 콘텐츠 제안**. 일반·보스 공통, N→1 연결. 빈칸/파괴/온전한 타일은 효과 0 |

**휴게실은 이전의 ‘일반 손님 심장 부담 −2’와 같은 능력이 아니다.** 앞으로 보호/수리를 다른 방식으로 설계할 수 있으며, 이 회복량+1은 일단 **시험값**이다.

처음 표시 배치는 `① 안내판 → ② 빈칸 → ③ 라디오 → ④ 휴게실 → ⑤ 빈칸 → ⑥ 닫힌 객실`이고 경영 중 무료 변경 가능하다.

### 3.3 경영 비용·모집·융합

| 항목 | 기존 설정 9 시험값을 유지한 항목 |
|---|---|
| 직원 모집 | 1명 4. 각 경영 단계 5종 중 서로 다른 **3종 후보**, 그중 최대 **2명** 모집. 단계 중 재추첨 없음 |
| 기본 시설 | 종류별 가격 6, 단계마다 시설별 1개 재고 |
| 확장 | `6→8=8`, `8→10=12`, `10→12=16`. 빈 슬롯만 추가 |
| 융합 | 이종 직원 2명 소모, 각 쌍 고정 3후보 중 1종 선택. 추가 융합 화폐 없음 |
| 보스 추가 정액 보상 | 기존 시험값 **20**, 초과 공포 수익과 별개인 **MVP 추가 보상 후보** |
| 유지비·판매·재굴림·유료 재추첨 | 제공하지 않음 |

**경영 시점:** 시작, 일반 손님 1·2·3 처치 뒤(3번째 뒤 보스 직전), 보스 격퇴 후, 일반 손님 4 처치 뒤 = 총 6차례. 마지막 손님 5 처치 뒤에는 구매 단계 없이 끝낸다.

**경영 자원은 공포 총량으로 생기지 않는다.** 각 ♥ 제거 시 초과 공포만큼 늘어나므로, 이전의 시작 자원 16·모집4·시설6·확장8 등 **가격 곡선은 아직 경제 검증을 통과하지 못했다**. 적은 재화로 다음 융합이 막히면 그 자체를 기록하고 임의로 지원금을 늘리지 않는다.

### 3.4 반복 이동·내구도

입장시 첫 이동은 0→1이고, 이후 N번째 슬롯 다음은 항상 1이다. **일반 손님도 경계를 지나서 돌아온다.** 현재 방문자의 위치·공포·♥·4상태는 회전 간 계속 유지된다. 각 슬롯에는 영구 시설 또는 괴이 한 개만 배치한다. 영업 중 영구 자산을 옮기지 않고 경영 단계에 무료 보관·재배치한다.

**[시험 운용]** 일반 손님과 보스의 공격 1회당 피해량은 모두 **1**, 타일 시작·최대 내구는 **4**다. 이 피해량은 **사용자가 아직 정하지 않은 미정값을 이번 시험에만 채운 임시 제안**이다. 이전 보스의 `도착 칸 피해2`를 자동 승계하지 않는다. 일반 손님은 **최종 도착 칸만 1회**, 보스는 **이동 중 방문한 매 칸을 실제 방문 횟수만큼** 공격한다. 공격 전에 마지막 ♥가 없어졌다면 한 번도 공격하지 않는다.

**[MVP 시험 전제]** 일반 손님 사이에는 타일 손상을 자동 회복시키지 않는다. 보스를 격퇴하면 **살아 있는** 타일의 내구를 4로 회복시키는 이전 MVP 시험안을 유지한다. **일반 영업간 손상 지속·보스 후 회복 시점은 정식 미정**이므로, 인간 테스트 전 재확인할 사항이다. 이미 파괴된 타일은 이번 판에서 자동 복구하지 않는다.

## 4. 상태 판정

| 상태 | 역할 | 대표 입력 |
|---|---|---|
| **불안** | 아직 일어나지 않은 일을 예고받은 걱정 | 접객원·안내판 |
| **환청** | 출처를 찾을 수 없는 목소리 | 녹음기사·라디오 |
| **기시감** | 일어나지 않은 일이 이미 기록된 것 같은 기억 | 특정 융합 괴이 |
| **봉인** | 걱정·소리·기억을 봉합한 흔적 | 특정 융합 괴이 |

상태 4종의 기본 상한은 각 **9**, 비음수 정수, 자연 감소 없음. **공포 게이지·심장 토큰·경영 재화는 상태가 아니다.** 심장마비로 공포가 0이 되어도 상태는 유지된다.

- **최대 n 소비:** 실제 상태량 내에서 소비. **정확히 n 필요:** 부족하면 불발. **참조:** 상태 감소 없음.
- **1:1 변환:** 출력 여유가 있는 만큼만 입력 소비. **1→2 생성/서로 다른 두 상태 생성:** 완전한 묶음만 허용.
- 공포 수확 효과는 **현재 공포 게이지를 증가**시킬 뿐, 초과 재화는 **심장마비가 발생하는 순간**에만 정산한다.
- `심장 부담 +1`, `심장 부담 −2` 등의 과거 표기는 현재 능력에 남겨두지 않는다.
- 한 타일의 통과 효과에서 실제 변환량을 `q`로 기록하는 경우 그 방문에서 **해당 타일 자체가 바꾼 양만** 도착 효과에 사용한다.

## 5. 직원 5종 — 새 발동 방식

**[콘텐츠 제안]** 비용은 모두 2. 한 카드로 한 슬롯에 **이번 턴**의 통과·도착 효과를 붙이고 그 슬롯의 실제 방문 때만 발동한다.

| 코드·직원 | 핵심 행동 | 통과 효과 | 도착 효과 |
|---|---|---|---|
| **S 접객원** | 예고 | 불안 +2 | 없음 |
| **R 녹음기사** | 재생 | 환청 +2 | 없음 |
| **K 기록원** | 기록·대조 | 없음 | 부착 시 지정한 상태 1종을 최대2 참조 → 1개당 공포+2. 상태 소비 없음 |
| **H 봉합사** | 타일 봉합 | **부착한 슬롯의 살아 있는 시설·괴이 내구 +2**, 최대4(일반·보스 공통) | 없음 |
| **C 교환원** | 전환·중계 | 불안 최대2 → 환청 1:1 변환 | 없음 |

**봉합사 개정은 새로운 제안**이다. 기존 일반 손님 `심장 부담 −2`는 완전 폐기했으며 일반/보스 모두 **그 타일 자체**를 회복한다. 이미 온전하거나 빈 슬롯이면 효과 0, 미리 보호막을 쌓지 않는다. 기록원의 빈 슬롯 도착 공포 수확은 유지하되, 그것만으로 ♥ 제거와 재화를 보장하지 않는다.

## 6. 고정 융합 조합 10쌍·괴이 30종

모든 괴이는 **영구 배치 자산**, 슬롯 1개, 시작·최대 내구도 **4**다. 매번 실제 방문 시 명세대로 작동하며, 직원처럼 턴말 제거되지 않는다. 공급형·지원형이 도착 효과를 갖지 않아도 허용한다. 표에 없는 효과·추가 소비·이동·소환·부활은 없다.

**획득:** 각 쌍에서 선택한 한 종류의 타일 1개. 직원 선택 순서는 무관하고 같은 쌍의 후보를 재추첨하지 않는다. 같은 괴이를 다시 제작할 수 있지만 매번 새로운 직원 두 개체를 소모한다.

| 조합 | 고정 후보 ① | 고정 후보 ② | 고정 후보 ③ |
|---|---|---|---|
| **S+R 접객원+녹음기사** | SR1 대답하는 벽 | SR2 금지된 안내방송 | SR3 오지 않은 호출 |
| **S+K 접객원+기록원** | SK1 미리 적힌 투숙기록 | SK2 빈 이름의 명부 | SK3 반복되는 첫날 |
| **S+H 접객원+봉합사** | SH1 봉합된 비상구 | SH2 안심을 꿰매는 손 | SH3 문밖에 남은 불안 |
| **S+C 접객원+교환원** | SC1 잘못 연결된 프런트 | SC2 먼저 접수된 민원 | SC3 나에게 돌아온 안내 |
| **R+K 녹음기사+기록원** | RK1 목소리의 투숙대장 | RK2 삭제된 녹취록 | RK3 원본 없는 증언 |
| **R+H 녹음기사+봉합사** | RH1 입을 꿰맨 라디오 | RH2 봉합선의 합창 | RH3 무음 치료실 |
| **R+C 녹음기사+교환원** | RC1 혼선 교환대 | RC2 수신자 없는 통화 | RC3 지난밤의 발신자 |
| **K+H 기록원+봉합사** | KH1 봉합 진료기록 | KH2 흉터 보관함 | KH3 지워지지 않는 병력 |
| **K+C 기록원+교환원** | KC1 반송되는 고해실 | KC2 수취인이 바뀐 장부 | KC3 접수되지 않은 고백 |
| **H+C 봉합사+교환원** | HC1 통증 교환실 | HC2 감각이 바뀐 치료실 | HC3 이송되는 봉합선 |

아래는 모두 **시연용 신규 명세**다. 법칙·사건 설명은 판정 외의 숨은 효과를 추가하지 않는다. 과거 기록에 등장한 이름도 여기의 입력·수치·발동으로 다시 평가한다.

### 6.1 S+R — 예고가 손님의 목소리로 재생된다

접객원의 ‘앞으로 겪을 일’이 녹음기사의 재생 내용이 된다. **걱정을 목소리로 바꿔 수확할지, 목소리를 남겨 둘지, 이미 겪은 기억으로 넘길지**가 후보의 차이다.

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **SR1 대답하는 벽** — 안내받고 걱정한 일을 벽 속 자신의 목소리가 대답한다 | 불안 **정확히 1** 소비 → 환청 **2**. 출력 공간 2 필요 | 환청 최대 2 소비 → 1개당 공포 4 | 불안에서 바로 환청 수확으로 연결. 후방에 남길 환청은 소비될 수 있음 |
| **SR2 금지된 안내방송** — 걱정하던 경고가 이미 들었던 안내방송으로 확인된다 | 없음 | **불안 1 이상일 때** 환청 최대 2 참조 → 1개당 공포 2. 두 상태 모두 소비 없음, 추가 부작용 없음 | 작은 수익을 얻고 두 입력을 다음 방에 보존. 불안과 환청을 따로 마련해야 함 |
| **SR3 오지 않은 호출** — 아직 받지 않은 호출을 이미 들었다는 기억이 생긴다 | 불안 **1과 환청 1**을 함께 소비 → 기시감 **2**. 두 입력·출력 공간 모두 필요 | 없음 | 기본 두 상태로 기시감 경로 개방. 자체 수확 없음 |

입력은 안내판·라디오로 마련할 수 있다. SR3을 만드는 데 두 공급 직원이 사라져도 이 시설들은 남는다. SR2의 불안 조건은 참조이므로 불안을 1개 소비하는 것으로 처리하지 않는다.

### 6.2 S+K — 예고가 이미 기록된 사실이 된다

접객원의 예고를 기록원이 대조 가능한 과거로 확정한다. **불안을 기록으로 저장하거나, 기록되지 않은 불안만 드러내거나, 기록을 다시 미래의 걱정으로 돌린다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **SK1 미리 적힌 투숙기록** — 처음 방문했는데 장부에는 이미 머문 기록이 있다 | 불안 최대 2 → 기시감 1:1 변환 | 없음 | 안내판으로 기시감 공급 가능. 당장의 불안 수확 입력을 줄이며 자체 수확은 없음 |
| **SK2 빈 이름의 명부** — 장부로 설명되지 않는 걱정만 빈 이름을 채운다 | 없음 | `n = min(2, max(불안−기시감, 0))`. 불안 n 소비 → 공포 4n | 기시감보다 많은 불안을 수익으로 사용. 기시감을 앞에서 늘리면 수확 가능량 감소 |
| **SK3 반복되는 첫날** — 기록된 첫날을 읽자 같은 일이 다시 일어날 것이라 예상한다 | 없음 | 기시감 최대 2 참조하여 n 결정 → **불안 +n**, 이어 공포 **2n**. 기시감 소비 없음 | 기시감을 보존하며 후방 불안 수확을 준비. 기시감 공급원이 없으면 작동하지 않음 |

SK2는 불안과 기시감을 둘 다 소비하는 카드가 아니다. SK3의 불안은 직접 부여이므로 상한 초과분만 버리며, 불안 상한 때문에 참조 수익을 취소하지 않는다. 기시감은 SR3·RK1·SC2 등 다른 쌍에서도 마련할 수 있다.

### 6.3 S+H — 예고받은 걱정을 봉합한다

봉합사가 접객원의 예고를 없애는 대신 형태를 갖춘 봉인으로 꿰맨다. **봉인을 열어 수확하거나, 실제 회복의 흔적으로 남기거나, 아직 남은 불안과 함께 대면한다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **SH1 봉합된 비상구** — 걱정을 문틈에 꿰맸는데 나가려 하자 안쪽에서 열린다 | 불안 최대 2 → 봉인 1:1 변환 | 봉인 최대 2 소비 → 1개당 공포 4 | 기본 불안 공급만으로 봉인 수확까지 연결. 봉인을 후방에 남기는 선택과 경쟁 |
| **SH2 안심을 꿰매는 손** — 걱정을 봉합재로 써 손상된 이 방을 고친 만큼 봉인 흔적이 남는다 | **불안 최대 2를 자기 타일에서 실제 회복할 수 있는 양만큼 소비**하여 내구를 같은 양 회복하고 봉인을 같은 양 부여. 아래 상세식 적용 | 없음 | 손상된 타일의 자가 수리와 봉인 준비를 연결. 자기 타일이 온전하면 공급되지 않음 |
| **SH3 문밖에 남은 불안** — 꿰매 넣었던 걱정과 아직 남은 걱정이 문 양쪽에서 만난다 | 없음 | 불안 **1과 봉인 1**을 함께 소비 → 공포 **8**, 추가 부작용 없음 | 혼합 입력으로 혼합 수확. 봉인만 많이 공급해서는 작동하지 않음 |

**SH2 상세(개정 제안):** 일반 손님·보스 모두 `n=min(2, 불안, 4−이 괴이 내구, 9−봉인)`으로 계산한다. 불안 n 소비 → **이 타일 내구 +n** → 봉인 n 부여. 자기 타일이 온전하거나 출력 공간이 없으면 불안을 소비하지 않는다. 기존 폐기된 부담 회복 분기는 이 능력으로 이어지지 않는다.

SH1은 자기 통과 변환으로 불안을 모두 없앨 수 있다. 그 뒤 SH3까지 연결하려면 불안 재공급이나 남길 양이 필요하다. ‘같은 테마의 괴이’라는 이유로 자동 연계된다고 보지 않는다.

### 6.4 S+C — 안내가 잘못된 수신자에게 돌아온다

접객원의 안내가 교환원의 연결로 다른 의미를 갖는다. **들린 목소리를 다시 걱정으로 돌리거나, 걱정 하나를 목소리와 기억으로 나누거나, 두 흔적을 함께 대면한다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **SC1 잘못 연결된 프런트** — 남의 목소리인 줄 알았던 안내가 자신의 예정된 일로 연결된다 | 환청 최대 2 → 불안 1:1 변환 | 없음 | 라디오 입력을 기본 불안 수확에 연결. 환청 수확보다 앞에 놓으면 그 입력을 빼앗음 |
| **SC2 먼저 접수된 민원** — 아직 말하지 않은 걱정이 자기 목소리의 ‘이미 접수된 민원’으로 돌아온다 | 불안 **1** 소비 → 환청 **1**과 기시감 **1**. 두 출력 모두 공간 필요 | 없음 | 한 입력을 두 종류로 분할해 혼합·참조 경로 준비. 직접 수확은 없고 한 번에 하나의 묶음만 처리 |
| **SC3 나에게 돌아온 안내** — 자신에게 건넨 경고를 내선 끝의 자신이 대답한다 | 없음 | 불안 **1과 환청 1**을 함께 소비 → 공포 **8** | 두 기본 시설만으로 혼합 수확 가능. 한 종류만 남기는 변환과 충돌 |

SC2는 다른 방의 사건을 재현하거나 다음 칸에 원격 발동하는 능력이 아니다. 현재 방문자의 상태만 바꾸며, 새 상태는 방문자가 실제 이동하면서 가져간다.

### 6.5 R+K — 목소리가 기록과 대조된다

녹음기사의 소리를 기록원이 과거의 증거로 다룬다. **목소리를 기억으로 바꾸거나, 지워진 목소리를 수확하거나, 남아 있는 두 증거의 일치를 참조한다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **RK1 목소리의 투숙대장** — 낯선 목소리가 자신의 과거 투숙 기록으로 정리된다 | 환청 최대 2 → 기시감 1:1 변환 | 없음 | 라디오에서 기시감 경로 개방. 환청은 줄어들며 자체 수확 없음 |
| **RK2 삭제된 녹취록** — 지웠다는 기록만 남은 목소리를 손님이 다시 알아듣는다 | 환청 최대 2 제거. **실제 제거량 q** 기록 | **이번 방문의 q×4** 공포 | 현재 남은 환청이 아니라 지운 양을 수확. 도착하지 않고 지나치면 제거만 일어남 |
| **RK3 원본 없는 증언** — 들리는 목소리와 자기 기억이 일치하지만 원본은 존재하지 않는다 | 없음 | `n=min(2, 환청, 기시감)`을 참조 → 공포 **3n**. 두 상태 소비 없음 | 두 입력을 보존하는 혼합 참조, 최대 6. 환청이나 기시감 한쪽만 있으면 불발 |

RK2에서 녹음기사 효과를 **같은 칸**에 붙이면 괴이의 제거가 먼저, 직원의 환청 공급이 나중이다. 따라서 그 직원이 새로 만든 환청은 이번 q에 포함되지 않는다. 제거량을 늘리려면 실제 경로의 더 앞칸에 공급해야 한다.

### 6.6 R+H — 봉합한 목소리와 사라진 소리를 재생한다

봉합사가 소리를 가두고, 녹음기사는 봉합선이나 회복 뒤의 침묵을 재생한다. **목소리를 보관하거나, 보관물을 열어 수확하거나, 실제 회복을 새로운 소리의 원인으로 만든다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **RH1 입을 꿰맨 라디오** — 재생되는 목소리를 봉합선 안에 가둔다 | 환청 최대 2 → 봉인 1:1 변환 | 없음 | 라디오를 봉인 공급으로 전환. 자체 수확 없음 |
| **RH2 봉합선의 합창** — 봉합선을 열자 가둔 목소리가 여러 곳에서 돌아온다 | 없음 | 봉인 최대 2 → 환청 1:1 변환. **실제 변환량 n당 공포 3** | 수확하면서 후방 환청을 준비. 환청이 상한이면 변환·연동 수익 감소 |
| **RH3 무음 치료실** — 방의 상처가 꿰매질 때 사라진 소리가 다시 흘러나온다 | **자신의 내구도를 최대 2 회복**, 실제 회복량 q만큼 **환청 +q** (일반·보스 동일) | 없음 | 손상된 방일 때만 회복과 환청 공급이 연결됨 |

RH3은 회복이 먼저이며 환청의 초과분은 버린다. 환청 상한을 이유로 이미 가능한 회복을 막지는 않는다. RH2는 반대로 봉인이 환청으로 **변환되는 능력**이므로 출력 공간만큼만 입력을 소비한다.

### 6.7 R+C — 재생과 연결이 소리의 출처를 바꾼다

교환원이 넘긴 입력을 녹음기사가 여러 목소리로 재생하거나, 되돌아온 통화를 다른 상태로 받는다. **입력을 소비해 증폭하거나, 음성을 걱정으로 반송하며 수확하거나, 기억을 보존한 반복 공급을 만든다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **RC1 혼선 교환대** — 한 사람의 걱정이 서로 다른 두 발신자의 목소리로 분리된다 | 불안 최대 2 소비, **1개당 환청 2**. 출력 두 개가 들어가는 묶음만 처리 | 없음 | 불안에서 많은 환청을 빠르게 준비. 불안 수확 입력을 소모하며 자체 수확은 없음 |
| **RC2 수신자 없는 통화** — 듣던 목소리를 돌려보냈더니 아직 일어나지 않은 자기 일의 경고가 된다 | 없음 | 환청 최대 2 → 불안 1:1 변환. **실제 변환량 n당 공포 3** | 환청 수확과 후방 불안 공급을 연결. 불안이 상한이면 입력·수익 제한 |
| **RC3 지난밤의 발신자** — 이미 겪은 기억을 지우지 않고 그때의 목소리만 다시 연결한다 | 기시감 최대 2 참조 → 같은 양 환청 부여. 기시감 소비 없음 | 없음 | 기시감을 남기는 반복 공급 경로. 먼저 기시감 공급원이 있어야 하며 자체 수확은 없음 |

RC3은 과거 효과·카드를 복제하지 않는다. 현재 기시감 수만 참조해 환청을 생성하는 한 번의 통과 효과다. 실제 별도 발신자나 소환물도 생기지 않는다.

### 6.8 K+H — 회복하거나 봉합한 흔적이 기록으로 남는다

봉합사가 없애거나 가둔 것이 기록원의 증거가 된다. **실제 회복량을 수확하거나, 기억을 봉인하거나, 기억과 봉합 흔적을 함께 읽는다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **KH1 봉합 진료기록** — 손상된 방을 수리한 내역이 기록되며 그 회복량만큼 공포가 생긴다 | **자신의 내구도 최대 2 회복**, 실제 회복량 q 기록(일반·보스 동일) | **이번 방문의 q×4** 공포 | 타일의 실제 손상을 고친 양으로 수확. 회복 여지가 없거나 도착하지 않으면 공포 0 |
| **KH2 흉터 보관함** — 과거의 기억을 꿰매어 몸에 남는 흔적으로 보관한다 | 기시감 최대 2 → 봉인 1:1 변환 | 없음 | 기시감 엔진을 봉인 엔진으로 연결. 자체 수확 없음 |
| **KH3 지워지지 않는 병력** — 기억과 봉합 흔적이 같은 사건을 가리키자 지워진 상처가 증명된다 | 없음 | 기시감 **1과 봉인 1**을 함께 소비 → 공포 **8**, 추가 부작용 없음 | 두 심화 상태로 안전 수확. 두 상태의 공급을 각각 확보해야 함 |

KH1의 q에는 같은 칸에 붙인 봉합사 카드의 후속 회복을 합산하지 않는다. 직원 회복을 더 앞칸에 쓰면 오히려 KH1이 회복·수확할 양을 줄일 수 있다. 이 상충도 명세대로 처리한다.

### 6.9 K+C — 연결된 기록과 연결되지 않은 기록을 다르게 처리한다

교환원의 전달을 기록원이 결과·수신자·누락으로 대조한다. **실제 전달한 양을 수확하거나, 상태의 수신자를 바꾸거나, 전달되지 않은 차이만 읽는다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **KC1 반송되는 고해실** — 넘겨버린 걱정이 자신의 목소리와 접수 기록으로 돌아온다 | 불안 최대 2 → 환청 1:1 변환. 실제 변환량 q 기록 | **이번 방문의 q×4** 공포. 환청 추가 소비 없음 | 변환 과정 자체를 수확하고 환청은 후방에 남김. 이미 가진 환청만으로는 도착 수확하지 못함 |
| **KC2 수취인이 바뀐 장부** — 장부의 두 수신자가 바뀌어 걱정과 목소리의 양이 뒤바뀐다 | 현재 **불안과 환청의 수량을 동시에 교환** | 없음 | 두 상태 비율을 크게 뒤집어 기존 경로 재활용. 적합한 공급 순서를 되돌려 버릴 수도 있음 |
| **KC3 접수되지 않은 고백** — 목소리로 전달되지 못한 걱정의 차이만 장부에 남는다 | 없음 | `n=min(2, max(불안−환청, 0))` 참조 → 공포 **3n**. 상태 소비 없음·추가 부작용 없음 | 불안을 남기며 초과분 수확. 환청을 앞에서 많이 공급·변환하면 오히려 수익 감소 |

**KC2의 값 교환은 이 괴이만의 콘텐츠 제안**이다. 교환 전 불안 3·환청 1이면 이후 불안 1·환청 3이다. 둘 다 0~9라 별도 초과가 없고 합계는 유지된다. 입력·출력을 두 번 순차 대입하거나 복제하는 처리가 아니며, 기시감·봉인은 바꾸지 않는다. 같은 효과를 두 번 연속 받으면 원래 비율로 돌아갈 수 있다.

**KC1은 예전 이름을 재사용했지만 새 명세다.** 예전 시연의 ‘변환 후 환청 소비 수확’을 혼용하지 않는다. 여기서는 자기 통과 변환량 q로 수확하고 그 환청은 소비하지 않는다.

### 6.10 H+C — 봉합한 것을 다른 상태·대상으로 넘긴다

교환원이 봉합사의 처리 대상과 결과를 옮긴다. **봉인을 걱정으로 풀거나, 목소리를 봉합 재료로 바꾸어 회복하거나, 봉합선을 다음 타일에 전달한다.**

| 괴이·법칙과 사건 | 통과 효과 | 도착 효과 | 선택 이유와 포기하는 것 |
|---|---|---|---|
| **HC1 통증 교환실** — 가둔 흔적을 풀었더니 앞으로 겪을 일의 걱정으로 바뀐다 | 봉인 최대 2 소비, **1개당 불안 2**. 출력 두 개가 들어가는 묶음만 처리 | 없음 | 봉인 경로를 기본 불안 수확에 다시 연결. 봉인을 쓰는 다른 후속 효과와 경쟁 |
| **HC2 감각이 바뀐 치료실** — 들리던 목소리를 이 방을 수리할 봉합 재료로 삼는다 | 환청 **정확히 2** 소비 → 봉인 **1**, 이어 **자신의 내구도 최대 2 회복**(일반·보스 동일) | 없음 | 환청을 봉인과 타일 회복으로 변환. 환청 1개로는 불발하며 RH1보다 봉인 수율이 낮음 |
| **HC3 이송되는 봉합선** — 여기의 봉합선을 다음 객실로 연결한다 | 봉인 **1** 소비 → **바로 다음 슬롯의 살아 있는 타일** 내구 최대 2 회복. 일반·보스 공통. 실제 회복 여지가 있어야 봉인 소비 | 없음 | 다음 슬롯을 보존하는 지원. 직접 공포 수확은 없고 봉인 공급 필요 |

HC2는 환청 2와 봉인 공간 1이 모두 있어야 전체 효과를 실행한다. 회복할 손상이 없어도 변환은 가능하다. 반대로 변환할 수 없으면 회복만 무료로 실행하지 않는다.

**HC3의 인접 회복은 이 괴이만의 개정 콘텐츠 제안**이다. 일반 손님과 보스에서 ‘바로 다음’은 이동 방향의 다음 슬롯 하나이며 N 다음은 1이다. 빈칸·온전한 타일·파괴된 타일이면 봉인을 소비하지 않는다. 건너뛰어 다른 타일을 찾지 않으며, 방문자의 위치·이동·도착·공격 대상을 바꾸지 않는다. 기존 일반 영업의 심장 부담 회복 분기는 폐기한다.

### 6.11 입력 공급과 재료 소모의 점검

| 필요한 입력 | 재료 직원을 다시 확보하지 않고도 사용할 경로의 예 |
|---|---|
| 불안 | 기본 안내판 / SC1의 환청→불안 / RC2의 도착 변환 / SK3·HC1 |
| 환청 | 기본 라디오 / SR1·RC1·KC1의 불안 변환 / RH2·RH3·RC3 |
| 기시감 | 안내판→SK1 / 라디오→RK1 / 두 기본 상태→SR3 / 불안→SC2 |
| 봉인 | 안내판→SH1 / 라디오→RH1 / 기시감→KH2 / RH·HC 관련 경로 중 조건을 충족하는 것 |
| 타일 손상 | 일반 손님은 도착 칸, 보스는 모든 방문 칸을 방문 횟수만큼 공격한다. 타일 내구가 줄어든 뒤 회복형 괴이를 활용할 수 있음 |

이 표는 **목록 전체에 대체 경로가 있다는 구조 점검**이다. 한 판에서 모든 타일이 무료로 제공되거나 항상 제작 가능하다는 보장은 아니다. 필요한 쌍·자금·슬롯·모집 기회가 실제로 남는지 따로 확인한다. 기시감·봉인을 사용하는 후보를 보여 줄 때에는 현재 호텔에 입력이 있는지와 아직 필요한 자산을 함께 알린다.

30종의 형식을 채웠다는 사실만으로 24개 체크리스트를 모두 충족했다고 표시하지 않는다. 특히 두 직원의 기여가 플레이어에게 납득되는지, 서로 다른 후보가 실질적인 대안인지, 제작 후 호텔이 달라지는지는 **플레이 검증 대기**다.

## 7. 방문자·공격·종료와 재설계

### 7.1 일반 손님 5명 — 임시 시험 구성

아래 **공포 한계와 ♥ 수는 사용자 확정 숫자가 아닌 최초 시험값 제안**이다. 심장 토큰 기본 1~3개, 한계 수치 차별화 원칙을 사용한다.

| 일반 손님 | 심장 토큰 H | 토큰당 공포 한계 T | 매 턴 공격 |
|---|---:|---:|---|
| 1번째 | **1** | **12** | 최종 도착 칸 피해 1 |
| 2번째 | **2** | **12** | 최종 도착 칸 피해 1 |
| 3번째 | **1** | **16** | 최종 도착 칸 피해 1 |
| 4번째 | **2** | **16** | 최종 도착 칸 피해 1 |
| 5번째 | **1** | **20** | 최종 도착 칸 피해 1 |

- 입장 상태는 공포0, 상태 4종0, 최초 위치0, 위 표의 ♥로 시작한다. 심장마비 후 **공포만 0 리셋**하고 상태는 그대로다.
- 최종 토큰 제거 후 **사망·영업 종료**한다. 이는 정상적인 영업 성공이다. `생존 퇴장·사망 시 수익 몰수·경찰 의심도`는 존재하지 않는다.
- **[MVP 시험 제안]** 공포 생산 불능으로 처치할 수 없거나 계속 돌아서 일반 손님 영업이 끝나지 않으면 **12턴 종료를 실패 진단값**으로 둔다. 이는 게임의 정식 실패 규칙이 아니라 **자동 시연 무한 반복 방지 장치**다. 손님이 12턴째 마지막 ♥를 제거하면 성공으로 끝낸다.

### 7.2 보스 — 한계 45, 심장 토큰 1개(최초 시험안)

| 항목 | v0.2 적용 또는 결정 상태 |
|---|---|
| 보스 이름 | 호텔 감찰관(임시) |
| 토큰당 공포 한계 | **45**. 기존 v0.1의 **한 번 채우는 목표 공포45**를 **토큰당 한계로 재사용한 시험 해석**. 새 규칙의 확정 수치가 아님 |
| 심장마비 토큰 | **1개**(시험값). 방문자 기본 범위 1~3 내. 2~3개 보스는 후속 시험 |
| 공격 | 실제 방문한 **모든 슬롯**, 반복 방문하면 그 슬롯 **또 한 번**. 방문 1회당 **피해1**(시험값) |
| 이동 | 1d6 K=3 중 하나 선택, 일반 손님과 동일한 원형 루프 반복 이동 |
| 공포·상태 | 공포0·상태0으로 시작. 심장마비 후 공포0, 상태 유지. 마지막 ♥ 제거 시 격퇴 |
| 덱 소진 | 일반 손님과 동일: 이번 턴 주사위 개수−1, 셔플 후 부족한 드로우 재개 |
| 턴 제한 | **8턴**(이전 MVP 시험값의 잠정 유지) |
| 승리 | 마지막 ♥ 제거 시 즉시 격퇴·남은 이동·효과·공격 중단 |
| 실패 후보 | 8턴 후 토큰 남음 → 시간 초과, 더 이상 어떤 타일/직원으로도 공포 생산 불가 → 생산 불능 |
| 보스 보너스 | 격퇴 시 기존 시험값 **재화+20** 추가(재화가 초과 공포에서도 이미 발생할 수 있음을 분리 기록). 최종 채택 미정 |

**주의:** 보스는 한 턴에 여러 칸을 공격하므로 기존의 `한 턴 도착 한 칸에 피해2`와 피해 총량이 크게 다르다. **현재 피해1·♥1·T45·8턴 조합은 밸런스 검증 전**이며, 실패해도 목표나 주사위를 몰래 바꾸지 않는다.

**반복 방문 예:** N=4, 보스가 ①→②→③→④→①→② 여섯 칸을 실제 방문하면 **총 여섯 번 공격 시도**. ①·②는 각각 두 번 피해를 받는다. 다만 **최종 도착 ②에 통과+도착 효과가 있다는 이유만으로 마지막 ②에 두 번 추가 타격을 가하지 않는다.** 모든 공격은 이동·효과가 끝난 뒤 살아 있을 때 처리한다.

### 7.3 시설 손상·종료

- 영구 타일은 시작·최대 내구 **4**. **피해량은 일반/보스 각각 이번 시험에서 1**. 파괴될 때 해당 타일을 이번 판에서 제거하되 슬롯은 남는다.
- 일반 손님 공격은 매 턴 **도착 한 칸 1회**. 보스는 **실제 방문 경로 전체**의 각 방문마다 1회.
- **[MVP 시험 운영]** 공격은 타일 효과 처리 후, 마지막 ♥가 남은 경우에만 이동 중 방문 순서대로 적용한다. 타일이 앞선 타격으로 파괴되어 빈칸이 되었으면 같은 슬롯의 후속 타격은 빗나간다.
- 경영 단계에 타일을 무료 보관·재배치할 수 있다. 이번 판에서 파괴된 타일은 자동 복원하지 않는다.
- **보스 격퇴 후 살아 있는 타일은 내구4 회복**, 일반 손님 사이에는 자동 전부 회복 없음(둘 다 이번 설정의 **잠정 운영안**). 회복·수리의 일반 규칙은 사용자가 아직 확정하지 않았다.
- 공포 생산 불능 여부는 현재 **잠긴 직원 덱의 빈칸 기록원 수확, 살아 있는 시설·괴이, 방문자에게 남은 상태**까지 고려한다. 단지 수확 타일 하나가 없어졌다고 불능을 선언하지 않는다.

## 8. 텍스트 진행 방식과 공개 정보

### 8.1 진행자 역할

난수는 현재 단계에서만 뽑는다. 사용자 선택 시 사용자가 경영·융합·배치·주사위·직원 사용을 결정한다. 자동 시연 요청에서는 진행자가 선택도 하되 **선택 근거를 기록하고 사람의 재미 검증으로 해석하지 않는다**. 이미 공개된 덱·주사위 결과는 유리한 결과를 위해 다시 뽑지 않는다.

### 8.2 필요한 턴별 정보

| 시점 | 공개하거나 기록할 것 |
|---|---|
| 시작 | 손님/보스, 현재 공포/한계, ♥ 개수, 4상태, 슬롯·타일 내구, 덱/버림 더미 수 |
| 드로우 | 실제 뽑은 카드, 소진 여부·셔플 후 **보충 드로우**, 이번 턴 실제 굴릴 주사위 개수 |
| 주사위 | 후보 눈 전부, 각각 경로·최종 도착·마나·일반/보스의 공격 대상 **방문 순서와 중복 횟수** |
| 직원 | 카드 개체·비용·부착 칸·선택 상태, 실제 발동 예상 조건, 남은 마나 |
| 이동 | 각 슬롯의 영구 통과 → 직원 통과 → (도착 때만) 영구 도착 → 직원 도착, 실제 공포/상태 변화 |
| 심장마비 | F/T, ♥ 제거, **초과 공포와 즉시 재화 증가**, 공포0 리셋, 남은 ♥와 이동 계속 여부 |
| 공격·종료 | ♥가 남으면 일반 도착1회/보스 방문 횟수대로 타격. 피해 후 내구, 파괴, 사망·격퇴·실패·턴말 임시 부착 제거 |
| 경영 | 누적 **초과 공포 재화**, 실제 잔액, 시설·직원 구매 비용, 융합 직원 소모, 손실과 새 배치 |

미래 덱/주사위/모집 후보는 보여주지 않는다. 입력이 0인 카드도 이동 중 입력이 생길 수 있으면 부착할 수 있으며, 실제 타일 발동의 결과는 당시에 확인한다. 공포 증가량과 경영 재화 증가량을 혼동하지 않는다.

## 12. 동일 슬롯 재방문 공격의 별도 진단 장면 — 메인 설정 외

**이 항목은 실제 한 판의 호텔 길이·주사위 면수를 바꾸지 않는 별도 시험 장면이다.** 설정9 v0.2의 정상 호텔은 **최소 6칸이고 1d6 최대 이동은 6칸**이므로, 일반 플레이에서는 **한 이동 중 동일 슬롯을 두 번 밟는 경우가 나오지 않는다**. 사용자 확정 규칙인 '보스는 두 번 방문하면 두 번 공격'을 검증하려면 아래의 별도 장면이 필요하다.

- **진단 전용 조건:** 슬롯 ①②③④(내구 모두4), 보스 위치 경계0, 공포 한계와 토큰은 진단 중 처치되지 않도록 충분히 설정, 카드·타일 공포 효과 없음, 이동 눈6, 방문 1회당 피해1.
- **실제 방문 경로:** `① → ② → ③ → ④ → ① → ②`.
- **기대 공격:** `①1회, ②1회, ③1회, ④1회, ①2회째, ②2회째` — 총 **6회 공격**.
- **기대 내구:** ①·②는 **2/4**, ③·④는 **3/4**.
- **주의:** 최종 도착 ②에서 통과/도착 효과가 둘 다 있다고 해도 **마지막 ② 방문 자체는 공격 한 번**이다. 첫 번째 ② 방문은 별도로 한 번 공격받기 때문에 합계 두 번이다.

이 장면은 **반복 방문에 따른 공격만** 시험한다. 같은 이동에서 직원의 임시 효과가 재통과 때 다시 발동하는지의 정식 판정은 별도의 미정 규칙이다.
