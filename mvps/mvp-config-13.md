# Dread-to-Dead: Fears Go Round — 설정 13 공급·수확·수비 도착지 경쟁 실험

> v0.1 · 2026-10-31 · **실행 전 시험안.** [현행 규칙](../rules.md)을 적용한다. 시험 수치·콘텐츠·운영·확정 계산은 [설정 13 명세](../undecided.md#u-mvp13)에 둔다. 이 문서 작성은 구현·플레이·재미 검증의 완료를 뜻하지 않는다.

## 1. 검증 질문

**불안·처치까지의 거리·괴이의 위험·액티브 잔량이 달라지면, 같은 호텔에서도 도착하고 싶은 층과 그 이유가 바뀌는가?**

설정 12에서는 U를 경유해 공급을 받으면서 Q에 도착해 수확할 수 있었고, U 자체의 도착 공급은 통과보다 작았다. G/R에는 도착 효과가 없었다. 따라서 수확 가능한 눈을 고르는 판단은 있었어도, 다른 역할의 괴이를 적극적으로 발동시키려고 멈출 이유는 약했을 수 있다. [실제 진행 기록](../mvp_text_12/runs/playthrough.md)은 이 가설의 출발점이며 도착 욕구나 재미를 입증한 인간 표본은 아니다.

| 경쟁할 도착 목적 | 원하는 이익 | 함께 보는 비용 |
|---|---|---|
| U 공급 | 통과보다 많은 불안을 남겨 다음 수확 준비 | 현재 공포 진행을 미루고 반격을 받음 |
| Q 수확 | 불안을 소비해 공포·처치 진행 | 남는 불안 감소, 처치하지 못하면 반격 |
| G 수비 | 이번 공격의 실제 피해를 막거나 원격 방어 횟수를 보존 | 당장 수확을 미룸, 다른 괴이의 피해는 남을 수 있음 |

**세 역할을 비슷한 횟수로 고르거나 매 턴 오래 고민하는 것이 목표가 아니다.** 계산으로 좋은 답을 찾는 것, 잘 만든 호텔 덕분에 쉽게 고르는 것은 실패가 아니다. 상태가 달라져도 늘 같은 역할만 원하는지, 다른 도착지의 이익을 자발적으로 원하게 되는지를 확인한다.

불리해져 선택지가 줄어드는 것 자체도 결함으로 판정하지 않는다. 위기에 대응하는 구간과 결과가 이미 정해진 뒤 입력만 반복하는 구간을 구분한다. 설정 12의 수확 불가 두 턴만으로 후자를 확정하지 않는다.

## 2. 범위와 비교 구조

| 항목 | 실행 기준 |
|---|---|
| 공통 호텔·손님·초기화·상한 | [운영 명세](../undecided.md#u-mvp13-setup) |
| U/G 변경, Q/B 유지, 효과 조합 4종 | [콘텐츠·비교군](../undecided.md#u-mvp13-content) |
| G 대상 선택·흡수·액티브와의 관계 | [세부 판정](../undecided.md#u-mvp13-effects) |
| 같은 상태의 역할 경쟁과 기대 계산 | [D0~D5 진단](../undecided.md#u-mvp13-diagnostics) |

- **주 실험은 U 도착 공급 강화와 G 도착 방어 추가다.** U 통과 공급, G 원격 액티브, Q 수확, B, 내구, 공포·공략 판정은 유지한다.
- 통제 진단에서는 기준 M0 / 공급만 MU / 수비만 MG / 둘 다 MUG를 비교한다. 정상 연속 운영은 M0와 MUG만 비교한다. 원인 분리가 필요하면 MU/MG의 연속 운영을 별도 후속 실험으로 추가한다.
- 모든 군에 같은 괴이를 지급하고 같은 배치를 쓴다. 구매·재배치·E/R을 포함하지 않아 목적지 변화의 원인을 좁힌다. 이는 획득·경영 규칙의 폐기가 아니라 이번 시험의 범위 제한이다.
- R 밸런스, 웹 경로·자리 경쟁, 영구 손실, 액티브 사용 시점 개편, 새로운 주사위 조작은 이번 수정 대상이 아니다. 불리한 상태의 입력 반복은 관찰만 한다.
- M0는 **설정 12 효과를 쓰는 설정 13의 공통 대조 조건**이다. 자산 지급·구매 절차가 다른 과거 정상 캠페인과 완주 턴을 직접 비교해 개선율을 계산하지 않는다.

## 3. 진행

### A. 진행자 판정 검사

D0~D5를 먼저 검산한다. 같은 시작 상태와 선택 눈에서 효과 조합만 바꿔 미리보기 결과를 비교한다. 손상·잔량·현재 눈을 강제한 진단은 정상 플레이와 분리한다. 결과가 맞지 않으면 선호를 분석하기 전에 판정을 수정한다.

D1은 다음 한 턴의 가능한 주사위 묶음 전체를 계산해 공급의 미래 이익을 확인한다. 유리한 후속 눈 하나를 골라 공급이 항상 우세하다고 주장하지 않는다. D3/D4는 보호가 가능한 경우와 즉시 처치로 보호가 불필요해지는 경우를 함께 본다. D5는 원격 액티브가 남아 있을 때도 도착 방어를 원할 이유가 있는지 확인한다.

**이 계산표와 특정 역할을 고르라는 해설은 참가자의 첫 플레이 전에 보여주지 않는다.** 능력·공격·현재 상태·선택 결과는 공개하되 정답 역할을 암시하지 않는다. 기대 계산은 규칙 검사용이며 참가자 선택의 정답표가 아니다.

### B. 정상 연속 운영

각 군을 동일한 고정 호텔로 시작해 영업 A의 V1→V2, 영업 B의 V3→V4를 진행한다. B/G는 정상 초기 횟수로 시작한다. 진단처럼 잔량을 미리 없애거나 손상을 넣지 않는다. 영업 사이에는 규정된 복구만 처리하고 구매·재배치는 하지 않는다.

매 턴 다음 순서로 기록한다.

1. **눈 공개 전:** 현재 위치에서 이동 거리 1~6을 자유롭게 고를 수 있다고 가정했을 때 원하는 도착층·이유·사용할 액티브 계획을 짧게 남긴다. 실제 경로의 통과 효과·공격은 그대로이며 순간이동을 가정하지 않는다. B·빈층·동률·특별한 희망 없음도 허용한다. 이 답은 실제 행동을 구속하지 않는다.
2. **눈 공개 후:** 현재 눈으로 갈 수 있는 도착층·효과·공격 결과를 확인하고 실제 선택·액티브·G 도착 보호 대상을 정한다. 희망층을 포기했다면 도달 불가 때문인지, 다른 선택의 이익 때문인지 기록한다.
3. **처리 후:** 예상과 실제 결과를 대조한다. 공급한 불안이 이후 수확에 쓰였는지, G가 실제 타격을 흡수했는지, 남긴 액티브가 후속 손님에서 쓰였는지를 추적한다.

죽인 턴의 방어 생략과 준비가 필요 없는 턴의 Q 선택은 정상적인 좋은 선택으로 기록한다. 지켜야 할 괴이가 있다는 이유만으로 G를 고르도록 유도하지 않는다. 괴이를 희생하고 다른 수확 지점으로 가는 계획도 유효한 대안이다.

### C. 같은 상태의 후속 비교

첫 선택 기록을 보존한 뒤 **MUG에서 다음 7개 분기**를 별도 통제로 이어간다. 후속 선택은 현재 공개 정보만 사용하는 같은 진행 방식과 정책 버전으로 수행하며 시작 전에 기록한다.

| 통제 | 강제 첫 선택 이후 이어갈 분기 | 확인할 후속 이익 |
|---|---|---|
| D1 | U 도착 / Q 도착 | 공급 준비와 지금 공포 중 무엇이 실제 처치 기회를 만드는지 |
| D3 | U 도착 / G 도착 / Q 도착 | 공급자를 희생하고 남긴 불안으로 수확하는 계획과 공급자를 지키는 계획의 차이 |
| D5 | Q 도착+원격 G1회 / G 도착+액티브0회 | 당장 공포와 남긴 방어 횟수의 실제 후속 쓰임 |

각 진단 손님은 그 분기의 영업 A 첫 손님으로 취급한다. 처치하면 같은 영업의 다음 손님 V2까지 추적한다. 이때 정상 손님 교체를 적용해 위치·F/A·괴이 C·임시 흡수를 초기화하고, P·B/G 잔량은 이월한다. 준비한 불안·보호한 괴이·D5에서 남긴 횟수가 각 유효 기간 안에서 실제로 쓰였는지 확인한다. 실패한 분기는 다음 손님으로 넘기지 않는다. 후속 난수는 D별로 짝을 맞추며 정상 캠페인과 합산하지 않는다.

인간의 첫 자발적 플레이는 정상 운영에서 기록한다. 이후 통제 상태를 보여주고 역할 비교를 요청한 선택은 **비교 안내 후 선택**으로 구분한다. 자동 분기·수동 AI 분기는 가능한 작동과 선택 이유의 자료이며 인간 선호로 세지 않는다.

### D. 난수와 반복

- seed는 시작 전에 **13001·13002·13003**으로 고정한다. 정상 운영은 seed별 M0/MUG 한 쌍, 총 6캠페인을 계획한다. 중단·미실행도 남기고 성공 사례로 대체하지 않는다.
- 주사위는 매 턴 독립 3d6이며 중복 눈도 그대로 쓴다. `seed / 정상 또는 진단ID / 손님ID / 해당 손님의 턴` 단위로 같은 묶음을 배정해 분기의 턴 수 차이가 다음 손님의 난수를 밀지 않게 한다. 비교군·선택은 난수 키에 넣지 않는다. 생성 방식·버전도 실행 전에 기록한다.
- D1/D3/D5 후속 비교는 seed 13001에서 시작한다. 진단에서 지정한 첫 눈 이후만 정상 난수로 진행하며 해당 D의 모든 선택에 같은 후속 묶음을 쓴다. 이는 제한된 경로 확인이고 전반 승률 비교가 아니다.
- 미래 눈을 조회하거나 이전 분기에서 본 미래 눈을 다음 선택의 근거로 쓰지 않는다. 구현 시 분기별 의사결정 기록·상태를 분리한다. 인간의 군 순서는 교차 배정하고, 같은 사람이 같은 난수 쌍을 재경험했다면 학습·노출을 표시한다. 최초 노출 자료를 자발적 선호의 주 근거로 삼고 동일 난수 재경험은 학습·비교 후 선택으로 별도 집계한다.
- 설정 12의 현재 턴 가중합 자동 정책은 미래 수확 준비를 충분히 평가한다고 보장되지 않는다. 그 정책의 U/G 선택률을 희망층·최적 전략·재미의 증거로 쓰지 않는다.

## 4. 기록과 해석

```text
실행 ID / config·rules·명세 버전·해시 / seed / 군 / 인간·수동 AI·자동 / 정상·통제:
영업·손님·턴 / 위치·F/T/H/A / 괴이별 층·C/L/P / B/G 잔량:
눈 공개 전 희망층·역할·이유·계획한 액티브 / 동률·희망 없음:
현재 눈 / 도달 가능한 살아 있는 역할·개별 층 / 경유·도착·공격 목록:
실제 선택·이유 / 희망층 포기 이유 / 두 역할 이상 동시 도달 가능 여부:
액티브 순서·대상·소모 / G 도착 대상·도착 흡수·액티브 흡수:
타격별 실제 흡수·남은 위력·C/P / 처치·반격 취소·파훼·파괴:
U에서 준비한 불안의 후속 사용·상한 낭비 / Q 공포·초과분·남은 불안:
G와 같은 경로에서 도착 방어가 없었을 때의 차이 / 다음 손님의 보호 자산·횟수 사용:
현재 선택의 포기 비용 / 예상과 실제 / 안내 전·후 / 미래 눈 노출 여부:
위기 대응 중인지·결과 확정 뒤 반복인지·불명인지와 근거 / 종료·상한·중단:
```

Q는 두 층, U/G는 한 층이므로 실제 방문 수를 그대로 비교하지 않는다. **눈 공개 전 희망 역할**, **서로 다른 두 역할 이상을 고를 수 있었던 턴의 선택과 분모**, **원했지만 눈이 없어 못 간 경우**를 나눈다. 같은 역할의 두 Q는 역할 집계에서 한 후보 역할이며, 개별 층 선택은 따로 남긴다. 중복 눈과 P0 층도 구별한다.

G에 도착해 공격 표적을 피한 효과와 G의 흡수가 막은 효과를 구분한다. 같은 경로에서 도착 방어만 끈 결과를 함께 보고, 처치로 취소된 공격·쓰이지 않은 흡수를 보호 성과에 더하지 않는다. 공급·방어의 후속 이익은 생존 수치만 남기지 않고 실제로 활용했는지까지 기록한다.

| 관찰 | 판단·다음 확인 |
|---|---|
| 같은 사람이 상태 변화에 따라 U/G/Q를 원하고 포기 비용·후속 결과를 설명 | 목적이 다른 도착지의 경쟁을 지지하는 사례. 균등 선택률이나 전체 밸런스의 증거는 아님 |

| G보다 Q+원격 방어를 계속 선호 | 실제로 포기한 횟수와 후속 수요를 확인. 액티브가 있을 때의 도착 방어 가치가 미지지된 것이며 G0 진단만으로 통과 처리하지 않음 |
| 상태와 무관하게 U 또는 G만 반복 | 세 목적의 경쟁 대신 다른 단일 목적지가 지배하는지 확인. 효과를 함께 강화하지 않고 해당 효과만 분리 비교 |
| 결과를 계산하면 좋은 선택이 쉽게 보임 | 그 자체로 문제 아님. 상태가 달라졌을 때 원하는 역할과 이유도 바뀌는지 확인 |
| 손실 후 선택지가 줄어듦 | 그 자체로 문제 아님. 대응 가능 구간과 결과 확정 뒤 불필요한 입력을 근거와 함께 분리 |

완료 보고는 **판정 일치 / 통제 상태의 교환 / 정상 운영의 자발적 도착 욕구 / 인간의 체감**을 나눈다. 인간 참가자가 플레이하지 않았다면 해당 항목은 미검증이다. 새 도착 효과가 발동했다는 사실, 완주 턴 감소, 강제 상태에서 세 역할을 한 번씩 고른 사실만으로 메커니즘의 재미가 개선됐다고 결론내리지 않는다.
