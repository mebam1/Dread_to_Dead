# Dread-to-Dead: Fears Go Round — MVP 제작·검증 계획

> 2026-10-31. 판정은 [rules.md](../rules.md), 미정 수치·콘텐츠는 [undecided.md](../undecided.md)를 따른다. 설정 [9](mvp-config-9.md)·[10](mvp-config-10.md)은 과거 시험안이며 [당시 명세](legacy-specs-9-10.md)와 함께 보관한다. 현행 규칙의 실행 전 시험안은 [설정 11](mvp-config-11.md)이다.

## 1. 목표와 관찰 기준

**같은 플레이어가 융합 괴이의 법칙을 설명하고, 자발적으로 다음 조합을 찾는가**를 우선 확인한다. 괴이의 공격 연결을 직원으로 지키고, 축적 상태를 공격과 지원에 배분하는 선택을 관찰한다.

| 검증 대상 | 실제 관찰 |
|---|---|
| 융합 | 재료 두 지원 행동이 공격 법칙으로 변한 관계, 후보 선택·포기 이유, 다음 조합 탐색 |
| 직원 역할 | 즉시 지원·배치 예약의 사용 이유, 미방문 칸 보호, 상태 소비와 공격 준비의 경쟁 |
| 공격·생존 | 손님별 범위·단타/다단에 따른 보호 선택, 공략도 감소·파훼 감수·피해 이전의 차이 |
| 소진·경제 | 드로우의 즉시 이익과 이후 굴림 페널티, 처치 고정 보상으로 투자 가능한지 |
| 손실·재설계 | 남은 괴이로 공급·수확을 재구성하고 직원 지원을 조정하는 행동 |

설명→융합 관계의 자유 설명→다음 조합 탐색을 순서대로 기록한다. 힌트 뒤 반응은 첫 반응과 분리한다. 자동 시연의 계산 성공·수익·카드 사용률은 인간의 재미나 시장성 증거가 아니다.

## 2. 제작과 판정 확인

새 config에는 직원의 즉시/배치 구분·상태 소비·비용, 괴이별 공략 한계·파훼 토큰, 손님별 공격 패턴·개별 타격 위력·고정 보상, 덱·주사위 하한·영업 경계를 명시한다. 난수·수치를 진행 중 결과에 맞춰 바꾸지 않는다.

| 확인 장면 | 기대 판정 |
|---|---|
| 즉시 지원·드로우 | 미방문 대상 지원과 같은 직원 사용 단계의 추가 카드 사용이 가능 |
| 배치 후 재방문 | 지정 조건에서 1회 발동 후 제거. 미발동분도 턴말 제거 |
| 공략도 한계 초과 | 개별 타격마다 최대 파훼 1회·공략도 0·초과분 소멸 |
| 단타와 다단 | 동일 합계 위력도 타격 구성이 다르면 파훼 횟수가 달라질 수 있음 |
| 드로우 전후 소진 | 굴림 전 소진은 곧 이어질 굴림, 선택 후 소진은 다음 굴림부터 적용 |
| 중복 소진·손님 교체 | 굴림당 주사위 감소는 1개, 누적분은 이후 굴림·같은 영업의 손님에게 이월 |
| 영업 종료 | 남은 주사위 페널티 초기화 |
| 중간 심장마비·최종 처치 | 중간 보상 없음. 마지막 토큰 제거 시 고정 보상 1회·남은 효과/이동/공격 중단 |

화면·로그에는 방문자 F/T/H와 상태, 괴이 C/L/P, 즉시 효과·배치 예약·소비 상태, 개별 타격, 페널티 잔여 횟수·실제 주사위 수, 고정 보상·잔액을 구분한다.

## 3. 문제별 수정 우선순위

| 관찰 | 먼저 점검할 것 |
|---|---|
| 직원이 괴이 역할을 대신함 | 공격·상태 공급 침범, 상태 소비가 지원에 머무는지 |
| 보호 선택이 늘 같음 | 공격 패턴·타격 구성·공략도/파훼 상태·비용 |
| 배치를 쓸 이유가 없음 | 이동 중 공급되는 상태, 발동 위치·지원 범위·즉시 사용과의 차이 |
| 무위험 지연·드로우 반복 | 회복·자원 연쇄의 비용, 다음 굴림 페널티, 손님 교체·영업 경계 |
| 처치 후 투자 불가 | 종류별 고정 보상과 모집·융합·확장 비용 |
| 융합 뒤 탐색·재설계 없음 | 재료 인과·괴이의 법칙 차이·손실 부담·대체 공급 경로 |

**완료 기준:** 채택한 시험값으로 판정이 일관되고, 같은 플레이어의 자기 설명·자발적 탐색·선택 이유가 관찰된다. 기능 발동이나 자동 완주만으로 인간 검증을 완료하지 않는다.

## 4. 과거 설정 8 시연 요약

2026-10-30의 rules v0.8·config 8을 적용한 **텍스트 시연 1회**다. 원본 config 8은 현재 저장소에 없다. 일반 손님 생존 퇴장·심장 부담·경찰·옛 소진 등은 당시 조건이며 현재 규칙에 적용하지 않는다. 설정 9 v0.1 자동 시연 역시 과거 자료다.

### 조건과 범위

독립 공정 1d6 세 개 중 하나를 골랐고 카드 비용은 모두 2였다. 매 턴 현재 후보만 공개했으며 미래 난수 참조·유리한 재굴림은 없었다. 아래는 **당시 실제 사용한 임시 능력과 횟수**다.

| 직원 | 당시 능력 | 카드 사용 |
|---|---|---:|
| S 접객원 | 방문자 A +2 | 4 |
| R 녹음기사 | 방문자 B +2 | 0 |
| K 기록원 | 지정 타일의 이번 이동 첫 유효 수확 공포 +4 | 3 |
| H 봉합사 | 일반 부담 −2 또는 살아 있는 타일 내구 +2(최대 4) | 1(보스 회복) |
| C 교환원 | A 최대 2→B 1:1 | 0 |

S+R·C+K·H+S 세 쌍에서 총 4회 융합했고 S+R은 다른 후보로 재융합했다. 임시 후보 9종 중 실제 획득·배치는 대답하는 벽·반송되는 고해실·봉합된 비상구·금지된 안내방송 4종, 실제 상태는 A/B뿐이다. **직원 5종·후보 9/30종·상태 4종 전체를 검증한 기록이 아니다.**

|---|---:|---:|---:|---|

- 자금 `16+일반 수입80+보스 보상20−모집36−확장8−시설6=66`. 직원 `5+9−4×2=6`.
- 보스 공포 28은 일반 수입 80과 합산하지 않는다. 마지막 수입 32 직전 잔액은 34였고 정산 뒤 구매는 없었다. 최종 잔액만으로 각 구매 시점의 자금 제약을 판단하지 않는다.

### 선택 장면과 한계

- 손님 2 첫 턴에 즉시 수확 가능한 6 대신 1을 택해 뒤의 기회를 남겼으나 필요한 눈이 나오지 않아 수입 0. 현재 확정 결과와 미래 기회를 구별할 정보가 필요했다.
- 손님 5 첫 턴은 2마나로 S/K 중 S를 선택해 같은 당장 수입 8과 A 1을 남겼다. 세 번째 턴은 중간 눈 2로 벽 수확과 뒤의 기회를 보존했고, 네 번째는 빈손으로 고해실 자체 수확을 활용했다.
- 보스 두 번째 턴에 6을 골라 재도착·공격 위험을 감수하고 마나 4를 K/H에 썼다. 고해실 내구 `2→회복4→피해2`로 생존했으며 회복이 없으면 파괴될 상황이었다. 승리 자체가 회복 덕분이었다는 뜻은 아니다.
- S+R을 소비형 벽에서 참조형 안내방송으로 재융합하고 라디오·배치를 바꿔 참조→소비를 연결했다. 인간의 이해·호기심은 별도 확인해야 한다.
- 보스 마지막 턴은 소진으로 예고 피해 3이었지만 승리로 취소됐다. 파괴가 0이므로 소진 위험의 적정성·부분 손실 뒤 복구 동기는 검증하지 못했다.

최종 배치: `안내판→닫힌 객실→라디오→라디오→금지된 안내방송→휴게실→대답하는 벽→반송되는 고해실`. 봉합된 비상구는 보관했다. 안내방송이 남긴 B를 벽이 소비하고 고해실이 남은 A를 B로 바꿔 수확하는 연결이 실제 작동했다.

이 시연은 임시 콘텐츠의 완주·선택 장면을 확인한 자료다. 실제 참가자의 이해·호기심·재미·피로·플레이 시간·위협 적정성·재설계 동기·장기 균형·상업성은 판정하지 않는다. 다른 설정과 수익만 비교해 개선율이나 단일 변경의 인과 효과를 계산하지 않는다.
