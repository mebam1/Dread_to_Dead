# 사이비 호텔 — MVP 제작·검증 계획

> 2026-10-30 압축본. 규칙은 [rules.md](../rules.md), 시험 절차는 [설정 9](mvp-config-9.md)를 따른다. 범위·수치·콘텐츠 제안은 [undecided.md](../undecided.md#u-mvp)에 모았다. 아래 설정 8 기록은 **옛 규칙의 시연**이다.

## 1. 목표와 관찰 기준

**같은 플레이어가 융합 괴이의 법칙을 자기 말로 설명하고, 자발적으로 다음 직원 조합을 찾는가**를 우선 검증한다. 경험의 중심은 호텔로 심장 토큰을 제거하고 초과 공포를 벌며, 방문자 공격으로 손상된 호텔을 재설계하는 것이다.

| 검증 대상 | 실제 관찰 | 대체 지표로 쓰지 않을 것 |
|---|---|---|
| 융합 | 재료 두 행동의 인과, 고정 후보 차이·포기 이유, 자발적 다음 조합 탐색 | 선택 횟수·진행자 설명 |
| 공포·경제 | 빠른 처치와 큰 초과 수익의 차이·선택 이유 | 공포 총량·수익만 높음 |
| 주사위·직원·소진 | 경로/마나/공격을 비교하고 적어진 후보 안에서 부착 위치 선택 | 카드 사용률·굴림 횟수 |
| 손실·재설계 | 남은 자산으로 다른 공포 생산 경로를 만들려는 행동 | 강제 피해·단순 원상복구 |

직원 행동 설명→융합 인과의 자유 설명→다음 조합의 자발적 행동을 순서대로 기록한다. 힌트 뒤 반응은 첫 반응과 분리한다. 시장성·장기 성장·3D 효용·대규모 콘텐츠·인간 재미는 자동 텍스트 시연으로 검증하지 않는다.

## 2. 제작과 평가 순서

| 단계 | 필요한 기능·장면 | 다음 단계 조건 |
|---|---|---|
| 판정 기준 | 반복 루프·공포/토큰·초과 재화·일반/보스 공격·소진을 일관되게 처리 | 미정값이 분리되고 사건 검산 가능 |
| 첫 융합 | 직원 사용→두 직원 소모→고정 후보 비교→영구 배치·발동 | 같은 사람이 자기 설명과 자발적 탐색을 함께 보임 |
| 공격·경제 | 반복 영업, 임시 카드 부착, 후보별 이동/마나/피해, 실제 재화로 투자 | 선택 이유를 설명하고 조작을 이해함 |
| 보스·재설계 | 매 방문 공격·재방문 반복, 실제 손실 뒤 남은 직원/타일로 재구성 | 손실을 겪은 참가자가 재구성을 원함 |
| 콘텐츠 확장 | [단계별 범위](../undecided.md#u-mvp-scope)와 [능력 기준](../ability_checklist.md) 적용 | 후보 법칙의 차이를 설명하며 탐색 지속 |
| 초회 플레이 | 새 참가자가 안내 후 완주하고 사건·원인을 복기 | 도움 없이 진행하고 핵심 반응 재현 |

필수 화면 정보는 직원 풀/덱·융합 소모, 공급/변환/수확과 내구·빈칸, 소진 후 실제 주사위 수, 카드 비용·대상·발동, F/T·토큰·초과 재화, 공격 순서·손실·진행 속도다. 후보에는 두 직원의 행동, 새 법칙 한 문장, 손님 사건, 입력/출력·통과/도착, 수익·배치·공격 조건, 재료 소모 후 대체 공급 경로를 기록한다.

## 3. 문제별 수정 우선순위

| 관찰 | 먼저 점검·수정할 것 |
|---|---|
| 초과 수익 0 반복·모집 불가 | 수확 폭·공포 한계·가격 중 한 요소씩 |
| 일반 손님이 끝나지 않음 | 입력 부족·파괴·토큰/한계, 대체 수확과 실험 턴 상한 |
| 보스가 호텔을 즉시 파괴 | 확정 공격 범위 유지, 피해·내구·토큰/한계 중 한 요소씩 |
| 카드가 뽑혀도 판단 없음 | 후보 수와 선택 이유, 무의미한 클릭 수 |
| 회복 직원을 쓸 수 없음 | 폐기된 부담 능력 잔재와 새 능력의 실제 대상/시점 |
| 융합 설명만 하고 탐색 없음 | 직원 행동·후보 법칙·용도 차이·작동 장면 |
| 손실 뒤 재설계 거부 | 복구 노동·손실량·모집/대체 경로·피로를 분리 시험 |

**완료 기준:** 채택한 시험 범위가 현재 판정으로 작동하고 재설계·재영업까지 이어진다. 같은 초회 플레이어에게 자기 설명+자발적 탐색이 반복되며 처치/수익/위험/카드 선택 이유를 관찰한다. 기능 발동·자동 완주만으로 인간 검증을 완료 처리하지 않는다.

## 4. 과거 설정 8 시연 요약

2026-10-30의 rules v0.8·config 8을 적용한 **텍스트 시연 1회**다. 원본 config 8은 현재 저장소에 없다. 일반 손님 생존 퇴장·심장 부담·경찰·옛 소진 등은 당시 조건이며 현재 규칙에 적용하지 않는다. 설정 9 v0.1 자동 시연 역시 과거 자료다.

### 조건과 범위

독립 공정 1d6 세 개 중 하나를 골랐고 카드 비용은 모두 2였다. 매 턴 현재 후보만 공개했으며 미래 난수 참조·유리한 재굴림은 없었다. 아래는 **당시 실제 사용한 임시 능력과 횟수**다.

| 직원 | 당시 능력 | 카드 사용 |
|---|---|---:|
| S 접객원 | 방문자 A +2 | 4 |
| R 녹음기사 | 방문자 B +2 | 0 |
| K 기록원 | 지정 타일의 이번 이동 첫 유효 수확 공포 +4 | 3 |
| H 봉합사 | 일반 부담 −2 또는 살아 있는 타일 내구 +2(최대 4) | 1(보스 회복) |
| C 교환원 | A 최대 2→B 1:1 | 0 |

S+R·C+K·H+S 세 쌍에서 총 4회 융합했고 S+R은 다른 후보로 재융합했다. 임시 후보 9종 중 실제 획득·배치는 대답하는 벽·반송되는 고해실·봉합된 비상구·금지된 안내방송 4종, 실제 상태는 A/B뿐이다. **직원 5종·후보 9/30종·상태 4종 전체를 검증한 기록이 아니다.**

### 결과와 정산

| 구간 | 턴 | 일반 수입 | 카드 사용 | 당시 결과 |
|---|---:|---:|---:|---|

- 일반 17턴/보스 3턴. 일반 수확 9회(9/17≈0.529), 일반 카드 5회(5/17≈0.294). 카드 사용 턴 7(일반 5/보스 2), 미사용 13(일반 12); 빈손 일반 1/보스 0.
- 소진 일반 5/보스 1회. 실제 보스 공격 2회(마지막 공격 승리로 취소). 모든 후보가 퇴장인 턴 5/20.
- 모집 9명·융합 4회·최종 직원 6명. 최종 슬롯 8·시설 5·괴이 4(1개 보관), 당시 경찰 의심도 0.
- 자금 `16+일반 수입80+보스 보상20−모집36−확장8−시설6=66`. 직원 `5+9−4×2=6`.
- 보스 공포 28은 일반 수입 80과 합산하지 않는다. 마지막 수입 32 직전 잔액은 34였고 정산 뒤 구매는 없었다. 최종 잔액만으로 각 구매 시점의 자금 제약을 판단하지 않는다.

### 선택 장면과 한계

- 손님 2 첫 턴에 즉시 수확 가능한 6 대신 1을 택해 뒤의 기회를 남겼으나 필요한 눈이 나오지 않아 수입 0. 현재 확정 결과와 미래 기회를 구별할 정보가 필요했다.
- 손님 5 첫 턴은 2마나로 S/K 중 S를 선택해 같은 당장 수입 8과 A 1을 남겼다. 세 번째 턴은 중간 눈 2로 벽 수확과 뒤의 기회를 보존했고, 네 번째는 빈손으로 고해실 자체 수확을 활용했다.
- 보스 두 번째 턴에 6을 골라 재도착·공격 위험을 감수하고 마나 4를 K/H에 썼다. 고해실 내구 `2→회복4→피해2`로 생존했으며 회복이 없으면 파괴될 상황이었다. 승리 자체가 회복 덕분이었다는 뜻은 아니다.
- S+R을 소비형 벽에서 참조형 안내방송으로 재융합하고 라디오·배치를 바꿔 참조→소비를 연결했다. 인간의 이해·호기심은 별도 확인해야 한다.
- 보스 마지막 턴은 소진으로 예고 피해 3이었지만 승리로 취소됐다. 파괴가 0이므로 소진 위험의 적정성·부분 손실 뒤 복구 동기는 검증하지 못했다.

최종 배치: `안내판→닫힌 객실→라디오→라디오→금지된 안내방송→휴게실→대답하는 벽→반송되는 고해실`. 봉합된 비상구는 보관했다. 안내방송이 남긴 B를 벽이 소비하고 고해실이 남은 A를 B로 바꿔 수확하는 연결이 실제 작동했다.

이 시연은 임시 콘텐츠의 완주·선택 장면을 확인한 자료다. 실제 참가자의 이해·호기심·재미·피로·플레이 시간·위협 적정성·재설계 동기·장기 균형·상업성은 판정하지 않는다. 다른 설정과 수익만 비교해 개선율이나 단일 변경의 인과 효과를 계산하지 않는다.
