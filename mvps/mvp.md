# Dread-to-Dead — MVP 검증 계획과 플레이 기록

**현재 검증 대상은 텍스트 MVP 21(`text-21-v1.1`)이다.** 생존 동료 한 장을 직선 보드에서 옮기는 선택이 이번 수의 반격과 다음 수의 배치를 어떻게 바꾸는지 본다. [핵심 규칙](../rules.md) · [21판 설정과 판정 예시](mvp-config-21.md) · [실행 안내](../mvp_text_21/README.md)

## 규칙을 재현하는 장면

| 장면 | 확인할 결과 |
|---|---|
| 10칸이 모두 찬 동료 행에서 1→10 | 이동자 이외의 아홉 동료가 각각 왼쪽으로 한 칸 밀린다. 2~9번만 통과 기술을 쓰고 10번에서는 이동자의 도착을 판정한다. |
| 카운터가 1인 적 둘 중 한 명을 이동으로 처치 | 살아남은 적만 행동한다. 둘 다 살아남으면 편성 순서로 처리하며 뒤 적은 앞 적의 이동·밀림 뒤 자리에서 시작한다. |
| 순찰이 8번에서 오른쪽을 예고 | 전투가 계속되면 9→10→9 순서로 타격한다. 9번의 재방문도 표시한다. |
| 이동 치유형이 다른 적의 칸까지 걸어감 | 매 걸음 교환한 뒤 최종 위치의 이웃만 회복한다. 대상의 현재 체력과 최대 체력 차이만큼만 실제 회복이 찍힌다. |
| 3번째 이동에서 성기사의 기존 방어와 한도를 사용 | 그 수에 만료된 적 행동과 상태 정산을 마친 뒤 한도를 복구하고 방어를 얻는다. 검토·속공·철수 지점 설치로는 재충전 시점이 당겨지지 않는다. |
| 마지막 적 처치와 동료 탈진이 같은 수에 발생 | 독·탈진을 정산한 뒤 승패를 기록한다. 일반·엘리트 철수 접촉은 해당 칸의 가스·밀림·타격 전에 방문을 끝낸다. |
| 이동 검토 뒤 확정하고 다시 열기 | 검토는 배치와 난수를 보존한다. 확정한 이동·반응·실제 피해·회복과 행동 번호, 남은 적 카운터가 저장된다. |

전투·CLI 검사는 `mvp_text_21`에서 `npm test`로, 막별 피격 검증은 `npm run verify:balance`로 재현한다. 피격 검증은 만피·미강화 동료 11종과 세 공격 패턴을 막마다 한 번씩 조합한다. 막별 평균 **40.3%·60.6%·80.1%**는 이 99개 장면에서 자체 방어와 초과 피해 상한을 반영한 값이다. [측정 스크립트](../mvp_text_21/verify-balance.mjs)

## 다음 플레이에서 비교할 선택

먼저 **지원 동료로 배치를 준비한 두 수**와 **공격수로 바로 공격한 두 수**를 비교한다. 같은 판·같은 전투의 같은 입력 직전 상태에서 시작해 두 번째 이동이 끝난 뒤의 적 처치, 반격 횟수, 동료 체력과 다음 적 카운터를 기록한다. 기본 규칙에서 가능한 예는 추기경이 새로 연결한 성가대원이 다음 성전사의 정면에 반응하는 경우다. [두 수 연계의 판정](mvp-config-21.md#두-차례-연계와-확인-장면)

준비 이동으로 달라지는 결과를 확인한 뒤 1·2막 첫 반격까지의 생존, 전투 중 실제 회복, 영입·교체의 영향을 차례로 살핀다. 직접 선택한 구간과 공개 예고를 전수 비교한 자동 구간을 기록해 같은 조건끼리 비교한다. 판 번호가 같아도 선택이 달라지면 서로 다른 원정이다. [공유된 플레이 관찰과 미채택 후보](../undecided.md)

## 과거 설정 8 시연 요약

2026-10-30의 rules v0.8·config 8을 적용한 **텍스트 시연 1회**다. 원본 config 8은 현재 저장소에 없다. 일반 손님 생존 퇴장·심장 부담·경찰·옛 소진 등은 당시 조건이며 현재 규칙에 적용하지 않는다. 설정 9 v0.1 자동 시연 역시 과거 자료다.

### 조건과 범위

독립 공정 1d6 세 개 중 하나를 골랐고 카드 비용은 모두 2였다. 매 턴 현재 후보만 공개했으며 미래 난수 참조·유리한 재굴림은 없었다. 아래는 **당시 실제 사용한 임시 능력과 횟수**다.

| 직원 | 당시 능력 | 카드 사용 |
|---|---|---:|
| S 접객원 | 방문자 A +2 | 4 |
| R 녹음기사 | 방문자 B +2 | 0 |
| K 기록원 | 지정 타일의 이번 이동 첫 유효 수확 공포 +4 | 3 |
| H 봉합사 | 일반 부담 −2 또는 살아 있는 타일 내구 +2(최대 4) | 1(보스 회복) |
| C 교환원 | A 최대 2→B 1:1 | 0 |

S+R·C+K·H+S 세 쌍에서 총 4회 융합했고 S+R은 다른 후보로 재융합했다. 임시 후보 9종 중 실제 획득·배치는 대답하는 벽·반송되는 고해실·봉합된 비상구·금지된 안내방송 4종, 실제 상태는 A/B뿐이다. **직원 5종·후보 9/30종·상태 4종 전체를 검증한 기록이 아니다.**

### 선택 장면과 한계

- 손님 2 첫 턴에 즉시 수확 가능한 6 대신 1을 택해 뒤의 기회를 남겼으나 필요한 눈이 나오지 않아 수입 0. 현재 확정 결과와 미래 기회를 구별할 정보가 필요했다.
- 손님 5 첫 턴은 2마나로 S/K 중 S를 선택해 같은 당장 수입 8과 A 1을 남겼다. 세 번째 턴은 중간 눈 2로 벽 수확과 뒤의 기회를 보존했고, 네 번째는 빈손으로 고해실 자체 수확을 활용했다.
- 보스 두 번째 턴에 6을 골라 재도착·공격 위험을 감수하고 마나 4를 K/H에 썼다. 고해실 내구 `2→회복4→피해2`로 생존했으며 회복이 없으면 파괴될 상황이었다. 승리 자체가 회복 덕분이었다는 뜻은 아니다.
- S+R을 소비형 벽에서 참조형 안내방송으로 재융합하고 라디오·배치를 바꿔 참조→소비를 연결했다. 인간의 이해·호기심은 별도 확인해야 한다.
- 보스 마지막 턴은 소진으로 예고 피해 3이었지만 승리로 취소됐다. 파괴가 0이므로 소진 위험의 적정성·부분 손실 뒤 복구 동기는 검증하지 못했다.

최종 배치: `안내판→닫힌 객실→라디오→라디오→금지된 안내방송→휴게실→대답하는 벽→반송되는 고해실`. 봉합된 비상구는 보관했다. 안내방송이 남긴 B를 벽이 소비하고 고해실이 남은 A를 B로 바꿔 수확하는 연결이 실제 작동했다.

이 시연은 임시 콘텐츠의 완주·선택 장면을 확인한 자료다. 실제 참가자의 이해·호기심·재미·피로·플레이 시간·위협 적정성·재설계 동기·장기 균형·상업성은 판정하지 않는다. 다른 설정과 수익만 비교해 개선율이나 단일 변경의 인과 효과를 계산하지 않는다.
