# 사이비 호텔 — 1인 개발 MVP 제작·검증 계획

> **문서:** `mvp-1.md` · **개정 버전:** **v0.2** · **개정:** 2026-10-30  
> **규칙 기준:** `rules.md` **v1.0**, `ability_checklist.md` **v0.3**  
> **중요:** §12에 보존한 **설정 8의 텍스트 시연은 과거 rules v0.8·config 8 조건의 기록**이며, 새 공포·심장·공격·덱 소진 규칙의 검증 결과가 아니다. `mvp-config-9.md` **v0.1** 자동 시연도 같은 이유로 과거 로그다.

## 1. 핵심 MVP 목표

**가장 중요한 플레이 판단은 ‘같은 플레이어가 융합 괴이의 법칙을 자기 말로 설명하고, 자발적으로 다음 직원 조합을 찾아보는가’다.** 텍스트 자동 플레이에서 진행자가 설명·선택했다는 사실만으로 재미가 검증되지는 않는다.

새 게임의 기본 경험은 **호텔 엔진으로 공포를 채워 심장마비 토큰을 깨고, 그때의 초과 공포를 경영 재화로 벌면서, 방문자의 반복 공격으로 손실된 호텔을 재설계하는 것**이다. 일반 손님을 살려 보내거나 심장 부담·경찰 의심도를 관리하는 목표는 **폐기되었다**.

### 1.1 네 가지 후속 검증

| 검증 대상 | 실제 관찰할 것 | 대신 성공으로 세지 않을 것 |
|---|---|---|
| 융합 후보 선택 | 같은 조합 고정 3종의 법칙·활용 차이를 이해하고 포기한 이유를 말한다 | 후보 선택 횟수만 많음 |
| 공포·재화 | **빠른 토큰 파괴**와 **한계 초과 재화**의 차이를 이해하고 선택 이유를 설명한다 | 공포 총량, 초과 수익만 높음 |
| 주사위·직원·소진 | 이동/마나/호텔 공격 범위와 이번 턴 주사위 후보 감소를 비교하고 카드 부착 위치를 선택한다 | 카드 사용률이나 굴림 횟수만 높음 |
| 손실·재설계 | 일반 손님·보스 공격 후 남은 타일·직원으로 다시 공포 생산 경로를 만든다 | 매번 피해를 강제로 입힘, 단순 원상복구 |

**검증하지 않는 것:** 시장 성공률, 장기 메타 성장, 풀 3D의 효용, 30종 이상의 규모, 자동 텍스트 시연에서의 인간 재미.

| 시각 표현 | 2D 카드와 고정 테이블, 핵심 인과·♥ 제거·타일 타격 읽히기 | MVP 제안 |

### 2.1 첫 콘텐츠 검증 단위

직원 **3종 → 이종 3쌍 → 후보 9종**으로 시작한다. 이 단위에서 **직원 카드 사용 → 두 직원 융합 → 3후보 비교 → 괴이 배치 → 공포 게이지/심장마비/공격**까지의 연결을 경험하도록 한다. 핵심 반응이 약하면 30종 확대를 보류하고 직원·후보 법칙·작동 표현을 먼저 수정한다.

### 2.2 전체 30종 원칙

최종 쌍은 `AB, AC, AD, AE, BC, BD, BE, CD, CE, DE`다. 각 후보에는 재료 직원 두 명의 행동, 새 법칙 한 문장, 손님이 겪는 사건, 통과/도착·입력/출력, 실제 공포·초과 수익 가능성, 공격·배치 조건, 재료 직원 소모 뒤의 대체 공급 경로를 기록한다. 같은 조합의 세 후보는 단순 수치 상하위보다 역할·조건이 구별되어야 한다.

## 3. 한 판의 목표·진행·종료

### 3.1 공통 진행

**[확정]** 일반 손님과 보스 모두 **원형 루프를 반복 순환**한다. 현재 공포 `F`가 한계 `T`에 닿으면 **♥ 토큰 1개 제거 → 초과 공포 `max(0,F−T)`만큼 재화 → 공포 0 리셋**이다. 마지막 토큰이 사라지면 일반 손님은 사망, 보스는 격퇴하며 **그 턴의 남은 이동·효과·공격을 즉시 중단**한다. 토큰이 남아 있다면 공격한다.

**[MVP 제안]** `시작 경영 → 일반 손님 3명 처치 → 보스전 → 격퇴 후 재설계 → 일반 손님 2명 처치 → 완주`. 실제 손님 수·일반/보스 턴 상한은 정식 확정이 아니다. **일반 손님의 생존 퇴장·경찰 의심도 실패**는 사용하지 않는다.

### 3.2 공격과 손실

- 일반 손님: 매 턴 **마지막 도착 슬롯에 공격 1회**. 중간 통과 칸은 공격하지 않는다.
- 보스: 실제 방문 순서대로 **통과·도착 모든 슬롯 각각 1회**. 한 턴 같은 칸을 두 번 방문하면 **2회 공격**한다. 도착 칸의 통과·도착 효과가 둘이라도 **그 방문의 공격은 한 번**이다.
- 공격은 모든 이동·발동이 끝나고 **심장 토큰이 남은 경우에만** 처리한다.
- **[MVP 제안]** 내구 0인 시설·괴이는 이번 판에서 제거하고 슬롯은 보존한다. 파괴된 타일의 즉시 부활은 없다. 재배치·재모집 등으로 엔진을 재설계한다.
- **[미정]** 일반/보스 공격 1회당 피해, 일반 손님 사이의 타일 손상 지속·회복 시점, 전투 실패와 턴 제한.

### 3.3 덱 소진과 직원 개입

**[확정]** 손패를 뽑을 덱이 비면 **이번 턴 굴리는 주사위 개수 −1**, 버린 카드 셔플 후 부족한 드로우를 **계속 뽑는다**. 다음 턴 주사위 수는 기본으로 복원한다. 이전의 부담 +2·보스 피해 +1·드로우 중단은 폐기다.

주사위 하나 선택 후 임의 슬롯에 마나 비용을 지불하고 직원 통과/도착 효과를 이번 턴 붙인다. 영구 타일과 부착 효과는 **방문 사건에서 발동**하고 턴말에 부착만 제거한다.

**[미정]** 기본 K=1에서 소진 시 0개가 되는지, 같은 턴 여러 소진이 중첩되는지. 개별 시험 설정에서만 별도 잠정 처리한다.

### 3.4 경영 재화

재화는 **심장마비 토큰 한 개 제거 사건에서 한계 초과 공포만큼만** 지급된다. 공포를 올린 모든 효과의 합을 그대로 화폐로 지급하지 않는다. 초과가 0인 심장마비는 토큰을 제거하지만 재화는 0이다. 이전에 얻은 재화는 해당 방문자가 이후 사망해도 몰수되지 않는다.

공통 경영 재화는 직원 모집·시설 구매·루프 확장에서 경쟁적으로 사용한다. 기존의 경영 시작 자금·모집 가격·시설 가격은 새 수익 모델 아래에서 **다시 점검해야 할 시험값**이다. 보스 처치의 추가 정액 보상은 공포 초과 수익과 구별하며 아직 최종 확정이 아니다.

| UI·연출 | 발동 원인, 심장마비와 사망 구별, 공격 순서·경영 재화·진행 속도 | 숫자를 읽는 것을 넘어서 사건을 설명할 수 있는가 |

**공통 검증 원칙:** 기능이 정상 발동한 횟수, 카드 사용률, 총 공포, 초과 공포 재화 수입을 **재미 검증 결과로 대체하지 않는다**.

## 5. 콘텐츠 재명세 필요 범위

설정 9 v0.1의 직원·괴이 30종은 **규칙 변경 전의 콘텐츠 제안**이다. 현재 규칙으로 계속 사용할 경우 다음은 **새 콘텐츠 제안으로 명세를 수정**해야 한다.

- **봉합사**의 일반 손님 `심장 부담 −2` → 해당 역할 폐기. 이제 일반 손님도 시설을 공격하므로 **타일 내구 회복** 등으로 다시 설계할 수 있다.
- **휴게실**의 일반 손님 부담 감소, `SH2`, `RH3`, `KH1`, `HC2`, `HC3`의 부담 회복 분기는 새 대상·발동 시점이 필요하다.
- 기존 수확 시 **`심장 부담 +1` 페널티는 폐기**한다. 공포 발생량과 심장마비·재화의 계산은 별도다.
- 새로운 일반 손님/보스 공격 범위 아래에서 **내구 4, 보스 8턴, 기존 피해 2** 등의 밸런스는 재검증 전에는 확정하지 않는다.
- 직원의 한 턴 부착 방식 자체는 유지한다. 기록원의 빈칸 참조 수확 등은 여전히 콘텐츠 제안이지 보편 규칙이 아니다.

## 6. 단계별 검증과 확장

| 단계 | 완성해야 할 장면 | 다음 단계 조건 |
|---|---|---|
| 1. 판정 기준 | 심장 토큰·초과 재화·반복 순환·두 공격 범위·드로우 재개를 모순 없이 기록 | 미정 수치가 시험용 config에 분리됨 |
| 2. 융합 첫 경험 | 직원 3종·3쌍·9종, 직원 사용→융합→괴이 발동 | 같은 사람이 자유 설명+자발 탐색을 함께 보임 |
| 3. 공격과 경제 | 일반 손님이 반복 순환하며 타격, 손님마다 ♥가 소진될 때 재화 정산 | 수익·공격·카드 사용을 이유로 선택하고 조작을 이해함 |
| 4. 보스와 재설계 | 보스 모든 방문 공격·재방문 2타격, 일부 자산 손실 뒤 다른 연결 | 실제 손실을 경험한 참가자가 재구성을 원함 |
| 5. 콘텐츠 확장 | 5종·10쌍·30종, 역할별 후보·상태·수확 경로 | 법칙의 차이를 스스로 설명하며 탐색을 이어감 |
| 6. 초회 플레이 | 처음 보는 사람이 안내 후 완주, 사건·원인 복기 | 도움 없이 진행하고 핵심 반응이 새 참가자에게 반복됨 |

### 6.1 설정별 시험값 지위

**과거 config 8:** X=6·K=3·비용2·2장 드로우·시작 16·모집 4·시설 6·보스 목표24·내구4 등은 **옛 규칙의 수치**다.  
**과거 config 9 v0.1:** 같은 주사위/경제에서 보스 단일 목표45로 1회 자동 시연했다. 변경된 심장 토큰 규칙의 결과가 아니다.  
**최신 config 9 v0.2:** 공포 한계·♥·공격 피해량과 폐기된 부담형 능력을 다시 명세하며, 사용자 지정 45는 **과거 보스 목표 값**이라는 출처를 보존한다. 이를 토큰당 공포 한계로 바꾸는 것은 **시험안**이지 사용자 확정 규칙이 아니다.

## 7. 플레이 평가 방식

## 12. 설정 8 텍스트 시연 기록

### 12.1 조건과 실제 경험한 콘텐츠

`mvp-config-8.md`를 적용해 시작 자산부터 초기화한 **텍스트 시연 1회**다. 주사위는 공정한 1d6 세 개 중 하나 선택, 직원 카드 비용은 모두 2였다. 매 턴 현재 후보를 공개한 뒤 선택하고 카드를 사용했으며, 다음 턴의 눈을 미리 보고 배치·구매를 정하거나 유리한 결과를 위해 다시 굴리지 않았다. 시연에 쓰인 임시 능력은 최종 콘텐츠의 확정 명세가 아니다.

| 임시 직원 | 시연에서 사용한 능력 명세 | 실제 카드 사용 |
|---|---|---:|
| 접객원 S | 현재 방문자에게 A 상태 +2 | 4회 |
| 녹음기사 R | 현재 방문자에게 B 상태 +2 | 0회 |
| 기록원 K | 지정 타일의 이번 이동 첫 유효 수확에 공포 +4 | 3회 |
| 봉합사 H | 일반 손님 부담 −2 또는 살아 있는 타일 내구 +2, 최대 4 | 1회. 보스 타일 회복에 사용 |
| 교환원 C | A 최대 2개를 B로 1:1 변환 | 0회 |

융합은 **접객원+녹음기사, 교환원+기록원, 봉합사+접객원**의 세 조합에서 총 4회 진행했다. 접객원+녹음기사를 다시 융합하면서 다른 후보를 선택했다. 세 조합의 고정 후보 9종은 임시 정의했지만, 실제 획득·배치한 괴이는 **대답하는 벽, 반송되는 고해실, 봉합된 비상구, 금지된 안내방송의 4종**이다. 실제 누적·활용한 상태는 A·B 두 종류다.

따라서 이번 기록은 직원 5종의 모든 카드 행동, 후보 9종 전체, 최종 괴이 30종, 상태 4종의 검증 완료를 뜻하지 않는다. 특히 녹음기사·교환원은 융합 재료로 사용했어도 카드 행동을 실제로 발동하지 않았다.

최종 배치는 **수상한 안내판 → 닫힌 객실 → 벽 속 라디오 → 벽 속 라디오 → 금지된 안내방송 → 휴게실 → 대답하는 벽 → 반송되는 고해실**이다. 봉합된 비상구는 파괴되지 않고 보관했다. 안내방송의 비소비 참조 수확에서 남은 B 상태를 뒤쪽 벽의 소비 수확에 사용하고, 고해실은 남은 A를 B로 바꾸어 추가 수확했다. 이 연결은 마지막 손님에서 실제 작동했다.

### 12.5 해석의 범위

이번 시연은 **정해진 임시 콘텐츠와 선택 경로에서 한 판이 완주되고, 설명할 수 있는 선택 장면이 생겼다는 근거**다. 사용자의 별도 채택으로 주사위 선택 방식은 정식 규칙이 되었지만, 그 사실이 재미 검증을 대신하지 않는다.

실제 참가자의 융합 이해·다음 조합에 대한 호기심, 선택의 재미와 피로, 실제 플레이 시간, 보스 위협의 적정성, 부분 손실 뒤 재설계 동기, 장기 균형·리플레이성·상업성은 이 기록으로 판정하지 않는다. 특히 다른 설정의 한 판과 수익을 비교해 개선율이나 인과 효과를 계산하지 않는다. 다음 투자 판단은 §1.1과 §7의 사람에 대한 관찰을 따른다.
