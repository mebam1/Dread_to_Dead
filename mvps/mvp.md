## 1. 목표와 관찰 기준

**같은 플레이어가 괴이의 연결을 설명하고, 주사위·직접 사용·지도 경로·구매·증설·층 배치를 바꾸는가**를 확인한다. 손님 한 명 안의 공략 위험, 한 전투의 사용 횟수 배분, 같은 막의 파훼 토큰 손상과 새 막의 복구를 구분한다.

현재 우선순위는 **얻은 괴이와 주사위가 호텔의 크기·배치·모험 경로를 바꾸며, 선택의 결과와 대가를 미리 읽을 수 있는가**다. 회복 노드의 토큰 배분·강화 선택과 새 막 복구가 생존 계획에 미치는 영향도 확인한다. 계산해서 답이 쉽게 보이거나 불리해져 선택지가 줄어드는 것 자체를 결함으로 판정하지 않는다.

| 검증 대상 | 실제 관찰 |
|---|---|
| 층 이동·발동 | 경유 층의 통과와 최종 층의 도착을 구별하고, 도착 층에서 통과가 발생하지 않음을 예측 |
| 괴이 역할·배치 | 공급·수확·수비·지원 역할을 층에 나누거나 겸하도록 배치하고 선택 이유 설명 |
| 직접 사용 | 같은 턴 반복 사용과 이후 손님을 위한 보존 비교, 준비 진입 시 횟수 복구·불안 비용의 활용 |
| 공격·생존 | 손님별 공격 목록과 개별 타격에 따라 보호·수리·파훼 감수·탈출 선택 |
| 경제·지도 | 영혼을 괴이 구매와 증설에 배분하고, 공개된 전투·상점·회복·발견·이벤트 경로를 비교 |
| 주사위·증설 | 같은 눈의 변경된 도착층과 경로를 비교하고, 장비 교체와 호텔 재배치를 연결 |
| 회복·강화 | 토큰 총 2개 배분과 개체 하나 강화 중 선택하고, 보스 이후 토큰 복구까지 고려 |
| 초기화·재설계 | 손님별 공략도 초기화·전투별 사용 횟수 복구·막별 토큰 복구를 구별 |
| 정보 이해 | 전체 호텔·1단위 공략도 바·심장 토큰과 결과 미리보기만으로 다음 선택을 설명 |

선택 전 예상→실제 결과→다음 자발적 변경을 같은 참가자 안에서 기록한다. 힌트 후 반응은 첫 반응과 분리한다. 자동 시연의 계산 성공·완주·능력 사용률은 인간의 재미나 시장성 증거가 아니다.

## 2. 제작과 판정 확인

현재 기준은 3막·막당 8노드 방문, 호텔 6~10층, 주사위 3개, 기본 괴이 6종, 영혼 경제다. 전투마다 최대 토큰을 복구하지 않는다. 같은 막에서는 손상을 유지하고, 1·2막 보스의 필수 보상 확정 후 다음 막에 진입할 때 생존 보유 괴이의 토큰을 최대치로 복구한다. 새 실험은 이 기준에서 바꿀 항목과 관찰 조건을 별도 config에 적고, 진행 중 난수·수치를 결과에 맞춰 바꾸지 않는다.

| 확인 장면 | 기대 판정 |
|---|---|
| 꼭대기 층 이후 이동 | 엘리베이터로 한 층씩 진행하며 현재 꼭대기 다음은 1층 |
| 최종 층의 효과 | 도착 효과만 처리. 같은 방문에서 통과 효과를 먼저 적용하지 않음 |
| 단타·다단 공격 | 개별 타격마다 최대 파훼 1회·공략도 0·초과분 소멸 |
| 손님 교체 | 괴이 공략도·보호 초기화, 같은 전투의 남은 토큰·사용 횟수 유지 |
| 새 전투 준비 최초 진입 | 공략도·보호 초기화와 사용 횟수 복구를 한 번 처리. 토큰·강화 유지 |
| 새 막 진입 | 필수 괴이 보상 확정 후 배치·보관 중 생존 개체의 토큰 최대 복구. 파괴·계약 제거 개체는 부활하지 않음 |
| 같은 액티브 반복 | 같은 턴에도 재사용 가능하되 각 사용의 횟수·자원 제한 충족 |
| 조건부 횟수 복구 | 명시한 사건에서만 복구. 자기 효과로 무한 재충전되는지 확인 |
| 방화문 충전·비활동 | 도착 충전은 다음 턴부터 사용. 충전 자체와 직접 사용의 활동 판정을 구별 |
| 탈출구·영업 종료 | 빈층 설치와 실제 통과·도착 종료를 구별. 빈층 없으면 설치 불가, 접촉 뒤 이동·공격 중단 |
| 공포와 정산 | 방문자 공포와 영혼을 분리. 마지막 심장 제거 때 고정 보상 1회·남은 효과/이동/공격 중단 |
| 구매·증설 | 상점 상품 슬롯별 1회 구매. 4·6·8·10영혼의 증설·잔액·기존 층 번호 유지·변경 경로 확인 |
| 전투 보상 | 완승 후 서로 다른 기본 괴이 3종 중 1개 필수 획득. 엘리트만 이후 특수 주사위 교체/건너뛰기 |
| 최종 승리 | 3막 보스의 마지막 심장을 제거하면 승리 잠금. 마지막 괴이 보상 확정 후 결과 화면, 별도 토큰 복구 없음 |
| 패배·재시작 | 모든 막 보스 탈출·배치 괴이 전멸·포기는 패배. 새 판은 초기 자산으로 시작 |

화면·로그에는 전체 이름, 공개 눈과 경유/도착 층, 손님의 공포·한계·심장·불안, 괴이의 공략도·파훼 토큰, 직접 사용의 횟수·복구 조건·비용, 개별 타격, 영혼 잔액과 지출을 구분한다. 비활동의 누적·발동까지 남은 턴, 탈출구 위치·실제 종료 여부도 표시한다. 미리보기·호버·취소는 상태나 난수를 소비하지 않는다.

현재 규칙·오프라인 UI 검사는 88개가 통과했다. 실제 브라우저 시각 검증과 막 전환 토큰 복구를 적용한 캠페인 전체 재실행은 아직 수행하지 않았다. [보존된 캠페인 6판](../mvp_user_3/README.md#검증과-확인-범위)은 복구를 넣기 전 규칙의 자동 정책 결과이며 현재 밸런스의 증거로 합산하지 않는다. 후속 검증에서는 현행 규칙의 정상 플레이와 10층 호텔·호버·터치·키보드·이동 연출을 확인한다.

## 3. 문제별 수정 우선순위

| 관찰 | 먼저 점검할 것 |
|---|---|
| 수비가 필요하지 않음 | 한 손님 안에서 공략도가 한계 12에 도달할 가능성, 공격 목록·위력·생존 턴 |
| 액티브가 늘 몰아 쓰기 또는 늘 보존으로 수렴 | 영업의 손님 구성, 사용 횟수·복구 조건·상태 소비·보호 이익 |
| 안전한 대기·충전 반복 | 처치 지연으로 얻는 이익, 충전 조건의 반복 가능성과 공격 압력 |
| 지도·구매 경로가 매번 같음 | 현재 호텔의 부족한 역할, 후속 노드·예산·증설·회복·강화의 기회비용 |
| 회복이나 강화 중 하나만 선택함 | 같은 막의 손상 압력·보스까지 남은 전투·다음 막 토큰 복구·강화의 후속 기여 |
| 괴이 하나만 계속 활용함 | 경유/도착 선택, 공급·수확·수비의 연결, 다른 층에 배치할 기회비용 |
| 규칙 설명은 하지만 선택을 바꾸지 않음 | 미리보기의 정보량, 효과 간 차이, 선택 결과가 다음 손님·구매에 미치는 영향 |

**완료 기준:** 채택한 현행 규칙으로 판정이 일관되고, 같은 플레이어의 자기 설명·자발적 탐색·선택 이유가 관찰된다. 기능 발동이나 자동 완주만으로 인간 검증을 완료하지 않는다.

설정 [12](mvp-config-12.md)·[13](mvp-config-13.md)·[14](mvp-config-14.md)의 명세와 AI 진행 기록도 당시 조건으로 보존한다. 설정 9·10은 [당시 명세](legacy-specs-9-10.md), 설정 11은 [당시 명세](legacy-specs-11.md)와 [시연 결과](../mvp_text_11/runs/playthrough.md)에 보관한다. 설정 11은 직원 보존·융합 3후보의 4개 캠페인 35턴·42개 검사를 수행했다. 직원·마나·덱 소진, 도착 시 통과+도착 등 이전 규칙을 사용했으므로 현행 규칙의 검증 결과로 합산하지 않는다.


## 5. 과거 설정 8 시연 요약

2026-10-30의 rules v0.8·config 8을 적용한 **텍스트 시연 1회**다. 원본 config 8은 현재 저장소에 없다. 일반 손님 생존 퇴장·심장 부담·경찰·옛 소진 등은 당시 조건이며 현재 규칙에 적용하지 않는다. 설정 9 v0.1 자동 시연 역시 과거 자료다.

### 조건과 범위

독립 공정 1d6 세 개 중 하나를 골랐고 카드 비용은 모두 2였다. 매 턴 현재 후보만 공개했으며 미래 난수 참조·유리한 재굴림은 없었다. 아래는 **당시 실제 사용한 임시 능력과 횟수**다.

| 직원 | 당시 능력 | 카드 사용 |
|---|---|---:|
| S 접객원 | 방문자 A +2 | 4 |
| R 녹음기사 | 방문자 B +2 | 0 |
| K 기록원 | 지정 타일의 이번 이동 첫 유효 수확 공포 +4 | 3 |
| H 봉합사 | 일반 부담 −2 또는 살아 있는 타일 내구 +2(최대 4) | 1(보스 회복) |
| C 교환원 | A 최대 2→B 1:1 | 0 |

S+R·C+K·H+S 세 쌍에서 총 4회 융합했고 S+R은 다른 후보로 재융합했다. 임시 후보 9종 중 실제 획득·배치는 대답하는 벽·반송되는 고해실·봉합된 비상구·금지된 안내방송 4종, 실제 상태는 A/B뿐이다. **직원 5종·후보 9/30종·상태 4종 전체를 검증한 기록이 아니다.**

| 구간 | 턴 | 일반 수입 | 카드 사용 | 당시 결과 |
|---|---:|---:|---:|---|

| 손님 2 | 3 | 0 | 0 | 무수확 생존 퇴장 |
| 손님 3 | 3 | 16 | 1 | 생존 퇴장 |

- 일반 17턴/보스 3턴. 일반 수확 9회(9/17≈0.529), 일반 카드 5회(5/17≈0.294). 카드 사용 턴 7(일반 5/보스 2), 미사용 13(일반 12); 빈손 일반 1/보스 0.
- 소진 일반 5/보스 1회. 실제 보스 공격 2회(마지막 공격 승리로 취소). 모든 후보가 퇴장인 턴 5/20.

- 자금 `16+일반 수입80+보스 보상20−모집36−확장8−시설6=66`. 직원 `5+9−4×2=6`.
- 보스 공포 28은 일반 수입 80과 합산하지 않는다. 마지막 수입 32 직전 잔액은 34였고 정산 뒤 구매는 없었다. 최종 잔액만으로 각 구매 시점의 자금 제약을 판단하지 않는다.

### 선택 장면과 한계

- 손님 2 첫 턴에 즉시 수확 가능한 6 대신 1을 택해 뒤의 기회를 남겼으나 필요한 눈이 나오지 않아 수입 0. 현재 확정 결과와 미래 기회를 구별할 정보가 필요했다.
- 손님 5 첫 턴은 2마나로 S/K 중 S를 선택해 같은 당장 수입 8과 A 1을 남겼다. 세 번째 턴은 중간 눈 2로 벽 수확과 뒤의 기회를 보존했고, 네 번째는 빈손으로 고해실 자체 수확을 활용했다.
- 보스 두 번째 턴에 6을 골라 재도착·공격 위험을 감수하고 마나 4를 K/H에 썼다. 고해실 내구 `2→회복4→피해2`로 생존했으며 회복이 없으면 파괴될 상황이었다. 승리 자체가 회복 덕분이었다는 뜻은 아니다.
- S+R을 소비형 벽에서 참조형 안내방송으로 재융합하고 라디오·배치를 바꿔 참조→소비를 연결했다. 인간의 이해·호기심은 별도 확인해야 한다.
- 보스 마지막 턴은 소진으로 예고 피해 3이었지만 승리로 취소됐다. 파괴가 0이므로 소진 위험의 적정성·부분 손실 뒤 복구 동기는 검증하지 못했다.

이 시연은 임시 콘텐츠의 완주·선택 장면을 확인한 자료다. 실제 참가자의 이해·호기심·재미·피로·플레이 시간·위협 적정성·재설계 동기·장기 균형·상업성은 판정하지 않는다. 다른 설정과 수익만 비교해 개선율이나 단일 변경의 인과 효과를 계산하지 않는다.
