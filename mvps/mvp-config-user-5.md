# Dread-to-Dead — 사용자 설정 5 · 종이 카드 호텔

> 2026-11-06 · 사람이 브라우저에서 플레이하는 그래픽 MVP. 전투와 캠페인 판정은 [텍스트 설정 17](mvp-config-17.md)의 `text-17-v1.1`을 사용한다.

## 한 판의 구성

영혼 2, 일반 주사위 3개, 10층 호텔로 1막을 시작한다. 1층 문틈의 시선, 3층 시선의 주인, 5층 룬 문자 벽, 6층 유혹하는 금고를 놓고 나머지 여섯 층은 빈 카드로 둔다. 각 막에서 연결된 노드 여덟 곳을 방문한다. 3막 보스 처치 후 마지막 괴이 보상의 배치·교체·폐기까지 확정하면 승리한다.

괴이 15종의 본 효과·강화, 주사위 면, 손님 수치·공격, 잠복·봉인·비활동, 시드별 난수와 복구 시점은 17판 엔진을 공유한다. 막당 구매력은 시작 자금 2와 처치·이벤트 수입 최대 9다. 일반 손님 하나에 1, 엘리트에 3영혼을 수입 한도 안에서 지급한다. 보스가 지급한 다음 막 자금 2와 지갑 이월을 구분한다. 승리를 위해 조작할 때 텍스트 명령이나 선택 이유를 입력할 필요가 없다.

## 지도와 호텔 화면

새 판은 1막의 **모험 지도**에서 시작한다. 지도를 열면 현재 막의 분기 노드와 연결선을 표시한다. 모든 노드의 정보를 살펴볼 수 있고, 방문은 현재 위치에서 갈 수 있는 노드에만 허용한다. 손님 칸과 괴이 칸은 모두 지도에서 제외한다. **호텔 보기**로 배치를 확인한 뒤 **모험 지도**로 돌아갈 수 있다.

전투 준비·전투의 진행 탭에서는 호텔 보드가 자동으로 열린다. 상점·융합·회복·보상 등에서는 해당 선택을 먼저 표시하고 **호텔 보기**로 보드를 열 수 있다. 노드를 완료하면 다음 경로를 고르는 지도로 돌아간다. 새로고침하면 저장된 막의 지도가 먼저 열리며, 진행 중이던 방문은 해당 진행 탭에서 이어간다.

## 호텔을 보여 주는 법

- **층 하나가 큰 세로형 종이 카드 한 장이다.** 1→10층 순서로 카드를 가로로 펼친다. 화면이 좁으면 좌우로 넘긴다. 10층 다음은 항상 1층이다. 건물 단면이나 객실을 카드 뒤에 그리지 않는다.
- **보드는 2행 × 10열이다.** 아래 행의 열마다 괴이 카드 또는 빈 종이 카드 한 장, 바로 위의 같은 열마다 손님 카드 또는 빈 종이 카드 한 장을 둔다. 입장 전에는 위 열 장이 모두 비어 있고, 이동 중에는 현재 위치의 위 카드 한 장만 손님이다. 양쪽 행은 함께 스크롤하며, 손님이 떠난 위 칸은 다시 빈 종이 카드가 된다.
- 주사위 눈에 마우스를 올리거나 키보드 초점을 맞추면 해당 눈의 예고를 보여 준다. 위쪽 카드에는 통과·도착, 아래쪽 카드에는 손님이 공격할 층을 표시한다. 이웃·거울 공격은 1~10층 안에 드는 대상에만 표식을 붙인다. 거울 감찰관이 1층에 도착하는 예고에는 3층에만 공격 표식이 뜬다. 경로 공격은 실제 이동에서 10층→1층을 지난 경우 두 층 모두 표시한다. 빈층 빗나감·반복 공격·대리 피격을 구별하고, 비활동으로 생길 무작위 피격은 후보로 표시한다. 주사위를 한 번 클릭하거나 탭하면 그 눈이 즉시 확정되고 이동 준비로 넘어간다. 키보드에서는 원하는 주사위에 초점을 맞춘 뒤 Enter 또는 스페이스바로 확정한다.
- 주사위 확정 전부터 공격받을 카드에 검붉은 직사각형 스티커로 **공략도 +N**을 표시한다. 점유층의 N은 해당 타격에서 방어를 차감한 공략도 증가량이다. 글씨는 흰색 볼드체이며, 현재 방어 또는 이번 이동에서 얻을 방어로 일부라도 흡수하면 `+N`만 하늘색으로 바꾼다. 전부 막으면 하늘색 `+0`이다. 빈층에는 공격 위력을 흰색 숫자로 예고하고 ‘빗나감’을 병기한다. 대리 피격은 실제로 대신 맞는 괴이에 표시한다. 연속 타격의 결과가 같으면 `×횟수`를 붙이고, 첫 타격으로 방어를 소모해 다음 결과가 달라지면 타격 순서대로 구분해 표시한다.
- 위쪽 손님 칸에는 선택한 주사위로 해당 위치에서 얻을 불안·탐욕·예언을 상태 그림과 `×획득량`으로 표시한다. 같은 층을 다시 방문해 같은 상태를 얻으면 그 층의 수량에 합산한다. 이동 전 주사위 효과는 현재 손님 위치에 표시하며 입장 전이라면 입구에 표시한다. 손님 카드의 보유 중첩과 획득 예고는 별도로 읽을 수 있다. 실제로 상태를 얻으면 테두리가 빛나는 동안 실제 획득량을 표시한다.
- 이동 확정 후 실제로 방문한 층을 순서대로 따라 위쪽 손님 카드를 옮긴다. 10→1 순환, 중간 처치·탈출, 다음 손님의 입장 전 위치를 반영한다. 동작 줄이기 환경에서도 같은 순서의 판정 결과를 확인할 수 있다. 현재 공포/한계는 손님 카드와 보드 하단에 표시하며, 손님이 입장하기 전에도 보드 하단에서 확인할 수 있다.
- 마지막 심장을 잃은 손님은 해당 층에 ‘처치’로 표시한다. 다음 손님은 첫 이동까지 보드 하단 입구에 초상·이름·순번을 표시하고, 직전 손님이 처치된 층과 이름을 함께 적는다. 첫 이동을 실행하면 새 손님 카드가 1층으로 들어온다.
- 손님 카드·입구 초상·명부의 이름을 선택하면 공격 패턴과 고유 효과를 읽을 수 있다. 현재 손님의 상세에는 남은 심장, 공포/한계, 불안·탐욕·예언 중첩과 비활동 턴 수도 표시한다. 고유 효과가 비어 있으면 ‘없음’으로 표시한다.
- 실제 손님 공격은 한 타격마다 아래쪽 대상 카드로 돌진한 뒤 원래 위쪽 칸으로 돌아온다. 대리 피격은 피해를 받는 괴이, 빗나감은 빈층을 향한다. 공포나 상태를 얻으면 손님과 효과를 낸 괴이의 테두리가 약 0.15초간 함께 빛난다. 색은 공포 보라, 불안 적갈, 탐욕 금색, 예언 남보라다. 같은 층의 연출을 순서대로 마친 뒤 다음 층으로 이동한다.
- 위쪽 손님의 현재 위치와 이동 경로는 4px 테두리로 강조한다. 예상 통과층은 점선, 예상 도착층은 실선이다. 플레이어가 선택한 아래쪽 칸의 강조 테두리도 4px 실선이다.
- 비전투 중 **호텔 보기**를 열어도 아래쪽 괴이는 같은 종이 카드로 표시한다. 재배치나 획득·제거를 확정할 때만 배치를 갱신하며, 대기 중에는 지정한 층에 그대로 놓여 있다.
- 상점 진열과 완승 보상의 선택지에도 각 괴이의 삽화와 이름을 인쇄한 종이 카드를 놓는다. 구매 가격은 해당 카드에서 읽는다.
- 점유 카드는 층 번호, 해당 괴이의 삽화와 이름, 공략도와 파훼 토큰을 표시한다. 빈층은 같은 크기와 종이 질감을 가진 빈 카드다. 번호와 빈층 표기로 이동 거리, 출구 또는 배치 대상을 식별한다.
- 속공이 있는 괴이 카드는 오른쪽 아래에 속공 하나당 금화 한 개를 놓는다. 원본 A·B 모두 속공이 있으면 왼쪽 금화는 A, 오른쪽 금화는 B다. 각 효과의 발동 조건과 비용을 따로 판정한다. 지금 쓸 수 있으면 밝은 번개 앞면, 쓸 수 없으면 어두운 빗금 뒷면이다. 상점과 보상에서도 뒷면으로 속공 보유 여부를 읽을 수 있다.
- **상태 토큰은 작은 상태 그림과 `×중첩 수`로만 표시한다.** 불안·탐욕·예언, 봉인·잠복·방어, 파훼 토큰을 카드·손님·상세·예고에 같은 표식으로 보여 준다. 바 형태를 쓰지 않는다. 그림에는 상태 이름과 설명을 붙이고, 카드에서 0인 일시 상태는 생략한다. 공략도·공포는 현재/한계 숫자로 읽는다.
- 카드를 클릭하거나 키보드로 선택하면 각 원본의 본 효과·강화와 현재 상태를 확인한다. 융합체는 본체 삽화의 왼쪽 반과 재료 B 삽화의 오른쪽 반을 결합하고 두 원본을 명시한다. 손님 위치·통과·도착과 선택층은 글자 또는 기호로도 구별한다.
- 정비 중에는 아래쪽 괴이 카드를 빈층에 끌어 놓아 이동하고 점유층에 놓아 서로 맞바꾼다. 층 재배치 메뉴에서 출발층과 목적층을 골라도 된다. 전투 또는 획득 처분 중에는 해당 단계에서 합법인 조작만 허용한다.

## 화면별 결정

| 단계 | 플레이어가 보고 결정할 내용 |
|---|---|
| 모험 지도 | 현재 막의 방문 기록과 연결된 경로, 전투 노드의 손님 정보를 확인하고 다음 방문지를 고른다. |
| 전투 준비 | 호텔 보드에서 괴이 배치와 손님 순서·공포 한계·심장·반격을 검토한 뒤 영업을 시작한다. |
| 전투 | 세 주사위의 경로와 예상 피격·토큰 손실을 본 뒤 눈 하나를 확정한다. 밝은 금화를 누르면 해당 속공만 발동하고 그 비용만 지불한다. 대상이 필요한 속공은 표시된 괴이 카드를 선택해야 발동한다. 선택 중 취소하거나 Esc를 누르면 비용을 쓰지 않는다. 필요하면 빈층에 출구를 설치한 뒤 이동한다. 미래 재굴림과 무작위 표적은 확정값처럼 공개하지 않는다. |
| 융합 | 각 막 깊이 2·5의 융합 노드에서 생존한 미융합 괴이 두 개체를 A·B 순서로 고른다. 미리보기에는 A의 층에서 함께 쓸 두 본 효과와 각각의 강화, A의 내구, 비게 될 B의 층을 표시한다. 순서를 비교한 뒤 무료로 한 번 확정하거나 건너뛴다. 융합체는 재융합하거나 분해할 수 없다. |
| 상점·전투 보상 | 상점의 여덟 슬롯 또는 완승 보상의 세 후보에서 선택한다. 새 괴이를 즉시 빈층에 놓거나 버린다. 만실이면 사라질 기존 카드와 새 카드를 식별한 뒤 교체한다. |
| 회복·이벤트·주사위 | 총 2토큰 이내의 회복, 한 개체 강화, 건너뛰기를 구분한다. 이벤트는 실제 영혼 지급액과 제거 대상을 보여 준다. 특수 주사위는 엘리트 완승·짐 이벤트에서 기존 세 자리 중 하나와 교체하거나 거절한다. |
| 정산 | 손님별 처치·영혼·파괴, 완승 보상, 막 전환, 승패를 장부에 기록한다. 새 판은 초기 자산으로 시작한다. |

## 실행과 검증 기준

로컬에서 [그래픽 MVP](../mvp_user_5/README.md)를 실행한다. 현재 판의 결정과 진행을 보존해 새로고침 뒤 이어갈 수 있게 한다. 판 번호를 지정해 같은 배치·주사위 선택을 재현할 수 있다.

검사할 경계는 10층 순환과 빈 카드, 융합 노드 전용 확정, 만실 교체, 수입 한도, 전투 중 재배치 금지, 미리보기 무소모, 최종 보상 후 승리다. 전투 엔진 검사와 브라우저 조작 검사를 따로 기록한다.
