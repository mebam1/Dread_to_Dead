# Dread-to-Dead: Fears Go Round — 설정 11 공격 연결과 직원 지원 실험

> v0.1 · 2026-10-31 작성 · **과거 config**. 직원 카드·마나·덱·융합을 사용하던 당시 절차와 [명세](legacy-specs-11.md#u-mvp11)를 보존한다. 아래의 현재·새 규칙·실행 전은 작성 당시 기준이다. 이후 [텍스트 시연](../mvp_text_11/runs/playthrough.md)에서 4개 캠페인·35턴과 42개 검사를 수행했으며, 현행 괴이 중심 규칙용 config가 아니다.

## 1. 검증 목표

**괴이의 공격 연결을 만들고, 직원으로 그 연결을 지키는 선택이 손님과 상황에 따라 달라지는가?** 융합으로 얻는 공격 법칙과 사라지는 지원 카드를 함께 비교한다.

| 근거 | 이번에 확인할 선택 |
|---|---|
| [Slay the Spire 분석](../competing_products/slay_the_spire.md) §5~7 | 총 보호량뿐 아니라 어떤 공급자·수확자를 살렸는지, 즉시 사용과 배치가 언제 유효한지, 추가 드로우의 비용이 언제 발생하는지 |
| [Balatro 분석](../competing_products/balatro.md) §3~4 | 단일 큰 공포와 실제 연쇄의 토큰 제거 차이, 공급·지원 소비·수확의 순서, 고정 보상에서도 지연할 이유가 남는지 |
| [설정 10 당시 기록](../mvp_text_10/runs/playthrough.txt) | 직원이 공격을 대신하던 문제와 안전한 지연을 새 역할·보상 규칙으로 재검증. 당시 수치를 현재 성능과 직접 비교하지 않음 |

## 2. 시험 구성

| 명세 | 위치 |
|---|---|
| 시작 자산·주사위·영업 경계·손실 유지·가격 | [공통 조건](legacy-specs-11.md#u-mvp11-setup) |
| 지원 직원·공격 괴이·고정 융합 후보 | [콘텐츠](legacy-specs-11.md#u-mvp11-content) |
| 방어 순서·배치 실패·사용 카드·소진 예외 | [세부 판정](legacy-specs-11.md#u-mvp11-operations) |
| 손님별 공격 목록·한계·보상 | [방문자](legacy-specs-11.md#u-mvp11-visitors) |
| 통제 시작 상태·계산 답안 | [판정 진단](legacy-specs-11.md#u-mvp11-diagnostics) |

범위는 상태 1종, 지원 직원 5종, 시작 괴이 3종, 한 직원쌍의 고정 융합 후보 3종이다. 일반 시설·범용 공격 복제·직원의 공격 강화·파훼 토큰 복구는 이번 콘텐츠에 포함하지 않는다. 공급·공포·증폭은 괴이만 수행한다.

## 3. 진행 순서

### A 판정 사전 점검

[진단](legacy-specs-11.md#u-mvp11-diagnostics)의 D1~D7을 먼저 검산한다. 공격은 타격별로, 공포는 실제 효과별로 처리한다. 계산이 다르면 플레이 결과를 해석하기 전에 판정·표시를 수정한다.

고정 현재 눈과 덱 순서는 해당 진단에만 사용한다. 실제 플레이에서 나온 저장점이나 공정 난수 표본으로 취급하지 않는다. 진단 답안은 진행자용이며 참가자의 첫 설명 전에 해설하지 않는다.

### B 직원 보존 또는 융합 후 연속 영업

시작 괴이의 공급·증폭·수확과 직원의 지원 효과를 짧게 소개한 뒤, G/T 보존 또는 융합을 선택하게 한다. 고정 후보의 전체 효과와 소모될 직원 개체를 공개하고 배치·편성을 확정한다. 보존도 유효한 선택이다.

첫 영업의 손님 둘을 같은 호텔로 연속 상대한다. 그 사이 구매·재배치·편성은 하지 않으며 손상과 남은 페널티를 이월한다. 영업을 끝내면 페널티만 초기화하고, 고정 보상으로 모집·괴이 구매·공략도 수리를 선택한 뒤 다음 영업을 진행한다. 파훼 토큰과 파괴 자산을 무료 복구하지 않는다.

일반 플레이는 매 단계 실제 셔플·굴림을 수행하며 미래 순서를 공개하지 않는다. 같은 난수 분기를 비교할 때는 같은 현재 턴까지만 확인한다. 소진·행동 횟수가 달라 난수 소비가 달라졌다면 결과 차이를 후보 하나의 효과로 단정하지 않는다.

각 손님이 끝나면 선택 이유와 남은 공격 연결을 기록한다. 지시 전에 다른 배치·융합 후보를 스스로 찾는지 관찰한다. 비교를 요청한 뒤 나온 행동은 안내 후 반응으로 분리한다. 다른 후보의 비교는 독립된 시작 상태에서 재료를 다시 소모하는 새 분기다.

### C 패턴과 지원 시점 비교

D3의 같은 시작 상태에서 손님의 공포 한계만 바꿔, 상태를 공격에 남길지 지원에 소비할지 선택하게 한다. 별도 D2-P 분기에서는 공격 패턴만 바꿔 같은 손패의 보호 필요·주사위 선택이 달라지는지 본다.

미방문 괴이를 즉시 지원하는 D2와 이동 중 공급을 기다리는 D3를 구분한다. D4에서는 한 이동의 재방문에도 배치 지원이 한 번만 발생하는지 확인한다. 미리보기를 읽은 답과 확인 전 예측을 나누고, 수치 적중보다 원인 설명을 평가한다.

### D 드로우와 지연의 영업 전체 비용

D5에서 추가 드로우로 얻은 카드를 같은 사용 단계에 쓰고, 현재 눈이 그대로인 채 페널티만 늘어나는지 확인한다. 현재 방문자 처치 뒤 같은 영업의 다음 손님으로 넘어가 이월을 확인하고, 영업 마지막 손님 직전 분기와 비교한다. 마지막 처치 후 더 굴리지 않는 페널티를 실질 손해로 계산하지 않는다.

D5는 처리·이월 검증이다. 처치로 공격이 취소되므로 G의 실효 보호량은 0이다. 추가 드로우의 현재 보호 이익과 미래 비용은 B의 방문자가 살아남는 턴에서 별도로 비교한다.

D7에서는 즉시 처치와 한 번 더 순환하며 회복하는 선택을 비교한다. 고정 보상 외에 남은 C/P, 추가 턴·소진·보호 비용을 기록한다. 지연 후 보상이 같아도 회복·준비 때문에 항상 기다리는 편이 유리한지 따로 본다.

## 4. 공개 정보와 기록

매 턴 현재 손패·마나·주사위 후보, 이동 경로, 순서 있는 공격 목록, 괴이 C/L/P, 상태, 남은 페널티, 고정 보상을 표시한다. 카드 선택 후에는 즉시 변화와 설치된 배치를 구별해 미리보기를 갱신한다. 직원이 손님 상태를 새로 공급하거나 공포를 내는 표시는 오류다.

```text
실행 ID / 날짜 / config·rules·시험 명세 버전 또는 해시:
모드: 인간 플레이 / 자동 판정 시연
참가자 ID / 단계·분기 / 초기화·통제 조건:
영업·손님 / 공격 패턴 / F·T·H·상태 / 위치 / 고정 보상:
직원 풀·실제 덱 / 융합 재료·후보·선택 이유 / 괴이 배치·C/L/P:
드로우·버림·사용 중 카드 / 소진 발생 시점과 횟수:
페널티: 이월량 → 굴림 전 추가 → 이번 소비 → 사용 단계 추가 → 종료 잔량
공개 눈·선택·마나 / 즉시 카드 대상·상태 소비 / 배치 위치·대상·발동·불발:
공포 효과별 공급자·입력·소비·F/H 변화·버린 초과량:
타격별 원래 대상·위력 → 흡수 → 이전 대상 → 최종 증가량 → C/P·파괴:
고정 보상 지급 여부·누계 / 구매·수리·직원 소모 / 다음 손님의 연결:
선택 전 설명 / 미리보기 확인 여부 / 진행자 힌트 / 다음 자발적 행동:
종료: 처치 / 관찰 상한 / 생산 불능 / 참가자 중단 / 판정 오류
```

소진 횟수와 실제 감소한 굴림 횟수는 별도로 센다. 공략도 감소를 파훼 토큰 회복으로, 공략도 0을 온전한 괴이로 기록하지 않는다. 참가자별 설명과 행동을 다른 사람의 결과와 합쳐 성공 사례로 만들지 않는다.

## 5. 판단과 다음 수정

| 관찰 | 판단·수정 우선순위 |
|---|---|
| 패턴·남은 C/P에 따라 보호 대상이나 방식이 달라짐 | 보호가 공격 연결 유지에 기여한 구체 사례로 기록 |
| 지원에 상태를 쓰면 공격이 늦어지고, 남기면 처치로 반격을 취소함 | 두 선택이 각각 유효한 조건을 기록. 항상 한쪽이면 상태·피해·한계 중 한 변수부터 조정 |
| 큰 한 번과 연쇄의 차이를 설명하고 목표 도착·후보를 바꿈 | 실제 효과 수와 토큰 제거가 읽히는지 확인 |
| 추가 드로우가 늘 정답이거나 늘 기피됨 | 현재 보호 이익·덱 크기·누적 페널티·영업 마지막 사용을 분리 |
| 고정 보상인데도 안전한 회복·축적 대기가 반복됨 | 지연으로 얻는 이익과 공격 패턴·성장 상한부터 점검 |
| 후보가 달라도 같은 직원·배치만 반복함 | 조합 수를 늘리기 전에 공급·수확·보호 수요의 차이를 수정 |

자동 검산·완주는 판정과 가능한 전략의 근거다. 인간 검증은 같은 사람이 융합의 인과를 설명하고 실제 선택을 바꾸며 다음 조합을 자발적으로 탐색하는지로 판단한다. 이 절차는 실행 전에 작성되었다. 이후의 자동 시연 결과는 [별도 기록](../mvp_text_11/runs/playthrough.md)에 있으며 인간의 재미 검증은 수행하지 않았다.
