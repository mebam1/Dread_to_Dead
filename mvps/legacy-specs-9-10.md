# 설정 9·10 — 과거 시험 명세

> 2026-10-31 분리 보관. 아래는 2026-10-30에 작성한 시험안으로 **현행 규칙에 적용하지 않는다**. 본문의 ‘확정·현재’는 작성 당시 기준이다. 공격 직원·시설, 초과 공포 보상, 단일 내구, 종류별 고정 공격 범위, 옛 소진 처리를 새 실험에 계승하지 않는다. 현행 판정은 [rules.md](../rules.md)를 따른다.

<a id="legacy-rules"></a>

## 당시 공통 판정 요약

- 반복 원형 루프에서 선택한 주사위 눈이 이동·마나를 함께 결정한다. M4 융합은 직원 2명 소모·고정 3후보 중 1개 선택이며 덱은 0~20장이다.
- 턴은 드로우·소진 → 주사위 선택 → 직원 부착 → 이동·효과 → 생존 방문자 공격 → 정리 순서였다. 모든 직원은 슬롯에 통과·도착 효과를 예약하며 즉시 발동하지 않았다.
- 도착은 통과 후 도착 효과. 공포·방문자 상태는 회전 사이에 유지되고, 공포 한계 도달 시 심장 토큰 1개 제거·공포 0·초과 공포만 재화로 지급했다.
- 마지막 심장 토큰 제거 시 남은 효과·이동·공격을 모두 중단했다. 일반 손님은 최종 도착 칸 1회, 보스는 실제 방문한 칸을 방문 횟수만큼 공격했다.
- 덱 소진은 그 턴 주사위 수 −1·버림 셔플·보충 드로우로 처리했다. 손패는 셔플하지 않았다. 중복 소진 등 시험별 예외는 아래 명세를 따랐다.
- 사용 카드·잔여 손패는 버리고 임시 직원 효과·마나는 턴말 정리했다. 타일 내구·재방문 직원 발동·운영·콘텐츠는 아래 시험값을 사용했다.
- 각 설정의 시작 조건·분기 복원은 실험 통제이며 게임의 무료 자산·부활 규칙이 아니다. 작성 당시 검증 상태를 보존하며 새 실행 결과를 추가하지 않았다.

## MVP 범위·설정 9 시험안

아래는 기존 설정 9 v0.2와 MVP 계획의 **미채택 시험 제안**이다. 새 플레이·밸런스·인간 재미 검증은 아직 없다. 확정 공통 규칙은 [rules.md](#legacy-rules)를 따른다.

<a id="u-mvp-scope"></a>

### 제작·관찰 범위 제안

- 팩션 1개, 직원 5종(복수 모집 가능), 이종 10쌍×고정 3후보=괴이 30종, 시설 4종·상태 4종, 일반 손님 5명·보스 1종. M4는 동종도 허용하지만 이 MVP에서는 제외한다.
- 첫 제작 단위는 직원 3종→이종 3쌍→후보 9종. 직원 사용→융합→후보 비교→배치→심장마비·공격을 먼저 검증하고, 반응이 약하면 30종 확대를 보류한다.
- 한 판: 시작 경영→일반 손님 3명 처치→보스 격퇴→경영·재설계→일반 손님 2명 처치. 2D 카드·고정 테이블 표현을 우선한다.
- 첫 경험 참가자 4~6명에게 문제를 찾고 수정 후 새 참가자로 재확인한다. 시장성을 입증하는 표본은 아니다.
- 후순위: 두 번째 보스·다섯 번째 상태, 과도한 전신/3D 애니메이션, 장기 메타 성장, 복제·소환·대리도착·별도 시스템, 전체 도감·게임 내 설문 관리.

### 설정 9: 세부 판정 제안

- 소진 페널티는 **턴 첫 소진에만 주사위 −1**(3→2); 같은 턴 재소진은 추가 감소 없음. 버림까지 비면 부족한 드로우만 중지하고 턴은 계속한다. 정식 K=1·다중 소진·주사위 하한 판정은 미정이다.
- 발동 순서: `영구 통과→직원 통과→최종 도착에서 영구 도착→직원 도착`. 같은 단계의 직원은 사용 순서. 필요한 상태 종류는 부착할 때 지정하되 입력량은 발동 시 확인한다. 부착 시 입력 0이어도 가능하며, 미방문·조건 부족은 불발·환급 없음.
- 직원 부착은 **실제 방문마다 한 번씩 재발동**한다는 시험안이다. 확정된 보스 재방문 공격과 구별한다.
- 개별 공포 효과는 토큰을 최대 1개 제거한다. 같은 이동의 서로 다른 후속 효과는 별도 심장마비를 만들 수 있다.
- 입장 시 위치 0·공포 0·상태 모두 0. 매 방문자 시작에 편성 덱을 셔플하고 손패·마나를 초기화하며 직원 부착은 이월하지 않는다.
- 공격은 이동·효과 뒤 기록된 방문 순서대로 해결한다. 빈칸·파괴된 칸은 빗나가며 대체 대상을 찾지 않는다. 내구 0 이하 타일은 이번 판에서 제거하되 슬롯·다른 자산·직원 풀·획득 재화는 남는다. 자동 부활 없음.
- 일반 손님 사이 손상은 유지한다. 보스 격퇴 뒤 **살아 있는 타일만 내구 4로 회복**한다. 정식 회복 시점은 미정이다.

### 설정 9: 상태·시설·직원·괴이 제안

모든 내용은 시험 콘텐츠다. 특히 봉합사·휴게실·SH2·RH3·KH1·HC2·HC3의 **타일 회복은 폐기된 심장 부담 회복을 대체한 신규 제안**이다. 설명에 없는 추가 소비·이동·소환·부활·숨은 효과는 없다.

**상태:** 불안(예고된 걱정), 환청(출처 없는 목소리), 기시감(일어나기 전 기록된 듯한 기억), 봉인(걱정·소리·기억을 봉합한 흔적). 각 0~9 정수, 자연 감소 없음. 회전·심장마비에도 유지하고 방문자 종료 시 정리한다. 공포·토큰·재화는 이 4상태와 별개다.

**공통 계산:** `최대 n 소비`는 가진 만큼, `정확히 n 필요`는 부족 시 불발, `참조`는 소비 없음. 1:1 변환은 출력 여유만큼만 소비한다. 1→2 또는 두 상태 생성은 **완전한 묶음**만 처리한다. 직접 부여는 상한 초과분만 버린다. 아래 q는 **그 방문에서 해당 영구 타일 자체가 실제 처리한 양**이며 후속 직원 효과를 합산하지 않는다. 공포 효과는 F를 높이고, 재화는 심장마비 때 초과분만 지급한다.

| 시설 | 통과 | 도착 |
|---|---|---|
| 수상한 안내판 | 불안 +1 | 없음 |
| 벽 속 라디오 | 환청 +1 | 없음 |
| 닫힌 객실 | 없음 | 불안 최대 2 소비, 1개당 공포 +4 |
| 휴게실 | 이동 방향의 바로 다음 슬롯에 있는 살아 있는 시설·괴이 내구 +1(최대 4); N→1 연결, 빈칸·파괴·온전한 타일이면 0 | 없음 |

| 직원·행동 | 통과 | 도착 |
|---|---|---|
| S 접객원·예고 | 불안 +2 | 없음 |
| R 녹음기사·재생 | 환청 +2 | 없음 |
| K 기록원·기록/대조 | 없음 | 부착 시 지정한 상태 1종 최대 2 참조, 1개당 공포 +2; 빈 슬롯도 가능 |
| H 봉합사·타일 봉합 | 부착 슬롯의 살아 있는 시설·괴이 내구 +2(최대 4); 온전·빈칸이면 0, 보호막 축적 없음 | 없음 |
| C 교환원·전환/중계 | 불안 최대 2→환청 1:1 | 없음 |

다음 **각 쌍의 3행이 고정 후보**다. 같은 쌍의 선택 순서는 무관하고 재추첨하지 않는다. 괴이는 영구 타일로 방문할 때 발동하며 턴말 제거하지 않는다. 공급·지원형의 도착 효과는 없어도 된다.

| **RH2 봉합선의 합창** — 봉합을 열자 목소리가 돌아옴 | 없음 | 봉인 최대 2→환청 1:1, 실제 변환량 n당 공포 3 |
| **RH3 무음 치료실** — 방을 꿰맬 때 사라진 소리가 다시 흐름 | 자기 내구 최대 2 회복→실제 회복량 q만큼 환청 +q. 환청 상한은 회복을 막지 않음 | 없음 |
| **R+C / RC1 혼선 교환대** — 한 걱정이 여러 발신자의 목소리가 됨 | 불안 최대 2 소비, 1개당 환청 2; 출력 2개 단위의 완전한 묶음만 | 없음 |
| **RC2 수신자 없는 통화** — 반송한 목소리가 미래의 경고가 됨 | 없음 | 환청 최대 2→불안 1:1, 실제 변환량 n당 공포 3 |
| **RC3 지난밤의 발신자** — 기억은 남기고 그때의 목소리를 연결 | 기시감 최대 2 참조→같은 양 환청 부여; 기시감 보존 | 없음 |
| **K+H / KH1 봉합 진료기록** — 방 수리 기록이 공포를 만듦 | 자기 내구 최대 2 회복, 실제 회복량 q 기록 | 공포 4q. 손상·도착 없으면 0 |
| **KH2 흉터 보관함** — 기억을 봉합 흔적으로 보관 | 기시감 최대 2→봉인 1:1 | 없음 |
| **KH3 지워지지 않는 병력** — 기억과 봉합 흔적이 지운 상처를 증명 | 없음 | 기시감 1+봉인 1 소비→공포 8; 추가 부작용 없음 |
| **K+C / KC1 반송되는 고해실** — 전달한 걱정이 자기 목소리·접수기록이 됨 | 불안 최대 2→환청 1:1, 실제 변환량 q 기록 | 공포 4q, 환청 추가 소비 없음; 기존 환청만으로 수확 불가 |
| **KC2 수취인이 바뀐 장부** — 두 수신자가 바뀌어 걱정과 소리가 뒤바뀜 | 현재 불안·환청 수량을 **동시에 교환**. 합계 유지, 기시감·봉인 불변 | 없음 |
| **KC3 접수되지 않은 고백** — 전달되지 못한 걱정의 차이만 남음 | 없음 | `n=min(2,max(불안−환청,0))` 참조→공포 3n. 상태 보존·추가 부작용 없음 |
| **H+C / HC1 통증 교환실** — 봉인을 풀어 미래의 걱정으로 넘김 | 봉인 최대 2 소비, 1개당 불안 2; 출력 2개 단위의 완전한 묶음만 | 없음 |
| **HC2 감각이 바뀐 치료실** — 목소리를 방 수리의 봉합재로 전환 | 환청 정확히 2→봉인 1→자기 내구 최대 2 회복. 환청 2·봉인 공간 1 모두 필요 | 없음 |
| **HC3 이송되는 봉합선** — 봉합선을 다음 객실로 전달 | 봉인 1 소비→이동 방향의 바로 다음 슬롯에 있는 살아 있는 시설·괴이 내구 최대 2 회복. 실제 손상이 있을 때만 소비 | 없음 |

**해석 경계·선택의 상충:**

- SR2는 불안 조건만 참조한다. SK2는 불안만 소비한다. SH2는 온전하거나 봉인 공간이 없으면 불안을 쓰지 않는다. SH1 뒤 SH3을 쓰려면 남은 불안/재공급이 필요하다.
- RK2의 q에는 같은 칸의 후속 녹음기사 공급이 들어가지 않는다. KH1의 q에도 후속 봉합사 회복을 합산하지 않으며, 앞서 회복하면 KH1 수확량은 줄어든다.
- RH2·RC2·KC1은 **변환**이므로 출력 상한에 막힌 만큼 소비·공포도 줄어든다. RH3은 **회복 후 부여**이므로 환청 상한과 무관하게 회복한다.
- KC2는 순차 대입·복제가 아니다(불안 3/환청 1→불안 1/환청 3); 두 번 적용하면 원래 비율로 돌아갈 수 있다. KC1은 옛 시연의 환청 소비 수확과 혼용하지 않는다.
- HC2는 온전해도 변환 가능하지만 변환 불가 시 무료 회복도 없다. HC3은 N→1로 연결하며 빈칸·파괴·온전한 타일이면 소비 없음; 건너뛰기·위치/도착/공격 대상 변경 없음.
- SC2는 원격 발동/사건 재현이 아니고 RC3는 과거 효과 복제·소환이 아니다. 현재 방문자의 상태만 처리한다.
- 소비/변환은 뒤쪽 수확 입력을 줄일 수 있고 참조는 보존한다. 차이 수확 SK2·KC3는 비교 상태를 늘리면 감소한다. 직접 수확이 없는 후보는 공급·지원의 배치 가치로 비교한다.

**재료 직원 소모 후 입력 경로:**

| 입력 | 대체 공급 예 |
|---|---|
| 불안 | 안내판 / SC1 / RC2 / SK3 / HC1 |
| 환청 | 라디오 / SR1 / RC1 / KC1 / RH2 / RH3 / RC3 |
| 기시감 | 안내판→SK1 / 라디오→RK1 / 불안+환청→SR3 / 불안→SC2 |
| 봉인 | 불안→SH1 / 환청→RH1 / 기시감→KH2 / 조건을 갖춘 SH2·HC2 |
| 회복할 손상 | 일반 도착 공격·보스 매 방문 공격 이후의 타일 손상 |

목록에 경로가 있다는 사실이 한 판의 제작 가능성을 보장하지 않는다. 실제 남은 직원 쌍·재화·슬롯·모집 기회를 확인하고, 기시감·봉인 후보에는 현재 입력과 추가 필요 자산을 함께 표시한다. 30종 명세 작성만으로 체크리스트 통과나 후보 차이·재배치·인간의 인과 이해를 검증한 것으로 보지 않는다.

|---|---:|---:|---:|---:|
| 일반 1 | 1 | 12 | 1 | 12 |

- 일반 12턴은 자동 시연 교착 방지용 실패 진단값이다. 12턴째 마지막 토큰을 제거하면 성공한다.

- 보스는 8턴 뒤 토큰이 남으면 시간 초과, 어떤 타일/직원으로도 공포를 만들 수 없으면 생산 불능을 실패 후보로 둔다. 생산 불능은 잠긴 덱의 기록원·살아 있는 타일·남은 상태까지 고려한다. 수확 타일 하나의 파괴만으로 선언하지 않는다.
- 전 경로 공격으로 피해 총량이 달라졌으므로 옛 보스 도착 피해 2를 승계하지 않는다. 피해 1·H1·T45·8턴 조합과 가격·수복 시점 모두 밸런스 검증 대기다. 실패를 숨기려고 목표·난수를 바꾸지 않는다.

<a id="u-mvp-diagnostic"></a>

### 별도 재방문 공격 진단안

메인 설정 N≥6·최대 이동 6에서는 한 이동 중 동일 슬롯 중복 방문이 없다. **메인 설정 변경 없이** 별도 장면을 사용한다.

- 조건: N=4, 각 내구 4, 보스 위치 0, 진단 중 처치되지 않을 T/H, 공포 효과 없음, 이동 6·피해 1.
- 경로/공격: `①→②→③→④→①→②`, 총 6회. 기대 내구 `①②=2/4, ③④=3/4`.
- 최종 도착의 통과·도착 효과가 둘이어도 마지막 ② 방문 공격은 한 번이다. 이 장면은 공격만 시험하며 직원 재방문 발동 여부는 별도 미정이다.

일반 실행의 셔플·굴림은 현재 단계에서만 수행·기록한다. L의 첫 덱과 C/E의 고정 현재 상태는 교육·진단을 위한 통제 조건이며 공정 난수 표본으로 집계하지 않는다. 저장점은 진단용 구성 상태이며 실제 플레이에서 얻은 로그라고 주장하지 않는다. 재실행은 별도 분기로 기록하며 유리한 결과만 남기지 않는다.

### L 학습과 F 자유 선택의 시작 상태

| 항목 | 값 |
|---|---|
| 직원 풀·기본 덱 | S01 접객원, R01 녹음기사, K01·K02 기록원. 각 보유 개체당 카드 1장, 기본 4장. 경영에서 0~20장 범위 편성 가능 |
| 자산·재화 | 안내판·라디오·닫힌 객실 각 1, 내구 모두 4. 괴이·보관 자산 0, 잔액 0 |
| 배치 | ① 안내판 → ② 빈칸 → ③ 라디오 → ④ 빈칸 → ⑤ 닫힌 객실 → ⑥ 빈칸 |
| 방문자 초기값 | 위치 0, F=0, 상태 모두 0, 손패·버림·마나 0 |
| L 방문자·첫 덱 | 일반 H=1·T=12. 첫 덱 위부터 S01→R01→K01→K02로 고정해 직원 행동을 소개. 이후 소진 셔플은 공정하게 수행 |
| F 방문자·첫 덱 | 일반 H=2·T=12. L 종료 후 위 시작 자산을 복원하고 경영 선택. 편성 확정 후 공정 셔플 |
| 첫 융합 선택 | 보존 또는 S01+R01→SR1/SR2/SR3 중 1. 추가 재화 비용 없음. 확정 전 무료 취소, 확정하면 두 개체 영구 소모 |
| 융합 뒤 기본 덱 | 남은 K01·K02 두 장. 편성을 변경하면 실제 덱을 기록. 후보 비교에서 편성이 다르면 통제된 동일 조건 비교로 해석하지 않음 |

**L은 명시된 풀·덱·배치를 고정하고 경영 선택은 F부터 허용한다.**

두 기록원은 S/R을 소모한 뒤에도 상태를 수확하게 하는 시험 편성이다. S/R의 중복 대체 직원은 주지 않는다. 두 K를 매번 함께 쓰는 것이 일률적으로 유리하면 그 자체를 관찰 결과로 남긴다. 덱 감소와 소진 변화는 융합 법칙의 효과와 구분한다.

| 후보 | 유지하는 기존 법칙 | 재료 소모 뒤 실행 경로 |
|---|---|---|
| SR1 대답하는 벽 | 통과: 불안 정확히 1→환청 2. 도착: 환청 최대 2 소비→개당 공포 4 | 안내판으로 불안 공급, 라디오로 환청 보충. 소비 뒤 K가 참조할 상태가 남는지 확인 |
| SR2 금지된 안내방송 | 도착: 불안≥1일 때 환청 최대 2 참조→개당 공포 2. 상태 보존 | 안내판·라디오로 조건 충족. 남은 상태를 K나 이후 도착에서 재사용 |
| SR3 오지 않은 호출 | 통과: 불안 1+환청 1 소비→기시감 2. 자체 공포 없음 | 안내판·라디오→SR3→K의 기시감 참조 도착으로 수확. 직접 수확이 없다는 점을 선택 전에 표시 |

출력 공간·묶음 처리·상태 상한은 계승 명세대로 적용한다. 위 경로는 작동 가능성을 설명하며 세 후보의 동등한 효율을 보장하지 않는다. F의 다른 후보를 비교할 때는 융합 전 상태부터 새 분기를 시작해 S/R을 다시 소모하고, 여러 턴의 상태·판단을 기록한다.

<a id="u-mvp10-space"></a>

### C 공간 진단 저장점

주사위 공개 후·선택 전 상태를 복원한다. 풀·덱은 K01/K02, 두 장을 정상 드로우한 첫 턴으로 소진 없음, 손패 K01/K02·뽑을 덱 0·버림 0·마나 0·잔액 0이다. 이 진단에는 SR1이 시작 자산으로 주어지므로 융합 선택의 증거로 사용하지 않는다.

| 공통 항목 | 값 |
|---|---|
| 방문자 | 일반, 위치 0·F=0·T=6·H=1·모든 상태 0 |
| 타일 | 안내판·SR1·라디오·닫힌 객실 각 1, 내구 모두 4 |
| 현재 공개 눈 | [2, 3, 3], K=3. 여기서 한 눈 확정 후 카드 사용 |
| A 배치 | ① 안내판 → ② SR1 → ③ 라디오 → ④ 닫힌 객실 → ⑤ 빈칸 → ⑥ 빈칸 |
| B 배치 | ① SR1 → ② 안내판 → ③ 라디오 → ④ 닫힌 객실 → ⑤ 빈칸 → ⑥ 빈칸 |
| 비교 | 첫 행동만 비교하고 매번 초기 상태 복원. A→B / B→A를 참가자별 교차. 이후 자유 재배치 진단 1회 |

**진행자 검산 기준 — 참가자의 첫 예측 전에 해설하지 않는다.**

| 선택·예약 | 기대 결과 |
|---|---|
| A에서 2, 카드 없음 | 안내판 불안 1→SR1 환청 2→환청 소비·공포 8. H=0·재화+2·공격 없음 |
| A에서 3, K 1장을 ③에 부착해 환청 참조 | SR1은 통과만 해 환청 2, 라디오로 3. K 공포 4, F=4·H=1·재화 0, 라디오 내구 3 |
| B에서 2, K 1장을 ②에 부착해 불안 참조 | SR1 입력 부족, 안내판 불안 1, K 공포 2. F=2·H=1·재화 0, 안내판 내구 3 |

각 눈의 마나는 같은 숫자이며, 2·3마나로는 비용 2의 K를 한 장만 쓸 수 있다. 위 선택들은 판정 확인 사례이며 모든 최적 행동을 열거한 답안이 아니다. A의 작은 눈이 유리한 사례만으로 주사위 시스템 전체를 검증하지 않는다.

<a id="u-mvp10-economy"></a>

### E 수익 지연 진단 저장점

주사위 공개 후·선택 전의 구성 상태다. 풀·편성 K01/K02, 이번 턴 소진으로 버림을 섞어 두 장을 보충한 뒤이므로 손패 K01/K02·뽑을 덱 0·버림 0, 실제 K=2다.

| 항목 | 값 |
|---|---|
| 배치 | ① 안내판(4/4) → ② 빈칸 → ③ 라디오(4/4) → ④ 빈칸 → ⑤ 닫힌 객실(1/4) → ⑥ 빈칸 |
| 방문자 | 위치 3·F=2·T=8·H=1, 불안 2·환청 1·기시감 0 |
| 현재 공개 눈·재화 | [2, 3]·마나 0·잔액 0 |
| 비교 조건 | 같은 상태에서 일반 손님 / 보스 각각 실행. 달라지는 것은 확정 공격 범위뿐 |
| 첫 선택 비교 | 2로 ⑤ 도착해 즉시 처치 / 3으로 ⑥ 도착하고 K로 공포를 준비 |
| 후속 진행 | 다음 턴 드로우·소진부터 정상 처리하고 현재 실제 K만큼 공정 굴림. 방문자 종료 또는 시작점부터 8턴까지 관찰 |
| 순서 | 일반→보스 / 보스→일반을 참가자별 교차. 즉시 처치·지연 분기는 각각 초기화 |

**진행자 검산 기준:**

- 눈 2·카드 없음: ④→⑤, 객실이 불안 2를 소비해 공포 8. F2+8−T8=재화 2, H=0. 일반·보스 모두 공격 중단, 객실 내구 1 유지.
- 눈 3·K 1장을 ⑥에 부착해 불안 참조: ④→⑤→⑥, 객실 도착 효과 없음. K 공포 4로 F=6, 불안 2·환청 1 유지, H=1·재화 0.
- 위 지연에서 일반 손님은 빈칸 ⑥을 공격해 피해 0. 보스는 실제 경로의 ⑤도 공격해 객실 파괴. 기록원은 남으므로 객실 파괴만으로 생산 불능이라 판정하지 않는다.
- 일반 분기에서 이후 다른 공포 효과 없이 살아 있는 객실에 도착하면 공포 8로 재화 6을 얻을 수 있다. 필요한 미래 눈·도착은 보장하지 않는다. 이것은 무위험 준비의 가능성을 찾는 조건부 계산이며 무한 수익을 뜻하지 않는다.

즉시 수익과 최종 수익, 추가 턴·선택 횟수, 피해·파괴, 지연 중 반복 행동을 분리해 기록한다. 장기 경제·가격 균형을 이 진단으로 판정하지 않는다.

### 선택적 다음 직원쌍 탐색

F의 자발적 관찰 뒤 다른 직원쌍을 시험하려는 참가자에게만 독립 확장 상태를 연다. F 시작의 시설·배치·풀을 복원하고 **시험 예산 8**을 제공한다. 이는 플레이로 번 재화가 아니며 경제 성과에서 제외한다.

- 고정 모집 후보 S/R/K, 비용 각 4, 총 최대 2명. 같은 종류 중복 모집 가능, 새 개체 ID를 부여한다. 후보 재추첨 없음.
- 이종 S+R·S+K·R+K의 고정 3후보씩, 기존 총 9후보만 사용한다. 동종 조합은 이번 콘텐츠 범위에서 제외한다.
- 풀·재화가 허용하는 융합·편성·재배치를 수행하고 F와 같은 방문자 1회 실행한다. 여러 융합도 실제 직원 2개체씩 소모한다.
- 제안한 조합, 실제 모집·융합, 입력·수확 경로, 바꾼 배치·카드 사용을 기록한다. 입력이나 수확 수단이 막히면 추가 직원·무료 괴이로 수습하지 않는다.
- 참가자가 계속하고 싶었으나 시간 상한으로 실행하지 못했다면 관심·계획만 기록하고 실제 탐색 실행은 미관찰로 남긴다.
