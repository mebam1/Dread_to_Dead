# Dread-to-Dead: Fears Go Round — 사용자 설정 1

> v1.1 · 2026-11-01 · 이름·효과 표시, 카드와 층 박스, 호버 정보, 층 액티브 버튼을 반영한 웹 게임 설정. 구매·배치부터 최종 보스 처치, 패배, 재시작까지 연결하는 2D 도형 프로토타입의 구현 명세. 사용자 결정과 위임받아 채운 기본값을 함께 고정한다. 구현·플레이·밸런스 검증을 완료했다는 뜻은 아니다.

## 1. 적용 범위와 결정의 출처

- 이 프로토타입에는 본 문서를 우선 적용한다. 공통 골격은 [핵심 규칙](../rules.md), 용어는 [terms.md](../terms.md), 표현 원칙은 [arts.md](../arts.md)를 참고한다.
- 사용자 결정은 아래 표와 같다. 과거 설정의 고정 구매망, 구매 잠금, 파괴된 괴이의 층 점유·다음 영업 부활은 이번 프로토타입에 적용하지 않는다.
- 나머지 수치·콘텐츠·경계 판정은 사용자가 위임한 프로토타입 기본값이다. [설정 12 콘텐츠](../undecided.md#u-mvp12-content)와 [설정 14 판정](../undecided.md#u-mvp14)을 바탕으로 아래에 실행값을 명시한다.
- 한 판을 시작한 뒤 난수나 수치를 결과에 맞춰 바꾸지 않는다. 밸런스 변경은 다음 명세 버전·새 판부터 적용한다.

| 사용자 결정 | 이번 설정의 적용 |
|---|---|
| 처음 보는 개념마다 짧은 설명 팝업, 옵션으로 표시 여부 선택 | 상황별 첫 등장 튜토리얼과 표시 켜기/끄기 제공 |
| 일반 영업 3회 뒤 보스 1회, 이를 2번 반복 | 영업·보스 구간을 합쳐 총 8전투 |
| 일반 영업의 손님은 3명 | 일반 6구간 × 3명 + 보스 2명 = 최대 20명 상대 |
| 마지막 보스 처치가 최종 목표 | 8번 구간에서 최종 보스의 마지막 심장을 제거하면 즉시 승리 |
| 탈출 후 처치한 손님의 보상만 유지하고 계속 진행 | 현재 탈출 손님·미등장 손님은 무보상, 최종 보스 탈출은 패배 |
| 파괴된 괴이 복구 불가, 즉시 빈층, 동종 재구매 허용 | 해당 개체는 영구 손실, 다른 구매 노드에서 새 개체 획득 가능 |
| 보유 중인 괴이도 블러드 웹에 중복 출현 가능 | 보유 여부와 무관하게 추첨, 같은 웹 안에서도 같은 종류 중복 가능 |
| 랜덤 구매망, 연결·선행 조건·가격 공개 | 연결과 괴이 종류를 생성하고 현재 웹 전체를 공개 |
| 영업 종료마다 리셋권 1회 추가 | 보관 가능한 리셋권 +1, 사용 시에만 웹 재생성 |
| 구매한 노드는 재방문 불가 | 노드별 1회 구매·소진, 구매 이력을 선행 조건 판정에 사용 |
| 괴이는 약자 대신 이름과 효과로 표시 | 화면·도움말·로그·설정에서 괴이와 상태 이름을 풀어 쓰고 수치·대상·조건을 함께 표시 |
| 구매 전·배치 전·보관 중에는 카드 형태 | 블러드 웹과 보관함에서 같은 양식의 괴이 카드 사용 |
| 배치 후에는 층의 박스 형태 | 호텔 층 안의 박스에 이름·주요 효과·현재 상태 표시 |
| 배치된 층 호버 시 카드 정보 | 마우스 호버·키보드 초점·탭으로 동일한 상세 카드 확인 |
| 사용 가능한 액티브는 층의 버튼으로 실행 | 현재 사용할 수 있는 층에 효과 이름을 쓴 버튼 표시, 대상이 필요한 효과는 층 선택으로 완료 |
| 웹 게임, 직관성과 편의성 우선 | 설치 없이 브라우저에서 플레이, 클릭 중심 조작·사전 결과 표시·취소 가능한 대상 선택 제공 |

**전투 횟수의 단위:** 여기서 총 8전투는 일반 영업·보스전을 합친 구간 수다. 일반 영업 안의 손님 3명은 같은 구간에서 연속으로 상대한다. UI에는 ‘전투 1/8 · 손님 1/3’처럼 두 단위를 분리한다. 모두 처치하면 손님 단위 교전은 총 20회이며, 탈출로 미등장 손님을 건너뛰면 실제 교전 수는 줄어든다.

## 2. 한 판의 진행과 종료

### 2.1. 전체 순서

새 게임 → 최초 구매·배치 → 일반 영업 1 → 구매·배치 → 일반 영업 2 → 구매·배치 → 일반 영업 3 → 구매·배치 → 중간 보스 → 구매·배치 → 일반 영업 4 → 구매·배치 → 일반 영업 5 → 구매·배치 → 일반 영업 6 → 구매·배치 → 최종 보스 → 결과.

| 전투 구간 | 구분 | 방문 순서 | 처치 보상 최대 |
|---|---|---|---:|
| 1/8 | 일반 영업 1 | 성급한 투숙객 → 성급한 투숙객 → 복도 점검원 | 6 |
| 2/8 | 일반 영업 2 | 성급한 투숙객 → 복도 점검원 → 옆방을 확인하는 손님 | 6 |
| 3/8 | 일반 영업 3 | 복도 점검원 → 옆방을 확인하는 손님 → 두 번 확인하는 손님 | 6 |
| 4/8 | 중간 보스 | 거울 감찰관 한 명 | 6 |
| 5/8 | 일반 영업 4 | 옆방을 확인하는 손님 → 두 번 확인하는 손님 → 야간 점검원 | 6 |
| 6/8 | 일반 영업 5 | 두 번 확인하는 손님 → 야간 점검원 → 거울을 보는 손님 | 6 |
| 7/8 | 일반 영업 6 | 야간 점검원 → 거울을 보는 손님 → 거울을 보는 손님 | 6 |
| 8/8 | 최종 보스 | 호텔의 조사관 한 명 | 10 |

- 일반 영업은 세 손님을 모두 처치하면 종료한다. 손님 교체 사이에는 구매·배치·웹 리셋을 할 수 없다.
- 중간 보스는 처치 또는 탈출로 종료하고 5번 구간으로 간다. 중간 보스 처치 여부는 최종 보스 입장 조건이 아니다.
- 일반 영업 도중 탈출하면 그 영업의 나머지 손님을 건너뛰고 다음 구간으로 간다. 건너뛴 구간을 재도전하거나 추가 영업으로 돈을 벌 수 없다.
- 전체 방문 순서·모든 손님의 능력·보상은 최초 경영 화면부터 확인할 수 있다.

### 2.2. 승리·패배·포기

- 승리: 최종 보스의 마지막 심장을 제거한다. 보상 10을 한 번 지급한 뒤 결과 화면으로 간다.
- 패배: 영업 중 마지막 생존 배치 괴이가 파괴되거나, 최종 보스가 탈출구에 접촉하거나, 플레이어가 ‘이번 판 포기’를 확정한다.
- 배치 괴이 전멸은 보관 중인 괴이·재화·리셋권이 남아 있어도 즉시 패배다. 영업 중 보관 괴이를 꺼내 구조하지 않는다.
- 마지막 괴이 파괴 직후 판을 종료하므로, 새로 생긴 빈층에 탈출구를 열거나 다음 영업의 복구를 적용할 수 없다.
- 처치·탈출·전멸은 실제 효과·이동·타격 순서에서 먼저 발생한 종료를 적용한다. 종료 뒤 남은 효과·이동·공격·비활동 패널티는 처리하지 않는다.
- 고정 턴 제한과 생산 불능 자동 패배는 두지 않는다. 당장 수확할 수 없다는 이유로 패배시키지 않으며, 포기는 경영·전투 화면에서 항상 선택할 수 있다.
- 결과 화면에는 승리/패배 사유, 도달 구간, 처치 수/20, 탈출한 손님 수, 미등장으로 건너뛴 손님 수, 누적 획득·지출 재화, 파괴된 괴이 수를 표시한다.
- ‘새 판 시작’은 새 난수 번호와 초기 자산으로 시작한다. 이전 판의 재화·괴이·구매 노드·리셋권·진행도는 이월하지 않는다. 옵션과 튜토리얼 확인 이력은 유지한다.

## 3. 시작 자산과 경영

| 항목 | 고정값 |
|---|---|
| 호텔 | 6층, 층마다 괴이 최대 1개 |
| 이동 | 1 → 2 → 3 → 4 → 5 → 6 → 1 순환 |
| 주사위 | 매 턴 공정한 6면체 주사위 세 개를 독립적으로 굴려 공개하고 정확히 하나 선택 |
| 시작 괴이 | 문틈의 속삭임 1개, 이름을 부르는 객실 2개, 빈 프런트의 호출벨 1개 |
| 기본 배치 | 1층 문틈의 속삭임 1호 / 2층 빈층 / 3층 이름을 부르는 객실 1호 / 4층 빈층 / 5층 이름을 부르는 객실 2호 / 6층 빈 프런트의 호출벨 1호 |
| 시작 재화 | 구매용 공포 4 |
| 최초 웹 | 새 랜덤 웹 1개를 무료 생성 |
| 시작 리셋권 | 0 |
| 시작 상태 | 공략도 0, 파훼 토큰은 초기 최대값, 빈 프런트의 호출벨 직접 사용 2회 |
| 경영 권한 | 구매·무료 재배치·빈층으로 이동·층끼리 교환·무료 보관 |
| 보유 제한 | 같은 종류 여러 개 보유·배치 가능, 보관함 개수 제한 없음 |
| 이번 범위 | 층 증축·괴이 판매·임의 폐기·별도 수리 구매·진행도에 따른 영구 해금은 제공하지 않음 |

- 구매는 새 개체를 보관함에 추가한다. 구매만으로 기존 배치가 교체되지 않으며, 플레이어가 원하는 층에 배치한다.
- 같은 종류의 여러 개체는 공략도·파훼 토큰·액티브 잔량·개체 식별 번호를 각각 가진다. 같은 종류를 중복 배치해도 각 층의 효과는 해당 방문마다 독립 발동한다.
- 영업 중에는 구매·배치·보관·교환·웹 리셋을 할 수 없다.
- ‘영업 시작’은 생존 괴이를 한 개 이상 배치했을 때 활성화한다. 빈층은 의무가 아니며, 모든 층을 채우면 빈층이 생길 때까지 탈출구를 설치할 수 없다.
- 보관·재배치·화면 전환은 회복 사건이 아니다. 새 영업 시작을 확정할 때만 §7의 복구를 한 번 적용한다.
- 다음 영업 전에 마지막 영업의 처치·탈출·미등장 수와 수입, 영구 손실, 리셋권 증가를 정산창에 보여준다.

## 4. 블러드 웹과 경제

### 4.1. 구매망 생성

- 웹은 무료 시작점과 구매 노드 12개로 구성한다. 시작점은 괴이를 주지 않으며 구매 대상으로 세지 않는다.
- 시작점 다음 1단계는 3노드다. 2단계 수는 4·5·6 중 균등 추첨하고, 남은 구매 노드를 3단계에 둔다.
- 각 구매 노드는 바로 전 단계의 부모 하나와 연결한다. 2단계의 첫 세 연결은 1단계 부모 세 개를 무작위 순서로 한 번씩 사용하고, 나머지는 해당 전 단계 부모 중 균등 추첨한다. 따라서 모든 1단계 노드는 후속 노드를 가진다.
- 모든 연결은 부모에서 자식으로 향하며 순환하지 않는다. 3단계 부모는 2단계 노드 중 각각 균등 추첨한다.
- 각 웹에는 문틈의 속삭임·이름을 부르는 객실·빈 프런트의 호출벨·닫히지 않는 방화문·따라오는 발자국·벽을 꿰매는 그림자가 최소 한 노드씩 등장한다. 나머지 6개 슬롯은 여섯 종류를 같은 확률로 독립 추첨한다. 소유 목록은 추첨에서 제외 조건으로 사용하지 않는다.
- 종류 배치는 1단계에 닫히지 않는 방화문 또는 따라오는 발자국이 최소 하나, 문틈의 속삭임 또는 이름을 부르는 객실이 최소 하나 있도록 제한한 뒤 무작위로 정한다. 이 조건을 만족하는 배치 중에서 추첨한다. 같은 종류의 중복 노드는 허용한다.
- 모든 구매 노드는 괴이 카드로 그린다. 현재 웹의 모든 카드·이름·효과·가격·연결·선행 조건을 처음부터 공개한다. 각 카드는 자신의 가격과 미구매 선행 노드를 포함한 남은 경로 총비용을 보여준다.

### 4.2. 구매와 소진

- 1단계는 무료 시작점에 연결되어 즉시 접근 가능하다. 2·3단계는 직접 부모 노드가 구매 완료되어야 구매할 수 있다.
- 부모 노드의 구매 기록이 조건을 열어준다. 구매 완료 노드를 다시 방문·선택·구매할 필요는 없다.
- 노드 상태는 ‘선행 구매 필요 / 구매 가능 / 구매 완료’로 구분한다. 재화 부족은 접근 조건과 별도로 표시한다.
- 재화가 충분한 합법 구매는 가격 차감·새 개체 지급·노드 구매 완료를 함께 확정한다. 해당 노드는 이후 비활성화하고 자식을 개방한다.
- 한 노드의 재고는 1이며 취소·환급·재구매·재방문이 없다. 그 노드에서 산 괴이가 파괴되어도 구매 완료 상태는 유지한다.
- 같은 종류의 다른 노드는 각각 구매할 수 있다. 부활이 아니라 새 개체 획득이며, 리셋한 웹에서 같은 종류가 다시 등장해도 구매 가능하다.
- 한 갈래를 구매해도 다른 갈래는 사라지지 않는다. 웹을 리셋하기 전까지 미구매 노드·구매 상태·연결을 영업 사이에 유지한다.

### 4.3. 리셋권

- 일반 영업의 세 손님 처치, 일반 영업의 탈출 종료, 중간 보스 처치·탈출, 최종 보스 처치·탈출처럼 영업이 종료될 때 리셋권을 정확히 1회 추가한다. 손님 한 명 처치마다 지급하지 않는다.
- 전멸·포기로 판 자체가 끝난 경우에는 영업 종료 보너스를 주지 않는다. 최종 보스 종료의 리셋권은 최종 정산에만 남고 이후 경영은 없다.
- **리셋권 지급과 웹 갱신은 별개다. 영업이 끝나도 웹을 자동으로 바꾸지 않는다.**
- 리셋권은 누적 가능하며 보유 상한은 없다. 경영 화면에서 1개를 소비하면 현재 구매망을 버리고 새 랜덤 구매망을 생성한다.
- 리셋하면 연결·노드 종류·노드 식별 번호·구매 상태를 모두 새로 만든다. 새 웹의 선행 조건은 새 웹에서 구매한 노드로만 충족한다.
- 기존에 획득한 괴이와 남은 재화는 유지한다. 옛 노드에 지출한 돈은 환급하지 않고 옛 노드를 다시 열지 않는다. 구매 이력은 결과 기록에 남긴다.
- 권리가 남아 있으면 같은 경영 화면에서 여러 번 리셋할 수 있다. 초기 화면에는 권리 0으로 시작하며 최초 웹 생성은 권리를 소모하지 않는다.

### 4.4. 고정 가격과 보상

| 괴이 이름 | 구매 가격 |
|---|---:|
| 문틈의 속삭임 | 3 |
| 이름을 부르는 객실 | 4 |
| 빈 프런트의 호출벨 | 3 |
| 닫히지 않는 방화문 | 4 |
| 따라오는 발자국 | 3 |
| 벽을 꿰매는 그림자 | 4 |

- 같은 종류는 노드의 깊이·중복·전반/후반 여부에 관계없이 같은 가격이다.
- 일반 손님 처치당 2, 중간 보스 처치 6, 최종 보스 처치 10을 한 번 지급한다. 중간 심장마비·초과 공포·미처치 손님·미등장 손님은 무보상이다.
- 보상은 처치 순간 잔액에 더하고 정산창에서는 내역만 보여준다. 탈출·영업 정산 때 다시 지급하지 않는다.
- 초기 지급은 4, 전원 처치 수입은 최대 52다. 최종 보스 보상 전까지 받을 수 있는 처치 수입은 최대 42다.
- 구매 재화는 방문자의 현재 공포와 별도로 표시하고 저장한다. 액티브에는 구매 재화를 쓰지 않는다.

## 5. 괴이 6종과 상태

방문자 상태는 불안 하나를 사용한다. 불안은 0~9 정수, 자연 감소 없음, 한 바퀴 순환 후에도 유지한다. 부여는 9를 넘기지 않고 실제 증가량을 기록한다. 손님 교체 때는 새 손님의 불안 0으로 시작한다.

| 괴이 이름 | 역할 | 통과할 때 | 도착할 때 | 직접 사용 효과 | 공략 한계 / 초기 파훼 토큰 |
|---|---|---|---|---|---|
| 문틈의 속삭임 | 불안 공급 | 손님 불안 2 증가 | 손님 불안 4 증가 | 없음 | 12 / 2 |
| 이름을 부르는 객실 | 불안 수확 | 없음 | 손님 불안을 최대 3 소비하고, 소비한 불안 1당 공포 4를 한 번에 부여 | 없음 | 12 / 2 |
| 빈 프런트의 호출벨 | 즉시 공격 | 없음 | 손님 공포 2 증가 | 손님 공포 6 증가. 영업 시작 시 2회 | 12 / 1 |
| 닫히지 않는 방화문 | 보호·충전 | 없음 | 자신의 남은 방어 횟수 1 충전. 보유 최대 2회 | 살아 있는 배치 괴이 하나에 이번 턴 공략도 6 흡수. 영업 시작 시 2회 | 12 / 2 |
| 따라오는 발자국 | 불안 증폭 | 현재 불안만큼 불안을 추가하되 최대 2 증가. 불안 상한 9 적용 | 손님 불안 1 증가 | 없음 | 12 / 1 |
| 벽을 꿰매는 그림자 | 불안 소비·수리 | 없음 | 없음 | 손님 불안 2를 소비해 살아 있는 배치 괴이 하나의 공략도를 최대 6 감소 | 12 / 2 |

- 최종 도착층에서는 도착 효과만 발생한다. 문틈의 속삭임 도착은 불안 4 증가이며 통과 효과의 2 증가를 더하지 않는다.
- 이름을 부르는 객실은 불안 0이면 소비·공포가 모두 0이다. 소비한 불안이 1/2/3이면 공포 4/8/12를 한 효과로 부여한다. 따라서 심장마비를 최대 한 번만 만든다.
- 따라오는 발자국 통과는 불안 0이면 공급 0이다. 불안 1이면 1 증가, 불안 2~7이면 2 증가, 불안 8이면 1 증가, 불안 9이면 0이다.
- 액티브는 ‘직접 사용’으로 표시한다. 배치되어 살아 있는 소유 괴이만 사용할 수 있으며 보관·파괴된 개체는 사용할 수 없다.
- 모든 액티브의 사용 구간은 눈 확정 뒤·첫 이동 전이다. 같은 액티브를 같은 턴에 여러 번 사용할 수 있고 매번 횟수·자원·대상 조건을 검사한다.
- 닫히지 않는 방화문과 벽을 꿰매는 그림자는 자기 자신을 포함해 어느 층의 생존 괴이든 지정할 수 있다.
- 벽을 꿰매는 그림자는 대상 공략도가 1 이상이고 손님 불안이 2 이상일 때 사용할 수 있다. 횟수 제한 없이 매번 불안 2를 소비한다. 공략도만 줄이고 파훼 토큰은 되돌리지 않는다.
- 닫히지 않는 방화문의 흡수는 같은 대상에 합산하고 실제 타격 순서대로 소비한다. 남은 흡수는 그 턴의 손님 공격 뒤 또는 손님 종료 때 제거한다.
- 이미 부여한 흡수는 닫히지 않는 방화문이 먼저 파괴되어도 유지한다. 대상이 파괴되면 남은 흡수를 다른 괴이로 이전하지 않는다.
- 닫히지 않는 방화문 도착은 즉시 방어를 주지 않는다. 새로 충전한 횟수는 다음 턴부터 사용할 수 있다. 상한에서의 초과 충전은 버린다.
- 불법 액티브 입력은 자원·횟수 차감 없이 거부한다. 완료한 효과의 취소·환급은 없다. 빈 프런트의 호출벨로 처치하면 이후 액티브·이동·공격을 즉시 중단한다.

## 6. 방문자와 공격

모든 손님은 입장 전 위치 0·현재 공포 0·불안 0·표의 남은 심장 수로 들어온다. 위치 0은 실제 층이 아니다. 아래층·위층과 거리 2층의 대상은 1~6층으로 순환한다.

| 손님 이름 | 공포 한계 / 남은 심장 | 살아 있을 때 공격 순서 | 처치 보상 |
|---|---|---|---:|
| 성급한 투숙객 | 12 / 1 | 도착층에 공략도 6 → 같은 층에 공략도 6 | 2 |
| 복도 점검원 | 12 / 1 | 실제 방문 경로 순서대로 각 방문층에 공략도 4 한 번 | 2 |
| 옆방을 확인하는 손님 | 16 / 1 | 도착층 바로 아래층에 공략도 6 → 도착층에 공략도 6 | 2 |
| 두 번 확인하는 손님 | 12 / 2 | 도착층에 공략도 6 → 같은 층에 공략도 6 | 2 |
| 야간 점검원 | 16 / 2 | 실제 방문 경로 순서대로 각 방문층에 공략도 4 한 번 | 2 |
| 거울을 보는 손님 | 16 / 2 | 도착층에서 아래로 2층에 공략도 6 → 위로 2층에 공략도 6 | 2 |
| 거울 감찰관 | 16 / 2 | 도착층에서 아래로 2층에 공략도 8 → 위로 2층에 공략도 8 | 6 |
| 호텔의 조사관 | 20 / 3 | 홀수 턴: 도착층에 공략도 6 두 번. 짝수 턴: 도착층에서 아래로 2층에 공략도 8 → 위로 2층에 공략도 8 | 10 |

- 같은 이름이 여러 번 등장해도 방문자별 독립 개체다. 최종 보스의 턴 번호는 입장 때 1부터 시작한다.
- 경로 공격에는 실제 방문한 중간층과 최종층을 모두 포함한다. 재방문은 별도 타격이며 중복 대상을 합치지 않는다.
- 빈층 타격은 빗나간다. 앞선 타격으로 괴이가 파괴되면 뒤의 해당 층 타격도 빗나가며 다른 층으로 옮기지 않는다.
- 손님이 처치되거나 탈출했다면 공격 목록 자체를 실행하지 않는다. 보스도 이 원칙을 따른다.
- 현재 공격 대상·순서·위력·흡수 후 예상 공략도와 파훼 토큰, 다음 턴 공격 패턴을 표시한다. 미래 주사위와 비활동 패널티의 실제 추첨 대상은 공개하지 않는다.

## 7. 공포·파훼·영구 손실과 복구 경계

### 7.1. 공포와 공략 판정

- 각 공포 효과에서 현재 공포에 새 공포를 더한 값이 공포 한계 이상이면 남은 심장 1 감소·현재 공포 0으로 처리하고 초과 공포는 버린다. 한 효과로 심장을 최대 하나 제거한다.
- 심장이 남으면 후속 효과·이동·공격을 계속한다. 심장이 0이면 고정 보상을 한 번 지급하고 현재 손님을 끝낸다. 심장마비 자체는 불안을 지우지 않는다.
- 손님 공격은 타격마다 보호 흡수 → 남은 위력을 공략도에 추가 → 즉시 공략 한계 도달 여부 판정 순서다.
- 공략도가 한계 이상이면 파훼 토큰 1 감소·공략도 0으로 처리하고 초과 공략도는 버린다. 한 타격으로 토큰을 최대 하나 잃고, 다단 공격은 타격별로 반복한다.
- 파훼 토큰이 0이면 해당 개체를 즉시 배치·소유 목록에서 제거하고 손실 기록에 남긴다. 해당 층은 즉시 빈층이 된다.
- 파괴된 개체는 다음 손님·다음 영업·리셋·재배치로 복구하지 않는다. 새 노드에서 구매한 같은 종류는 새 식별 번호·공략도 0·초기 파훼 토큰·초기 액티브를 가진 별도 개체다.
- 파괴 직후 생존 배치 괴이가 0인지 검사한다. 전멸이면 뒤 타격·패널티·영업 정산으로 넘어가지 않고 패배한다.

### 7.2. 경계별 처리

| 경계 | 처리 |
|---|---|
| 같은 영업의 다음 손님 | 모든 생존 보유 괴이의 공략도 0. 파훼 토큰과 빈 프런트의 호출벨·닫히지 않는 방화문의 잔량은 유지. 새 방문자는 입장 전 위치·현재 공포 0·불안 0·초기 심장 수. 흡수·비활동 카운터 제거 |
| 영업 종료 직후·경영 중 | 공략도·파훼 토큰·잔량은 종료 상태로 표시. 탈출구·흡수·방문자 상태는 정리하고 정산. 아직 파훼 토큰·액티브를 복구하지 않음 |
| 다음 영업 시작 확정 | 생존 보유 괴이의 공략도 0·파훼 토큰 초기값. 빈 프런트의 호출벨·닫히지 않는 방화문의 잔량은 정확히 2회. 보관 개체도 같은 복구 적용. 파괴된 개체는 제외 |
| 구매 | 새 개체만 공략도 0·초기 파훼 토큰·초기 액티브. 기존 개체는 회복하지 않음 |
| 보관·재배치·웹 리셋 | 기존 개체의 공략도·파훼 토큰·잔량 변화 없음 |
| 승리·패배 | 결과 직전 상태를 보존. 다음 영업 복구를 적용하지 않음 |
| 새 판 | 초기 자산으로 새로 시작. 옵션·튜토리얼 확인 이력만 유지 |

괴이의 파훼 토큰은 손님의 남은 심장과 별도다. 살아남은 괴이의 토큰 복구와 파괴 개체 부활을 혼동하지 않는다.

## 8. 한 턴의 입력과 처리

1. 현재 위치·공포와 한계·남은 심장·불안·괴이별 공략도와 한계·파훼 토큰·액티브 잔량·비활동 상태·공격 패턴을 보여준다.
2. 플레이어가 ‘주사위 굴리기’를 누르면 6면체 주사위 세 개를 공개한다. 선택 확정 전에는 각 눈의 경유층·도착층·효과·공격 결과를 미리 볼 수 있다.
3. 공개 눈 하나를 확정하면 이동 전 액티브·탈출구 설치 구간으로 간다. 각 층의 액티브 버튼과 탈출구 설치 순서를 자유롭게 정한다. 완료한 행동은 즉시 반영하며 눈을 재선택할 수 없다.
4. ‘이동 실행’을 누르면 선택 거리만큼 한 층씩 이동한다. 매 방문에서 먼저 탈출구 접촉을 확인하고, 없다면 중간층의 통과 또는 마지막 층의 도착 효과만 처리한다. 공포 효과마다 즉시 처치 여부를 검사한다.
5. 이동 후 손님이 남아 있으면 예고된 공격을 타격 순서대로 처리한다. 괴이 파괴마다 전멸을 검사한다.
6. 종료되지 않았다면 남은 흡수를 제거하고 이번 턴의 활동 이력으로 비활동 카운터·패널티를 처리한다. 패널티 파괴에서도 전멸을 검사한다.
7. 손님이 남아 있으면 다음 턴으로 간다. 처치했으면 손님 결과를 보여주고 다음 손님 또는 영업 정산으로, 탈출했으면 영업 정산 또는 최종 패배로 간다.

- 빈층 도착도 정상 이동이며, 한 바퀴를 돌아도 공포·불안·공략도·파훼 토큰을 자동 초기화하지 않는다.
- 미리보기는 게임 상태·주사위·패널티 추첨을 소비하지 않는다. 액티브를 사용한 뒤 미리보기도 현재 상태로 갱신한다.
- 눈 공개 전 희망층 입력·선택 이유 작성은 요구하지 않는다. 플레이어는 버튼과 대상 선택만으로 진행할 수 있다.

### 8.1. 비활동 패널티

- 턴 중 실제 양수의 공포 부여, 실제 불안 증가, 합법적으로 완료한 괴이 액티브 중 하나라도 발생하면 활동이다. 턴말 순증가가 아니라 발생 이력으로 판단한다.
- 이름을 부르는 객실의 불안 0 수확, 불안 상한 9에서의 증가 시도, 불법 액티브 입력은 활동이 아니다.
- 닫히지 않는 방화문 도착 충전과 탈출구 설치는 활동이 아니다. 합법적인 보호 액티브는 실제 흡수량이 0이어도 활동이며, 벽을 꿰매는 그림자의 합법 사용도 활동이다.
- 새 손님은 비활동 누적 0·발동 기준 3으로 시작한다. 비활동 턴마다 누적을 1 늘리고 기준에 닿으면 패널티 후 누적 0·기준 2로 바꾼다. 계속 비활동이면 이후 2턴마다 반복한다.
- 활동이 발생하면 비활동 누적 0·발동 기준 3으로 복귀한다.
- 패널티는 정상 공격과 흡수 제거 뒤, 그때 살아 있는 배치 괴이 중 하나를 균등 추첨해 직접 공략도 12를 추가한다. 보호로 막지 않고 공략 한계 도달을 한 번 판정한다.
- 처치·탈출·전멸로 끝난 턴에는 별도 비활동 패널티를 처리하지 않는다.
- UI는 ‘활동 없이 1턴 / 2턴 더 이어지면 무작위 괴이에 공략도 12’처럼 누적과 위험을 풀어 쓴다. 추첨 후보와 가능한 결과를 확인할 수 있지만 추첨 전 실제 대상은 확정해서 보여주지 않는다.

### 8.2. 탈출구

- ‘탈출구 열어주기’는 괴이 액티브와 별도 버튼이다. 이동 전 구간에서 빈층 하나를 골라 무료 설치한다.
- 영업당 하나만 설치할 수 있고 설치 후 이동·취소·추가 설치는 할 수 없다. 다음 영업에는 제거된다.
- 괴이가 배치된 층에는 설치할 수 없다. 파괴로 비워진 층에는 이후 이동 전 구간에서 설치할 수 있다. 빈층이 없으면 버튼을 비활성화하고 이유를 표시한다.
- 손님의 현재 빈층에 설치할 수도 있지만 설치 순간은 접촉 사건이 아니다. 이후 실제 이동으로 그 층을 다시 방문해야 종료된다.
- 탈출구를 통과하거나 도착하는 순간 현재 영업 전체를 종료한다. 그 뒤 이동·층 효과·공격·패널티는 처리하지 않고, 앞서 발생한 효과·소모는 유지한다.
- 이미 처치한 손님 보상은 유지한다. 탈출 손님과 아직 등장하지 않은 손님에게 보상을 주지 않는다.
- 일반 영업·중간 보스의 탈출은 다음 구간으로 진행하며, 최종 보스의 탈출은 패배다. 설치 화면과 최종 보스 입장 안내에 이 차이를 표시한다.

## 9. 웹 게임 화면과 조작

### 9.1. 실행 환경과 화면 구성

- 설치 없이 웹 브라우저에서 플레이하는 2D 도형 게임으로 만든다. PC 가로 화면·마우스를 기본으로 하고 키보드·터치로도 정보 확인과 주요 조작이 가능하게 한다.
- 1280×720에서 6개 층과 현재 단계의 핵심 버튼을 함께 읽을 수 있게 구성한다. 큰 화면에서는 패널 여백을 늘리고, 작은 화면에서는 호텔·정보·카드 패널을 세로로 배치한다.
- 호텔은 1층이 아래인 세로 직사각형 6칸과 층 번호로 표현한다. 손님은 원, 빈층은 윤곽, 탈출구는 문 모양과 ‘탈출’ 글자로 표시한다.
- 6층→1층 순환은 연결 화살표와 짧은 이동 표시로 보여준다. 경유층·도착층·공격 대상·액티브 대상을 서로 다른 테두리와 글자로 구분한다.
- 경영 화면: 호텔의 층 박스, 보관 중인 괴이 카드, 보유 공포 재화, 웹 리셋권, 카드 노드로 구성된 구매망, 다음 손님 목록, ‘영업 시작’.
- 전투 화면: 호텔의 층 박스, 손님 상태, 공격 예고, 주사위 세 개, 경로 미리보기, 층별 액티브 버튼, 탈출구 버튼, 비활동 예고, 최근 결과 로그.
- 현재 조작 단계를 ‘경영 중 / 주사위 굴리기 / 이동 거리 선택 / 이동 전 준비 / 이동·공격 처리 중 / 정산’으로 표시한다. 주요 진행 버튼은 단계에 맞는 하나를 중심에 둔다.

### 9.2. 이름과 상태의 표기

- 괴이는 모든 카드·층 박스·버튼 설명·도움말·팝업·미리보기·로그에 전체 이름을 쓴다. 알파벳 약자나 내부 식별 번호를 플레이어에게 보여주지 않는다.
- 손님도 ‘성급한 투숙객’, ‘거울 감찰관’처럼 이름으로 표시한다. 동일 종류 개체를 구분할 때는 전체 이름 뒤에 ‘1호 / 2호’를 보조로 붙인다.
- 색·도형은 이름을 알아보기 위한 보조 표식이다. 문틈의 속삭임은 삼각형, 이름을 부르는 객실은 마름모, 빈 프런트의 호출벨은 원, 닫히지 않는 방화문은 사각형, 따라오는 발자국은 육각형, 벽을 꿰매는 그림자는 십자를 쓴다.
- 상태도 한 글자 변수 대신 아래 명칭과 숫자를 사용한다. 아이콘에는 같은 이름의 설명을 연결한다.

| 표시 대상 | 화면 표시 예 | 뜻 |
|---|---|---|
| 손님의 현재 공포·한계 | 공포 8 / 12 | 현재 8, 심장마비까지 필요한 한계 12 |
| 손님의 남은 심장 | 남은 심장 2 | 앞으로 심장마비를 두 번 더 일으키면 처치 |
| 손님의 불안 | 불안 3 / 9 | 수확·수리에 사용할 수 있는 현재 상태 |
| 괴이의 공략도·한계 | 공략도 6 / 12 | 현재 6, 한계 12에 닿으면 파훼 토큰 하나 소모 |
| 괴이의 파훼 토큰 | 파훼 토큰 2 / 2 | 남은 2개, 0개가 되면 영구 파괴 |
| 횟수형 직접 사용 | 남은 사용 1 / 2회 | 현재 영업에서 쓸 수 있는 잔량과 보유 상한 |
| 이번 턴 보호 | 이번 턴 보호 6 | 현재 대상이 다음 공격에서 흡수할 수 있는 공략도 |
| 구매 자원 | 보유 공포 재화 4 | 손님의 공포와 구별하는 구매 잔액 |
| 웹 갱신 자원 | 웹 리셋권 1개 | 현재 구매망을 새로 뽑을 수 있는 횟수 |

### 9.3. 괴이 카드의 공통 정보

- 구매 전, 구매 후 아직 배치하지 않은 상태, 보관 중인 상태에서는 괴이를 카드 형태로 보여준다.
- 배치된 괴이의 호버 카드도 같은 양식을 사용한다. 이름과 효과의 위치·표현을 화면마다 바꾸지 않는다.
- 카드에는 이름, 보조 도형, 역할, 위치·소유 상태, ‘통과할 때 / 도착할 때 / 직접 사용’ 세 항목, 공략 한계·파훼 토큰을 표시한다. 없는 효과도 ‘효과 없음’으로 명시한다.
- 각 효과는 무엇이 얼마나 변하는지, 누가 대상인지, 언제 발동하는지, 필요한 비용·횟수·조건·지속시간이 무엇인지 적는다.
- 수확은 ‘불안 최대 3 소비 → 소비한 불안 1당 공포 4, 최대 공포 12’처럼 표시한다. 효과 제목이나 ‘수확’이라는 단어만 보여주지 않는다.
- 방어는 ‘살아 있는 괴이 하나가 이번 턴 받는 공략도를 6 흡수’, 충전은 ‘방어 횟수 1 충전, 최대 2회, 다음 턴부터 사용’으로 표시한다.
- 수리는 ‘손님 불안 2 소비 → 괴이 하나의 공략도 최대 6 감소, 공략도가 있는 대상 필요’로 표시한다. 파훼 토큰이 복구되는 것처럼 그리지 않는다.
- 횟수형 액티브에는 현재 잔량과 ‘새 영업 시작 시 2회로 복구’를, 비용형 액티브에는 현재 불안과 ‘사용할 때마다 불안 2 소비’를 함께 적는다.
- 구매 전 카드는 가격·현재 보유 개수·선행 구매 이름·구매 가능 여부를 표시한다. 아직 소유하지 않은 괴이의 상태는 ‘구매 시 공략도 0 · 파훼 토큰 2개’처럼 초기값으로 구분한다.
- 소유 카드에는 실제 공략도·파훼 토큰·잔량을 표시한다. 경영 중 손상 상태에는 ‘다음 영업 시작 시 생존 괴이 복구’ 안내를 붙여 지금 회복된 것처럼 표시하지 않는다.
- 현재 손님이 있으면 실제 상태를 반영한 효과도 별도 줄로 보여준다. 예: ‘현재 불안 2 → 불안 2 소비, 공포 8 증가’. 손님이 없는 구매 화면에서는 고정 설명만 표시한다.
- 이름과 효과는 줄바꿈해 모두 읽을 수 있게 한다. 긴 이름을 약자로 줄이거나 효과를 말줄임표로 숨기지 않는다.

### 9.4. 구매·보관·배치의 연결

- 블러드 웹의 구매 대상은 연결선이 있는 카드 노드다. 카드 안에 효과와 가격을 바로 보여주고 ‘구매’ 버튼을 둔다.
- 선행 조건이 잠겼으면 ‘문틈의 속삭임 구매 후 개방’처럼 실제 선행 괴이 이름을 적는다. 동종 선행 카드가 여럿이면 연결된 카드를 함께 강조한다.
- 구매 불가 이유는 ‘공포 재화 1 부족 / 연결된 이전 카드 구매 필요 / 이미 구매 완료’로 카드에 표시한다. 구매 가능·선행 미충족·재화 부족·구매 완료를 색과 문구로 함께 구분한다.
- 구매를 완료하면 보관함에 새 카드가 나타나고 잠깐 강조된다. 구매한 웹 카드는 ‘구매 완료’로 남아 연결과 진행 상태를 보여준다.
- 보관 카드의 ‘배치하기’를 누르면 카드를 선택하고 배치 가능한 층을 강조한다. 층을 클릭하면 그 층 박스에 괴이를 배치한다.
- 빈층 선택 시 즉시 배치한다. 점유층을 선택하면 기존 괴이가 보관함으로 돌아갈 예정임을 미리 보여주고 ‘교체 배치’로 확정한다. 경영 중 층끼리 교환도 가능하다.
- 배치된 층의 ‘보관하기’를 누르면 해당 괴이를 카드로 보관함에 되돌린다. ‘위치 바꾸기’를 누르면 이동할 층을 고르게 한다.
- 배치 선택은 취소 버튼이나 ESC로 해제할 수 있다. 선택·호버·이동 미리보기 자체는 자산·상태를 바꾸지 않는다.
- 드래그 없이 클릭만으로 모든 구매·배치·교체·보관 조작을 완료할 수 있게 한다. 보관함이 비면 ‘구매한 괴이가 이곳에 카드로 보관됩니다’라는 안내를 보여준다.

### 9.5. 배치된 층 박스

- 배치 후에는 해당 층의 직사각형 박스 안에 괴이를 그린다. 기본 배치 화면에 큰 카드를 늘어놓지 않는다.
- 박스에는 층 번호, 괴이 전체 이름, 보조 도형, 한 줄 핵심 효과, 공략도 게이지와 수치, 파훼 토큰, 사용 가능한 액티브 버튼을 표시한다.
- 한 줄 핵심 효과는 ‘통과: 불안 +2 / 도착: 불안 +4’, ‘도착: 불안 최대 3 → 공포 최대 12’처럼 핵심 수치를 포함한다. 자세한 조건은 호버 카드에서 읽을 수 있게 한다.
- 이번 턴 보호를 받은 층에는 보호 잔량을 표시한다. 손상·파훼 토큰 감소·충전·효과 발동은 해당 층에서 짧게 강조한다.
- 빈층에는 ‘빈층’과 경영 중 ‘여기에 배치’, 대상 선택 중 ‘탈출구 설치 가능’처럼 현재 가능한 동작을 표시한다.
- 파괴된 괴이 박스는 짧은 파괴 표시 후 즉시 빈층 표현으로 바꾼다. 이름이 남아 살아 있는 괴이처럼 보이지 않게 한다.

### 9.6. 층 호버 정보 카드

- 배치된 층의 박스에 마우스를 약 150밀리초 올려두면 그 괴이의 상세 카드를 띄운다. 카드에는 §9.3의 효과 설명과 실제 현재 상태를 모두 표시한다.
- 상세 카드는 층 박스 옆의 여유 공간에 띄우고 브라우저 화면 밖으로 나가지 않게 위치를 조정한다. 액티브 버튼·대상 층·주사위·주요 진행 버튼을 가리지 않는다.
- 마우스가 박스에서 카드로 이동해도 즉시 사라지지 않게 한다. 박스와 카드에서 모두 벗어나면 약 150밀리초 뒤 닫는다.
- 전투 중 층 박스를 클릭하거나 정보 버튼을 누르면 카드를 고정해 읽을 수 있다. 다른 층을 선택하거나 닫기를 누르면 전환·해제한다.
- 키보드 초점이나 터치의 정보 버튼으로도 같은 카드를 열 수 있게 한다. 중요한 설명을 마우스 호버에서만 제공하지 않는다.
- 배치·보호·수리·탈출구 대상을 고르는 동안에는 층 클릭을 해당 대상 선택으로 사용한다. 그때 정보 확인은 호버·정보 버튼으로 제공해 대상 선택과 충돌하지 않게 한다.
- 호버 카드는 정보용이다. 실행은 원래 층의 버튼이나 카드의 구매·배치 버튼에서 수행한다. 튜토리얼 팝업을 꺼도 호버·정보 카드는 계속 제공한다.

### 9.7. 층 안의 액티브 버튼과 대상 선택

- 현재 사용할 수 있는 액티브의 실행 버튼은 그 괴이가 배치된 층 박스 안에 나타난다. 별도 약자 목록에서 시전 괴이를 다시 찾게 하지 않는다.
- 버튼은 눈 확정 뒤·이동 실행 전이며, 소유 괴이가 생존하고 비용·잔량·합법 대상 조건을 모두 만족할 때만 표시한다.
- 현재 사용할 수 없으면 실행 버튼 대신 ‘눈 선택 후 사용 / 남은 횟수 없음 / 불안 2 필요 / 수리할 대상 없음’ 같은 상태 문구를 둔다. 상세 카드에는 항상 전체 조건을 남긴다.
- 실행 버튼 자리의 높이를 확보해 표시·숨김으로 층과 클릭 위치가 갑자기 움직이지 않게 한다.

| 괴이 이름 | 층 안의 실행 버튼 예 | 사용 가능 조건 | 누른 뒤 조작 |
|---|---|---|---|
| 빈 프런트의 호출벨 | 공포 6 주기 · 남은 2회 | 이동 전 사용 구간, 손님 생존, 잔량 1회 이상 | 현재 손님에게 즉시 공포 6, 잔량 1회 소비 |
| 닫히지 않는 방화문 | 보호하기 · 남은 2회 | 이동 전 사용 구간, 잔량 1회 이상, 살아 있는 배치 대상 존재 | 보호할 층을 클릭하면 이번 턴 공략도 6 흡수, 잔량 1회 소비 |
| 벽을 꿰매는 그림자 | 공략도 줄이기 · 불안 2 | 이동 전 사용 구간, 손님 불안 2 이상, 공략도가 1 이상인 생존 배치 대상 존재 | 수리할 층을 클릭하면 공략도 최대 6 감소, 불안 2 소비 |

- 대상이 필요한 버튼은 누른 즉시 비용을 지불하지 않는다. ‘보호할 괴이가 있는 층을 선택하세요’처럼 할 일을 표시하고 유효한 층만 강조한다.
- 대상 호버 시 보호 후 공격 결과, 또는 수리 전후 공략도·불안 잔액을 미리 보여준다. 대상 클릭 때 한 번만 비용·횟수를 소비하고 적용한다.
- 취소 버튼·우클릭·ESC는 대상 선택만 해제하며 비용을 소비하지 않는다. 대상 선택 중에는 ‘이동 실행’을 잠그고 ‘대상 선택을 완료하거나 취소하세요’라고 안내한다.
- 빈 프런트의 호출벨 버튼 호버에는 현재 공포가 얼마나 오르고 심장마비·처치가 발생하는지 보여준다. 버튼 클릭은 현재 손님을 대상으로 바로 실행한다.
- 실행 뒤 모든 카드·버튼 잔량·상태·경로·공격 미리보기를 즉시 갱신한다. 액티브를 여러 번 쓰려면 갱신된 버튼으로 계속 사용할 수 있다.
- 처리 중에는 중복 입력을 잠그고 조건을 다시 검사한다. 마지막 심장 제거로 처치하면 버튼·대상 선택을 즉시 끝내고 손님 결과로 간다.

### 9.8. 결과 미리보기와 피드백

- 주사위에 호버·초점·터치 선택을 하면 실제 층 순서와 최종 도착층을 강조하고, ‘2층 통과 → 3층 도착’처럼 경로를 글자로도 표시한다.
- 미리보기는 ‘이동 중 얻는 불안 → 도착 시 소비·공포 → 손님 심장 변화 → 남으면 받는 개별 공격 → 괴이의 예상 공략도·파훼 토큰’ 순서로 보여준다.
- 처치 가능하면 ‘처치 · 손님 공격 없음’, 출구 접촉이면 ‘탈출 · 이번 영업 종료’, 최종 보스 출구 접촉이면 ‘탈출 시 패배’라고 명확히 표시한다.
- 무작위 패널티가 발생할 때는 가능한 표적과 결과를 구분하고 실제 추첨 결과처럼 확정하지 않는다.
- 카드와 결과 로그는 ‘1층 문틈의 속삭임 통과: 불안 0 → 2’, ‘3층 이름을 부르는 객실 도착: 불안 2 소비, 공포 0 → 8’처럼 원인·이름·변화량을 연결한다.
- 빈층으로 빗나간 공격, 파괴로 취소된 후속 타격, 사용한 보호·남은 보호도 짧은 문구로 보여준다.
- 단순 호버·카드 선택에는 구매·배치·비용 소비가 발생하지 않는다. 무료 배치 선택과 액티브 대상 선택은 실행 전까지 쉽게 취소할 수 있게 한다.
- 효과·개별 타격은 순서가 읽히는 짧은 강조로 표현한다. 이동·공격 처리 중에는 다른 게임 입력을 잠그고 배속은 판정 순서를 바꾸지 않는다.

### 9.9. 웹 접근성과 편의성

- 카드 본문과 효과 설명은 기본 14픽셀 이상으로 읽히게 하고, 주요 버튼은 충분한 클릭 영역을 확보한다. 카드가 많으면 패널 스크롤을 제공하고 글자를 지나치게 축소하지 않는다.
- 긴 이름과 효과는 줄바꿈하고, 여러 카드의 동일한 정보는 같은 위치에 정렬한다. 구매망의 스크롤·카드 펼침이 호텔의 층 순서를 바꾸지 않게 한다.
- 구매 가능·손상·선택·위험은 색뿐 아니라 글자·아이콘·테두리로 구분한다. 모든 버튼에 이름과 키보드 초점을 제공한다.
- 옵션에서 ‘설명 팝업 표시 켜기/끄기’와 ‘연출 속도 보통/빠름’을 바꿀 수 있다.
- ESC는 먼저 현재 배치·대상 선택·고정 정보 카드를 해제한다. 해제할 조작이 없으면 옵션 메뉴를 연다. 옵션 메뉴는 입력·연출을 일시정지한다.
- 포기·진행 중 새 판 시작처럼 판을 끝내는 동작은 확인창을 제공한다. 확인창에는 현재 선택의 결과를 적고 취소할 수 있게 한다.

## 10. 첫 등장 설명 팝업

### 10.1. 표시·옵션·기억

- 기본값은 ‘설명 팝업 표시 켜기’다. 제목, 1~3문장의 짧은 설명, 해당 UI 강조, ‘확인’ 버튼으로 구성한다.
- 처음 관련 화면을 열거나 해당 기능·사건을 처음 접할 때 팝업을 표시한다. 아직 관련 없는 개념을 시작 시 한꺼번에 설명하지 않는다.
- 설명을 읽는 동안 입력·연출을 일시정지한다. 여러 설명이 같은 사건에서 발생하면 하나씩 순서대로 보여주고 중복 표시하지 않는다.
- 원자적인 효과·타격과 즉시 종료 판정을 먼저 확정하고, 다음 효과나 화면 전환 전에 팝업을 보여준다. 팝업이 처치·전멸·보상·난수 순서를 바꾸지 않는다.
- 개념별 확인 이력은 ‘확인’을 눌렀을 때 기록한다. 다른 판에서도 같은 개념을 자동 반복하지 않도록 같은 브라우저의 로컬 설정에 저장한다.
- 표시를 끈 동안에는 자동 팝업과 대기 목록을 만들지 않으며, 미확인 개념을 확인한 것으로 기록하지 않는다. 다시 켜면 현재 관련된 미확인 개념과 이후 처음 만나는 개념부터 설명한다.
- 옵션의 ‘설명 팝업 다시 보기’는 확인 이력만 초기화한다. 현재 판의 재화·배치·주사위·진행 상태는 그대로 유지한다.
- ‘도움말’에서는 표시 옵션과 관계없이 모든 시스템 설명과 괴이·손님 능력을 다시 열 수 있다. 카드·호버 정보·효과 설명·사용 불가 사유는 팝업을 꺼도 항상 제공한다.

| 탈출구 | 탈출구 버튼 최초 확인 | 빈층에 출구를 열고 손님이 실제로 닿아야 영업이 끝납니다. 탈출 손님과 남은 손님의 보상은 받지 못합니다. |
| 영구 파괴 | 첫 괴이 파괴 직후 | 파괴된 괴이는 돌아오지 않고 층은 비워집니다. 다른 노드에서 같은 종류의 새 괴이를 살 수 있습니다. |
| 손님·영업 경계 | 같은 영업의 첫 손님 처치 후 | 다음 손님이 오면 공략도만 0이 됩니다. 남은 파훼 토큰과 사용 횟수로 이번 영업을 이어갑니다. |
| 영업 복구·리셋권 | 첫 영업 정산 | 다음 영업 시작 때 생존 괴이의 파훼 토큰과 횟수형 액티브가 복구됩니다. 웹 리셋권도 하나 얻습니다. |
| 웹 리셋 | 리셋 버튼이 처음 활성화 | 권리 하나로 구매망 전체를 새로 뽑습니다. 가진 괴이는 남지만 이전 웹에 쓴 돈은 돌아오지 않습니다. |
| 보스 | 중간 보스 전 경영 화면 | 이번 영업은 보스 한 명을 상대합니다. 공격 패턴과 남은 심장 수를 보고 배치를 준비하세요. |
| 최종 목표·탈출 패배 | 최종 보스 전 경영 화면 | 마지막 보스를 처치하면 승리합니다. 이 보스를 탈출시키면 이번 판은 패배합니다. |

‘능력 확인’은 해당 괴이의 상세 정보·구매 카드·관련 버튼을 처음 여는 상황을 포함한다. 도움말을 수동으로 읽은 개념도 같은 확인 처리로 중복 팝업을 줄인다.

## 11. 난수·상태 유지·재시작

- 새 판마다 난수 번호를 생성하고 결과 화면의 상세 기록에서 확인할 수 있게 한다. 동일 구현 버전·난수 번호·행동 순서에서는 같은 결과를 재현한다.
- 주사위, 웹 생성, 비활동 표적은 서로 독립적인 난수 흐름으로 분리한다. 리셋 횟수나 미리보기 사용이 이후 주사위를 바꾸지 않는다.
- 주사위·비활동 추첨은 구간 번호·손님 순번·그 손님 턴을 키로 구분한다. 웹은 생성 회차를 별도로 사용한다.
- 옵션·도움말·팝업·호버 카드·배치 미리보기는 난수를 진행시키지 않는다. 현재 웹 이외의 다음 웹과 미래 눈을 미리 공개하지 않는다.
- 한 판의 상태는 타이틀로 돌아가거나 새 판을 확정하기 전까지 유지한다. 옵션을 열고 닫거나 팝업 표시를 바꿔도 초기화하지 않는다.
- 저장·불러오기 UI와 판 사이 영구 성장은 이번 범위에서 제외한다. 옵션과 튜토리얼 확인 이력은 같은 브라우저의 로컬 설정에 유지한다. 브라우저의 해당 사이트 데이터를 지우면 이 이력도 초기화된다.
