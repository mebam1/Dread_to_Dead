# 설정 18 구현·플레이 검정 결과

2026-11-07 · 기준 `text-18-v1.5` · 실행 환경 Node.js 24.12.0 / Windows.

**설정 18의 실행 구현과 규칙 검증을 완료했다. 배치·주사위 배분은 실제 결과를 바꾸지만, 이번 플레이에서는 후반의 동료 상실과 공격 중단이 원정 지속력을 무너뜨렸다.** 수치와 규칙은 설정 18 그대로 유지했다. 아래 결과를 근거로 밸런스 통과나 정상 원정 완주를 선언하지 않는다.

## 1. 반영 범위와 검증 방법

- `rules.md`, `terms.md`, `undecided.md`를 설정 18 기준으로 갱신했다. 기존 호텔·공포·공략도·공여 효과·구판 지도/경제와 충돌하는 현행 설명을 제거했다.
- `mvp_text_18`은 독립 Node 엔진이다. 세 적 행, 긴 적, 11종 동료, 본 효과 융합, 다섯 토큰, 직선 인접, 3막 지도, 회복·상점·강화·철수·보상·저장을 구현했다.
- 마지막 처치 뒤 공통 종료, 독·탈진 동반 전멸, 분노 광역·다단, 시종 복사, 성기사 대신 받기, 제공자 사망, 긴 적 가스 흡수 등을 회귀 검사했다.
- **자동 검사 43개 통과.** 이 중 혼합 통제 상태 50개에서 미리보기와 실제 이벤트열을 비교했고, 정상 명령으로 끝낸 6원정 전체를 다시 재생해 저장과 정확히 일치함을 확인했다.
- 실제 대화형 터미널에서 이유 입력·전투 시작·배분·미리보기·이동·종료·이어하기를 확인했다. JSON 단일 명령 모드의 저장·불법 입력 무변화·분기 저장·중단된 파일 교체 복구도 검사했다.

미리보기는 실제 난수를 읽지 않고 가능한 무작위 결과를 조건별로 열거한다. 최대 64분기를 넘으면 불완전 표시를 한다. 정상 자동 원정 6판에서는 불완전 미리보기가 없었다. 다음 굴림·미방문 재고는 선택에 사용하지 않았다.

### 배분에는 의미가 있지만 공격 중단 문제는 남는다

선택 정책의 235회 배분 중 200회는 여섯 대안의 평가값이 달랐다. 127회는 기본과 다른 배분을 택했다. 이는 체력 보존·우선 처치·빈 행 배분을 판단할 여지가 있다는 근거다. 사람의 재미나 피로까지 측정한 것은 아니다.

24라운드 전투는 31001의 2막 깊이 13이다. 2·4라운드에 적 둘을 잡았지만 나머지를 처리하지 못했다. 비활동 패널티가 8회 발생했고, 전투사제는 12라운드, 성가대원은 22라운드에 그 패널티로 상실됐다. 독 치료사만 남아 24라운드에 철수했다. **평균 전투 시간보다, 마지막 적을 상대로 공격 진전이 끊기는 꼬리를 우선 살펴볼 필요가 있다.** 토큰 부족이 없어도 도착 기회·공격 동료·인접 연결이 끊기면 사용자가 싫어한 무력한 소모전이 다시 생길 수 있다.

### 후반 병목은 누적 상실과 2막 엘리트다

선택 정책 세 판 모두 2막 깊이 15 엘리트에서 철수했다. 이 적은 공격력 4의 경로 반격을 긴 카드의 세 이동마다 사용한다. 동료 대부분의 최대 체력 3~4에 비해 한 타격의 부담이 크다. 31002는 이 전투에서 동료 4명을 잃었고, 31003은 현재 배분의 모든 예고가 패배여서 첫 행의 1번 방문에서 반격 전에 철수했다.

이후 회복을 거쳤어도 31001·31002의 2막 보스 입장 동료는 각각 2명·4명뿐이었다. 두 판 모두 입장 시 남은 동료의 체력은 최대였지만 인원이 부족했다. 31003도 3막 초반 손실 뒤 연속 철수가 발생했고, 깊이 13에는 전투사제 한 명만 남았다. **전원 회복의 양만 높여서는 해결되지 않는 재편 문제**다. 상실 → 공격/보상 감소 → 추가 상실의 연결을 확인해야 한다.

### 적 체력 산정의 평균 1타 가정은 후반 추가 검증이 필요하다

선택 정책에서 보호 차감 전 실제 피해 사건 평균은 1막 **1.46**(120건), 2막 **1.90**(175건), 3막 **1.93**(30건)이었다. 초기 산정 D=1·2·3과 비교하면 특히 3막의 D=3은 이번 결과에서 재현되지 않았다. 다만 3막은 이미 약해진 한 원정의 표본이며, 일반적인 완성 빌드의 평균이라고 볼 수 없다. 피해 사건은 광역의 적별 타격·반응·복사를 각각 센다. 이 자동 정책 표본에는 적 독 피해가 없었다.

### 가격 산식은 맞지만 실제 구매량과는 구분해야 한다

모든 전투 완승을 가정한 캠페인 정산 검사는 27개 전투 보상·13개 구매·최종 잔액 3을 확인했다. 이 산술 검사는 전투 승리를 가정한 별도 검사다. 실제 선택 정책의 구매는 7·8·9명으로, 철수와 원정 종료 시점에 따라 달랐다. 현재 결과만으로 가격 6이 틀렸다고 판단하기보다 상실·보상 공백·상점 접근 시점을 먼저 비교하는 것이 타당하다.

지도에서는 회복 깊이가 모든 경로에 고정되어 있다. 회복은 보급 간격을 만들지만 이번 구성에서 ‘회복 노드를 갈지 다른 종류를 갈지’라는 경로 선택은 없다. 그 선택의 재미는 이번 지도에서 검증했다고 볼 수 없다.

## 4. 같은 조건의 시작 배치 통제

같은 ABC, 같은 최대 체력의 시작 동료를 두고 첫 굴림 216가지와 각 여섯 배분을 전수 비교했다. 동료 상실 최소 → 적 처치 최대 → 적 체력 감소 최대 → 아군 잔여 체력 최대 순으로 고른 결과다. 총 2,592개 예고이며 정상 원정 승률과 구분한다. [전체 방법·결과](validation/placement-control.md)

성가대원 중앙은 공격을 유발하는 도착을 2·3번에서 1·2·3번으로 늘려 기대 피해가 약 43.2% 증가했다. 대신 성녀와 성기사의 인접을 잃으며 `[1,1,1]`에서는 성녀 사망을 피할 수 없었다. 공격 빈도와 보호를 맞바꾸는 배치 선택이 존재한다. 전체 전투나 원정에서 항상 우월하다는 결론은 아니다.

## 5. 후반 작동 검증과 남은 한계

정상 원정이 도달하지 못한 3막 엘리트·보스는 별도 통제 편성으로 실제 전투 엔진을 실행했다. **전원 강화·최대 체력의 10개 몸체, 성기사+성전사 융합을 포함한 11원본을 삽입한 상태**다. 적 수치와 판정은 변경하지 않았다.

| 통제 대상 | 결과 | 라운드 | 동료 상실 | 잔여 체력 합계 |
|---|---|---:|---:|---:|
| 3막 엘리트 | 완승 | 2 | 2 | 27 |
| 3막 보스 | 완승 | 3 | 3 | 23 |

이는 긴 카드·보호·교대 반격·여러 동료 효과·종료의 작동 사례다. **정상 원정에서 이 편성을 얻거나 유지할 수 있음을 입증하지 않는다.** [통제 결과](validation/controlled-late-summary.json)

이번 자동 정책은 수달 도착 연계를 높게 평가했다. 정상 선택 원정에서 융합은 총 1회에 그쳤고, 강화 경로를 주로 택했다. 그러므로 융합 대 강화, 같은 역할 대 다른 역할 융합, 스컹크 중심 원정의 재미·균형은 아직 판단할 근거가 부족하다. 직접 살포 플레이와 규칙 검사가 전체 빌드 검증을 대신하지 않는다.

후속 조정은 **① 2막 엘리트의 경로 타격과 세 차례 반격이 만드는 총 압박, ② 핵심 동료 상실 후 재편 가능성, ③ 마지막 적의 공격 공백, ④ 정상 원정에서 3막 D=3에 도달하는 성장량** 순으로 비교하는 것이 좋다. 이 보고서에서는 조정을 시행하지 않았다. 완주 실패만으로 현재 규칙의 완주 불가능을 주장하지도 않는다.

## 재현

이 폴더에서 실행한다.

```powershell
node --test
node verify-campaign.mjs
node validation/placement-control.mjs
node verify-manual.mjs
node analyze-results.mjs
```

자동 진행의 `elapsedSeconds`는 계산 실행 시간이며 사람의 플레이 소요 시간이 아니다. 보고서의 수치는 [집계 자료](validation/analysis-metrics.json), 각 원정의 `*.rounds.csv`, `*.decisions.jsonl`, `*.save.json`으로 추적할 수 있다. 진행 저장은 CLI `--save`로 열 수 있다. 그래픽 MVP 5는 이전 17판 그대로이며 이번 구현은 텍스트 버전이다.
