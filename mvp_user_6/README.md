# Dread to Dead · 안개숲 원정

[사용자 설정 6](../mvps/mvp-config-user-6.md)의 로컬 브라우저 게임. [텍스트 MVP 19](../mvp_text_19/engine.mjs)와 같은 `text-19-v1.3` 엔진으로 전투, 지도, 보상, 강화와 융합을 판정한다.

## 실행

Node.js 22 이상에서 Windows의 [play.cmd](play.cmd)를 열면 로컬 서버와 브라우저가 열린다. 터미널에서도 실행할 수 있다.

```powershell
cd mvp_user_6
npm start
```

브라우저에서 [안개숲 원정 열기](http://127.0.0.1:4176). 서버를 종료하려면 터미널에서 Ctrl+C를 누른다. 게임 실행에 추가 패키지 설치는 필요 없다.

## 첫 전투

1. 지도에서 첫 지점을 고르고 **이 지점으로 이동**을 누른다. 지역 정보에서 세 적의 체력과 공격 시점을 볼 수 있다.
2. 전투 준비에서 동료와 목적지를 차례로 선택해 무료로 배치를 바꾸고 전투를 시작한다. 전장은 넓은 화면에서 10열, 세로로 든 휴대폰처럼 폭이 좁은 화면에서는 5열씩 두 구역으로 보인다. 같은 번호의 적과 동료는 위아래로 마주 본다.
3. 매 차례 6면 주사위 세 개가 공개된다. 하나를 고르고 동료 카드를 가리키면 보드에 이동 경로와 도착 칸이 표시된다. 고른 주사위를 동료에게 끌어 놓거나, 주사위와 동료를 차례로 탭해 이동한다. 키보드에서는 Tab으로 이동하고 Enter 또는 스페이스로 선택한다. 카드의 효과 전문은 주사위를 고르기 전에 카드를 눌러 확인한다.
4. 적 셋을 처치하고 살아남으면 보상 동료를 골라 배치하거나 건너뛴다. 막마다 깊이 18의 보스가 기다린다.

상단의 **원정 기록**에서 실제 결과를 다시 읽을 수 있다. **원정 관리**에서 판 번호를 지정해 새로 시작할 수 있다. 기본 시드는 31001이다. 각 행동은 이 폴더의 `saves/current.json`에 자동 저장된다. 같은 주소로 다시 열면 현재 원정에서 이어진다.

## 검사

```powershell
# mvp_user_6 폴더에서
npm test
npm run test:browser
npm --prefix ../mvp_text_19 test
```

브라우저 검사는 Playwright Core와 Chromium 계열 브라우저를 사용하며 별도의 임시 저장으로 진행한다. 환경에 따라 `USER6_PLAYWRIGHT`로 Playwright Core 경로를 지정할 수 있다. 서버 포트는 `PORT`, 게임 저장 경로는 `USER6_SAVE`로 지정한다.
