# Dread-to-Dead — 사용자 프로토타입 1

[설정 문서](../mvps/mvp-config-user-1.md)를 바탕으로 만든 브라우저용 2D 도형 게임입니다. 외부 패키지나 설치 과정 없이 Node.js로 로컬 서버를 실행합니다.

## 실행

Windows에서는 [play.cmd](play.cmd)를 더블 클릭하면 로컬 서버를 시작하고 브라우저를 엽니다. 서버 창을 닫으면 실행이 종료됩니다. Node.js 20 이상이 필요하며 추가 패키지는 설치하지 않습니다.

이 디렉터리에서 터미널을 열고 실행합니다.

```powershell
npm start
```

브라우저에서 [게임 열기](http://127.0.0.1:4173)를 선택합니다. 서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다. 모듈을 사용하는 게임이므로 HTML 파일을 직접 더블 클릭하는 대신 위 로컬 주소를 이용합니다.

## 조작

- 블러드 웹의 카드를 구매하면 보관함에 괴이 카드가 추가됩니다.
- 보관 카드의 배치 버튼을 누르고 층을 선택합니다. 배치 후에는 층의 박스로 표시되며, 호버하거나 정보 버튼을 누르면 효과와 현재 상태를 확인할 수 있습니다.
- 영업을 시작한 뒤 주사위를 굴리고 이동 거리 하나를 선택합니다. 선택 전 경로와 공격 결과를 확인할 수 있습니다.
- 이동 전에는 해당 층에 나타난 직접 사용 버튼으로 공격·보호·수리를 사용합니다. 보호·수리는 대상 층을 고른 뒤 비용을 소비합니다.
- 이동 실행으로 통과·도착 효과와 손님의 공격을 처리합니다. 영업 사이에는 구매·배치·보관·웹 리셋을 할 수 있습니다.
- 옵션에서 첫 등장 설명 팝업과 연출 속도를 바꿀 수 있습니다. 설명을 꺼도 상세 카드와 도움말은 사용할 수 있습니다.

일반 영업 6회에 손님 3명씩, 보스전 2회를 합쳐 총 8구간·최대 20명을 상대합니다. 최종 보스를 처치하면 승리합니다. 배치 괴이 전멸과 최종 보스 탈출은 패배이며, 파괴된 괴이는 복구되지 않습니다.

## 판정 확인

```powershell
npm test
```

Node.js 기본 테스트 도구로 통과·도착 구분, 공포·다단 공격, 보호·수리, 비활동, 탈출·영구 파괴, 구매망, 경계 복구, 승패·재시작·난수 미리보기를 확인합니다. 자동 검사 결과는 실제 플레이의 재미나 난이도 적정성 검증과 별개입니다.

공개된 눈과 정상 구매·사용 규칙만으로 캠페인을 진행하는 확인 스크립트도 포함했습니다.

```powershell
node verify-campaign.mjs 1 1
```

난수 번호 1에서 8구간·손님 20명 전원 처치·최종 보스 승리를 확인했습니다. 검사 과정에서는 미래 눈을 조회하거나 전투 상태를 주입하지 않습니다.

화면·동작 검사는 브라우저 없이 실행하는 검사도 포함합니다. 개발 환경의 브라우저 자동 제어가 Windows의 현재 URL을 확인하지 못해 중단되어, 실제 브라우저의 레이아웃·호버 위치 실측 확인은 완료하지 못했습니다.
